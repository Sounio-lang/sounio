ESTABLISHED BOUNDARY
--------------------

For accepted inputs bounded by 8 reachable states, 18 globally unique actions,
3 nominal outcomes per action, 65,536 constructed policies, 256 retained
working-frontier witnesses per state, and 1 MiB canonical policy/frontier text:

1. The OCaml compiler performs branch-conditioned backward induction over an
   acyclic action/outcome DAG. Each benefit coordinate is immediate value plus
   its minimum continuation value. Each burden coordinate is immediate burden
   plus its maximum continuation burden.
2. Per-state Pareto pruning preserves the complete achievable non-dominated
   robust value frontier. Concrete retained policy-tree witnesses are
   deterministic and replayable. This does not claim enumeration of every
   structurally distinct tree that a parent min/max bottleneck maps to an
   already represented value vector.
3. Every action has one closed nominal partition indexed exactly 0..n-1. This
   establishes exhaustiveness only for in-program result tags. Physical
   observation classification remains external evidence authority.
4. Compile reserves only the selected root resource. Observe releases the
   current resource and reserves the policy-prescribed successor, or completes,
   while holding one exclusive machine.lock across state replay, successor
   validation, verified append, fsync, and post-append replay.
5. The journal is authority. Apache Arrow is a verified-derived projection and
   refuses semantic or hash-chain laundering.
