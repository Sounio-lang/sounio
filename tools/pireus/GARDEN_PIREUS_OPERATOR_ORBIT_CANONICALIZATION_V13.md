## Operator Carrier

Let `V=F2^4`. A normalized twisted-XOR operator is represented by a Boolean
sign table `f:V x V -> F2` with

    e_i * e_j = (-1)^f(i,j) e_(i XOR j)

and unit axes `f(0,j)=f(i,0)=0`. This is the complete phenotype. Its
225-coefficient mixed Boolean ANF over nonempty left and right masks is the
genotype. Every admitted V13 operator must carry exact forward and inverse ANF
checks and a 256-entry destination-major microprogram with the ascending input
reduction spine inherited from V12.

## Declared Equivalence

Identify `V` with integers `0..15`, with coordinate
`v_r=(v >> r) & 1` for `r=0..3`. A row-packed matrix code stores entry
`M_(r,c)` at bit `4*r+c` and acts by

    (M v)_r = parity(row_r(M) AND v).

The sign-table cell for `(i,j)` is `16*i+j`. Canonical cell order is ascending
in that integer, so it visits `i` first and then `j`. For a nonzero vector,
the highest basis bit is `1 << max{r | v_r=1}`.

For an invertible matrix `M` and `s in C2`, define

    action(M,0,f)(i,j) = f(M i, M j)
    action(M,1,f)(i,j) = f(M j, M i).

The matrix fixes zero and preserves XOR. Operand swap compares an operator with
its opposite multiplication; it is an explicit equivalence choice, not a
claim that the two algebras are identical.

A basis-sign gauge is `q:V -> F2`, `q(0)=0`, acting by the coboundary

    d q(i,j) = q(i) XOR q(j) XOR q(i XOR j)
    gauge(q,f) = f XOR d q.

The kernel of `d` is exactly the four-dimensional space of linear forms
`q:V->F2`. Fixing `q` to zero on the four basis vectors therefore cuts every
coboundary coset exactly once and leaves eleven effective gauge coordinates,
one for each nonzero nonbasis vector. All declared actions preserve unit axes
and send coboundaries to coboundaries. Consequently the full transformation
group is the semidirect product of the 2048-element coboundary image by the
declared pullback action group, not a direct product in which gauges are
independent of matrix pullback.

These formulas use the V5 pullback convention. Consequently their exact
composition law is

    action(M,s, action(N,t,f)) = action(N M, s XOR t, f).

The matrix codes therefore realize `GL(4,F2)^op x C2`, which is canonically
isomorphic to `GL(4,F2) x C2` through matrix inversion. This reversal must be
preserved in witness composition; it does not change the enumerated set of
40,320 transformations or its canonical minimum.

V13 equivalence is exactly

    g ~ f
      iff exists M in GL(4,F2), s in C2, q,
          g = action(M,s,f) XOR d q.

It is linear/swap/gauge equivalence of the declared twisted-XOR basis tables.
It is not nonlinear permutation equivalence, isotopy, or unrestricted algebra
isomorphism.

## Exact Gauge Section

For every nonbasis vector `v`, let `h(v)` be its highest set basis bit and let
`p(v)=v XOR h(v)`. In ascending `v`, choose the unique section gauge with
`q(0)=q(e_r)=0` and

    q(v) = f(p(v),h(v)) XOR q(p(v)).

Then `N(f)=f XOR d q` is zero on all eleven tree cells
`(p(v),h(v))`. The recurrence is triangular because `p(v)<v`. It therefore
defines one exact representative of every basis-sign gauge coset. The Sounio
executable must independently replay the eleven pivots, all 2048 canonical
gauge words, and all 256 cells per round trip before using the section.

## Canonical Form

Order 256-cell Boolean tables lexicographically by ascending cell index, with
`0 < 1`. Do not use integer word order or a digest as the ordering relation.

Define

    Canon(f) = min_(M in GL(4,F2), s in C2) N(action(M,s,f)).

Ties are resolved by the smallest packed action code `2*M+s`; the section
gauge is already unique. The canonicalization record carries the winning
matrix, swap bit, gauge word, and the full 256-cell canonical table.

For the declared finite domains:

    Canon(f) = Canon(g)  iff  f ~ g.

The forward direction follows by replaying both winning actions and gauges.
For the reverse direction, precomposition permutes the complete action set and
matrix pullback preserves the coboundary image, so both minima range over the
same normalized orbit.

The executable must not materialize a `40320 x 256` table atlas per operator.
It uses a streaming canonicalizer:

1. scan all 65,536 row-packed matrix codes;
2. retain exactly those whose action on all 16 vectors is bijective;
3. visit both swap bits for every retained matrix;
4. derive the eleven gauge pivots for that transformed view;
5. compare normalized cells with the current minimum in ascending order and
   stop that comparison at its first difference;
6. materialize all 256 cells only for the initial or a strictly smaller view;
7. replay the winning view over all 256 cells at the end.

Early comparison termination is a cost optimization only. Exhaustive action
visitation, exact ordering, and the winning replay remain mandatory. No hash
collision assumption enters equivalence.
