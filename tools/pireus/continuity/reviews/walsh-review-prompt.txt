## Generated operator

Pireus generated the exact identity

```text
r[d] = (1/16) * sum_k W[d,k]
       * sum_i character(k,i) * a[i] * b[i xor d].
```

The executable reconstructs every original Cayley-Dickson sign and checks the
unnormalized Parseval identity independently for each row. This makes
`WalshCharacterChannels` an executable operator candidate rather than a prose
analogy or a target-specific recipe.

## Discovered structure

The dimension-16 coefficient matrix has 256 nonzero entries: every displacement
uses every character channel. Rows 0 through 8 have one coefficient `-14` and
fifteen coefficients `2`; later rows use coefficients from `{-6,2,10}`. The
weighted coefficient checksum is 21232.

Full support refuses promotion based on spectral sparsity at this dimension.
It does not prove that the family remains dense asymptotically, nor that a
different block, recursive, or matrix-valued transform cannot be sub-quadratic.
Hardware cost and material promotion remain open.

# Pireus Walsh twist channels

Status: Garden

## Seed

The diagonal sign-gauge route to a single pure XOR convolution is refuted. A
richer exact representation may still exist by expanding each displacement
row of the Cayley-Dickson twist in the Walsh character basis.

For `S_d(i) = sigma(i, i xor d)`, define the unnormalized coefficients

```text
W[d,k] = sum_i S_d(i) * (-1)^popcount(k and i).
```

Then

```text
S_d(i) = (1/n) * sum_k W[d,k] * (-1)^popcount(k and i),
```

so the twisted product can be represented as a weighted family of ordinary XOR
correlations with character-modulated inputs. Pireus should discover the
number and shape of required channels from the Sounio sign law rather than from
a hand-written backend recipe.

## Differentiating result

- Sparse support may yield a useful exact transform candidate.
- Dense support still yields an exact generated candidate, but blocks promotion
  based on sparsity alone.
- The dimension-16 observation cannot establish asymptotic complexity.
- Candidate generation is not candidate selection or hardware parity.

## Falsifier

The representation is invalid if inverse Walsh reconstruction differs from
the original Cayley-Dickson sign on any displacement/index pair, or if Parseval
energy differs from `n*n` for any row.

// Sounio semantic authority for a generated Walsh-channel representation of
// the Cayley-Dickson sign-twisted XOR convolution.

fn cd_sign(a: i64, b: i64, bits: i64) -> i64 {
    if a == 0 || b == 0 { return 1 }
    if bits <= 1 { return 0 - 1 }
    let half = 1 << (bits - 1)
    let a_hi = if a >= half { 1 } else { 0 }
    let b_hi = if b >= half { 1 } else { 0 }
    let a_lo = a & (half - 1)
    let b_lo = b & (half - 1)
    if a_hi == 0 && b_hi == 0 { return cd_sign(a_lo, b_lo, bits - 1) }
    if a_hi == 0 && b_hi == 1 { return cd_sign(b_lo, a_lo, bits - 1) }
    if a_hi == 1 && b_hi == 0 {
        if b_lo == 0 { return cd_sign(a_lo, 0, bits - 1) }
        return 0 - cd_sign(a_lo, b_lo, bits - 1)
    }
    if b_lo == 0 { return 0 - cd_sign(0, a_lo, bits - 1) }
    cd_sign(b_lo, a_lo, bits - 1)
}

fn bit_parity(value: i64, bits: i64) -> i64 {
    var parity: i64 = 0
    var bit: i64 = 0
    while bit < bits {
        parity = parity ^ ((value >> bit) & 1)
        bit = bit + 1
    }
    parity
}

fn character(k: i64, i: i64, bits: i64) -> i64 {
    if bit_parity(k & i, bits) == 0 { 1 } else { 0 - 1 }
}

fn walsh_coefficient(d: i64, k: i64, bits: i64) -> i64 {
    let dimension = 1 << bits
    var coefficient: i64 = 0
    var i: i64 = 0
    while i < dimension {
        coefficient = coefficient + cd_sign(i, i ^ d, bits) * character(k, i, bits)
        i = i + 1
    }
    coefficient
}

fn popcount(value: i64, bits: i64) -> i64 {
    var count: i64 = 0
    var bit: i64 = 0
    while bit < bits {
        count = count + ((value >> bit) & 1)
        bit = bit + 1
    }
    count
}

fn main() -> i32 with IO {
    let bits: i64 = 4
    let dimension: i64 = 16
    var coefficients: [i64; 256] = [0; 256]
    var union_mask: i64 = 0
    var total_support: i64 = 0
    var coefficient_checksum: i64 = 0
    var parseval_failures: i64 = 0
    var reconstruction_failures: i64 = 0

    print("schema=pireus-walsh-twist-channel-spectrum-v1\n")
    print("producer_language=Sounio\n")
    print("producer_role=SEMANTIC_AUTHORITY\n")
    print("operator=XorConvolution bits=4 twist=CayleyDicksonSign\n")
    print("candidate=WalshCharacterChannels equivalence=EXACT status=GENERATED\n")
    var d: i64 = 0
    while d < dimension {
        var support: i64 = 0
        var support_mask: i64 = 0
        var energy: i64 = 0
        var k: i64 = 0
        print("d="); print_int(d)
        while k < dimension {
            let coefficient = walsh_coefficient(d, k, bits)
            coefficients[(d * dimension + k) as usize] = coefficient
            print(" w"); print_int(k); print("="); print_int(coefficient)
            coefficient_checksum = coefficient_checksum
                + (d + 1) * (k + 1) * coefficient
            energy = energy + coefficient * coefficient
            if coefficient != 0 {
                support = support + 1
                support_mask = support_mask | (1 << k)
                union_mask = union_mask | (1 << k)
            }
            k = k + 1
        }
        if energy != dimension * dimension {
            parseval_failures = parseval_failures + 1
        }
        total_support = total_support + support
        print(" support="); print_int(support)
        print(" support_mask="); print_int(support_mask)
        print(" energy="); print_int(energy); print("\n")
        d = d + 1
    }

    d = 0
    while d < dimension {
        var i: i64 = 0
        while i < dimension {
            var reconstructed: i64 = 0
            var k: i64 = 0
            while k < dimension {
                reconstructed = reconstructed
                    + coefficients[(d * dimension + k) as usize] * character(k, i, bits)
                k = k + 1
            }
            let expected = dimension * cd_sign(i, i ^ d, bits)
            if reconstructed != expected {
                reconstruction_failures = reconstruction_failures + 1
            }
            i = i + 1
        }
        d = d + 1
    }

    let union_channels = popcount(union_mask, dimension)
    print("total_coefficients=256\n")
    print("total_nonzero_coefficients="); print_int(total_support); print("\n")
    print("union_channel_mask="); print_int(union_mask); print("\n")
    print("union_channels="); print_int(union_channels); print("\n")
    if total_support == dimension * dimension {
        print("observed_sparsity=FULL\n")
        print("sparsity_promotion=REFUSED_AT_DIMENSION_16\n")
    } else {
        print("observed_sparsity=PARTIAL\n")
        print("sparsity_promotion=CANDIDATE_AT_DIMENSION_16\n")
    }
    print("coefficient_checksum="); print_int(coefficient_checksum); print("\n")
    print("parseval_failures="); print_int(parseval_failures); print("\n")
    print("reconstruction_failures="); print_int(reconstruction_failures); print("\n")
    print("material_promotion=PENDING_COST_AND_HARDWARE\n")
    print("claim_boundary=dimension-16-spectrum-not-asymptotic-complexity\n")
    if parseval_failures == 0 && reconstruction_failures == 0 {
        print("PIREUS_WALSH_TWIST_CHANNEL_SPECTRUM_PASS\n")
        return 0
    }
    print("PIREUS_WALSH_TWIST_CHANNEL_SPECTRUM_FAIL\n")
    1
}
