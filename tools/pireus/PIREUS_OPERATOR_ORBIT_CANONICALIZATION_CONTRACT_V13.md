## Canonical Domain

The carrier is the set of 256-bit normalized twisted-XOR sign tables on
`F2^4`, with zero phase on both unit axes. Vector bit `r` is `(v>>r)&1`;
row-packed matrix entry `(r,c)` is code bit `4*r+c`; matrix-vector action is
row parity; and table cell `(i,j)` is `16*i+j`. The declared equivalence is
generated by every invertible row-packed matrix, optional operand swap, and
every basis-sign coboundary. Coboundaries form a normal subgroup under matrix
pullback, so the combined transformation group is semidirect.

With the inherited pullback convention, action composition reverses the
matrix-code order:

    action(M,s, action(N,t,f)) = action(N M, s XOR t, f).

Witness composition must use this law. The represented action group is
`GL(4,F2)^op x C2`, canonically isomorphic to `GL(4,F2) x C2`.

The matrix scan covers all 65,536 encodings and must recover exactly 20,160
invertible matrices. Visiting both swap bits gives exactly 40,320 action views
per canonicalization. The effective gauge section has eleven coordinates and
2048 words because the coboundary kernel is exactly the four-dimensional space
of linear forms.

## Gauge Normalization

For each nonbasis `v`, in ascending order, the section sets basis gauges to
zero and solves

    q(v) = f(v XOR h(v), h(v)) XOR q(v XOR h(v)),

where `h(v)` is the highest set basis bit. Normalization is `N(f)=f XOR d q`.
All eleven tree cells must become zero. The executable verifies triangular
pivots and all 2048 section-word round trips over all 256 cells.

## Canonicalization

Canonical order is cellwise lexicographic order over cells 0 through 255 with
`0 < 1`. Numeric ordering of packed words and digest ordering are forbidden.

For every input table, the executable scans the full declared action set and
computes

    Canon(f) = min N(action(M,s,f)).

It may stop comparison of one action view at the first differing cell, but it
must still visit every action. It materializes a new table only when a view is
strictly smaller. The final record contains the minimum, winning packed action,
unique section gauge, exact action count, comparison count, replacement count,
and 256-cell replay.

Two evaluated tables are equivalent exactly when their 256 canonical bits are
equal. Digest equality is never used as the equivalence predicate.
