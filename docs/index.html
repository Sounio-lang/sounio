Why Sounio?

Modern scientific computing demands more than correct arithmetic—it demands epistemic integrity. Most languages treat uncertainty as an afterthought. Sounio makes it foundational.

Uncertainty is First-Class

Every value can carry its uncertainty. The Knowledge<T> type wraps values with uncertainty, confidence, and provenance metadata.

Automatic Propagation

GUM-compliant uncertainty propagation through all mathematical operations. You write the physics, the compiler handles the statistics.

Provenance Tracking

Data without origin is data without trust. Every measurement traces back to its source—essential for reproducibility and regulatory compliance.

Confidence Gates

When confidence drops below a threshold, execution can pause, warn, or take alternative paths. The system knows what it doesn't know.

Domain-Specific Power

Built-in DSLs for PK/PD modeling (MedLang), neuroimaging (fMRI), causal inference, and GPU-accelerated computing.

Standards Compliant

Designed for GUM, ISO 17025, 21 CFR Part 11, and FAIR principles. Compliance is not optional—it's architectural.

Hello, Uncertainty

// Every measurement knows its uncertainty
let dose: Knowledge<mg> = measure(500.0, uncertainty: 2.5, source: "clinical_trial")
let volume: Knowledge<L> = measure(5.0, uncertainty: 0.1, source: "calibrated_flask")

// Uncertainty propagates automatically (GUM-compliant)
let concentration = dose / volume  // Knowledge<mg/L> with computed uncertainty

// Confidence gates control execution
if concentration.confidence > 0.95 {
    administer(concentration)
} else {
    require_confirmation(concentration)
}
// Explicit effects in function signatures
fn read_config() -> string with IO {
    // Compiler tracks side effects
    read_file("/etc/config")
}

fn process_data(data: &[f32]) -> f32 with Alloc {
    // Memory allocation is tracked
    var buffer = allocate(data.len())
    compute_fft(data, &!buffer)
}
// GPU kernels as native language constructs
kernel fn matrix_multiply(
    a: &[f32], b: &[f32], c: &![f32],
    n: i32
) {
    let i = gpu.thread_id.x
    let j = gpu.thread_id.y

    var sum: f32 = 0.0
    for k in 0..n {
        sum += a[i * n + k] * b[k * n + j]
    }
    c[i * n + j] = sum
}
// Type-safe dimensional analysis
let dose: mg = 500.0
let weight: kg = 70.0
let concentration: mg/kg = dose / weight

// Compiler prevents unit mismatches
let bad = concentration + 5.0  // Type error: unitless + mg/kg

// Automatic unit conversion
let time: h = 2.5
let time_s: s = time  // Converts to 9000.0 s

Installation Guide

1. Download

Download the latest Sounio compiler for your platform:

Linux:   https://github.com/sounio-lang/sounio/releases
macOS:   https://github.com/sounio-lang/sounio/releases
Windows: https://github.com/sounio-lang/sounio/releases

2. Install

Run the automated installer:

curl -sSf https://souniolang.org/install.sh | sh

Or manually: extract the archive and add souc to your PATH.

3. Verify

Verify installation:

souc --version

Should output: souc 0.98.0

The Name

Cape Sounion (Σούνιο) stands at the southernmost tip of Attica, where the ancient Temple of Poseidon has watched over the Aegean for 2,500 years. At sunset, its Doric columns catch the last light—the horizon where certainty meets the unknown sea.

Sounio the language embodies this metaphor: computing at the boundary between what we know and what we don't.
