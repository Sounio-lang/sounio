# Εγκατάσταση και πρώτη εκτέλεση

Στόχος είναι να δείτε **το δικό σας σύστημα** να ελέγχει και να εκτελεί
ένα μικρό πρόγραμμα. Οι εντολές είναι οδηγίες αναπαραγωγής, όχι ισχυρισμός
ότι έχουν ήδη εκτελεστεί στον υπολογιστή σας.

## 1. Κατεβάστε το αποθετήριο

Χρειάζεστε Git, κέλυφος Bash και τα συνήθη εργαλεία Unix. Για την ανάγνωση
δεν χρειάζεται να κατασκευάσετε τον μεταγλωττιστή από την αρχή.

Χρησιμοποιήστε αρχεία και τερματικό με υποστήριξη UTF-8 ώστε τα ελληνικά
μηνύματα να εμφανίζονται σωστά. Η εμφάνισή τους δεν αλλάζει το συμβόλαιο
του προγράμματος ή τα αρχικά διαγνωστικά του μεταγλωττιστή.

```sh
git clone https://github.com/Sounio-lang/sounio.git
cd sounio
git rev-parse HEAD
uname -sm
```

Κρατήστε την αναθεώρηση που εμφανίστηκε. Μην χρησιμοποιείτε το «τρέχουσα
έκδοση» ως υποκατάστατο του ακριβούς κώδικα που δοκιμάζετε.

| Αποτέλεσμα πλατφόρμας | Διαδρομή |
|---|---|
| `Linux x86_64` | Το αποθηκευμένο προμεταγλωττισμένο Madaros, μέσω `./bin/souc`. |
| `Darwin arm64` | Ξεχωριστό εγγενές Madaros· διαβάστε την ενότητα macOS παρακάτω. |
| Άλλο αποτέλεσμα | Απαιτείται συμβατή και τεκμηριωμένη διαδρομή· μην εκτελείτε το Linux ELF. |

Το `bin/souc` είναι εκκινητής. Το αποτύπωμά του δεν ταυτοποιεί τα bytes
του πραγματικού μεταγλωττιστή που θα εκτελέσει.

## 2. Πρώτη επιτυχία σε Linux x86-64

Από τη ρίζα του αποθετηρίου, εκτελέστε το παρακάτω ως ξεχωριστό σενάριο
Bash. Σταματά αν λείπει προϋπόθεση, αν έχει επιλεγεί διαφορετικό προφίλ,
αν δεν ταιριάζει το αποτύπωμα ή αν αποτύχει το πρόγραμμα. Δεν εγκαθιστά
πακέτα και δεν αλλάζει σιωπηρά μηχανή μεταγλώττισης.

```sh
bash <<'SH'
set -euo pipefail
fail() { printf 'ΔΙΑΚΟΠΗ: %s\n' "$*" >&2; exit 1; }
test "$(uname -sm)" = 'Linux x86_64' || fail 'Χρειάζεται η τεκμηριωμένη διαδρομή της δικής σας πλατφόρμας.'
test "${SOUNIO_SOUC_ENGINE:-madaros}" = madaros || fail 'Έχει επιλεγεί άλλη μηχανή· μην αναμειγνύετε προφίλ.'
command -v file >/dev/null || fail 'Λείπει το εργαλείο file.'
command -v sha256sum >/dev/null || fail 'Λείπει το εργαλείο sha256sum.'
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
expected="$(awk 'NR == 1 { print $1 }' bin/madaros-linux-x86_64.sha256)"
test -n "$expected" || fail 'Δεν βρέθηκε το αποθηκευμένο αποτύπωμα.'
info="$(./bin/souc info)" || fail 'Απέτυχε η επίλυση του μεταγλωττιστή.'
printf '%s\n' "$info"
raw="$(printf '%s\n' "$info" | sed -n 's/^raw_elf:[[:space:]]*//p')"
test -n "$raw" && test -f "$raw" || fail 'Δεν ταυτοποιήθηκε το πραγματικό εκτελέσιμο.'
file "$raw" || fail 'Δεν ήταν δυνατή η επιθεώρηση του εκτελέσιμου.'
digest="$(sha256sum "$raw")" || fail 'Δεν ήταν δυνατή η ανάγνωση του αποτυπώματος.'
actual="${digest%% *}"
test "$actual" = "$expected" || fail 'Διαφορετικά bytes μεταγλωττιστή· απαιτείται ξεχωριστό τεκμήριο προφίλ.'
printf 'SHA-256: %s\n' "$actual"
./bin/souc --version || fail 'Απέτυχε η εκτέλεση του μεταγλωττιστή.'
./bin/souc check examples/hello.sio || fail 'Απέτυχε ο έλεγχος του προγράμματος.'
if output="$(./bin/souc run examples/hello.sio)"; then
    :
else
    printf '%s\n' "$output"
    fail 'Απέτυχε η εκτέλεση του προγράμματος.'
fi
printf '%s\n' "$output"
printf '%s\n' "$output" | grep -F 'Hello, Sounio' >/dev/null || fail 'Δεν παρατηρήθηκε η απαιτούμενη έξοδος.'
printf 'Παρατηρήθηκε επιτυχής εκτέλεση και το απαιτούμενο μήνυμα.\n'
SH
```

Το αναμενόμενο μήνυμα είναι `Hello, Sounio` και η αναμενόμενη κατάσταση
τερματισμού είναι μηδέν. Οι έξοδοι του μεταγλωττιστή μπορεί να περιλαμβάνουν
πρόσθετες πληροφορίες. Αποθηκεύστε την πραγματική έξοδο· μην αντιγράφετε το
αναμενόμενο μήνυμα σε μια αναφορά ως δήθεν παρατήρηση.

Το σενάριο ταυτοποιεί το αποθηκευμένο προμεταγλωττισμένο προφίλ της δικής
σας αναθεώρησης. Για να χρησιμοποιήσετε ένα ιστορικό τεκμήριο του οδηγού,
πρέπει να ταιριάζουν και η συγκεκριμένη αναθεώρηση, οι εξαρτήσεις και το
αποτύπωμα που δηλώνει εκείνο το τεκμήριο. Το SHA-256 δεν αποδεικνύει μόνο του
ότι το εκτελέσιμο κατασκευάστηκε από τον σημερινό πηγαίο κώδικα.

## 3. Έλεγχος, μεταγλώττιση και εκτέλεση δεν είναι το ίδιο

Αφού ολοκληρωθεί η ταυτοποίηση του συμβατού προφίλ:

```sh
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
./bin/souc check examples/hello.sio
./bin/souc compile examples/hello.sio -o /tmp/sounio-hello.elf
./bin/souc run examples/hello.sio
```

- Το `check` τεκμηριώνει μόνο το στάδιο που πράγματι εκτελεί η επιλεγμένη διαδρομή.
- Το `compile` πρέπει να παράγει το αναμενόμενο αρχείο· η ύπαρξή του δεν αποδεικνύει ορθή εκτέλεση.
- Το `run` χρειάζεται έλεγχο της πραγματικής κατάστασης και της απαιτούμενης συμπεριφοράς.

Δεν απαιτείται εγκατάσταση Rust ή `cargo build` για αυτή τη διαδρομή.
Μην προσθέτετε μη τεκμηριωμένες επιλογές όπως `--show-types` προσδοκώντας
ότι κάθε προσαρμογέας τις υποστηρίζει.

## 4. macOS με Apple Silicon

Η εγγενής υποστήριξη ARM64 και η ειδική διαδρομή Metal είναι διαφορετικές
από το αποθηκευμένο Linux ELF. Η προετοιμασία χρειάζεται κατάλληλο υπογεγραμμένο
εγγενές εκτελέσιμο εκκίνησης, εργαλεία Apple/C++23, `timeout`, τις απαιτούμενες
κεφαλίδες Boost και, για την πλήρη σχετική δοκιμή, πραγματική συσκευή Metal.
Ένα όνομα αρχείου ή η υποστήριξη ARM64 άλλου λειτουργικού δεν αρκεί.

```sh
bash scripts/ci/build_madaros_macos_arm64.sh /absolute/path/to/current-source-seed
```

Το όρισμα είναι πραγματική προϋπόθεση, όχι αρχείο που παρέχεται από αυτόν
τον οδηγό. Η κατασκευή και οι έλεγχοι πρέπει να γίνουν στο επιτρεπόμενο
περιβάλλον της εργασίας σας. Διαβάστε την
[αναλυτική διαδικασία macOS ARM64](../compiler/MADAROS_MACOS_ARM64.md)
και τα [όριά της](../compiler/MADAROS_MACOS_CORPUS.md) — πηγές στα αγγλικά.
Η επιτυχία ενός συγκεκριμένου συνόλου δοκιμών Metal δεν σημαίνει πλήρη
υποστήριξη κάθε πυρήνα, τύπου ή λειτουργίας GPU.

Μετά την προετοιμασία, χρησιμοποιήστε το ίδιο `./bin/souc` και τη διαδικασία
ταυτοποίησης του εγγενούς προφίλ που περιγράφεται στον οδηγό. Μην συγκρίνετε
το αποτύπωμά του με το Linux εκτελέσιμο και μην παρακάμπτετε σφάλματα
υπογραφής αλλάζοντας σιωπηρά μηχανή.

## 5. Αν κάτι αποτύχει

| Σύμπτωμα | Τι κρατάτε και τι ελέγχετε |
|---|---|
| Ασύμβατη μορφή εκτελέσιμου | Host, αρχιτεκτονική, πραγματικό αρχείο και αποτύπωμα. Δεν είναι σφάλμα σύνταξης του προγράμματος. |
| Διαφορετικό αποτύπωμα | Ρητά overrides, επιλεγμένη αναθεώρηση και τεκμήριο του διαφορετικού προφίλ. |
| Άγνωστο όνομα ή import | Πλήρες διαγνωστικό, πραγματικό export, εξαρτήσεις και `SOUNIO_STDLIB_PATH`. |
| Σφάλμα μετά από επιτυχή έλεγχο | Ξεχωριστά logs ελέγχου, παραγωγής και εκτέλεσης. |
| Μη μηδενικός τερματισμός | Το συμβόλαιο του συγκεκριμένου προγράμματος: άλλες εφαρμογές μπορεί σκόπιμα να επιστρέφουν μη μηδενική τιμή. |
| Απουσία μηνύματος | Η επιτυχής εκκίνηση του εργαλείου δεν αποδεικνύει την απαιτούμενη συμπεριφορά. |

Μην στέλνετε κλειδιά, ιδιωτικά δεδομένα ή ολόκληρα περιβάλλοντα μεταβλητών
σε μια αναφορά σφάλματος. Δώστε μικρό αναπαραγώγιμο παράδειγμα και μόνο
τα στοιχεία ταυτότητας που χρειάζονται.
