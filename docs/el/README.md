# Η Sounio στα ελληνικά

Μια πλήρης **διαδρομή γνωριμίας και χρήσης** για ερευνητές, προγραμματιστές
και συνεργάτες: τι είναι η γλώσσα, πώς ξεκινάτε, ποιες εφαρμογές μπορείτε να
μελετήσετε και πού μπορείτε να βοηθήσετε. Η πρώτη δημόσια παρουσίαση στην
Ελλάδα αποτελεί την αφορμή αυτής της έκδοσης.

## Επιλέξτε διαδρομή

1. [Πρώτη εγκατάσταση και εκτέλεση](getting-started.md): ταυτότητα εργαλείου,
   συμβατή πλατφόρμα, έλεγχος, μεταγλώττιση και εκτέλεση.
2. [Χημεία και υδρογόνο](applications-chemistry.md): κινητική, καταλυτικές
   επιφάνειες, θερμοχημεία και διαχείριση της αβεβαιότητας.
3. [Τεχνητή νοημοσύνη](applications-ai.md): αυτόματη διαφόριση, τανυστές,
   μοντέλα μάθησης και διαχωρισμός εκπαίδευσης από τεκμηρίωση ορθότητας.
4. [Ανάπτυξη προγραμμάτων](developing.md): σύνταξη, δεδομένα, επιδράσεις,
   βιβλιοθήκες, διαγνωστικά και παραδείγματα.
5. [Οδηγός για μοντέλα γλώσσας](../guide/LLM_PROGRAMMING_GUIDE_EL.md): πλήρη
   παραδείγματα και τριάντα ελληνικά σενάρια εργασίας.
6. [Συνεισφορά και συνεργασία](contributing.md): συγκεκριμένες ανάγκες,
   διαδικασία αλλαγών και πώς προτείνετε ένα αναπαραγώγιμο ερευνητικό πρόβλημα.
7. [Προδιαγραφή και κατάσταση](language-reference.md): τι είναι απαίτηση,
   τι παρατηρήθηκε στην υλοποίηση και τι παραμένει ανοιχτό.

## Πώς διαβάζουμε τις υποσχέσεις

**Σχεδιασμός**, **υλοποίηση στον πηγαίο κώδικα**, **επιτυχής έλεγχος**,
**εκτέλεση συγκεκριμένου προγράμματος**, **ανεξάρτητη αριθμητική επαλήθευση**
και **εμπειρική επικύρωση** είναι διαφορετικά πράγματα. Οι οδηγοί δηλώνουν
ποιο επίπεδο τεκμηρίωσης διαθέτουν. Ένα υπάρχον τεκμήριο δεν επικυρώνει
αυτόματα μια αλλαγή σας, άλλον μεταγλωττιστή ή άλλη πλατφόρμα.

Η ελληνική διαδρομή δεν αλλάζει τα ονόματα των API, τις εντολές, τις λέξεις
κλειδιά ή τα τεκμήρια. Τα παραδείγματα κώδικα παραμένουν ίδια ώστε να είναι
δυνατή η σύγκριση με το αρχικό αρχείο. Οι αναλυτικές πηγές στα αγγλικά
σημειώνονται ως τέτοιες. Η πλήρης πολυκεφαλαιακή προδιαγραφή και κάθε
παλαιότερο έγγραφο του αποθετηρίου **δεν έχουν μεταφραστεί στο σύνολό τους**.
Για το ακριβές πεδίο της ελληνικής έκδοσης δείτε την
[αναφορά προετοιμασίας](review-receipt.md).

Δεν χρειάζεστε πρόσβαση στο ιδιωτικό υπολογιστικό σύμπλεγμα του έργου για
να διαβάσετε τον κώδικα ή να εκτελέσετε ένα μικρό πρόγραμμα σε συμβατό,
επιτρεπόμενο περιβάλλον. Αν εργάζεστε στην κοινόχρηστη υποδομή του έργου,
ισχύουν οι οδηγίες συντονισμού και απομακρυσμένων ελέγχων.
