# Τεχνητή νοημοσύνη και επιστημονική μάθηση

Η Sounio προσεγγίζει την τεχνητή νοημοσύνη από τη σκοπιά της επιστημονικής
σημασίας: τι είναι δεδομένο, τι είναι εκτίμηση, από πού προέρχεται η
αβεβαιότητα και τι απαιτεί ο έλεγχος μιας πρόβλεψης. Υπάρχουν σχετικές
υλοποιήσεις στο αποθετήριο, αλλά αυτό δεν αποτελεί υπόσχεση πλήρους
αντικατάστασης ενός ώριμου πλαισίου εκπαίδευσης.

## Δύο διαφορετικές χρήσεις

1. **Να αναπτύξετε μοντέλα και αριθμητικά εργαλεία στη Sounio.** Χρειάζεστε
   πραγματικές βιβλιοθήκες, συμβατή διαδρομή εκτέλεσης και ελέγχους αποτελέσματος.
2. **Να χρησιμοποιήσετε ένα LLM για να γράψετε Sounio.** Χρειάζεστε μικρό,
   ακριβές πλαίσιο, πλήρη παραδείγματα και ειλικρινή διαδικασία επαλήθευσης.

Ένας βοηθός που παράγει κώδικα δεν είναι το ίδιο με ένα μοντέλο που
εκπαιδεύτηκε ή εκτελέστηκε μέσα στη γλώσσα.

## Πού θα βρείτε πηγαίο κώδικα

| Πεδίο | Σημείο εκκίνησης | Ερώτημα επαλήθευσης |
|---|---|---|
| Αυτόματη διαφόριση | [`stdlib/autodiff/`](../../stdlib/autodiff/) και [`dual_demo.sio`](../../examples/autodiff/dual_demo.sio) | Εκτελείται η ζητούμενη παράγωγος στον επιλεγμένο μεταγλωττιστή και παραμένει σωστή η εξάρτηση από τις εισόδους; |
| Νευρωνικά συστατικά | [`stdlib/ml/`](../../stdlib/ml/) και [`neural.sio`](../../stdlib/ml/neural.sio) | Ποιοι τύποι, συναρτήσεις και καταναλωτές είναι πραγματικά διαθέσιμοι; |
| Τανυστές | [`stdlib/tensor/`](../../stdlib/tensor/) | Ποιες μορφές, διαστάσεις, λειτουργίες και διαδρομές μνήμης έχουν τεκμηριωμένη κάλυψη; |
| Γραμμική άλγεβρα και βελτιστοποίηση | [`stdlib/linalg/`](../../stdlib/linalg/) και [βιβλιοθήκη](../../stdlib/) | Ποια αριθμητική ακρίβεια και ποιες προϋποθέσεις απαιτεί η συγκεκριμένη λειτουργία; |
| Παραδείγματα μάθησης | [`examples/ml/`](../../examples/ml/) και [`qnn_mnist_train.sio`](../../examples/qnn_mnist_train.sio) | Υπάρχουν τα απαιτούμενα δεδομένα και πραγματικό τεκμήριο εκπαίδευσης για αυτό το ακριβές πρόγραμμα; |
| Παραγωγή κώδικα από LLM | [Ελληνικός οδηγός](../guide/LLM_PROGRAMMING_GUIDE_EL.md) | Ο νέος κώδικας ελέγχθηκε και εκτελέστηκε ή απλώς μοιάζει σωστός; |

Ο πίνακας είναι κατάλογος για διερεύνηση, όχι νέα εκτέλεση των παραδειγμάτων.
Τα συνδεδεμένα αρχεία κώδικα διατηρούν τα αρχικά API και σχόλιά τους· δεν
παρουσιάζονται ως μεταφρασμένες ή πρόσφατα εκτελεσμένες πηγές.
Ένα αρχείο που τυπώνει «Expected» περιγράφει πρόθεση· δεν είναι αυτόματα
έλεγχος της υπολογισμένης τιμής. Μια αναφορά σε MNIST δεν σημαίνει ότι
το σύνολο δεδομένων ή ένα εκπαιδευμένο μοντέλο περιλαμβάνεται στην εγκατάσταση.

## Μια πρακτική πρώτη εργασία

Ξεκινήστε από μια υπάρχουσα μικρή λειτουργία και τον πλήρη καταναλωτή της,
όχι από την εκπαίδευση ενός μεγάλου δικτύου. Καταγράψτε:

- μορφή και τύπο εισόδων, πηγή δεδομένων και επιτρεπόμενη χρήση τους,
- αναμενόμενη έξοδο και περίπτωση αποτυχίας,
- επιδράσεις, μεταβολές μνήμης και εξαρτήσεις βιβλιοθήκης,
- ακρίβεια, αβεβαιότητα και τυχόν κανάλι προέλευσης,
- ξεχωριστό θετικό και αρνητικό έλεγχο που διακρίνει το ζητούμενο.

Για αυτόματη διαφόριση, αλλάξτε μία λειτουργία κάθε φορά. Η εμφάνιση ενός
πεδίου παραγώγου δεν αποδεικνύει ότι όλη η αλυσίδα διαφόρισης εκτελέστηκε
σωστά. Για νέα ποσοτική αξίωση χρειάζεται κατάλληλη ανεξάρτητη επαλήθευση
με τις εγκεκριμένες γλώσσες ή το MLX, σύμφωνα με το ADR009.

## Χρήση με οποιοδήποτε μοντέλο γλώσσας

Με Node και Git στο checkout που περιέχει τα ιστορικά αντικείμενα αναφοράς:

```sh
node scripts/docs/sounio_task_context.mjs list --lang el
node scripts/docs/sounio_task_context.mjs show generic-function --lang el
```

Το εργαλείο δίνει κώδικα αναφοράς και ελέγχων, ελληνικό στόχο, βήματα και
παγίδες. Δεν καλεί LLM ή μεταγλωττιστή, δεν μεταφέρει δεδομένα στο διαδίκτυο
και δεν πιστοποιεί μια αλλαγή. Μπορείτε να δώσετε το παραγόμενο κείμενο σε
μοντέλο συνομιλίας χωρίς να απαιτείται εγκατάσταση εργαλείων από την πλευρά του μοντέλου.
Η διαδικασία δεν στηρίζεται σε συγκεκριμένο πάροχο και δεν ισχυρίζεται
μετρημένο ποσοστό επιτυχίας για όλα τα μοντέλα.

## GPU και μεγάλες εργασίες

Η υποστήριξη μιας σύνταξης GPU ή ενός ονόματος στόχου δεν αποδεικνύει
εκτέλεση στη συσκευή. Η εγγενής διαδρομή Metal έχει δικό της πεδίο
λειτουργιών και τεκμήρια. Οι διαδρομές CUDA, PTX, Pireus ή προσομοίωσης
δεν εξισώνονται αυτόματα. Δηλώστε συσκευή, runtime, πραγματικό εκτελέσιμο
και αν υπάρχει ή όχι εναλλακτική εκτέλεση CPU.

Οι μεγάλες εργασίες χρειάζονται ρητά επιτρεπόμενο περιβάλλον και πόρους.
Η πρόσβαση σε ένα εργαλείο ή η ανάγνωση αυτού του οδηγού δεν εγκρίνει
εκπαίδευση σε ιδιωτικά δεδομένα, δαπάνη υπηρεσίας ή χρήση κοινόχρηστης GPU.
