# Προδιαγραφή, τεκμήρια και κατάσταση της γλώσσας

Η ελληνική αυτή σελίδα εξηγεί πώς να χρησιμοποιήσετε την αναφορά της
γλώσσας. **Δεν είναι πλήρης μετάφραση όλων των κεφαλαίων της προδιαγραφής.**
Τα πλήρη κείμενα και οι πίνακες κανόνων παραμένουν στις αρχικές πηγές που
συνδέονται παρακάτω, στα αγγλικά.

## Τρία ερωτήματα που δεν συγχέουμε

1. **Τι απαιτεί ο σχεδιασμός;** Μια υιοθετημένη σημασιολογική απαίτηση
   παραμένει απαίτηση ακόμη και όταν η υλοποίηση δεν την επιβάλλει σωστά.
2. **Τι παρατηρείται στον πηγαίο κώδικα;** Μια πραγματική διαδρομή ελέγχου
   ή παραγωγής περιγράφει την τρέχουσα υλοποίηση, όχι αναγκαστικά τον επιθυμητό κανόνα.
3. **Τι εκτελέστηκε;** Ένα τεκμήριο αφορά ακριβή πηγή, εκτελέσιμο, στόχο,
   περιβάλλον και παρατηρήσιμα. Δεν γενικεύεται αυτόματα σε όλο το αποθετήριο.

Ονόματα αρχείων όπως `run-pass`, ισχυρισμοί παλαιότερων README και
αριθμοί σε αποθηκευμένες αναφορές δεν αντικαθιστούν αυτά τα ερωτήματα.

των προτάσεων ή πλήρη επιτυχία κάθε διαδρομής.

## Κατάσταση για τον νέο χρήστη

- Ο προεπιλεγμένος δημόσιος εκκινητής είναι `./bin/souc`, με Madaros.
- Το αποθηκευμένο προμεταγλωττισμένο Linux x86-64 και το εγγενές macOS ARM64
  έχουν ξεχωριστή προετοιμασία και ταυτότητα.
- Οι στόχοι, οι αριθμητικοί τύποι και οι λειτουργίες GPU απαιτούν ειδική
  τεκμηρίωση κάλυψης. Δεν υπάρχει εδώ υπόσχεση καθολικής ισοδυναμίας.
- Η σύνταξη μονάδων και τα επιμέρους τεκμήρια επιβολής δεν επιτρέπουν να
  χαρακτηρίσουμε κάθε έκφραση με μονάδες πλήρως υποστηριζόμενη παντού.
- Τα πενήντα ιστορικά περιστατικά του οδηγού LLM περιλαμβάνουν τριάντα
  επιτυχείς συμβάσεις εκτέλεσης, τέσσερις μόνο ελέγχους, οκτώ αναμενόμενες
  αρνήσεις και οκτώ αποτυχίες σε απομόνωση. Δεν είναι πενήντα επιτυχίες.
- Το Input/Measured που γίνεται δεκτό ως annotation δεν αποδεικνύει από
  μόνο του μεταφορά προέλευσης ή απόκτηση πραγματικής μέτρησης.

Για την τρέχουσα δημόσια κατάσταση ανατρέξτε στις
[εκτελέσεις CI](https://github.com/Sounio-lang/sounio/actions), στην
[αρχική αναφορά Madaros](../MADAROS_STATUS.md) και στα τεκμήρια του
συγκεκριμένου παραδείγματος. Ένα πράσινο CI αφορά το δηλωμένο σύνολο
ελέγχων και την ακριβή αναθεώρησή του, όχι κάθε μελλοντική εφαρμογή.

## Γλωσσάρι

| Όρος | Χρήση στον ελληνικό οδηγό |
|---|---|
| compiler | μεταγλωττιστής |
| effect | επίδραση· π.χ. `IO`, `Mut`, `Epistemic`, με αμετάβλητα ονόματα κώδικα |
| ownership / borrowing | κατοχή / δανεισμός πρόσβασης |
| uncertainty / confidence | αβεβαιότητα / βαθμός εμπιστοσύνης· δεν είναι το ίδιο κανάλι |
| provenance | προέλευση και ιστορικό δεδομένων, όχι αυθαίρετη βεβαίωση εγκυρότητας |
| receipt / witness | τεκμήριο καταγεγραμμένης εκτέλεσης / συγκεκριμένος μάρτυρας μιας ιδιότητας |
| quarantine | απομόνωση αποτυχημένου παραδείγματος από τις προτεινόμενες λειτουργικές συνταγές |
| refusal | απόρριψη· σε αρνητικό έλεγχο απαιτείται η προβλεπόμενη απόρριψη για τον σωστό λόγο |
| target / backend | στόχος / υποσύστημα παραγωγής κώδικα |
