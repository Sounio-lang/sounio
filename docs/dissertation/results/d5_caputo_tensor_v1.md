# D5 Caputo Tensor v1

## Scope

This lane lifts the scalar D.5 Caputo L1 helper into the D.2 closure-free
tensor tape. It adds a single tagged op, `TAPE_CAPUTO_L1`, with a linear
adjoint for one-dimensional trajectories. The implementation is intentionally
narrow: rank-1 `f64` trajectories of length `2..512`, fixed `dt`, and
fractional order `0 < alpha < 1`.

Closure-free means the tape stores op tags and scalar metadata only; backward
rules are selected by explicit dispatch, not by captured callbacks or function
pointers.

The lane incorporates the D.2 bootstrap and D.2 hardening commits first:

- `8d1ccd7f` - closure-free autograd tape bootstrap
- `9d852974` - flat-buffer matmul and activation backward hardening

## Implementation

The forward function is:

```text
tape_tensor_caputo_l1(tape, u_id, dt, alpha) -> output_id
```

It copies the rank-1 tape value into the fixed-size scalar helper buffer and
calls:

```text
caputo_l1_derivative(samples, len(u) - 1, dt, alpha)
```

The backward rule uses the exact adjoint of the scalar stencil currently
implemented in `stdlib/special/caputo.sio`:

```text
D_C^alpha u_n = scale * sum_j b_j * (u[n-j] - u[n-j-1])
scale = 1 / (Gamma(2-alpha) * dt^alpha)
```

For `L` samples and `intervals = L - 1`, the coefficient for `u[k]` is:

```text
k = 0:             -scale * b[intervals - 1]
0 < k < intervals: scale * (b[intervals - k] - b[intervals - 1 - k])
k = intervals:     scale * b[0]
```

This sign convention is validated directly by finite differences against the
scalar forward helper.

The focused test covers:

- constant trajectory squared residual: `D_C^alpha c = 0` and gradient of
  `(D_C^alpha c)^2` is zero within `1e-8`,
- non-trivial Mittag-Leffler trajectory generated by
  `fractional_decay_ml` in `stdlib/special/caputo.sio`, with `n = 20`,
  `alpha = 0.8`, `dt = 0.1`, `lambda = 0.1`; raw Caputo tape gradient
  matches finite differences within `1e-6`,
- a miniature fractional physics residual `D_C^alpha C + k C_last`, with
  non-zero forward residual and valid backward gradient through the Caputo
  trajectory input.

## Caveats

The Caputo op is a linear functional over the trajectory samples, so the raw
gradient of `D_C^alpha c` with respect to a constant trajectory is not zero.
The zero-gradient constant witness therefore uses the squared residual
`(D_C^alpha c)^2`, which is the PINN-relevant loss term and has zero gradient at
the exact constant residual.

The miniature physics residual stores `k * C_last` as a constant scalar because
this lane does not add slice/gather tape primitives. D.6 should add a
trajectory-last helper or equivalent differentiable slicing if it needs the
`k` contribution to flow through `C_last`; this D.5 lane validates the Caputo
operator's differentiability itself.
