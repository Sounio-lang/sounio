# PBPK28 M2 Hierarchical Eta/Epsilon Prior Decomposition — v2 (mass-conserving kernel)

**Supersedes:** `m2_hierarchical_v1.md`.
**Harness:** `stdlib/darwin_pbpk/validation/pbpk28_mc_cross_validation.sio`
(`mc28_hierarchical_selftest_main`). Rapamycin, 5 mg IV bolus, AUC_blood(0→168 h), N = 2000,
seeds 1729/1730; MC dt = 0.5 h, GUM/Hessian dt 0.05/0.1 h.
**Kernel:** Rannacher-started clamp-free Crank–Nicolson (`theta_pbpk28.sio`). v1 ran every
simulation through `pbpk28_full_cn_step`. At the nominal parameters, the audit measured its
floors inflating AUC_blood by +140% at dt = 0.5 h and +52% at dt = 0.1 h; the amount varies by
sample (`docs/audit/PBPK28_CN_RANNACHER_MASS_BALANCE_2026-09-26.md`). The v1 → v2 ratio of MC mean
AUC here is 1.076898/0.470662 = 2.29 (individual) and 1.153652/0.518412 = 2.23 (population).
**Run log:** `runs/m2_hierarchical_v2.txt`. The run-pass wrapper
`tests/run-pass/pbpk28_m2_hierarchical_prior.sio` does not compile on main (pre-existing E035 /
E259), so the log comes from a two-line probe that calls `mc28_hierarchical_selftest_main()`
under lean_single.
**Zhang 2009 prior components:** ω² = 0.0566, σ² = 0.0894 (unchanged). The method (v1 § Method)
is unchanged.
**Convention:** rel_X = |u_X − u_MC| / u_MC, computed by the harness from unrounded values
(mg·h/L throughout). Only the individual row is gated (rel_Hess ≤ 0.10); the population row is
informational.

## What changed (measured)

On the mass-conserving kernel, the individual rel_Hess falls from 19.2% to 3.6%, which passes the
≤ 10% gate. The informational population rel_Hess falls from 19.4% to 5.6%. v1 was produced
on 2026-05-14 code, and this harness was not re-run at the base commit (its run-pass wrapper does
not compile). Code changes since May other than the stepper are therefore not excluded as
contributors, although for the single-level harness E1 the base-commit rerun reproduced the
earlier M6 numbers exactly. This file does not test whether the η/ε hierarchy contributes to the
remaining 3.6%.

Context from other files, not measured here: the single-level LogNormal baseline (E1, M6 prior)
is rel_Hess = 0.018801 (`mc_cross_validation_lognormal_v3.md`).

**Limits (as in `mc_cross_validation_lognormal_v3.md`):** the N = 2000 MC resolves u_MC only to
≈ 1.6% relative; the GUM/Hessian budgets linearise at `cl_central = 12.4 L/h` while the MC centres
total CL at 12.7 L/h; and the three methods use different dt grids.
