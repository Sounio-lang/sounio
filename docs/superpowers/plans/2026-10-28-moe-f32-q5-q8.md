# MoE F32 Q5_K + Q8_0 Implementation Plan (Plan E)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship native Sounio Q5_K and Q8_0 `mul_mat_id` F32 kernels (dp4a + vec n=1), runtime loaders, `moe_ffn_q5k` / `moe_ffn_q8_0`, and L4 hetero demos - no llama.cpp.

**Architecture:** Twin stacks mirrored on the measured Q4_K path (SOTA+++: packed/`__ldg` loads in vec from first green). Separate CU/PTX/runtime/moe entry points per quant; shared `moe_topk` / SiLU / combine. No quant-enum dispatcher this cycle.

**Tech Stack:** Sounio (`.sio`), CUDA 12.6 PTX sm_89 (`.version 8.5`), hetero runtime (`ce_launch_2d_shmem`), L4 via `srun` on `gpuorangefs-r770-proxmox`, branch `cursor/moe-f32-q5-q8`.

**Spec:** `docs/superpowers/specs/2026-10-28-moe-f32-q5-q8-design.md`

## Global Constraints

- No llama.cpp runtime linkage.
- Measure on NVIDIA L4 with `srun` (not sbatch); nvcc 12.6; PTX `.version 8.5` / `-arch=sm_89`.
- Lab shapes: m=4096, k=2048, experts=128, slots=4, amax=1e5; NMSE <= 5e-4 vs CPU dequant+GEMM.
- Vec n=1 target us <= 120; if miss, document ceiling and keep NMSE gate.
- n=16 / n=64 targets: <2500 / <5500 us or documented ceilings.
- Host SiLU/combine stays on host.
- Do not change `llama_moe_ffn_block` (stays Q4_K).
- Do not introduce `moe_ffn(quant)` / `rt_mul_mat_id(quant)` enum.
- Commits: human-gated only. Propose message; do not `git commit` / `git push` / `gh pr create` without explicit human approval. Use `Assisted-by:` if human asks you to commit.
- Coord: `bin/sounio-coord claim/heartbeat` lane `moe-f32-q5-q8`; never merge `main`.
- ASCII only in code/docs comments.
- Notion mirror: prefix `SIO-moe-f32` when MCP auth available (controller).
