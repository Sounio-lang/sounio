# Required actual-Lowerer component protocol

These checks must call the real proposed helpers on the real Lowerer types.
A fixture that prints a desired marker is insufficient. They remain pending.
Use a separately qualified component producer after authorization; do not build
another full modern compiler merely to prepare this package.

1. Begin a compile-error scope and reset transient hard errors. Invoke
   shadow_refuse_scope with invalid current_fn and current_func_loaded=false.
   Do not make current_func readable merely to allow diagnostics.
2. BEFORE transient reset, require the recorded site30790, positive error total
   and active compile-error latch. Then call lower_hard_error_reset and traverse
   the actual next-dependency/new-Lowerer route. Publication must remain refused
   through the latch even if transient flag/total reset.
3. A mutant omitting lower_note_error must fail this survival test. A subsequent
   fresh compile scope plus transient reset must allow an otherwise clean compile.
   Probe mode and FO_INLINE_DEPTH rollback are separate controls.
4. All four Lowerer constructors initialize shadow_origin_body_closed=false.
   All three local binders initialize/reset the separate origin slot. Test slot0,
   slot4095, rejected negative/4096 indices, slot pop/reuse and same-name shadow.
   Verify cap64k/source constructors using actual backend layout, not source size.
5. Copy/clone contexts must not share writable origin state. Mutate cloned flags
   and first/last entries, then read the original. A rejected FO-inline analysis
   restores caller flags, origins, rows, pending state and channel count.
6. Positive origin is seeded only by direct supported word-int parameters or
   recursively proven integer declarations. Test every sigma/base-sigma,
   FO-row, pending closure/sensitivity, ref/global/raw/wide/aggregate and
   Knowledge tag guard independently, including legacy kn_value_float=-2.
7. Explicit i128/u128 param, alias and cast trees must fail classification.
   Inspect actual token/AST/type for suffix controls; unsupported parsing is not
   a semantic pass. An erased f64 suffix is a producer gap and blocks that claim.
8. Branch merge may only lose origin; assignment cannot recertify0→1. Within any
   loop, 1→0 declassification after an already emitted use must latch refusal.
   Outside loops later uses must not reuse the old proof.
9. None+canonicalZERO+empty sensitivity/Hessian remains None without channels or
   rows. Same-scope first real tracking uses a private dominating COPY cell.
   Outer-scope branch/loop promotion must refuse. Existing tracked paths must
   retain canonical results, including correlated channels and cancellation.
10. Place31+ closed integer aliases alongside real Knowledge channels. Compare
    channel/row allocations before and after against the untouched tracked path.
    Do not treat fo_nchan or scalar_kind as evidence of deterministic origin.

Keep mutations narrowly targeted: missing durable note, wide guard omission,
kind-only certification, aliased clone and loop-declassification acceptance.
Each must fail its corresponding real component assertion.
