# Scope and remaining qualification

This package is a reviewed TEMPLATE plus metadata controls. It is not an actual
source seal, preflight, compiler build, producer qualification or integration run.
No actual future HEAD/tree/producer hash is asserted and no real ROOT06 Ready exists.

Metadata tests use synthetic receipt schemas, a tiny private Git repository and
four-byte ELF-magic fixtures that are NEVER executed. They exercise contract
admission/refusal and publication ordering only. They do not numerically validate
a compiler, SDK capability or scientific result.

Complete full-Git fidelity supports regular blobs and literal symlinks with UTF8
paths. Unsupported Git object shapes fail, rather than dropping them. SDK roots
and qualified tool/runtime closure are explicitly root-supplied. The metadata
reader cannot discover omitted dynamic dependencies or infer truth from legacy
log text; actual private-SDK preflight and reviewed adapters remain necessary.

Root must review the supplied short-preflight script and actual original C++23
oracles/output, instantiate all actual input identities, freeze the recipe bundle,
seal the source graph, authorize and submit the phases. There is no automatic
submission call in this package. Source9 fixes and their qualified final producer
remain a mandatory waitpoint.
