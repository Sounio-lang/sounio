# Garden Seed Template

> **Status**: Internal template | **Last validated**: 2026-05-09 | **Source**: `docs/internal/garden/README.md`

Use this shape for new files under `docs/internal/garden/seeds/`.

## Title

Use a short title that preserves the first image or pressure of the idea.

## Butterfly

Quote or paraphrase the phrase that carried the idea.

## Core Idea

State the idea in plain language. Keep the metaphor alive, but separate it from
what the repo can actually prove today.

## Connections

List the nearby repo docs, examples, gates, papers, proofs, or prior Garden
entries. Prefer links to real files over broad references.

## Evidence State

| Layer | Status |
| --- | --- |
| `Garden` | What has been captured as image, intuition, or lineage. |
| `Hypothesis` | What could become testable or implementable. |
| `Executable` | The current command, gate, artifact, or implementation surface, if any. |
| `Claim-ready` | Say `No` unless there is explicit validation for the intended audience. |

## What This Is Not

Name the boundaries that protect the idea from overclaiming. Be especially clear
when a seed touches clinical pathways, math claims, external-facing artifacts,
physics metaphors, or compiler capability claims.

## Next Executable Bridge

Name one concrete bridge the repo could build next. If none exists yet, say so.
