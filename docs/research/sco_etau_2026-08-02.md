**Status:** theory-carrying strategy install (source) + corpus gate + install gate  
**Date:** 2026-08-02  
**Depends on:** Step I (SCO) · Step II (corpus V1–V3)

---

## 1. What is being installed

From Step I: \(E(\tau)\) is the set of rewrites legal at scientific type \(\tau\).

Step III does **not** yet enumerate every rewrite. It installs the **first compiler-visible carrier** of \(E\):

\[
\text{scientific effect set on a function}
\;\Longrightarrow\;
\texttt{compile\_strategy} = \texttt{PRECISION\_PRESERVING}
\]

so that any mid-end pass already keyed on strategy (epistemic e-graph pass, chaotic refusal, precision policy) treats the function under scientific theory rather than ordinary STANDARD floats.

| Corpus | Scientific signal | \(E\) intent (first cut) |
|--------|-------------------|---------------------------|
| V1 coverage | GUM / finite-dof \(k\) | no silent coverage collapse; prefer precision / GUM-aware passes |
| V2 algebra | `NonAssoc` | reassoc only under domain algebra — strategy must not be AGGRESSIVE/STANDARD free-float |
| V3 observe | `Observe` | observation barrier context — precision-preserving, not “optimise as pure data” |

**Install site:** `self-hosted/ir/lower.sio` · `lowerer_compute_strategy_from_ast_ref`  
**Markers (for gate grep):** `SCO_ETAU_INSTALL_V1`, `SCO_ETAU_ELEVATE_SCIENTIFIC_EFFECTS`

Effects elevated: **NonAssoc**, **Epistemic**, **Observe**  
(Chaotic already mapped to `PRECISION_PRESERVING_CHAOTIC` before this step.)

---

## 2. What this is *not*

- Not full `ocp_egraph_pass` on non-empty functions (still deferred).  
- Not mfi multi-module peels running mini/epistemic e-graph (multi-mod `-O` remains classical peels for stack safety).  
- Not a SepCompCert theorem.  
- Not SCO clause 6 fully discharged in a **shipping** binary until Madaros is rebuilt from this source and an ablation delta is measured on that binary.

Step III **creates** the obligation carrier in source and keeps the corpus live. Runtime non-vacuity on the **default pod binary** may lag one rebuild.
