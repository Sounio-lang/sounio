**E040 — `let mut` is not valid Sounio**

Sounio uses `var` for mutable bindings, not `let mut`.

**Fix:**
```sio
// ✗ WRONG
let mut counter = 0

// ✓ CORRECT
var counter = 0
counter = counter + 1
```
