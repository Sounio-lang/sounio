# E247 - Malformed zero-divisor locus

**Severity:** error

**Message pattern:** `error[E247]: ZD locus is not a well-formed sedenion pair`

## What happened

An `ExactlyPrivate` type named a zero-divisor locus that is not a pair of two
distinct sedenion imaginary units in the range `e1` through `e15`.

## Fix

Use a canonical pair `eIeJ` with `1 <= I < J <= 15`, such as `e3e7`.
