**E170 — `.value` on `Knowledge<T>` requires `with Epistemic`**

Reading the point estimate from a `Knowledge<T>` (or `Epistemic<T>`) value via `.value` is an epistemic operation — it collapses the uncertain quantity to a scalar. The calling function must declare `with Epistemic`.

**Minimal example:**
```sio
fn get_mass(k: Knowledge<f64>) -> f64 {
    k.value    // E170: missing `with Epistemic`
}
```

**Canonical fix:**
```sio
fn get_mass(k: Knowledge<f64>) -> f64 with Epistemic {
    k.value
}
```

The `Epistemic` effect propagates upward, making it visible in the call graph which functions "observe" uncertain quantities. This enables the compiler to enforce epistemic boundaries and generate GUM uncertainty chains.
