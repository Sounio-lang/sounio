**E072 — Kernel function must return `()`**

GPU kernel functions (`@kernel`) must return unit (`()`). Results are written to output arrays passed as parameters, not returned as values.

**Fix:**
```sio
// ✗ WRONG
@kernel fn vec_add(a: f64, b: f64) -> f64 { a + b }

// ✓ CORRECT
@kernel fn vec_add(a: &[f64; 256], b: &[f64; 256], out: &![f64; 256]) with Panic {
    let idx = thread_idx()
    out[idx] = a[idx] + b[idx]
}
```
