# E221 — No main function

**Severity:** error

**Message pattern:** `error[E221]: no main`

## What happened

The compiler found no `fn main()` entry point in the compilation unit.

## Example

```sounio
fn helper() -> i64 { 42 }
// No main → E221
```

## Fix

Add a `main` function:

```sounio
fn main() -> i64 with IO, Panic {
    print("hello\n")
    0
}
```

If you are compiling a library (no entry point), this is expected — the error only fires when the compiler expects an executable.
