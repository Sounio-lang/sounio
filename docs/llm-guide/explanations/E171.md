**E171 — Cannot cast `Knowledge<T>` to `T` directly**

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

`Knowledge<T>` is not `T`. Casting an epistemic value directly to its inner type discards the uncertainty envelope and is not permitted. Use `.value` (with `with Epistemic`) to extract the point estimate, or propagate the `Knowledge<T>` upward.

**Fix:**
```sio
// ✗ WRONG
let mass: f64 = k as f64

// ✓ CORRECT (propagate epistemic)
let mass_k: Knowledge<f64> = k
// or extract with effect
fn read_mass(k: Knowledge<f64>) -> f64 with Epistemic { k.value }
```
