---
code: E286
title: Ontology subsumption could not be verified
severity: error
component: type-checker/ontology
---

Madaros rejects a subclass property constraint that does not imply its parent constraint. Strengthen the child property; for example, `potency >= -1.0` does not imply a parent requirement of `potency >= 0.0`. This error previously reused E041, which now exclusively names unit mismatch on Madaros. The separate ontology warning W041 is unchanged.
