# E225 — Import dedup table full

**Severity:** error

**Message pattern:** `error[E225]: import dedup table full: PATH`

## What happened

The compiler's import deduplication table (1024 entries) is full. More than 1024 distinct files are being imported transitively.

## Fix

Reduce the number of distinct imported files, or split the build into multiple compilation units.
