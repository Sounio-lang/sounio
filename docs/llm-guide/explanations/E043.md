**E043 — Rust macro syntax `ident!(...)` is not valid Sounio**

Sounio has no macro system. Use regular function calls.

**Fix:**
```sio
// ✗ WRONG
println!("hello")
assert!(x == 5)
vec![1, 2, 3]

// ✓ CORRECT
println("hello")
assert(x == 5)
// Use fixed arrays: [1, 2, 3] or [T; N]
```
