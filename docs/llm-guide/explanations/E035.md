**E035 — Effect not declared in function signature**

A function performs an operation that requires an effect (IO, Mut, Div, Panic, Alloc, Observe, Audit, Hypothesis, Epistemic, ZD…) but the function's `with` clause does not list that effect.

Effects propagate upward: if an inner function needs `Div`, every caller must also declare `Div`.

**Minimal example:**
```sio
fn divide(a: f64, b: f64) -> f64 {   // missing `with Div`
    a / b
}
```

**Canonical fix:** Add the required effect to the `with` clause.

```sio
fn divide(a: f64, b: f64) -> f64 with Div {
    a / b
}
```

**Common effect triggers:**

| Operation | Effect required |
|-----------|----------------|
| `a / b` or `a % b` | `Div` |
| `arr[i]` | `Panic` |
| `assert(...)` | `Panic` |
| `println(...)` / `print(...)` | `IO` |
| `*x = v` or `self.field = v` | `Mut` |
| `var x = 0; x = 1` | `Mut` |
| `knowledge.value` | `Epistemic` |
| `if obs > threshold` on `Unobserved<T>` | `Observe` |
| Zero-divisor type (`ExactlyPrivate<T>` etc.) | `ZD` |
