**E036 — Unobserved<T> observation boundary violation**

An `Unobserved<T>` value (latent/hidden variable) was used in a context that "collapses" it to an observed value — comparing it, branching on it, or passing it to a function that expects `T` — without the calling function declaring `with Observe`.

**Minimal example:**
```sio
fn check_threshold(obs: Unobserved<f64>, threshold: f64) -> bool {
    obs > threshold   // E036: observation boundary without Observe
}
```

**Canonical fix:**

```sio
fn check_threshold(obs: Unobserved<f64>, threshold: f64) -> bool with Observe {
    obs > threshold
}
```

The `Observe` effect propagates upward to callers, making it visible in the type system which functions "collapse" latent variables.
