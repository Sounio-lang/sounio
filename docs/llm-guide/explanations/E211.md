# E211 — Study block requires at least one hypothesis

**Severity:** error

**Message pattern:** `error[E211]: study block requires at least one hypothesis at line L`

## What happened

A `study { ... }` block contains no `hypothesis` declarations. At least one hypothesis is required to use the `Study` effect.

## Example

```sounio
fn run() with Study {
    study {
        // empty — E211
    }
}
```

## Fix

Add at least one `hypothesis` inside the `study` block:

```sounio
fn run() with Study {
    study {
        hypothesis h1: x > 0
    }
}
```
