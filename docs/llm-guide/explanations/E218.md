# E218 — Tail type mismatch

> **⚠️ Reality check (Madaros v0.80.0, verified 2026-07-11):** the default `souc check` reports this defect as **E008**, not the code named here. See [error-catalog.md](../error-catalog.md).


**Severity:** error

**Message pattern:** `error[E218]: tail type mismatch at line L`

## What happened

The last expression in a function body has a type that does not match the function's declared return type, and neither type is a Knowledge type (which would allow epistemic boundary coercion).

## Example

```sounio
fn get_count() -> i64 {
    "hello"   // E218: string ≠ i64
}
```

## Fix

Ensure the final expression matches the return type:

```sounio
fn get_count() -> i64 {
    42
}
```
