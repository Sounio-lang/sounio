# E227 — Import too large for SRC buffer

**Severity:** error

**Message pattern:** `error[E227]: import too large for SRC buffer: PATH`

## What happened

The file at `PATH` (or the cumulative source after importing it) exceeds the 8 MiB source buffer. The compiler cannot load it.

## Fix

Split the large file into smaller modules, or reduce the total source size of the compilation unit.
