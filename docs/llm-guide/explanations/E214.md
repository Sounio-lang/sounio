# E214 — Confidence gate violation

**Severity:** error

**Message pattern:** `error[E214]: confidence gate violation at line L: args confidence C < minconf M`

## What happened

A function annotated with `@minconf(M)` was called with arguments whose combined epistemic confidence `C` falls below `M`. The call is rejected at compile time.

## Example

```sounio
@minconf(800)
fn high_stakes(x: Knowledge<f64>) -> f64 with Epistemic { x.value }

fn caller() -> f64 with Epistemic {
    let k = Knowledge(3.14, 500, 600)   // conf=500 < 800
    high_stakes(k)   // E214
}
```

## Fix

Either raise the confidence of the argument (more precise measurement), lower the `@minconf` threshold, or add a runtime guard before the call:

```sounio
if k.conf >= 800 { high_stakes(k) } else { fallback() }
```
