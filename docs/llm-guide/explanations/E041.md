---
code: E041
title: Unit mismatch
severity: error
component: type-checker/units
---

Madaros uses **E041** for incompatible units in arithmetic, comparison or a
function argument. Messages include `unit mismatch in arithmetic operation`
or `unit mismatch in call argument`. Even equal dimensions with different
scales require an explicit conversion before combination.

For example, `let a: km = 1.0`, `let b: m = 500.0`, then `a + b` is refused.
Use the same unit at the boundary or convert explicitly using a conversion
supported by the selected compiler. A cast's numerical behavior is a separate
contract; do not assume relabeling performs a scale conversion.

The registry (`self-hosted/diagnostics/mod.sio`) reserves E041 for unit mismatch.
Madaros ontology property weakening uses [E285](E285.md); Rust `&mut` reference
syntax uses [E286](E286.md). The registry's use-after-move constructor uses
[E287](E287.md).

**Legacy divergence:** `SOUNIO_SOUC_ENGINE=lean_single` still uses E041 for
Rust `&mut` syntax (use `&!T`) and E001 for unit mismatch in a `let` binding.
Its source and committed seed are unchanged by #3552. Alignment requires a
separate ADR-031 R3 seed refresh. Cite the engine with legacy diagnostics.
