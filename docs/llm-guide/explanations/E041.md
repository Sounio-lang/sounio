**E041 — `&mut` is not valid Sounio**

Sounio uses `&!T` for exclusive (mutable) references, not `&mut T`.

**Fix:**
```sio
// ✗ WRONG
fn fill(arr: &mut [i64; 8]) { ... }
fill(&mut buf)

// ✓ CORRECT
fn fill(arr: &![i64; 8]) with Mut, Panic { ... }
fill(&!buf)
```
