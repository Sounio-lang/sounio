# E215 — EpistemicComplete violation

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

**Severity:** error

**Message pattern:** `error[E215]: EpistemicComplete violation in fn NAME at line L`

## What happened

A function declared `with Epistemic` contains sub-expressions whose confidence falls below 100% (confidence value < 1000). The `Epistemic` effect requires all expressions in the body to be high-confidence.

## Fix

Either raise the confidence of the relevant sub-expressions, or remove the `Epistemic` effect from the function signature if full confidence is not achievable:

```sounio
// Before: fn compute() -> f64 with Epistemic { low_conf_val }
// After: remove Epistemic if sub-expressions can have lower confidence
fn compute() -> f64 { low_conf_val }
```

Alternatively, insert a confidence gate before the low-confidence value is used.
