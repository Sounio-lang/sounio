# E217 — Invalid function body span

**Severity:** error

**Message pattern:** `error[E217]: invalid function body span for fn#N NAME`

## What happened

The compiler's internal function body token range for function `NAME` is corrupt (zero-length or out-of-bounds). This is a compiler-internal invariant violation, typically caused by a malformed source file or a bug in the compiler itself.

## Fix

Check if the function is syntactically complete (matching braces). If the source looks correct, file a bug report with the source file that triggers this error.
