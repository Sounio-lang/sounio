# E220 — Unresolved function body for call target

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

**Severity:** error

**Message pattern:** `error[E220]: unresolved function body for call target fn#N NAME at line L`

## What happened

A call site references a function (`NAME`) whose machine-code body was never emitted. The function was declared (registered) but no body was compiled for it.

## Common causes

- Function is declared in an effect block as a prototype only
- Forward declaration without a matching definition
- Conditional compilation excluded the body

## Fix

Ensure the function has a complete definition (not just a signature) in the compiled source:

```sounio
fn my_fn(x: i64) -> i64 {   // body required
    x + 1
}
```
