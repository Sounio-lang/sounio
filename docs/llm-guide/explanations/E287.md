---
code: E287
title: Rust `&mut` syntax - use `&!` instead
severity: error
component: parser/compat
---

Madaros rejects Rust `&mut T` reference type syntax. Write `&!T` for an exclusive reference and `&!value` at the call site. This parser refusal previously reused E041. The legacy `lean_single` engine still reports E041 for this spelling; aligning it requires a separate ADR-031 R3 seed refresh.
