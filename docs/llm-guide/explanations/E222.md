# E222 — Code buffer overflow

**Severity:** error

**Message pattern:** `error[E222]: code buffer overflow at fn=N name=NAME`

## What happened

The generated machine code for function `NAME` exceeded the code buffer capacity. The function is too large.

## Fix

Split the function into smaller helper functions. There is no user-facing way to raise the code buffer limit — the compiler must be rebuilt with a larger `CD` array if this is a systemic issue.
