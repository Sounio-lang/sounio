# E248 - Wide-float conversion unavailable

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

**Severity:** error

**Message pattern:** `error[E248]: f128/f256 value conversion is not implemented`

## What happened

The program attempted a cast to or from `f128` or `f256`. Sounio defines their
format identities, but does not yet implement source-level wide-float value
conversion.

## Fix

Keep the value in a supported numeric format. Do not substitute an `f64` cast:
that would erase the precision contract rather than implement it.
