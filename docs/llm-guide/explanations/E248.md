# E248 - Wide-float conversion unavailable

**Severity:** error

**Message pattern:** `error[E248]: f128/f256 value conversion is not implemented`

## What happened

The program attempted a cast to or from `f128` or `f256`. Sounio defines their
format identities, but does not yet implement source-level wide-float value
conversion.

## Fix

Keep the value in a supported numeric format. Do not substitute an `f64` cast:
that would erase the precision contract rather than implement it.
