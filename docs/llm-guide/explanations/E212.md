# E212 — Hessian AD over a non-associative algebra

**Severity:** error

**Message pattern:** `error[E212]: Hessian AD over a non-associative algebra — reassociate: fano_selective required at line L`

## What happened

You attempted second-order automatic differentiation (Hessian) over a value whose algebra is non-associative (e.g., octonions). Hessian AD requires the `reassociate: fano_selective` annotation to acknowledge the non-associativity and select Fano-plane-selective reassociation.

## Fix

Annotate the function with `reassociate: fano_selective`:

```sounio
@reassociate: fano_selective
fn hessian_octonion(...) -> ... { ... }
```

See `formal/NonAssocHessian.lean` for the soundness proof.
