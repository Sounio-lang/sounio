# E208 — Refinement type violation (integer)

**Severity:** error

**Message pattern:** `error[E208]: refinement type violation — value N does not satisfy predicate at line L`

## What happened

A compile-time-known integer value was passed to a refined type position (parameter, let-binding, or return type) and failed the predicate check.

## Example

```sounio
type Pos = { v: i64 | v > 0 }

fn check(x: Pos) -> i64 { x }

fn main() -> i64 with IO, Panic {
    check(-5)   // E208: value -5 does not satisfy v > 0
}
```

## Fix

Pass a value that satisfies the predicate, or widen the refined type to accept the value:

```sounio
fn main() -> i64 with IO, Panic {
    check(10)   // ok
}
```

If the predicate is wrong, correct the type definition instead of working around the check.
