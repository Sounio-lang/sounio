# E250 - Unsupported extern C call

**Severity:** error

**Message pattern:** `error[E250]: call to an extern C function the native backend does not implement`

## What happened

The program called a body-less `extern "C"` declaration whose name is absent
from the native backend's closed builtin registry. Allowing the call would emit
an empty stub and fabricate a return value.

## Fix

Use an implemented builtin, add a real backend implementation together with an
execution witness, or provide a Sounio function body. Merely declaring the name
is legal; the unsupported call is what refuses.
