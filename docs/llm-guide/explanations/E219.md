# E219 — Function pass mismatch

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

**Severity:** error

**Message pattern:** `error[E219]: function pass mismatch compiled=N registered=M`

## What happened

The compiler completed code generation for `N` functions but `M` functions were registered during scanning. This indicates a compiler-internal bug where a function was registered but never compiled, or vice versa.

## Fix

This is an internal compiler error. Reduce the source file to a minimal reproducer and file a bug.
