# E219 — Function pass mismatch

**Severity:** error

**Message pattern:** `error[E219]: function pass mismatch compiled=N registered=M`

## What happened

The compiler completed code generation for `N` functions but `M` functions were registered during scanning. This indicates a compiler-internal bug where a function was registered but never compiled, or vice versa.

## Fix

This is an internal compiler error. Reduce the source file to a minimal reproducer and file a bug.
