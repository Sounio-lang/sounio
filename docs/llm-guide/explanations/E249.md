# E249 - Wide-float source value reserved

**Severity:** error

**Message pattern:** `error[E249]: f128/f256 is reserved for compiler-owned format identity`

## What happened

The source used `f128` or `f256` in a value-bearing position. V0-A reserves
these names for compiler-owned binary128 and binary256 format identity and
rejects source values before IR lowering.

## Fix

Use `f64` for executable source values until the corresponding ladder stage is
implemented. Do not encode a wide value through `f64` and claim wide precision.
