# E216 — Infinite recursive type

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

> **⚠️ Reality check (Madaros v0.80.0, verified 2026-07-11):** this code does **not** currently fire under the default `souc check` — the "wrong" example below compiles clean or surfaces a different code under the default engine. See the enforcement-reality note in [error-catalog.md](../error-catalog.md).


**Severity:** error

**Message pattern:** `error[E216]: infinite recursive type`

## What happened

A struct type directly contains itself (not through a pointer/box), creating an infinitely-sized type.

## Example

```sounio
struct Node {
    val: i64,
    next: Node,   // E216: infinite recursive type
}
```

## Fix

Use a pointer (`&Node`) or box (`Box<Node>`) for the recursive field:

```sounio
struct Node {
    val: i64,
    next: &Node,   // ok — pointer-sized slot
}
```
