**E070 — IO or Mut effect not allowed in kernel function**

Functions annotated with `@kernel` (lowered to GPU/K-AXI) must be pure with respect to IO and Mut. Side effects that interact with the host system are not available on the device.

**Canonical fix:** Remove `with IO` / `with Mut` from the kernel function signature. Pass inputs as immutable parameters and write outputs to a pre-allocated output array passed as a `&![T; N]` parameter. Do not call `print`, `println`, or any host-IO function from a kernel.
