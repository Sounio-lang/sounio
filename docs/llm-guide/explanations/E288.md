---
code: E288
title: Use after move
severity: error
component: diagnostics/ownership
---

The diagnostic registry constructor `diag_use_after_move` assigns E288 to use of a moved value. Pass or consume a value once, and avoid reusing it after transfer. This registry identity previously reused E041. This allocation describes the registry API; it does not claim that every Madaros ownership check uses this constructor. The checker retains its existing E039 linear-use diagnostic.
