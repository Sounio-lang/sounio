**E006 — Arity mismatch**

A function was called with the wrong number of arguments.

**Minimal example:**
```sio
fn add(a: i64, b: i64) -> i64 { a + b }

fn main() with IO {
    let x = add(1)    // E006: expected 2 args, got 1
}
```

**Canonical fix:** Pass exactly the number of arguments the function declares.

```sio
fn main() with IO {
    let x = add(1, 2)
}
```
