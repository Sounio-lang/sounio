# E213 — Tuple destructure arity mismatch

**Severity:** error

**Message pattern:** `error[E213]: tuple destructure arity mismatch: has N elements but type has M at line L`

## What happened

A tuple destructure pattern has a different number of elements than the tuple type being destructured.

## Example

```sounio
let (a, b) = make_triple()   // E213: has 2 but type has 3
```

## Fix

Match the number of pattern variables to the tuple's element count:

```sounio
let (a, b, c) = make_triple()   // ok
```
