# E210 — Algebra property violation

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

**Severity:** error

**Message pattern:** `error[E210]: algebra property violation — <property> at line L`

## What happened

An operation used an algebra type but the required algebraic property (e.g., associativity, commutativity) is not satisfied by the algebra registered for that type.

## Fix

Ensure the algebra declared with `algebra` satisfies the property expected at the call site, or use `reassociate: fano_selective` for non-associative algebras.
