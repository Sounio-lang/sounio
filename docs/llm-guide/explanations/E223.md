# E223 — Too many ExitProcess call sites (Windows PE)

> **Not refreshed by the October 2026 LLM-guide audit.** This retained
> explanation is reference material, not a current compiler or execution
> receipt. Codes, enforcement, and fixes can differ by engine and route. Start
> with the [current diagnostic guide](../error-catalog.md) and verify the full
> diagnostic against the selected artifact. Do not silently narrow precision,
> unwrap scientific values, or weaken effects/ownership to apply an old fix.

**Severity:** error

**Message pattern:** `error[E223]: too many ExitProcess call sites (N > 4096)`

## What happened

When targeting Windows (`--target x86_64-windows`), the compiler tracks all `ExitProcess` call sites for IAT patching. There are more than 4096 such sites, exceeding the internal table.

## Fix

This is almost certainly a compiler bug — real programs should not have thousands of exit calls. File a bug report.
