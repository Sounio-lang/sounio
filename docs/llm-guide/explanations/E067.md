**E067 — Potential confounding in epistemic computation**

A variable used in an epistemic computation may introduce confounding because it appears in both the predictor and the outcome path without being controlled. The compiler's causal-graph analysis flagged a possible unblocked back-door path.

**Canonical fix:** Either declare the variable as a controlled covariate with `with Audit`, or restructure the computation so the confounded path is blocked. If the confounding is intentional (e.g. a sensitivity analysis), annotate with `// @allow-confounding`.
