**E042 — Rust attributes `#[...]` are not valid Sounio**

Sounio has no attribute macro system. Remove `#[derive(...)]`, `#[cfg(...)]`, `#[allow(...)]`, and similar Rust annotations.

**Fix:** Remove the attribute entirely, or use the Sounio equivalent if one exists (e.g., there is no `#[derive(Debug)]` — implement display manually).
