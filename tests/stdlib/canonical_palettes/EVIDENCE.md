## Original witness and primary source

Slurm **17229** (`SIO176-data01`) compiled the independent C++23 reader/generator,
compared the pinned BIDS and Matplotlib RGB8 data, and checked the generated pure
lookup source. The same legacy-name witness compiled against original c21 and
ran to its explicit assertion failure (native exit 1 after complete data rows).
The independent comparator reports **992 of 1,024** canonical RGB triplets differ
from the existing eight-anchor/polynomial approximations. This is a mismatch
against the declared canonical listed palette, not a claim that every approximate
color is scientifically unusable.

Primary source bytes, licenses, URLs, commits and SHA-256 values are in
`tests/reference/data/canonical_palettes/PRIMARY_DATA.md`. Source is read as text
by C++23 and never executed as Python. The exact decimal and binary64 floor
quantization paths agree for every component. The final gate also proves all
3,072 represented canonical floating channels are bit-identical between the two
pinned sources, before checking their 1,024 quantized RGB triplets.

The checked-in lookup is regenerated by C++23 and compared byte-for-byte. The
historical native approximation stream is retained separately, SHA-bound, and
all 1,024 rows agree with the explicitly named new `*_approx_*` APIs. No D27 image
golden is generated or replaced. The legacy dynamic-fields oracle's high
viridis blue endpoint changes from rounded 37 to floor-quantized 36, with primary
source/conversion attribution rather than copying a new native result.

## Actual image bytes and viewing limitation

`preview/actual-native-canvas.png` is encoded from the **actual native Canvas
pixel stream**, through verified RLE and the existing C++ Canvas exporter. No SVG
redraw, inferred expected-image rendering, image generation or hand-edited image
is used. The RLE→PPM round trip is byte-identical to the positive native capture.
`preview/actual-native.svg` is the actual emitted SVG section.

The figure has four canonical gradients, true -1..1 endpoint labels, a uniform
constant-domain 2.5 colorbar, and a heatmap with explicit configured under/over/
missing colors. The first colorbar and heatmap use the same immutable
`PaletteScale`. It is a regression diagram; units/captions remain caller concerns.

A separate C++23 decoder independently parses PNG chunks/CRCs, decompresses the
stream using the existing system zlib runtime, and reconstructs PNG filters.
It accepts **RGB8, color type 2, no alpha**, and rejects ancillary profiles,
gamma or transparency: only IHDR/IDAT/IEND chunks are permitted. It constructs the
**entire** expected 720×480 raster independently from the primary palette and
font data, including black background, not merely the records that happened to
be present. It proves PNG = PPM = native map = primary expected raster for all
**345,600 pixels / 1,036,800 RGB bytes**.

Sixteen palette samples at x=80/200/400/590 across all four gradients and four
white endpoint-label samples are recorded. For example, viridis at (590,28) is
packed 16639780 in PNG/native/primary, and the endpoint label at (553,44) is
16777215 in PNG/native/primary. PNG SHA
`18105fcf3193e6c3b216b99aad4c41cd2761aa5aaf0c731f146cd1b793417db4`
is identical on the worker and the copied Mac file.

Slurm **17261** repeated image emission **after all mutant runs**, using only
untouched positive stdout in a fresh isolated directory. Its PPM and PNG match
the positive artifacts. Independent decode job **17272** also verified direct,
isolated, and SIPS-derived RGB rasters in full. Agent viewing-tool impressions
of these valid bytes disagreed; this remains a tool-observation limitation.
Neither file corruption nor a production renderer defect is inferred from that
impression, and no human visual acceptance is claimed. The verified native PNG
is provided for human review.
