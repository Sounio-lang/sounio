The resolve API is `unicode_bidi_resolve(&Utf8Text, paragraph_mode, max_result_bytes, max_work_bytes)`. Modes are0 explicitLTR,1 explicitRTL,2 auto with LTR fallback,3 auto with RTL fallback. Result payload charges56 bytes per source scalar plus40 per paragraph; work payload charges104 bytes per scalar plus4056 for the normative directional/bracket stacks. These budgets charge actual retained array capacities, separate from allocator pages and process memory. Empty input needs no payload and returns zero paragraphs.

Getters on BidiText use logical scalar indices, except visual_to_logical which takes a visual index. Removed X9 scalars keep code point/byte offset and have level and logical_to_visual value-1. Visual maps omit them. Paragraph start/end are half-open global scalar ranges; visual_start/end are global visual ranges. The explicit line API takes a half-open scalar range contained in one paragraph and refuses a split CRLF. A BidiLine's level getter takes a local logical offset; its visual_to_logical getter returns the original global source index. The line copies its storage and survives destruction of BidiText, just as BidiText survives destruction of its Utf8Text input.

Status0 is success,1 invalid configuration,2 payload budget exceeded,3 allocation failure,4 invalid index/range,5 invalid UTF8,6 table/algorithm failure. Failed owners report zero lengths and remain explicitly closeable. Close consumes ownership; no raw storage or borrowed payload escapes through these APIs. The gate also copies two unchanged negative templates into private paths and requires check and compilation to reject a second close with exact E039, without an emitted ELF. Slurm18424 qualifies these four rejection phases;18422 preserves the earlier harness diagnostic-code mismatch.

`unicode_bidi_mirroring(codepoint, level)` returns the mapped scalar plus a mirror_glyph flag. For odd levels, a mirrored glyph with no code-point mapping retains the original scalar and keeps the flag true for the renderer. Invalid scalars and levels outside0..126 return status1. This supplies L4 metadata while preserving scalar identities; it performs no normalization or font shaping.
