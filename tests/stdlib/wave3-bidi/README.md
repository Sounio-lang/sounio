The full gate is `scripts/stdlib/wave3_bidi_gate.sh FRESH_ABSOLUTE_OUTPUT`. It requires a scheduled Slurm job or identified official GitHub Actions context, qualified absolute `MADAROS_RAW_BIN` and `STDLIB_PLATFORM_LIBRARY`, and an isolated `ICU_PREFIX` for ICU79.1. Check, compile and execution are separately bounded. The gate hashes all source, the compiler, platform, oracle libraries, generated cases and executables, then rechecks them at exit. Every official case, all native controls, and the strict independent oracle remain mandatory. OFFICIAL_NATIVE_VERDICT records exact completed chunks/cases independently of ICU_CONFORMANCE_VERDICT; the aggregate status remains failed if either mandatory stage fails. There is no subset, runtime Unicode fallback, ICU exception list or acceptance mode that skips the canonical algorithm.

`wave3_bidi_generator.cpp` preserves all 861,948 official cases: 770,241 expanded BidiTest cases and 91,707 BidiCharacterTest cases, in 211 bounded binary chunks. Each record retains its source kind, source line, paragraph mode, code points, exact official levels (including X9's -1) and visual indices. The same native ELF runs every chunk in a private working directory. The generated wrong-level control changes the lone-AN expectation from2 to3 while preserving input and visual order; it must fail the unchanged native assertions.

`conformance.sio` checks every expected level, visual map, inverse map and paragraph base. It closes the input Utf8Text before accessing the result. `adversarial.sio` adds independent API controls for exact budgets, invalid UTF8, embedded NUL/source indices, P1 paragraph resets and CRLF, line-specific L1, rejection of cross-paragraph/split-CRLF lines, 300-deep explicit formatting, and Unicode18 BMP/supplementary mirror mappings. `smoke.sio` checks the basic owner/line lifetime and mirror composition. `api_edges.sio` checks empty owners, zero budgets, all four paragraph modes, strong-character selection over autoRTL fallback, invalid budgets/line indices and invalid mirroring inputs.

The official corpora explicitly cover through L2, excluding paragraph splitting and glyph rendering. The module supplies P1, per-line L1/L2 and L4 mirror metadata separately. L3 glyph attachment and font shaping are rendering-caller responsibilities; the result preserves scalar identities, logical indices and byte offsets. No normalization or glyph/font shaping is implicit.

ICU79.1's documented unidirectional optimization may return levels different from the full UBA. The independent oracle records those observations separately and requires exact official levels in every native case. It still requires all ICU visual maps and paragraph bases, and exact ICU levels for mixed text. That strict oracle currently FAILS on official BidiCharacterTest line61; it is not waived. Both ICU APIs agree on the differing levels/order with identity UTF16/scalar indices and default options. The bounded C++ X5a/X6a/I/L2 proof in `wave3_bidi_diagnostic.cpp` independently reproduces the official result; Slurm18328 additionally checks the dual RLI/LRO and nested PDI witnesses. This proof covers those three retained-L/R witnesses, not the full algorithm.
