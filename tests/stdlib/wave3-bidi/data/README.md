`current.bin` is the canonical 64-case ordinary-suite smoke bundle, generated by the C++23 `wave3_bidi_generator.cpp` as `SMOKE.bin`: the first32 nonempty-visible class cases and first32 character cases. It includes the explicit override/isolate witnesses. It is not the full-corpus gate. Full acceptance runs all211 generated chunks/all861948 cases.

The binary format is little endian: eight bytes `SBIDI18\\0`, versionu32=1, record-countu32; each record stores six u32 fields (scalar count, paragraph mode, resolved base, visual count, source kind, source line), followed by scalar-count code points, scalar-count levels (0xFFFFFFFF for X9), and visual-count logical indices. It preserves original row identities and exact expectations. The generator's bounded chunk size does not impose a production input limit.
