# stdlib/collections

Monomorphic collections (no generics - fixed types).

## Types
- `HeapI64Vec`, `HeapF64Vec`: Heap vectors
- `HashMap`, `HashSet`: Hash collections
- `Heap`: Binary heap
- `Deque`: Double-ended queue
- `BitSet`: Bitset
- `BTree`: B-tree
- `Trie`: Trie
- `Stack`: Fixed-capacity stack
