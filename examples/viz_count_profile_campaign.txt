Frozen B199 count-profile campaign report
=======================================

This example is a report of existing synthetic campaign observations. It does
not run a new campaign, fit a new model, estimate a rejection rate, pool B31,
change B199 or establish statistical calibration/validity.

Cohort selection was frozen on 2026-10-24 between 13:32:59Z and 13:33:11Z in
campaign_report_snapshot01. Only the original qualification_B199 batch0 of each
READY cell was copied. Seven cells were complete: all n16/n64 cells plus
n256/alpha0. Cells7/8 were not complete at selection and remain absent even if
the original campaign later finishes. The nine indices are fixed:
0/1/2=n16,3/4/5=n64,6/7/8=n256; within every group alpha=0,0.25,1.

Availability means CAL_RESULT status0, not process exit0, not LR sign and not
inferential validity. Every copied process has a terminal record and GNU wall
resource. Other result statuses are grouped as failed/unresolved. The C++ reader
checks dataset n/alpha/B199, all16 case identities, terminal/counter integrity,
process status, and original batch/cell summary availability/status counts.
P-values, rejection thresholds and the old summary's Wilson fields are NOT used
by this report.

The left panel includes true class-count zero for a complete cell. The right
panel masks a class with no observations instead of inventing a zero median.
Both panels mask entirely missing cells. Raw placeholders for missing cases are
-1; plotted masked storage is not an observation. Structured XML comments emit
NA for absent counts/medians.

Wall times are complete timed invocations from original GNU time resource files,
including wrapper/runtime work and early computational termination. They are
recorded at the resource's hundredth-second resolution. Median minutes are
conditional on the outcome class and cell. These are descriptive observations,
not an algorithm comparison or uncertainty interval. C++ parses elapsed values
as exact centiseconds and sorts by class. Sounio independently computes counts,
uses stats::dynamic_summaries to sort and obtain type7 q=0.5, and converts units.
The viewport upper is explicitly supplied by the C++ caller: the next whole
minute above the largest exact class median, at least1. The renderer does not
autorange or change the data. Counts use the declared0..16 domain.

The checker compares Sounio numeric payloads against raw observations BEFORE
projection, then verifies every SVG mark, provenance, class masks, colors,
footprints and text bounds. It checks a real Canvas pixel and rejects altered
copies of counts, a median and a missing mark. Default stdout is a complete SVG
with structured XML comments and a completion comment; no plain debug output.
Optional SOUNIO_VIZ_CANVAS_DUMP=1 emits the actual Canvas RLE afterward, for
scientific_canvas_export.cpp. That diagnostic export stream is not a standalone
XML document. PNG is decoded from native pixels, not redrawn from SVG.
