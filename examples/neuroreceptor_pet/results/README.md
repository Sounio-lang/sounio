# results/

This directory is reserved for numerical outputs, generated TAC curves, sensitivity profiles, and figures produced by `pet_2tcm_epistemic.sio`.

At present it contains no fabricated data. All results must be generated by running the example with the current Sounio compiler.

Future contents may include:
- JSON summary of GUM results (`pet_2tcm_gum_summary.json`)
- CSV time-activity curves for reference and perturbed runs
- Sensitivity heatmaps (when visualization support is added)
- Reproducibility manifests for NRM 2026 submission

**Policy**: Do not commit fabricated or hand-tuned numerical results. All outputs must be traceable to a specific compiler artifact and random seed (if stochastic components are later introduced).

See root `README.md` for scientific context and limitations.
