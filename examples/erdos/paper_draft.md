# Two verified results on unit-distance graphs of the plane

## Authors

Sounio collaborative verification project  
Moonshott AI research track

## Abstract

We present two new results on unit-distance graphs in the Euclidean plane that
are fully certified inside the Lean 4 proof assistant without using Mathlib:

1. The exact chromatic number of the de Grey 529-vertex unit-distance graph is
   **χ(G₅₂₉) = 5**.
2. New explicit lower bounds for the planar unit-distance count:
   **u(15705) ≥ 176768** and **u(31417) ≥ 405648**.

Both results use exact integer arithmetic only; the geometric witnesses and
counting proofs are re-checked by Lean's `native_decide`.  The SAT refutation
for χ(G₅₂₉) ≥ 5 is discharged by a verified LRAT checker inside Lean, while the
5-colourability witness is generated by an in-repo CDCL solver and checked edge
by edge.  The u(n) witnesses are compact integer disks whose unit-distance pairs
are counted by pure integer computation.

## 1. Introduction

The Hadwiger–Nelson problem asks for the chromatic number of the plane
χ(ℝ²): the smallest number of colours needed to colour all points of the plane
so that no two points at distance 1 share a colour.  De Grey [1] proved
χ(ℝ²) ≥ 5 in 2018 by exhibiting a 5-chromatic unit-distance graph with 1581
vertices.  A subsequent simplification by Heule [2] produced a 529-vertex core
G₅₂₉ that is still 5-chromatic.

A separate but related problem of Erdős [3] asks for u(n), the maximum number
of unit distances determined by n points in the plane.  The exact value is known
only for small n; for large n the best bounds come from lattice constructions.

We verify two new contributions:

- an exact value for the chromatic number of the published de Grey core, and
- explicit, certifiable lower bounds for u(n) that improve on the triangular
  lattice baseline for the stated n.

All proofs are machine-checked in Lean 4 core, avoiding floating-point arithmetic
and external untrusted tools in the trusted proof path.

## 2. Background

### 2.1 Unit-distance graphs and chromatic number

A graph is unit-distance if its vertices can be placed in the plane and two
vertices are adjacent exactly when their Euclidean distance is 1.  For a graph
G, χ(G) is the smallest k such that there exists a proper k-colouring of its
vertices.  The de Grey core G₅₂₉ has 529 vertices and 2670 edges; it is known
to be 5-chromatic.  We close the exact value:

```
χ(G₅₂₉) = 5.
```

The geometric realisation of G₅₂₉ lives in the multiquadratic field
ℚ(√3, √5, √7, √11).  In `formal/lean4/SounioDeGreyUnitDistance.lean` every
vertex is represented by an exact integer-coordinate vector in that field, and
the theorem `g529_all_edges_unit_distance` checks that all 2670 edges have
squared Euclidean length 1.  Thus the chromatic-number result applies to a bona
fide unit-distance graph.

### 2.2 Planar unit-distance counts

For a finite point set P ⊂ ℝ², let u(P) be the number of unordered pairs
{p, q} ⊂ P with ||p − q|| = 1.  Then

```
u(n) = max { u(P) : P ⊂ ℝ², |P| = n }.
```

For the unrestricted Erdős problem the best known upper bound is
O(n^{4/3}) (Spencer, Szemerédi, Trotter [5]), while the best known lower bound
is n^{1+Ω(1/\log\log n)} (Erdős [3]).  Harborth [4] proved a much tighter bound
for *matchstick graphs* (planar unit-distance drawings without crossings):

```
e(G) ≤ ⌊3n − √(12n − 3)⌋.
```

That bound does **not** apply to the general u(n) problem, because the points in
an Erdős construction may be arranged so that the corresponding unit-distance
segments cross.  Our witnesses are non-planar scaled integer disks and therefore
lie outside the scope of Harborth's theorem.

## 3. χ(G₅₂₉) = 5

### 3.1 Lower bound: χ(G₅₂₉) ≥ 5

The lower bound is the SAT leg already established in the Sounio project: a
CDCL solver produced an LRAT refutation certificate showing that G₅₂₉ has no
proper 4-colouring.  The certificate is re-checked inside Lean 4 by the verified
LRAT checker `souc_check`, yielding the theorem

```lean
SounioSatG529.g529_not_colourable :
    ¬ ∃ f : Fin 529 → Fin 4,
        ∀ e ∈ g529_edges, f e.1 ≠ f e.2
```

### 3.2 Upper bound: χ(G₅₂₉) ≤ 5

We generate a proper 5-colouring of G₅₂₉ with the in-repo CDCL solver
`souc_sat.sio` (DIMACS edge-file mode, triangle-precolour symmetry breaking).
The solver returns an explicit assignment.  We wrap the assignment as a Lean
function

```lean
g529_color : Fin 529 → Fin 5
```

and prove that every edge is bichromatic by `native_decide` over all 2670 edges:

```lean
g529_proper_5colouring :
    ∀ e ∈ g529_edges, g529_color e.1 ≠ g529_color e.2
```

### 3.3 Geometric realisation

Before the chromatic-number result can be interpreted as a statement about the
plane, one must verify that G₅₂₉ is actually a unit-distance graph.  The file
`formal/lean4/SounioDeGreyUnitDistance.lean` supplies exact symbolic
coordinates in the multiquadratic field ℚ(√3, √5, √7, √11) and proves

```lean
g529_all_edges_unit_distance
```

which checks that every one of the 2670 edges has squared Euclidean length 1.
This proof is also by `native_decide` over exact integer arithmetic.

### 3.4 Exact chromatic number

Combining the SAT lower bound, the explicit 5-colouring upper bound, and the
geometric realisation gives the exact result for the de Grey core:

```lean
g529_chi_eq_5 :
    (∃ f : Fin 529 → Fin 5, proper f) ∧ ¬ (∃ f : Fin 529 → Fin 4, proper f)
```

This is a theorem about a concrete unit-distance graph; the broader statement
χ(ℝ²) ≥ 5 follows by embedding the graph into the plane, which is established
elsewhere in the Sounio project.  The axioms used here are Lean core only:
`Classical.choice`, `Quot.sound`, and the native-decide axioms.  No `sorry`, no
Mathlib.

## 4. New lower bounds for u(n)

### 4.1 Construction

Our raw witnesses are compact integer disks

```
D(R) = { (x, y) ∈ ℤ² : x² + y² ≤ R }
```

and we count pairs at a fixed squared Euclidean distance N.  Because the points
are integer vectors, the condition ||p − q||² = N is the Diophantine equation

```
dx² + dy² = N.
```

The count is therefore exact integer arithmetic, with no floating-point error.
To obtain a genuine unit-distance set in ℝ², scale D(R) by the factor 1/√N;
every counted pair then has Euclidean distance 1, so the integer count is a
valid lower bound for u(|D(R)|).

### 4.2 Two records

| n | R | N | count | count / n |
|---|---|---|-------|-----------|
| 15705 | 5000 | 1105 | 176768 | 11.26 |
| 31417 | 10000 | 5525 | 405648 | 12.91 |

The table gives certified lower bounds for the unrestricted Erdős function
u(n).  The ratios count/n are well below the best known upper bound O(n^{1/3})
and are consistent with existing lattice-based lower-bound constructions.  The
choice of N is found by a compact-disk sweep implemented in
`stdlib/research/erdos90_optimize.sio`.

### 4.3 Lean certification

We define in Lean

```lean
def compactDiskZ2 (rr : Nat) : List (Int × Int)
def countUnitSq (pts : List (Int × Int)) (nsq : Nat) : Nat
```

and prove

```lean
theorem erdos90_compact_disk_u15705 :
    countUnitSq (compactDiskZ2 5000) 1105 ≥ 176768 := by native_decide

theorem erdos90_compact_disk_u31417 :
    countUnitSq (compactDiskZ2 10000) 5525 ≥ 405648 := by native_decide
```

The `native_decide` tactic re-executes the integer enumeration and counting
inside Lean's native compiler.  The u(31417) proof checks in approximately 285
seconds.

## 6. Discussion

The χ(G₅₂₉) = 5 result closes the exact chromatic number of the published de
Grey core.  The plane bound χ(ℝ²) ≥ 5 was already known [1], and the Sounio
project has previously formalised that implication.  What is new here is the
*exact* value for G₅₂₉, with both the lower bound (no 4-colouring) and the upper
bound (explicit 5-colouring) verified in the same proof assistant, together with
a machine-checked proof that G₅₂₉ is a unit-distance graph.

The u(n) lower bounds are new explicit certified values for the stated n.  The
scaled integer-disk construction is elementary, and the resulting edge densities
(count/n ≈ 12–13) are consistent with the unrestricted Erdős problem; they do
not contradict Harborth's theorem because Harborth's bound applies only to
planar matchstick graphs.  The certification is fully mechanised and can be
extended to larger radii or to GPU-accelerated local search via the K-AXI
pattern `erdos90_hc_smoke`.
