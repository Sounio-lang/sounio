## 1. χ(G₅₂₉) = 5

### Statement

The de Grey unit-distance graph `G₅₂₉` (529 vertices, 2670 edges) has chromatic
number exactly 5.

### Proof ingredients

- **UNSAT leg:** `SounioSatG529.g529_not_colourable` proves that no function
  `Fin 529 → Fin 4` properly colours all edges.  The proof comes from a SAT
  refutation certificate discharged inside Lean via `native_decide`.
- **SAT leg:** `SounioDeGreyChi529Exact.g529_proper_5colouring` exhibits a
  concrete proper 5-colouring and verifies every edge with `native_decide`.
- **Conjunction:** `DeGrey529.g529_chi_eq_5` combines the two legs.

### Lean file

`formal/lean4/SounioDeGreyChi529Exact.lean`

### Reproduction

```bash
cd /workspace/sounio
examples/erdos/gen_g529_5coloring.sh
```

The script recompiles `examples/erdos/souc_sat.sio`, solves the 5-colouring,
validates it, emits the Lean file, and runs `lake build
SounioDeGreyChi529Exact`.

### Axioms

`#print axioms g529_chi_eq_5` reports `Classical.choice`, `Quot.sound`, and the
native-decide axioms only. No Mathlib, no `sorry`.

## 2. u(15705) ≥ 176768

### Statement

Among `n = 15705` points in the plane there exist at least `176768` pairs at
unit distance.  Equivalently, the planar unit-distance count satisfies

```
u(15705) ≥ 176768.
```

### Construction

The witness is the compact integer disk

```
{ (x, y) ∈ ℤ² : x² + y² ≤ 5000 }
```

which contains exactly 15705 lattice points.  The distance counted is the
squared Euclidean norm `N = 1105`, i.e. `dx² + dy² = 1105`.  Scaling the whole
configuration by `1/√1105` turns every such pair into a Euclidean unit-distance
pair, so the integer count is a valid lower bound for `u(15705)`.  (Harborth's
`tight` bound `⌊3n−√(12n−3)⌋` applies to *planar matchstick graphs*; our scaled
integer disks contain crossings and therefore lie outside that special case.)

### Verification

`formal/lean4/SounioErdos90PlanarLowerBound.lean` defines

- `compactDiskZ2 rr` — lists all integer points inside radius² = rr;
- `countUnitSq pts nsq` — counts unordered pairs at squared distance nsq;
- `erdos90_compact_disk_u15705` — the theorem
  `countUnitSq (compactDiskZ2 5000) 1105 ≥ 176768`.

The proof is by `native_decide`, which re-executes the integer arithmetic
inside Lean core.

### Reproduction

```bash
cd /workspace/sounio/formal/lean4
lake build SounioErdos90PlanarLowerBound
```

The computational search that discovered the witness can be reproduced with
`stdlib/research/erdos90_optimize.sio` (now re-enabled for the `lean_single`
compiler):

```bash
cd /workspace/sounio
./bin/souc-lean-single-x86_64 stdlib/research/erdos90_optimize.sio /tmp/opt.elf
/tmp/opt.elf   # sweep rr = 50 .. 10000
```

A run with rr = 50 .. 5000 produced `n = 15705, count = 176768`.
A full sweep to rr = 10000 produced the larger record `n = 31417, count = 405648`
with distance² = 5525.  The same sweep was reproduced independently on a Slurm
cluster node via `examples/erdos/erdos90_optimize_rr10000_bundle2.sbatch`, with
identical final record.

## 3. u(31417) ≥ 405648

### Statement

Among `n = 31417` points in the plane there exist at least `405648` pairs at
unit distance:

```
u(31417) ≥ 405648.
```

### Construction

The witness is the compact integer disk

```
{ (x, y) ∈ ℤ² : x² + y² ≤ 10000 }
```

which contains exactly 31417 lattice points.  The distance counted is the
squared Euclidean norm `N = 5525`, i.e. `dx² + dy² = 5525`; scaling by

### Verification

`formal/lean4/SounioErdos90PlanarLowerBound.lean` contains the theorem

```lean

    countUnitSq (compactDiskZ2 10000) 5525 ≥ 405648
```
