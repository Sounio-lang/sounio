## 私たちの約束

私たちは、Sounio プロジェクトに参加されるすべての方々に対して、開放的で歓迎する多様性があり、包摂的で健全なコミュニティを育むことに取り組んでおります。

## コミュニティ基準

肯定的な環境に寄与する行動の例:

* 他者に対して共感と親切を示すこと
* 異なる意見、見解、経験を尊重すること
* 建設的なフィードバックを与え、優雅に受け入れること
* 私たちのミスに対して責任を認め、謝罪すること
* 全体のコミュニティにとって最善のことに焦点を当てること
* 歓迎的で包摂的な言語を使用すること

受け入れがたい行動の例:

* 不適切な言語やイメージの使用
* 荒らし行為、侮辱的または中傷的なコメント、および個人的な攻撃
* あらゆる種類の公的または私的な嫌がらせ
* 明示的な許可なく他者の私的情報を公開すること
* 専門的な環境で合理的に不適切と見なされる可能性のあるその他の行動

## 責任

プロジェクトのメンテナーは、私たちの受け入れ可能な行動の基準を明確化し、施行する責任を負っております。不適切と判断されるあらゆる行動に対して、適切かつ公正な是正措置を取ります。

プロジェクトのメンテナーは、これらのガイドラインに沿わないコメント、コミット、コード、ウィキ編集、イシュー、およびその他の貢献を削除、編集、または拒否する権利と責任を有しております。また、適切な場合にモデレーション決定の理由を伝えます。

## 適用範囲

これらのガイドラインは、以下のすべてのコミュニティスペースに適用されます:

* GitHub リポジトリ(イシュー、プルリクエスト、ディスカッション)
* 公式コミュニケーション・チャネル(メーリングリスト、チャット、フォーラム)
* 個人がプロジェクトを代表する公的イベント
* Sounio コミュニティに反映するあらゆるスペース

## 施行

受け入れがたい行動の事例は、施行を担当するコミュニティリーダーに conduct@souniolang.org まで報告可能です。すべての苦情は迅速かつ公正に審査・調査されます。

すべてのコミュニティリーダーは、あらゆるインシデントの報告者のプライバシーとセキュリティを尊重する義務を負っております。

## 施行ガイドライン

コミュニティリーダーは、違反に対する結果を決定する際に、これらのガイドラインに従います:

### 1. 修正

**コミュニティへの影響**: 不適切な言語の使用またはその他の非専門的な行動。

**結果**: コミュニティリーダーからの私的な書面による警告。不適切性の性質を明確にし、行動がなぜ不適切であったかを説明します。公的な謝罪を求める場合があります。

### 2. 警告

**コミュニティへの影響**: 単一のインシデントまたは一連の行動による違反。

**結果**: 継続的な行動に対する警告と結果の指定。指定期間、関与した人々との交流を禁止します。これにはコミュニティスペースおよび外部チャネルでの交流の回避が含まれます。これらの条件に違反した場合、一時的または永久的な制限につながる可能性があります。

### 3. 一時的な制限

**コミュニティへの影響**: コミュニティ基準の重大な違反、持続的な不適切な行動を含む。

**結果**: 指定期間、コミュニティとのあらゆる交流または公的コミュニケーションの一時的な制限。この期間中、関与した人々との公的または私的な交流は許可されません。これらの条件に違反した場合、永久的な制限につながる可能性があります。

### 4. 永久的な制限

**コミュニティへの影響**: コミュニティ基準の違反のパターン、持続的な不適切な行動、または個人に対する攻撃性を示す。

**結果**: コミュニティ内でのあらゆる公的交流の永久的な制限。

## 帰属

これらのコミュニティガイドラインは、[Contributor Covenant](https://www.contributor-covenant.org)、バージョン 2.1 を基に改変したものであり、https://www.contributor-covenant.org/version/2/1/code_of_conduct.html で入手可能です。

コミュニティへの影響ガイドラインは、[Mozilla's code of conduct enforcement ladder](https://github.com/mozilla/diversity) から着想を得ております。

この行動規範に関する一般的な質問への回答については、https://www.contributor-covenant.org/faq の FAQ をご覧ください。
