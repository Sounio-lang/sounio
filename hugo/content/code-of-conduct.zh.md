## 我们的承诺

我们致力于为参与 Sounio 项目的每个人营造一个开放、欢迎、多元、包容和健康的环境。

## 社区标准

有助于营造积极环境的示例行为:

* 对他人表现出同理心和善意
* 尊重不同的意见、观点和经历
* 给予并优雅地接受建设性反馈
* 承担责任并在犯错时道歉
* 关注整体社区的最佳利益
* 使用欢迎和包容的语言

不可接受行为的示例:

* 使用不适当的语言或图像
* 喷子行为、侮辱或贬低性评论,以及人身攻击
* 任何形式的公开或私下骚扰
* 在未经明确许可的情况下发布他人的私人信息
* 其他在专业环境中合理被视为不适当的行为

## 责任

项目维护者负责澄清和执行我们可接受行为的标准,并将针对他们认为不适当的任何行为采取适当和公平的纠正措施。

项目维护者有权和责任移除、编辑或拒绝不符合这些指南的评论、提交、代码、维基编辑、问题和其他贡献,并在适当的时候传达审核决定的原因。

## 范围

这些指南适用于所有社区空间,包括:

* GitHub 仓库(问题、拉取请求、讨论)
* 官方通信渠道(邮件列表、聊天、论坛)
* 个人代表项目的公共活动
* 任何行为反映 Sounio 社区的空间

## 执行

不可接受行为的实例可以报告给负责执行的社区领导者,邮箱:conduct@souniolang.org。所有投诉将得到及时和公平的审查和调查。

所有社区领导者都有义务尊重任何事件报告者的隐私和安全。

## 执行指南

社区领导者在确定违规后果时将遵循这些指南:

### 1. 纠正

**社区影响**: 使用不适当的语言或其他不专业行为。

**后果**: 来自社区领导者的私人书面警告,提供违规性质的清晰说明以及为什么行为不适当的解释。可能要求公开道歉。

### 2. 警告

**社区影响**: 通过单一事件或一系列行动的违规。

**后果**: 对持续行为的警告。指定期间不得与涉事人员互动。这包括避免在社区空间以及外部渠道的互动。违反这些条款可能导致临时或永久限制。

### 3. 临时限制

**社区影响**: 严重违反社区标准,包括持续的不适当行为。

**后果**: 指定期间临时限制与社区的任何互动或公共通信。在此期间,不允许与涉事人员的公开或私人互动。违反这些条款可能导致永久限制。

### 4. 永久限制

**社区影响**: 显示出违反社区标准的模式,包括持续的不适当行为,或对个人的攻击性。

**后果**: 永久限制社区内的任何公共互动。

社区影响指南受 [Mozilla's code of conduct enforcement ladder](https://github.com/mozilla/diversity) 的启发。

有关此行为准则的常见问题解答,请参阅 https://www.contributor-covenant.org/faq 中的 FAQ。
