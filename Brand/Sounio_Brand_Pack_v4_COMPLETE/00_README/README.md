# Sounio Language — Brand Pack v4 (Complete)

This pack fixes the two issues that usually break “real-world usability”:

1) **Text fidelity**: the emblem badge and lockups are delivered as **SVG masters** with clean typography and correct URL (**souniolang.org**).
2) **Scalability**: the icon mark ships as a master + a full size set + favicon.ico, and stamps ship in 1‑color variants.

## Folder map
- `01_LOCKUPS_OPTIONC/` — lockups (SVG + PDF + PNG), Option C typography (GFS Neohellenic / DejaVu Sans Mono / EB Garamond Italic)
- `02_EMBLEM_BADGE/` — circular badge with **curved text** and perfect URL, SVG master + PNG renders
- `03_ICON_MARK/` — icon master + sizes + favicon.ico + background variants
- `04_STAMPS/` — 1‑color stamps (icon + emblem), transparent + on-white + on-navy
- `05_ORIGINAL_ARTWORKS/` — the photoreal mascots and earlier artworks (for hero sections / merch)

## Trademark-grade “finalisation”
Open any SVG in Inkscape/Illustrator and convert text to outlines/paths before printing/registration.
