# 圖像及渲染

Sounio 目前在此庫快照中擁有兩個真實的圖像家族：終端機原生科學顯示在 `examples/graphics/` 以及軟件光栅化圖像輸出在 `examples/render/`。
這些光栅化預覽是從檢查的 JIT 物件的標準輸出生成的，然後提交為網站的 SVG 資產。
此頁面現在展示了五個真實的光栅化預覽，而非兩個孤立的樣本。

## 為什麼要使用這個圖形堆棧？

- **真實編譯器輸出**：上圖的矢量化部分來自已檢查的 `souc run` 輸出，而非螢幕截圖
- **可攜輸出格式**：終端演示使用 Unicode/ANSI；矢量化演示輸出純文本的 PPM
- **無視窗依賴**：目前範例並無需要 X11、OpenGL 或 GUI 工具庫
- **SSH 友好**：終端和文件基準渲染均可在遠端系統上運行
