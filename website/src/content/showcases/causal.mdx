# Causal Inference with Sounio

Sounio treats causality as a type-system concern. `Intervention<T>` and `Counterfactual<T>` are first-class epistemic types — not library conventions.

## Causal Intervention: do(X=x)

```sio
// Express a causal intervention: do(Treatment = active)
let treated: Intervention<bool> = intervene(true)

// .epsilon carries causal confidence
if treated.epsilon > 0.90 {
    run_rct_arm(treated)
}
```

## Counterfactual Reasoning

```sio
// What earnings would Alice have had with education?
let cf: Counterfactual<f64> = counterfactual(
    observed: 30000.0,
    under: education_iv
)

if cf.epsilon > 0.90 {
    report_finding(cf)  // confidence-gated causal claim
}
```
