# Επαφή Αιτίωσης με Σουνιό

Σουνιό τρέχει την αιτίωση ως πρόβλημα συστήματος. `Intervention<T>` και `Counterfactual<T>` είναι τύποι συνθηκευόμενους — όχι διαδοχαίους της βιβλιοθήκης.

## Διάγραμμα Αιτίωσης με την δο-τελευταία της Pearl

```sio
// Εκτελέστε ένα Διάγραμμα Αιτίωσης με απόρρωση στοιχείων
var dag = causal_dag_new()
dag = dag_add_node(dag, 0)  // διάγραμμα αιτίωσης
dag = dag_add_node(dag, 1)  // αποτέλεσμα
dag = dag_add_edge(dag, 0, 1,
    ec_beta_new(8.0, 2.0), 0.5, 0.1)

// Την δο-τελευταία της Pearl απορρωσεύεται τους διάλεξεις
let intervened = do_intervention(dag, 1)
```

## Μέσος Εφαρμένος Εντοπισμός Αιτίωσης

```sio
// Ηλικτερνιστεί το ATE με απόρρωση
let ate = average_treatment_effect(dag, 0, 1)
```
