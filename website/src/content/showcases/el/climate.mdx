# Κλιματική επιστήμη με το Sounio

## Συνοπτική ανάγνωση

Αυτή η διαδρομή υπάρχει για να δείξει ότι το Sounio δεν αφορά μόνο ταχύτερους υπολογισμούς. Αφορά την άρνηση μετατροπής ασταθών τεκμηρίων σε έναν καθαρό αριθμό έτοιμο για πολιτική χρήση.

Το λογισμικό κλιματικής μοντελοποίησης είναι ένα καλό stress test, επειδή τιμωρεί την προσποίηση. Μπορείτε πάντα να δημοσιεύσετε άλλη μία προβολή. Η δυσκολότερη πειθαρχία είναι να αποφασίσετε πότε το εύρος του ensemble, η διαφωνία των μοντέλων ή η ποιότητα των δεδομένων έχουν γίνει τόσο αδύναμα, ώστε το πρόγραμμα να μην μπορεί πλέον να μιλά με ψευδή βεβαιότητα.

Αυτό είναι το επιχείρημα: η γλώσσα πρέπει να βοηθά τον επιστημονικό κώδικα να σταματά, να περιορίζει το πεδίο εφαρμογής του ή να δηλώνει άρνηση **πριν** η αβεβαιότητα «ξεπλυθεί» σε έναν τακτοποιημένο πίνακα ελέγχου.

## Τι προσπαθεί να αποδείξει αυτή η διαδρομή

Το Sounio πρέπει να είναι χρήσιμο σε ροές εργασίας όπου η σωστή απάντηση είναι μερικές φορές «μην προσποιείσαι ακόμη ότι αυτή η εκτίμηση είναι κατάλληλη για λήψη απόφασης».

Η διαδρομή του κλίματος αφορά επομένως την πειθαρχία της άρνησης:

- η συνάθροιση ensemble πρέπει να διατηρεί την αβεβαιότητα αντί να την ισοπεδώνει
- το επόμενο λογισμικό πρέπει να βλέπει την ιστορία εμπιστοσύνης και όχι μόνο τον μέσο όρο
- η αύξηση της διακύμανσης πρέπει να μπορεί να περιορίζει ή να σταματά έναν υπολογισμό
- ο χρήστης πρέπει να διακρίνει μια πρόβλεψη με όρια από μια καλοδουλεμένη προσποίηση

Αν η γλώσσα δεν μπορεί να υποστηρίξει αυτή τη στάση, τότε όλη η «επιστημολογική» ρητορική είναι διακοσμητική.

## Τι πρέπει να ρωτήσει ένας δύσπιστος αναγνώστης

- Είναι αυτό απλώς άλλο ένα wrapper αβεβαιότητας γύρω από συνηθισμένο αριθμητικό κώδικα;
- Δείχνει η διαδρομή πώς διαδίδεται η διαφωνία ή απλώς την αναφέρει;
- Επιτρέπεται στο πρόγραμμα να αρνηθεί ένα αποτέλεσμα ή απλώς το σχολιάζει εκ των υστέρων;
- Η αξίωση αφορά την ίδια την κλιματική επιστήμη ή την πειθαρχία του λογισμικού;

Η απάντηση πρέπει να είναι το δεύτερο: αυτή η διαδρομή δεν ισχυρίζεται ότι αντικαθιστά ένα πλήρες κλιματικό εργαστήριο. Ισχυρίζεται ότι το επιστημονικό λογισμικό πρέπει να κάνει τα όριά του ευανάγνωστα πριν αυτά μετατραπούν σε λάθη δημόσιας πολιτικής.

## Συνάθροιση ensemble

```sio
struct EpistemicValue {
    value: f64,
    variance: f64,
    conf_alpha: f64,
    conf_beta: f64
}

fn ensemble_mean_5(
    m1: EpistemicValue,
    m2: EpistemicValue,
    m3: EpistemicValue,
    m4: EpistemicValue,
    m5: EpistemicValue
) -> EpistemicValue {
    let n = 5.0
    let mean_value = (m1.value + m2.value + m3.value + m4.value + m5.value) / n
    let within_var = (m1.variance + m2.variance + m3.variance + m4.variance + m5.variance) / n

    // ... between variance calculated ...
    let total_var = within_var + between_var

    return EpistemicValue {
        value: mean_value,
        variance: total_var,
        conf_alpha: 1.0,
        conf_beta: 1.0
    }
}
```

Το παράδειγμα δεν υποστηρίζει ότι ο μέσος όρος είναι κάτι καινούργιο. Το σημείο είναι ότι η επιφάνεια συνάθροισης κρατά ζωντανή την ιστορία της αβεβαιότητας, αντί να την αντιμετωπίζει ως προαιρετικά μεταδεδομένα που μπορούν να απορριφθούν μόλις ο αριθμός γίνει αρκετά όμορφος.

## Γιατί έχει σημασία για τη γλώσσα

Το κλίμα είναι ένα από τα πιο καθαρά πεδία όπου το «παράγε πάντα μια απάντηση» μετατρέπεται σε πολιτικό τρόπο αποτυχίας.

Αν η στοίβα λογισμικού σας είναι βελτιστοποιημένη μόνο για να συνεχίζει να εκδίδει αριθμούς, γίνεται πολύ εύκολο να συγχέετε τη συνέχεια της εξόδου με τη συνέχεια της γνώσης. Μια γλώσσα που παίρνει στα σοβαρά την αβεβαιότητα πρέπει να δίνει στα προγράμματα μια άλλη επιλογή: να περιορίζουν το πεδίο εφαρμογής, να εμφανίζουν τη διαφωνία ή να σταματούν.

Γι’ αυτό αυτή η διαδρομή βρίσκεται δίπλα στη GPU και τη νευροαπεικόνιση στη δημόσια παρουσίαση. Δεν βρίσκεται εδώ για ποικιλία θεμάτων. Βρίσκεται εδώ επειδή τα πεδία όπου η άρνηση αποτελεί μέρος της επάρκειας διαμορφώνουν τη γλώσσα.

## Τι θα έπειθε έναν δύσπιστο αναγνώστη

- μια ορατή διαδρομή από τις τιμές που φέρουν αβεβαιότητα έως τις αποφάσεις που ακολουθούν
- παραδείγματα όπου η αύξηση του εύρους αλλάζει τη ροή ελέγχου και όχι μόνο το κείμενο
- ειλικρινής τεκμηρίωση της σημερινής, περιορισμένης κλιματικής επιφάνειας
- σαφής διάκριση ανάμεσα σε «ενδιαφέρουσα ερευνητική πίεση» και «παραγωγική πλατφόρμα πρόγνωσης»

Αυτό είναι το πρότυπο με το οποίο πρέπει να αξιολογείται η διαδρομή.

## Πού παραμένει το όριο

Αυτή η διαδρομή **δεν** ισχυρίζεται:

- ότι το Sounio είναι ήδη πλήρης πλατφόρμα κλιματικής μοντελοποίησης
- ότι τα σημερινά παραδείγματα αντικαθιστούν μια πλήρη στοίβα πρόγνωσης
- ότι κάθε επιστημονική ροή εργασίας έχει ήδη κωδικοποιηθεί με έλεγχο ροής που γνωρίζει να αρνείται

Η αξίωση είναι στενότερη: η κλιματική πίεση δείχνει γιατί το επιστημονικό λογισμικό χρειάζεται μια γλώσσα που διατηρεί την αβεβαιότητα και σταματά να μιλά όταν τα τεκμήρια δεν δικαιολογούν πλέον μια καθαρή απάντηση.
