# Κβαντική υπολογιστική με το Sounio

Το Sounio επιβάλλει το θεώρημα μη κλωνοποίησης της κβαντομηχανικής **κατά τη μεταγλώττιση**, μέσω γραμμικών τύπων: ένα `Qubit` είναι γραμμικός πόρος που πρέπει να καταναλωθεί ακριβώς μία φορά. Η προσπάθεια αντιγραφής του προκαλεί σφάλμα μεταγλώττισης.

## Γραμμικοί τύποι για κβαντικές καταστάσεις

```sio
// A Qubit cannot be cloned.
// standard quantum gates (H, X, Y, Z, CNOT) consume and return Qubits.

fn apply_hadamard(q: Qubit) -> Qubit {
    // apply H gate ...
}

struct QubitPair { fst: Qubit, snd: Qubit }

fn apply_cnot_pair(control: Qubit, target: Qubit) -> QubitPair {
    // apply CNOT gate ...
}

fn bell_state() -> QubitPair {
    let q1 = allocate_qubit()
    let q2 = allocate_qubit()

    let h1 = apply_hadamard(q1)
    let pair = apply_cnot_pair(h1, q2)

    pair
}
```
