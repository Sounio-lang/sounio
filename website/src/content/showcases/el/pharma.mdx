# Φαρμακομετρικές με την Επισκόπηση

Την Επισκόπηση προσφέρει μία δυνατή πλατφορμά για μοδελοποίηση φαρμακομετρικών, επιτρέποντας οπτιμισμό δόσεων φάρμακου με συνεπιτροπή εξαιρέσεων.

## Χρησιμοποίηση της GUM για Διανόμιση Βανκομυκιν

Η κατασκευή `Knowledge` της Επισκόπησης περιέχει νομίμους τιμές περισσότερες (`ε`) που προκαλούν προπαγάνδρευση στις υπολογισμούς.

```sio
// 15 mg/kg/day: Επίσημο Επίσταση Ε1A (Μετάναλυση Μετάδουσεων ΡΧΤ, 18 κέντρα, n=2204)
// Ε=0.92 ανταποδίδει την υψική ποιότητα της επίστασης με ιδιωτική διαφορά ανά πατιέντα.
let base_dose: Knowledge<f64> = Knowledge(15.0, ε=0.92, prov="ASHP_2020_Level1A_RCT")

// Μητροποίηση στοιχείου γυμνοθήκης του Ιστοτρόπου: ±0.5 kg σε πατιέντα 78.5 kg → ε=0.98 (εκκαλυπτημένο σύστημα).
let weight: Knowledge<f64> = Knowledge(78.5, ε=0.98, prov="hospital_scale_calibrated")
let ref_wt: Knowledge<f64> = Knowledge(70.0, ε=1.0)

// Η προπαγάνδρευση GUM είναι αυτόματη: ε(a/b) = ε(a)×ε(b) κατά διάφορες ανεξάρτητες.
let weight_factor: Knowledge<f64> = weight / ref_wt
let dose1: Knowledge<f64> = base_dose * weight_factor
// ε(dose1) ≈ 0.92 × 0.98 × 1.0 = 0.9016
```

## Εξαίρεσεις Ασφάλειας

Μπορείτε να επιβεβαιώσετε ασφάλεια ορίους στην εκκαλύψη χρησιμοποιώντας την περισσότερη πιστώση.

```sio
let conf_dose = dose3.ε

if conf_dose >= 0.82 {
    println("  ΠΡΟΣΚΕΥΗΣΗ: πιστώση πηραμένου παραλήπτους δόσεων επιτρέπεται")
} else {
    println("  ΑΞΗΡΗΜΕΥΕΤΗΣ: επιβεβαιώστε την τιμή της CrCl (CV Χρονική Μετάδουση Μετά την Γαλτ) για να είναι επίσης υψική")
}
```
