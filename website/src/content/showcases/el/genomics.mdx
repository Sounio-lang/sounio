# Γονιδιωματική και βιοπληροφορική με το Sounio

Το Sounio προσφέρει βασικούς αλγορίθμους για μετασχηματισμούς αλληλουχιών.

## Τελεστές αλληλουχιών

```sio
// Complement a single base (XOR with 0b11)
fn complement_base(b: u8) -> u8 {
    return b ^ 3
}

// Complement entire sequence
fn complement(seq: &[u8]) -> [u8] {
    return seq.map(|b| b ^ 3)
}

// Reverse complement
fn reverse_complement(seq: &[u8]) -> [u8] {
    let rev = seq.reverse()
    return rev.map(|b| b ^ 3)
}
```
