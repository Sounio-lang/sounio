# Γενομική & Βιοινουρηματική με Σουνιό

Σουνιό προσφέρει κεντρικούς τεχνολογίες για μετατροπές σειρας.

## Ορισμοί Σειράς

```sio
// Καταναλώστε τον ενός βασιδίου (ΧΟΡΙζόμενο με 0b11)
fn καταναλώστε_βασιδίο(b: u8) -> u8 {
    return b ^ 3
}

// Καταναλώστε την όλη σειρά
fn καταναλώστε(seq: &[u8]) -> [u8] {
    return seq.map(|b| b ^ 3)
}

// Αντικαταναλώστε καταναλώστε
fn αντικαταναλώστε(seq: &[u8]) -> [u8] {
    let rev = seq.reverse()
    return rev.map(|b| b ^ 3)
}
```
