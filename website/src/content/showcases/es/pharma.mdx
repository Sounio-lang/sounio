# Farmacometría con Sounio

Sounio ofrece una plataforma potente para la modelación farmacometría, permitiendo la optimización del dosaje de medicamentos con manejo riguroso de la incertidumbre.

## Dosaje de Vancomicina en Conformidad con GUM

El constructo `Knowledge` de Sounio contiene valores de confianza (`ε`) que se propagan a través de las operaciones.

```sio
// 15 mg/kg/día: evidencia de nivel 1A (meta-análisis de ensayos clínicos aleatorios, 18 centros, n=2204)
// ε=0.92 refleja una alta calidad de evidencia con variabilidad conocida entre pacientes.
let base_dose: Knowledge<f64> = Knowledge(15.0, ε=0.92, prov="ASHP_2020_Level1A_RCT")

// Escala de piso hospitalaria: ±0.5 kg en un paciente de 78.5 kg → ε=0.98 (dispositivo calibrado).
let peso: Knowledge<f64> = Knowledge(78.5, ε=0.98, prov="hospital_scale_calibrated")
let ref_wt: Knowledge<f64> = Knowledge(70.0, ε=1.0)

// La propagación GUM es automática: ε(a/b) = ε(a)×ε(b) bajo errores independientes.
let peso_factor: Knowledge<f64> = peso / ref_wt
let dose1: Knowledge<f64> = base_dose * peso_factor
// ε(dose1) ≈ 0.92 × 0.98 × 1.0 = 0.9016
```

## Puertas de Seguridad

Puedes aplicar umbrales de seguridad en tiempo de compilación o en tiempo de ejecución utilizando la confianza propagada.

```sio
let conf_dose = dose3.ε

if conf_dose >= 0.82 {
    println("  PRESCRIBE: confianza de la línea de dosaje suficiente")
} else {
    println("  BLOCKED:   refinar la estimación de CrCl (CV de Cockcroft-Gault demasiado alto)")
}
```
