# Genómica & Bioinformática con Sounio

Sounio ofrece algoritmos básicos para transformaciones de secuencias.

## Operadores de Secuencia

```sio
// Complementar una base individual (XOR con 0b11)
fn complement_base(b: u8) -> u8 {
    return b ^ 3
}

// Complementar toda la secuencia
fn complement(seq: &[u8]) -> [u8] {
    return seq.map(|b| b ^ 3)
}

// Complementar inverso
fn reverse_complement(seq: &[u8]) -> [u8] {
    let rev = seq.reverse()
    return rev.map(|b| b ^ 3)
}
```
