# Inferencia Causal con Sounio

Sounio trata la causalidad como una preocupación del sistema de tipos. `Intervention<T>` y `Counterfactual<T>` son tipos a nivel del compilador — no convenciones de biblioteca.

## DAG Causal con el operador do de Pearl

```sio
// Construye un DAG causal con incertidumbre en los bordes epistémicos
var dag = causal_dag_new()
dag = dag_add_node(dag, 0)  // tratamiento
dag = dag_add_node(dag, 1)  // resultado
dag = dag_add_edge(dag, 0, 1,
    ec_beta_new(8.0, 2.0), 0.5, 0.1)

// El operador do de Pearl elimina la confusión
let intervened = do_intervention(dag, 1)
```

## Efecto Tratamiento Promedio

```sio
// Estima ATE con incertidumbre epistémica
let ate = average_treatment_effect(dag, 0, 1)
```
