# Genómica & Bioinformática com Sounio

Sounio fornece algoritmos básicos para transformações de sequência.

## Operadores de Sequência

```sio
// Complementar um único base (XOR com 0b11)
fn complement_base(b: u8) -> u8 {
    return b ^ 3
}

// Complementar sequência completa
fn complement(seq: &[u8]) -> [u8] {
    return seq.map(|b| b ^ 3)
}

// Complementar inverso
fn reverse_complement(seq: &[u8]) -> [u8] {
    let rev = seq.reverse()
    return rev.map(|b| b ^ 3)
}
```
