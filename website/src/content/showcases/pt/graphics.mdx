# Gráficos e Renderização

Sounio possui, no momento, duas famílias de gráficos reais neste repositório de snapshot:
visualizações científicas nativas do terminal em `examples/graphics/` e imagens rasterizadas por software sob `examples/render/`.
As visualizações rasterizadas a seguir são geradas a partir do exato `stdout` do artefato verificado JIT, então commitadas como assets SVG para o site.
Essa página agora envia cinco visualizações rasterizadas reais em vez de dois amostras isoladas.

## Por que esta pilha gráfica?

- **Saída de compilador real**: A seção de raster acima é gerada a partir da saída verificada do `souc run`, não de capturas de tela
- **Formatos de saída portáveis**: Os demos de terminal utilizam Unicode/ANSI; os demos de raster emitem PPM puro
- **Sem dependência de janelhamento**: Não é necessário X11, OpenGL ou um kit de ferramentas gráficas para os exemplos atuais
- **Amigável para SSH**: A renderização por terminal e arquivos funcionam tanto em sistemas remotos

## Executando os Exemplos

```bash
SOUC_BIN=bin/souc

# Renderizações rasterizadas (PPM em saída padrão)
"$SOUC_BIN" run examples/render/triangle_basic.sio > triangle_basic.ppm
"$SOUC_BIN" run examples/render/cube_wireframe.sio > cube_wireframe.ppm

# Visualizações científicas
"$SOUC_BIN" run examples/visual/06_octonion_color_table.sio
"$SOUC_BIN" run examples/visual/10_kalman_filter_color.sio
"$SOUC_BIN" run examples/visual/12_animated_diffusion.sio

# Demonstrações da biblioteca gráfica
"$SOUC_BIN" run examples/graphics/demos/phase3_showcase.sio  # 3D
"$SOUC_BIN" run examples/graphics/demos/phase5_showcase.sio  # Animacao
"$SOUC_BIN" run examples/graphics/demos/phase7_showcase.sio  # Redes

# Atualiza as visualizações rasterizadas do site a partir da saída exata do compilador
npm --prefix website run generate:render-assets
```

## Estrutura da Biblioteca

| Fase | Módulos | Capacidades |
|-------|---------|--------------|
| **Fase 1** | `canvas`, `colors`, `drawing`, `text` | Primitivos básicos, cores ANSI, formas |
| **Fase 2** | `axes`, `scatter`, `line_plot`, `bar_chart`, `histogram`, `heatmap` | Gráficos bidimensionais |
| **Fase 3** | `projection`, `wireframe`, `scatter3d` | Visualização tridimensional |
| **Fase 4** | `input`, `interactive_plot` | Zoom, rolagem, mouse/teclado |
| **Fase 5** | `animation`, `particle_system`, `fluid_sim` | Animação, física |
| **Fase 6** | `phase_diagram`, `bifurcation`, `poincare`, `streamlines` | Gráficos científicos |
| **Fase 7** | `graph`, `force_directed`, `tree_layout`, `graph_render` | Visualização de rede |
