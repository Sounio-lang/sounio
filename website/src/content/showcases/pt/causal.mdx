# Inferência Causal com Sounio

Sounio trata a causalidade como uma preocupação do sistema de tipos. `Intervention<T>` e `Counterfactual<T>` são tipos de nível de compilador — não convenções de biblioteca.

## DAG Causal com o operador do de Pearl

```sio
// Construa um DAG causal com incerteza nas arestas epistêmicas
var dag = causal_dag_new()
dag = dag_add_node(dag, 0)  // tratamento
dag = dag_add_node(dag, 1)  // resultado
dag = dag_add_edge(dag, 0, 1,
    ec_beta_new(8.0, 2.0), 0.5, 0.1)

// O operador do de Pearl remove confundidos
let intervened = do_intervention(dag, 1)
```

## Efeito Médio de Tratamento

```sio
// Estime o ATE com incerteza epistêmica
let ate = average_treatment_effect(dag, 0, 1)
```
