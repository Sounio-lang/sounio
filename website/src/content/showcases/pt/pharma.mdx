# Farmacometria com Sounio

Sounio fornece uma plataforma poderosa para modelagem farmacométrica, permitindo otimização de dosagem de medicamentos com manejo rigoroso de incertezas.

## Dosing de Vancomycin em conformidade com GUM

A construção `Knowledge` de Sounio carrega valores de confiança (`ε`) que se propagam por computações.

```sio
// 15 mg/kg/dia: evidência de nível 1A (meta-análise de ensaios clínicos aleatórios, 18 centros, n=2204)
// ε=0.92 reflete a alta qualidade de evidência com variabilidade inter-paciente conhecida.
let base_dose: Knowledge<f64> = Knowledge(15.0, ε=0.92, prov="ASHP_2020_Level1A_RCT")

// Balança de piso hospital: ±0.5 kg em um paciente de 78.5 kg → ε=0.98 (dispositivo calibrado).
let weight: Knowledge<f64> = Knowledge(78.5, ε=0.98, prov="hospital_scale_calibrated")
let ref_wt: Knowledge<f64> = Knowledge(70.0, ε=1.0)

// A propagação GUM é automática: ε(a/b) = ε(a)×ε(b) sob erros independentes.
let weight_factor: Knowledge<f64> = weight / ref_wt
let dose1: Knowledge<f64> = base_dose * weight_factor
// ε(dose1) ≈ 0.92 × 0.98 × 1.0 = 0.9016
```

## Portas de Segurança

Você pode impôr limiares de segurança no tempo de compilação ou tempo de execução usando a confiança propagada.

```sio
let conf_dose = dose3.ε

if conf_dose >= 0.82 {
    println("  PRESCRIBE: dose pipeline confidence sufficient")
} else {
    println("  BLOCKED:   refine CrCl estimate (Cockcroft-Gault CV too high)")
}
```
