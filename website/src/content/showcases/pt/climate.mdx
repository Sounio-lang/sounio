# Ciência do Clima com Sounio

## Leitura Executiva

Essa rota existe para mostrar que Sounio não se limita a cálculos mais rápidos. Trata-se de negar a conversão de evidências instáveis em um número pronto para políticas.

O software climático é uma boa prova de estresse, pois castiga a falácia. Você sempre pode publicar outra projeção. A disciplina mais difícil é decidir quando a dispersão do conjunto, a desacordo dos modelos ou a qualidade dos dados se tornaram demais fracos para que o programa continue falando com confiança falsa.

Essa é a argumentação aqui: a linguagem deve ajudar o código científico a interromper, reduzir o alcance ou marcar a negação **antes** de que a incerteza seja lavada em um painel limpo.

## O que esta rota está tentando mostrar

Sounio deve ser útil em fluxos de trabalho onde a resposta certa é alguns vezes "não fique pretendo que esta estimativa ainda esteja de nível de decisão".- A agregação de ensembles deve preservar a incerteza em vez de a esmagar
- O software downstream deve ver a história de confiança, não apenas a média
- A ampliação da variância deve poder limitar ou parar uma operação
- O usuário deve poder distinguir entre um pronóstico limitado e um
  falso pretensioso

Se a linguagem não pode suportar esse postura, então toda a retórica "epistémica" é decorativa.

## Um leitor escéptico deve perguntar

- Isso é apenas outro envelopador de incerteza ao redor do código numérico normal?
- A rota mostra como a divergência se propagar, ou apenas mença isso?
- O programa está permitido a refusar um resultado, ou apenas anotá-lo depois do fato?
- A afirmação sobre a ciência do clima é sobre a própria ciência, ou sobre a disciplina do
  software?A resposta deve ser a segunda: esta rota não afirma pretender substituir um
laboratório climático completo. Ela afirma que o software científico deve tornar legíveis seus limites antes que esses limites sejam erros de políticas climáticas públicas.

## Por que isso importa para a linguagem

O clima é um dos lugares mais claros onde "providir sempre uma resposta" se torna um falho político.

Se sua pilha de software está otimizada apenas para continuar emitindo números, fica muito fácil confundir a continuidade de saída com a continuidade do conhecimento. Uma linguagem séria sobre a incertezza tem que dar a programas outra opção: escopo restrito, divergência na superfície ou parar.

É por isso que esta rota pertence ao lado dos GPUs e neuroimagem na janela de loja. Não está aqui para diversidade de tópicos. Está aqui porque prova que a linguagem está sendo moldada por domínios onde a recusa faz parte da competência.## O que convenceria um leitor escéptico

- um caminho visível de valores que suportam incertidumbre até as decisões embaixadas
- exemplos onde a ampliação do espalhamento altera o fluxo de controle em vez de apenas copiar
- documentação honesta da superfície climática limitada atual
- distinção explícita entre "pressão de pesquisa interessante" e "plataforma de previsão de produção"

Essa é a norma a qual esta rota deve ser mantida.

## Onde a fronteira ainda está

Essa rota não afirma:

- que Sounio já é uma plataforma de modelagem climática completa
- que os exemplos atuais substituem uma pilha de previsão completa
- que cada fluxo de trabalho científico já foi codificado com controle de fluxo consciente de negação

A afirmação é mais restrita: a pressão climática revela por que o software científico precisa de uma linguagem que pode preservar a incertidumbre e parar de falar quando a evidência já não justifica uma resposta limpa.
