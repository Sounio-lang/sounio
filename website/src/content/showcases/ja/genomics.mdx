# Sounioでの遺伝子解析とビオインフォマティク

Sounioはシーケンス変換の基本的なアルゴリズムを提供します。

## シーケンス演算子

```sio
// 1つのベースを補完（ビット演算のXORで0b11とのXOR）
fn complement_base(b: u8) -> u8 {
    return b ^ 3
}

// 全シーケンスを補完
fn complement(seq: &[u8]) -> [u8] {
    return seq.map(|b| b ^ 3)
}

// 逆補完
fn reverse_complement(seq: &[u8]) -> [u8] {
    let rev = seq.reverse()
    return rev.map(|b| b ^ 3)
}
```
