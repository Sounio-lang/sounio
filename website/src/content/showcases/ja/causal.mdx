# Sounioでの因果推論

Sounioは、因果性をタイプシステムの問題として扱います。`Intervention<T>` と `Counterfactual<T>` はコンパイラレベルのタイプです - ライブラリの契約ではありません。

## Pearlの do-演算子の因果DAG

```sio
// 知識的不確実性を持つ因果DAGを作成
var dag = causal_dag_new()
dag = dag_add_node(dag, 0)  // 治療
dag = dag_add_node(dag, 1)  // 結果
dag = dag_add_edge(dag, 0, 1,
    ec_beta_new(8.0, 2.0), 0.5, 0.1)

// Pearlの do-演算子は共因子を除去する
let intervened = do_intervention(dag, 1)
```

## 平均効果量

```sio
// 知識的不確実性を持つ平均効果量を推定
let ate = average_treatment_effect(dag, 0, 1)
```
