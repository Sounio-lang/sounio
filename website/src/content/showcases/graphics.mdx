# Terminal Graphics Library

Sounio provides a comprehensive terminal-native graphics library for scientific visualization. No GUI libraries, no X11, no dependencies—just Unicode and ANSI escape codes that work everywhere, including SSH sessions.

## Why Terminal Graphics?

- **Works everywhere**: SSH, Docker, minimal systems, remote servers
- **Zero dependencies**: No matplotlib, no OpenGL, no external libraries
- **Fast**: All examples render in under 1 second
- **SSH-friendly**: Perfect for remote scientific computing

## Phase 1: Core Primitives

### Canvas and Drawing

```sio
use graphics::canvas::{Canvas, Cell}
use graphics::drawing::{line, circle, rectangle}
use graphics::colors::{RED, GREEN, BLUE, traffic_light}

fn main() with IO {
    var canvas = Canvas::new(80, 24)

    // Bresenham's line algorithm
    line(&!canvas, 0, 0, 79, 23, Cell::char('/'))

    // Midpoint circle with 8-way symmetry
    circle(&!canvas, 40, 12, 10, Cell::colored('O', GREEN))

    // Filled rectangle
    rectangle(&!canvas, 5, 5, 20, 10, Cell::char('#'), fill: true)

    canvas.render()
}
```

## Phase 3: 3D Visualization

### 3D Projections

```sio
use graphics::projection::{Vec3D, isometric, perspective, rotate_xyz}

fn project_point(p: Vec3D, camera: Camera) -> (f64, f64) {
    // Rotate in 3D space
    let rotated = rotate_xyz(p,
        roll: camera.roll,
        pitch: camera.pitch,
        yaw: camera.yaw
    )

    // Project to 2D
    match camera.mode {
        Isometric => isometric(rotated),
        Perspective => perspective(rotated, focal_length: 500.0)
    }
}
```

### Wireframe Meshes

```sio
use graphics::wireframe::{Mesh3D, cube, pyramid, octahedron}

fn render_rotating_cube() with IO {
    let mesh = cube(size: 10.0)

    var angle = 0.0
    loop {
        let rotated = mesh.rotate_y(angle)

        var canvas = Canvas::new(80, 40)
        rotated.render_wireframe(&!canvas, projection: Isometric)

        // 3D axes: X=red, Y=green, Z=blue
        draw_axes(&!canvas)

        canvas.render()
        angle = angle + 0.05

        sleep(33)  // ~30 FPS
    }
}
```

```sio
fn interactive_explorer() with IO {

    // Mouse events
```

```sio
fn particle_fountain() with IO {
```

### Fluid Dynamics (Navier-Stokes)

```sio
use graphics::fluid::{FluidGrid, diffuse, advect, project}

fn smoke_simulation() with IO {
    // Based on Jos Stam's "Stable Fluids" (SIGGRAPH 1999)
    var fluid = FluidGrid::new(64, 64)

    loop {
        // Add density source (smoke)
        fluid.add_density(32, 60, 1.0)
        fluid.add_velocity(32, 60, 0.0, -0.5)  // Rising

        // Simulation step
        diffuse(&!fluid.velocity, viscosity: 0.0001)
        project(&!fluid.velocity)  // Incompressibility
        advect(&!fluid.density, fluid.velocity)

        fluid.fade(0.99)  // Dissipation
        fluid.render(colormap: Temperature)
    }
}
```

## Phase 6: Scientific Charts

### Phase Diagrams

```sio
use graphics::phase::{PhaseDiagram, PhaseRegion}

fn water_phase_diagram() with IO {
    var diagram = PhaseDiagram::new(
        x_param: "Pressure (atm)",
        y_param: "Temperature (°C)",
        x_range: 0.0..1000.0,
        y_range: -50.0..400.0
    )

    // Define phase regions with colors
    diagram.add_region(PhaseRegion {
        name: "Ice",
        color: BLUE,
        marker: '#',
        classify: |p, t| t < 0.0 && p < 1000.0
    })

    diagram.add_region(PhaseRegion {
        name: "Liquid",
        color: CYAN,
        marker: '~',
        classify: |p, t| t >= 0.0 && t < 100.0 * (p / 1.0).log10()
    })

    diagram.add_region(PhaseRegion {
        name: "Vapor",
        color: YELLOW,
        marker: '.',
        classify: |p, t| t >= 100.0 * (p / 1.0).log10()
    })

    diagram.render()
}
```

### Bifurcation Diagrams

```sio
use graphics::bifurcation::{BifurcationDiagram, logistic_map}

fn chaos_visualization() with IO {
    var diagram = BifurcationDiagram::new(
        parameter_range: 2.5..4.0,
        state_range: 0.0..1.0
    )

    // Logistic map: x_{n+1} = r * x_n * (1 - x_n)
    diagram.set_map(logistic_map)
    diagram.set_transient(500)   // Skip initial iterations
    diagram.set_samples(200)     // Points to plot per r value

    diagram.compute()
    diagram.render()

    // Shows period-doubling cascade to chaos!
}
```

### Vector Field Streamlines

```sio
use graphics::streamlines::{StreamlineField, dipole_field, vortex_pair}

fn electric_field_lines() with IO {
    var field = StreamlineField::new(
        bounds: (-10.0, -10.0, 10.0, 10.0),
        resolution: 80
    )

    // Electric dipole: +q at (2,0), -q at (-2,0)
    field.set_vector_field(dipole_field(
        positive: (2.0, 0.0),
        negative: (-2.0, 0.0)

    // Seed points for streamlines
    field.seed_grid(nx: 8, ny: 8)

    // Integrate using RK4
    field.trace(method: RK4, max_length: 50.0)
    field.render()
}
```

## Phase 7: Network Visualization

### Force-Directed Layouts

```sio
use graphics::graph::{Graph, GraphNode, GraphEdge}
use graphics::force_directed::{ForceDirectedLayout, fruchterman_reingold}

fn social_network() with IO {
    var graph = Graph::new()

    // Add nodes
    for person in people {
        graph.add_node(GraphNode {
            id: person.id,
            label: person.name,
            color: department_color(person.dept),
            size: influence_score(person)
        })
    }

    // Add edges
    for connection in connections {
        graph.connect(connection.from, connection.to,
            weight: connection.strength,
            directed: false
        )
    }

    // Fruchterman-Reingold layout with simulated annealing
    var layout = ForceDirectedLayout::new(graph)
    layout.randomize()

    for _ in 0..100 {
        layout.step()  // Apply forces
        layout.cool()  // Reduce temperature
    }

    layout.render()
}
```
