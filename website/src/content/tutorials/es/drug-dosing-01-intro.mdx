# ¿Qué es el Cómputo Epistémico?

Cada medición en la ciencia lleva incertidumbre. Cuando un farmacéutico mide el nivel de creatinina en un paciente en 1,2 mg/dL, ese número no es exacto: el ensayo tiene una coeficiente de variación de aproximadamente el 5%. Cuando un médico receta 500 mg de vancomicina, la dosis biológicamente disponible depende de la función renal, el peso y una docena de otros factores que solo conocemos de manera aproximada.

La mayoría de los lenguajes de programación ignoran esto. Un `float` es un `float`, y `1.2` se trata como si se supiera con precisión infinita. Sounio adopta un enfoque diferente.

## Conocimientos vs Datos

En Sounio, un valor puede llevar **metainformación epistémica**: información sobre la confianza que tenemos en ese valor. El sistema de tipos distingue entre:

- **Datos**: un número crudo (`f64`, `i32`)
- **Conocimientos**: un número más su incertidumbre (`Knowledge<f64>`)

Aquí está la diferencia:

```sio
// Datos crudos: sin información sobre la incertidumbre
let creatinine: f64 = 1.2

// Conocimientos: valor más incertidumbre estándar
let creatinine: Knowledge<f64> = measure(1.2, uncertainty: 0.06)
```

La función `measure` crea un valor `Knowledge<f64>`: la mejor estimación es 1.2, y la incertidumbre estándar es 0.06 (5% CV).

## ¿Por Qué Esto Importa?

Cuando se calculan con valores `Knowledge`, la incertidumbre **se propaga automáticamente**. Si se calcula la claramente de una medicina a partir de la creatinina, el resultado también lleva incertidumbre, y Sounio la seguimos por ti.

```sio
fn cockcroft_gault(age: f64, weight: Knowledge<f64>, scr: Knowledge<f64>) -> Knowledge<f64> {
    // CrCl = (140 - age) * weight / (72 * SCr)
    let numerator = (140.0 - age) * weight
    let denominator = 72.0 * scr
    numerator / denominator
}
```

La salida `Knowledge<f64>` refleja automáticamente la incertidumbre combinada de tanto `weight` como `scr`. No se necesita propagación de errores manual.

## Efectos: Seguimiento de Efectos Adicionales

Sounio también segrega **efectos**: lo que puede hacer una función. Si una función lee de un archivo, debe declarar `with IO`. Si se aloca memoria, `with Alloc`. Si puede dividir por cero, `with Div`.

```sio
fn safe_divide(a: f64, b: f64) -> f64 with Div {
    a / b
}

fn greet(name: string) with IO {
    print("Hello, ")
    print(name)
    print("\n")
}
```

Esto no es solo documentación: el compilador **lo impone**. Una función sin `with IO` no puede llamar a `print`. Esto significa que puedes mirar en cualquier firma de función y saber exactamente lo que puede hacer.

## Resumen clave

- El tipo `Knowledge<T>` de Sounio rastrea la incertidumbre como un concepto primario
- Los efectos (`with IO`, `with Div`, `with Mut`) hacen explícitos los efectos secundarios
- Juntos, estas características previenen la propagación silenciosa de malos supuestos — el error más peligroso en el cómputo científico
