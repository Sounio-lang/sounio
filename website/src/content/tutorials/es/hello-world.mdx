# Tutorial de Hola Mundo

En este tutorial, aprenderás los fundamentos de Sounio escribiendo un simple programa de Hola Mundo.

## Prerrequisitos

- Sounio instalado en tu sistema ([Guía de Instalación](/learn/getting-started))
- Un editor de texto de elección

## Paso 1: Crea tu archivo

Crea un nuevo archivo llamado `hello.sio`:

```sio
fn main() with IO {
    print("Hola, Mundo!")
}
```

Vamos a desglosar esto:

- `fn main()` declara la función principal, punto de entrada de todos los programas Sounio
- `with IO` declara que esta función realiza efectos de IO (imprimir en la consola)
- `print("...")` imprime texto en la consola

## Paso 2: Ejecuta tu programa

Abre tu terminal y ejecuta:

```bash
sounio run hello.sio
```

Debes ver:

```
Hola, Mundo!
```

¡Felicitaciones! Has escrito tu primer programa Sounio.

## Paso 3: Agrega variables

Vamos a hacerlo más interesante:

```sio
fn main() with IO {
    let name = "Sounio"
    let version = 1.0

    print("Bienvenido a " + name + " v" + version.to_string())
}
```
