# ハローワールドチュートリアル

このチュートリアルでは、Sounioの基本的な概念を学び、簡単なハローワールドプログラムを書くことでSounioについて学びましょう。

## 前提条件

- Sounioをシステムにインストールしてください（[インストールガイド](/learn/getting-started))
-好きなテキストエディター

## 手順1：ファイルを作成する

`hello.sio`という新しいファイルを作成しましょう：

```sio
fn main() with IO {
    print("Hello, World!")
}
```

これを解説します：

- `fn main()`は、Sounioプログラムのエントリポイントとなるメイン関数を宣言します
- `with IO`は、この関数がIO効果（コンソールに出力）を行うことを宣言します
- `print("...")`はテキストをコンソールに出力します

## 手順2：プログラムを実行する

ターミナルを開いて以下のコマンドを実行します：

```bash
sounio run hello.sio
```

以下の内容が表示されるはずです：

```
Hello, World!
```

最初のSounioプログラムを書いたことで、おめでとうございます！

## 手順3：変数を追加する

もっと面白くしてみましょう：

```sio
fn main() with IO {
    let name = "Sounio"
    let version = 1.0

    print("Welcome to " + name + " v" + version.to_string())
}
```
