# PKモデルの構築

一室の薬物動き学（PK）モデルは、薬が体内にどのように移動するかを説明します。それには以下の3つの核パラメータがあります：

- **クリアエリア（CL）**：薬が体内からどのくらい速く排出されるか（L/h）
- **分布体積（Vd）**：薬が分布する仮定された体積（L）
- **半衰期（t½）**：血中濃度が半分になるまでにかかる時間（h）

これらは関係があります：`t½ = 0.693 × Vd / CL`。

## モデルの定義

Sounioでは、PKパラメータを構造体として表現します：

```sio
struct PKParams {
    clearance: f64,    // L/h
    volume: f64,       // L
    dose: f64,         // mg
    tau: f64,          // 投与間隔、時間（時間）
}
```

次に、推論された量を計算する関数を書くことにしましょう。効果の注解を見てください：

```sio
fn half_life(pk: PKParams) -> f64 with Div {
    0.693 * pk.volume / pk.clearance
}

fn elimination_rate(pk: PKParams) -> f64 with Div {
    pk.clearance / pk.volume
}

## 問題：隠れた不確実性

このモデルは正確な数字を示しているのに見えます：Cmin = 6.8 mg/L。しかし、それはどれだけ信頼性があるのでしょうか？クリアエリアの値4.5 L/hは人口平均値でありました。この患者には、腎功能によって3.0から6.0 L/hの範囲で変化する可能性があります。

范囲が15–20 mg/Lの范囲内であるとされる范囲内値ですが、6.8 mg/Lは毒害閾値よりも安全な値であるのか、不確実性が大きいので、実際の槽点が危険に高い可能性があるのかどうかどうか回答する方法はありません。`f64`値ではその問いに答える方法はありません。次のレッスンでは、パラメーターを不確実性を持つ`Knowledge<T>`値に置き換えます。
