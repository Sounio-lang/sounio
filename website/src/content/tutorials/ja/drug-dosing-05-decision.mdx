# 信頼区間を伴う臨床決定

予測されたトラッフコンCENTリティには確率情報が付属しています。最終的でも重要なステップは、その情報を使って臨床決定をすることです。

## 決定問題

バンコミシンは狭い治療窓を持っています:
- **10 mg/L未満**: 下治剤的（感染が適切に治療されていない）
- **10–20 mg/L**: 治療効果の範囲
- **20 mg/L以上**: 腎臓毒性のリスクがある

モデルは、例えば14.2 ± 4.8 mg/LのトラッフコンCENTリティを予測します。この薬量は安全ですか？

ポイント推定値が14.2であると、传统システムは「範囲内です」と言いますが、±4.8の確率情報は、本当のトラッフコンCENTリティが ~5 から ~24 mg/L の間にある可能性があることを意味します - これは下治剤的から毒犠効果の範囲全体を覆っています。

## 信頼区間を伴う決定

Sounioは、`Knowledge`値に関する確率問いを行うことができます。
```sio
構造体 `DosingDecision` を定義します。

```sio
struct DosingDecision {
    recommendation: i32,    // 0 = safe, 1 = adjust up, 2 = adjust down, 3 = contraindicated
    confidence: f64,        // 治療範囲内の確率
    risk_below: f64,        // 下効効効率
    risk_above: f64,        // 上効効効率
}
```

関数 `evaluate_dose` を定義します。

```sio
fn evaluate_dose(trough: Knowledge&lt;f64&gt;,
                 lower: f64, upper: f64) -> DosingDecision
    with Mut, Panic, Div
{
    // Compute probability of being in [lower, upper]
    // Using normal distribution assumption (CLT)
    let z_lower = (lower - trough.value) / trough.uncertainty
    let z_upper = (upper - trough.value) / trough.uncertainty

    let p_below = normal_cdf(z_lower)
    let p_above = 1.0 - normal_cdf(z_upper)
    let p_in_range = 1.0 - p_below - p_above
}
```

## The Normal CDF Approximation

For the probability calculations, we need a normal CDF. Here's a Taylor series approximation suitable for Sounio:

```sio
fn normal_cdf(z: f64) -> f64 with Mut, Panic, Div {
    // Abramowitz & Stegun approximation (7.1.26)
    if z < 0.0 - 6.0 { return 0.0 }
    if z > 6.0 { return 1.0 }
```
