# 使用置信区间进行临床决策

我们现在有了一个预测的谷浓度及其不确定性。最后一步，也是最关键的一步，是使用这些信息做出临床决策。

## 决策问题

万古霉素有一个窄的治疗窗口：
- **低于10 mg/L**：治疗不足（感染未得到充分治疗）
- **10–20 mg/L**：治疗范围
- **高于20 mg/L**：肾毒性风险

我们的模型预测谷浓度为14.2 ± 4.8 mg/L。这个剂量安全吗？

使用14.2的预测值，传统系统会说“是的，它在范围内。”但是4.8的不确定性意味着真实的谷浓度可能在~5到~24 mg/L之间——涵盖从治疗不足到有毒的整个范围。

## 置信区间决策

Sounio 允许你对 `Knowledge` 值进行概率查询：
```sio
struct DosingDecision {
    recommendation: i32,    // 0 = 安全，1 = 增加剂量，2 = 减少剂量，3 = 禁忌
    confidence: f64,        // 治疗范围内的概率
    risk_below: f64,        // 低于治疗范围的概率
    risk_above: f64,        // 高于治疗范围的概率
}

fn evaluate_dose(trough: Knowledge<f64>,
                 lower: f64, upper: f64) -> DosingDecision
    with Mut, Panic, Div
{
    // 计算在 [lower, upper] 范围内的概率
    // 使用正态分布假设 (中心极限定理)
    let z_lower = (lower - trough.value) / trough.uncertainty
    let z_upper = (upper - trough.value) / trough.uncertainty

    let p_below = normal_cdf(z_lower)
    let p_above = 1.0 - normal_cdf(z_upper)
    let p_in_range = 1.0 - p_below - p_above
}

## 恭喜！

您已经构建了一个完整的基于不确定性的药物剂量系统：

1. **第1课**：理解了认识论计算以及为什么它很重要
2. **第2课**：使用类型化的结构体和效果构建了药代动力学模型
3. **第3课**：将`Knowledge<T>`升级为处理不确定测量的不确定性
4. **第4课**：在整个管道中传播不确定性
5. **第5课**：基于置信度的临床决策

这种模式——测量、传播、基于置信度的决策——适用于任何科学领域：气候建模、结构工程、金融风险、流行病学。Sounio将其作为语言原语，而不是事后考虑。
