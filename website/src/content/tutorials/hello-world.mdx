# Hello World Tutorial

In this tutorial, you'll learn the fundamentals of Sounio by writing a simple Hello World program.

## Prerequisites

- Sounio installed on your system ([Installation Guide](/learn/getting-started))
- A text editor of your choice

## Step 1: Create Your File

Create a new file called `hello.sio`:

```sio
fn main() with IO {
    print("Hello, World!")
}
```

Let's break this down:

- `fn main()` declares the main function, the entry point of every Sounio program
- `with IO` declares that this function performs IO effects (printing to console)
- `print("...")` outputs text to the console

## Step 2: Run Your Program

Open your terminal and run:

```bash
sounio run hello.sio
```

You should see:

```
Hello, World!
```

Congratulations! You've written your first Sounio program.

## Step 3: Add Variables

Let's make it more interesting:

```sio
fn main() with IO {
    let name = "Sounio"
    let version = 1.0

    print("Welcome to " + name + " v" + version.to_string())
}
```
