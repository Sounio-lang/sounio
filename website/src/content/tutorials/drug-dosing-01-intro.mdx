# What is Epistemic Computing?

Every measurement in science carries uncertainty. When a pharmacist measures a patient's creatinine level at 1.2 mg/dL, that number is not exact — the assay has a coefficient of variation of roughly 5%. When a doctor prescribes 500 mg of vancomycin, the actual bioavailable dose depends on the patient's renal function, weight, and a dozen other factors that we know only approximately.

Most programming languages ignore this. A `float` is a `float`, and `1.2` is treated as though it were known with infinite precision. Sounio takes a different approach.

## Knowledge vs Data

In Sounio, a value can carry **epistemic metadata** — information about how confident we are in that value. The type system distinguishes between:

- **Data**: a raw number (`f64`, `i32`)
- **Knowledge**: a number plus its uncertainty (`Knowledge<f64>`)

Here's the difference:

```sio
// Raw data — no uncertainty information
let creatinine: f64 = 1.2

// Knowledge — value + standard uncertainty
let creatinine: Knowledge<f64> = measure(1.2, uncertainty: 0.06)
```

The `measure` function creates a `Knowledge<f64>` value: the best estimate is 1.2, and the standard uncertainty is 0.06 (5% CV).

## Why Does This Matter?

When you compute with `Knowledge` values, uncertainty **propagates automatically**. If you calculate drug clearance from creatinine, the result also carries uncertainty — and Sounio tracks it for you.

```sio
fn cockcroft_gault(age: f64, weight: Knowledge<f64>, scr: Knowledge<f64>) -> Knowledge<f64> {
    // CrCl = (140 - age) * weight / (72 * SCr)
    let numerator = (140.0 - age) * weight
    let denominator = 72.0 * scr
    numerator / denominator
}
```

The output `Knowledge<f64>` automatically reflects the combined uncertainty from both `weight` and `scr`. No manual error propagation needed.

## Effects: Tracking Side Effects

Sounio also tracks **effects** — what a function can do. If a function reads from a file, it must declare `with IO`. If it allocates memory, `with Alloc`. If it can divide by zero, `with Div`.

```sio
fn safe_divide(a: f64, b: f64) -> f64 with Div {
    a / b
}

fn greet(name: string) with IO {
    print("Hello, ")
    print(name)
    print("\n")
}
```

This is not just documentation — the compiler **enforces** it. A function without `with IO` cannot call `print`. This means you can look at any function signature and know exactly what it might do.

## Key Takeaways

- Sounio's `Knowledge<T>` type tracks uncertainty as a first-class concept
- Effects (`with IO`, `with Div`, `with Mut`) make side effects explicit
- Together, these features prevent silent propagation of bad assumptions — the most dangerous bug in scientific computing
