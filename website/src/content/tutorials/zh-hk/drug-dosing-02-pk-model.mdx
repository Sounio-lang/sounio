# 建立PK模型

一室药代动力学（PK）模型描述药物在体内如何移动。它有三个核心参数：

- **清除率（CL）**：身体清除药物的速度（L/h）
- **分布容积（Vd）**：药物分布到的表观容积（L）
- **半衰期（t½）**：血浆浓度减半所需的时间（h）

这些参数之间存在关系：`t½ = 0.693 × Vd / CL`。

## 定义模型

在Sounio中，我们以结构体形式表示PK参数：

```sio
struct PKParams {
    clearance: f64,    // L/h
    volume: f64,       // L
    dose: f64,         // mg
    tau: f64,          // 给药间隔，小时
}
```

现在让我们编写计算衍生量的函数。注意效果注释：

```sio
fn half_life(pk: PKParams) -> f64 with Div {
    0.693 * pk.volume / pk.clearance
}

fn elimination_rate(pk: PKParams) -> f64 with Div {
    pk.clearance / pk.volume
}

fn peak_concentration(pk: PKParams) -> f64 with Div {
    // 首剂（IV bolus，一室）后的Cmax
    pk.dose / pk.volume
}

fn trough_concentration(pk: PKParams, ke: f64) -> f64 with Div, Mut, Panic {
    // 稳态时的Cmin
    let cmax = peak_concentration(pk)
    let numerator = cmax * exp_approx(0.0 - ke * pk.tau)
    let denominator = 1.0 - exp_approx(0.0 - ke * pk.tau)
    numerator / denominator
}
```

每个函数声明它需要哪些效果：
- `with Div` — 执行除法（如果CL = 0，则可能除以零）
- `with Mut` — 使用内部可变状态
- `with Panic` — 可以访问结构体字段（边界检查）

## 计算给药方案

让我们将它们与现实的万古霉素场景结合在一起：

```sio
fn exp_approx(x: f64) -> f64 with Mut, Panic, Div {
    if x > 10.0 {
        let half = exp_approx(x / 2.0)
        return half * half
    }
    if x < 0.0 - 10.0 { return 1.0 / exp_approx(0.0 - x) }
    var sum = 1.0
    var term = 1.0
    var n = 1
    while n &lt;= 25 {
        term = term * x / (n as f64)
        sum = sum + term
        n = n + 1
    }
    sum
}

fn main() -> i32 with IO, Mut, Panic, Div {
    let pk = PKParams {
        clearance: 4.5,  // L/h（万古霉素典型值）
        volume: 50.0,    // L
        dose: 1000.0,    // mg
        tau: 12.0,       // q12h给药
    }

    let ke = elimination_rate(pk)
    let t_half = half_life(pk)
    let cmax = peak_concentration(pk)
    let cmin = trough_concentration(pk, ke)

    print("半衰期：")
    println(t_half)            // ~7.7小时
    print("峰值（Cmax）：")
    println(cmax)              // 20.0 mg/L
    print("谷值（Cmin）：")
    println(cmin)              // ~6.8 mg/L

    0
}
```

## 问题：隐藏的误差

该模型给出了精确的数字：Cmin = 6.8 mg/L。但是这些数字有多可靠？清除率值4.5 L/h来自人口平均值。对于这个患者，它可能在3.0到6.0 L/h之间，取决于他们的肾功能。

万古霉素的治疗窗口为15–20 mg/L（AUC指导给药）。6.8 mg/L是否安全地低于毒性阈值，或者误差是否足够大，以至于真正的谷值可能危险地高？

使用原始`f64`值，我们无法回答这个问题。在下一课中，我们将用`Knowledge<T>`值替换我们的参数，这些值带有不确定性。

## 关键要点

- Sounio结构自然地建模PK参数
- 效果注释（`with Div, Mut, Panic`）使计算要求变得明确
- 传统的`f64`模型给出了看似精确的数字：它们隐藏了误差
