# 模型中不确定性的传递

我们已经定义了药代动力学参数的不确定性。现在让我们追踪不确定性如何流过整个剂量计算 — 从患者测量到预测药物浓度。

## 完整管道

临床药代动力学工作流程如下所示：

1. **测量** 患者实验室（肌酐，体重） → 不确定输入
2. **估计** 药代动力学参数（清除率，体积） → 推导不确定性
3. **预测** 药物浓度（Cmax，Cmin） → 复合不确定性
4. **决定** 剂量是否安全 → 置信限决策

在Sounio中，每个步骤都自动保存和传递不确定性。

## 第1步：患者测量

```sio
struct PatientLabs {
    serum_creatinine: Knowledge<f64>,  // mg/dL
    weight: Knowledge<f64>,            // kg
    age: f64,                          // 年（从记录，精确）
}

fn measure_patient() -> PatientLabs {
    PatientLabs {
        serum_creatinine: measure(1.2, uncertainty: 0.06),  // 5% 分析CV
        weight: measure(70.0, uncertainty: 1.0),            // ±1 kg 尺度精度
        age: 65.0,
    }
}
```

## 第2步：估计药代动力学参数

Cockcroft-Gault方程从患者实验室估计肌酐清除率。因为输入是 `Knowledge&lt;f64&gt;`，输出自动携带传递的不确定性：

```sio
fn estimate_clearance(labs: PatientLabs) -> Knowledge<f64> {
    // CrCl (mL/min) = (140 - age) × weight / (72 × SCr)
    let numerator = (140.0 - labs.age) * labs.weight
    let denominator = 72.0 * labs.serum_creatinine
    numerator / denominator
}

fn estimate_volume(labs: PatientLabs) -> Knowledge<f64> {
    // Vd ≈ 0.7 L/kg × weight (与模型不确定性)
    0.7 * labs.weight
}
```

清除率估计继承了 `weight` 和 `serum_creatinine` 的不确定性。体积估计继承了 `weight` 的不确定性。Sounio自动计算这些。

## 第3步：预测浓度

```sio
fn predict_trough(cl: Knowledge<f64>, vd: Knowledge<f64>,
                  dose: f64, tau: f64) -> Knowledge<f64> {
    let ke = cl / vd                          // 消除率
    let cmax = dose / vd                      // 峰值浓度
    let decay = exp_k(0.0 - ke * tau)         // exp(-ke × tau)
    let accumulation = 1.0 / (1.0 - decay)   // 稳态因子
    cmax * decay * accumulation
}
```

每个操作都复合不确定性。当我们达到最低点预测时，它反映了所有上游测量结果的组合不确定性。

## 第4步：敏感性分析

哪个测量对最终不确定性贡献最大？Sounio可以分解方差贡献：

```sio
struct SensitivityResult {
    scr_contribution: f64,     // 肌酐分数
    weight_contribution: f64,  // 体重分数
    total_cv: f64,             // 总体变异系数
}

fn analyze_sensitivity(labs: PatientLabs, dose: f64, tau: f64) -> SensitivityResult
    with Mut, Panic, Div
{
    let cl = estimate_clearance(labs)
    let vd = estimate_volume(labs)
    let trough = predict_trough(cl, vd, dose, tau)

    // 通过Sobol式分析的方差分解
    let total_var = trough.uncertainty * trough.uncertainty

    // 肌酐通过清除率贡献的方差
    let scr_var = cl.uncertainty * cl.uncertainty
    let scr_frac = scr_var / total_var

    // 体重通过清除率和体积贡献的方差
    let wt_frac = 1.0 - scr_frac  // 余数

    SensitivityResult {
        scr_contribution: scr_frac,
        weight_contribution: wt_frac,
        total_cv: trough.uncertainty / trough.value,
    }
}
```

这告诉临床医生：*"67%的剂量不确定性来自肌酐分析。如果你想更精确的剂量，获得更好的肌酐测量（例如，胱抑素C）而不是更精确的尺度。"* 

## 将所有放在一起

```sio
fn main() -> i32 with IO, Mut, Panic, Div {
    let labs = measure_patient()
    let cl = estimate_clearance(labs)
    let vd = estimate_volume(labs)

    let dose = 1000.0   // 1g 万古霉素
    let tau = 12.0       // q12h

    let trough = predict_trough(cl, vd, dose, tau)

    print("预测最低点：")
    println(trough.value)
    print(" ± ")
    println(trough.uncertainty)
    print(" mg/L\n")

    let sens = analyze_sensitivity(labs, dose, tau)
    print("肌酐贡献：")
    println(sens.scr_contribution)
    print("体重贡献：")
    println(sens.weight_contribution)

    0
}
```

## 关键要点

- 不确定性自动通过所有算术运算传递
- 敏感性分析揭示了哪些测量最重要
- 完整管道（测量 → 估计 → 预测 → 分析）是类型安全的
- 效果注释确保每个可能失败的操作都被声明
- 无需手动错误传播公式 — Sounio处理它
