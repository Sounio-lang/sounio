# Hello World 教程

在这个教程中，您将通过编写一个简单的 Hello World 程序学习 Sounio 的基础知识。

## 先决条件

- 在您的系统上安装了 Sounio（[安装指南](/learn/getting-started)）
- 您选择的文本编辑器

## 第 1 步：创建您的文件

创建一个名为 `hello.sio` 的新文件：

```sio
fn main() with IO {
    print("Hello, World!")
}
```

让我们来分解一下：

- `fn main()` 声明了主函数，Sounio 程序的入口点
- `with IO` 声明了此函数执行 IO 效果（控制台输出）
- `print("...")` 将文本输出到控制台

## 第 2 步：运行您的程序

打开终端并运行：

```bash
sounio run hello.sio
```

您应该看到：

```
Hello, World!
```

恭喜！您已编写了第一个 Sounio 程序。

## 第 3 步：添加变量

让我们让它更有趣：

```sio
fn main() with IO {
    let name = "Sounio"
    let version = 1.0

    print("Welcome to " + name + " v" + version.to_string())
}
```
