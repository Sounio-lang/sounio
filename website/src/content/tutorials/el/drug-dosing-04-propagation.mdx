# Εξαιρέσεις Προσπαθείας Μετά την Διάδροση

Επισημάστηκαν οι παραμέτρους PK με εξαιρέσεις. Τώρα δημιουργήσουμε την διάδροση της εξαιρέσεως προς την κατανόηση της προσπαθείας του παραμέτρου σε όλη την καλκολητική διάδροση — από τις μέρικες του συνολοποιητή σε τις προγνομένες κατανόησεων του φάρμακου.

## Η Πλήρης Χρήση

Μία διάδροση κλινικής καλκολητικής προσπαθείας έχει την ακόλουθη μορφή:

1. **Μέρικες** του συνολοποιητή (κρεατινίνα, βάρος) → εξαιρέσεις εισαιρέσεων
2. **Εστιμώσεις** των παραμέτρων PK (κατακατάραξη, ευθυμοσύνη) → εξαιρέσεις προσπαθείας προκαλουμένες
3. **Προγνομή** των κατανόησεων του φάρμακου (Cmax, Cmin) → εξαιρέσεις προσπαθείας συντηρημένες
4. **Κατανόηση** εάν ο δόσης είναι ασφαλής → κατανόηση με συνδυασμό εξαιρέσεων

Σούνιο αποδίδει την εξαιρέσεις αυτόματα σε κάθε βήμα.

## Βήμα 1: Μέρικες του Συνολοποιητή

```sio
struct PatientLabs {
    serum_creatinine: Knowledge<f64>,  // mg/dL
    weight: Knowledge<f64>,            // kg
    age: f64,                          // χρόνοι (από καταχωρήσεις, τοιχουργικό)
}

fn measure_patient() -> PatientLabs {
    PatientLabs {
        serum_creatinine: measure(1.2, uncertainty: 0.06),  // 5% εκτός της καλιβρίσης
        weight: measure(70.0, uncertainty: 1.0),            // ±1 kg τομέας τοιχουργίας
        age: 65.0,
    }
}
```
