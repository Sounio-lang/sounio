# Διάδοση αβεβαιότητας μέσα στο μοντέλο

Ορίσαμε τις παραμέτρους PK μαζί με την αβεβαιότητά τους. Τώρα θα παρακολουθήσουμε πώς αυτή η αβεβαιότητα ρέει σε έναν πλήρη υπολογισμό δοσολογίας — από τις μετρήσεις του ασθενούς έως τις προβλεπόμενες συγκεντρώσεις του φαρμάκου.

## Η πλήρης διαδρομή

Μια κλινική φαρμακοκινητική ροή εργασίας έχει την εξής μορφή:

1. **Μετρήστε** τις εργαστηριακές τιμές του ασθενούς (κρεατινίνη, βάρος) → αβέβαιες είσοδοι
2. **Εκτιμήστε** τις παραμέτρους PK (κάθαρση, όγκος) → παράγωγη αβεβαιότητα
3. **Προβλέψτε** τις συγκεντρώσεις του φαρμάκου (Cmax, Cmin) → συσσωρευμένη αβεβαιότητα
4. **Αποφασίστε** αν η δόση είναι ασφαλής → απόφαση με όρια εμπιστοσύνης

Στο Sounio, κάθε βήμα διατηρεί και διαδίδει αυτόματα την αβεβαιότητα.

## Βήμα 1: Μετρήσεις ασθενούς

```sio
struct PatientLabs {
    serum_creatinine: Knowledge<f64>,  // mg/dL
    weight: Knowledge<f64>,            // kg
    age: f64,                          // years (from records, exact)
}

fn measure_patient() -> PatientLabs {
    PatientLabs {
        serum_creatinine: measure(1.2, uncertainty: 0.06),  // 5% assay CV
        weight: measure(70.0, uncertainty: 1.0),            // ±1 kg scale precision
        age: 65.0,
    }
}
```

## Βήμα 2: Εκτίμηση παραμέτρων PK

Η εξίσωση Cockcroft–Gault εκτιμά την κάθαρση κρεατινίνης από τις εργαστηριακές τιμές του ασθενούς. Επειδή οι είσοδοι είναι `Knowledge<f64>`, η έξοδος μεταφέρει αυτόματα τη διαδιδόμενη αβεβαιότητα:

```sio
fn estimate_clearance(labs: PatientLabs) -> Knowledge<f64> {
    // CrCl (mL/min) = (140 - age) × weight / (72 × SCr)
    let numerator = (140.0 - labs.age) * labs.weight
    let denominator = 72.0 * labs.serum_creatinine
    numerator / denominator
}

fn estimate_volume(labs: PatientLabs) -> Knowledge<f64> {
    // Vd ≈ 0.7 L/kg × weight (with model uncertainty)
    0.7 * labs.weight
}
```

Η εκτίμηση της κάθαρσης κληρονομεί αβεβαιότητα τόσο από το `weight` όσο και από το `serum_creatinine`. Η εκτίμηση του όγκου κληρονομεί αβεβαιότητα από το `weight`. Το Sounio τα υπολογίζει αυτόματα.

## Βήμα 3: Πρόβλεψη συγκεντρώσεων

```sio
fn predict_trough(cl: Knowledge<f64>, vd: Knowledge<f64>,
                  dose: f64, tau: f64) -> Knowledge<f64> {
    let ke = cl / vd                          // elimination rate
    let cmax = dose / vd                      // peak concentration
    let decay = exp_k(0.0 - ke * tau)         // exp(-ke × tau)
    let accumulation = 1.0 / (1.0 - decay)   // steady-state factor
    cmax * decay * accumulation
}
```

Κάθε πράξη συσσωρεύει αβεβαιότητα. Όταν φτάσουμε στην πρόβλεψη της συγκέντρωσης κατωφλίου, αυτή αντανακλά τη συνδυασμένη αβεβαιότητα όλων των προηγούμενων μετρήσεων.

## Βήμα 4: Ανάλυση ευαισθησίας

Ποια μέτρηση συμβάλλει περισσότερο στην τελική αβεβαιότητα; Το Sounio μπορεί να αποσυνθέσει τις συνεισφορές στη διακύμανση:

```sio
struct SensitivityResult {
    scr_contribution: f64,     // fraction from creatinine
    weight_contribution: f64,  // fraction from weight
    total_cv: f64,             // overall coefficient of variation
}

fn analyze_sensitivity(labs: PatientLabs, dose: f64, tau: f64) -> SensitivityResult
    with Mut, Panic, Div
{
    let cl = estimate_clearance(labs)
    let vd = estimate_volume(labs)
    let trough = predict_trough(cl, vd, dose, tau)

    // Variance decomposition via Sobol-style analysis
    let total_var = trough.uncertainty * trough.uncertainty

    // Contribution from SCr (through clearance)
    let scr_var = cl.uncertainty * cl.uncertainty
    let scr_frac = scr_var / total_var

    // Contribution from weight (through both CL and Vd)
    let wt_frac = 1.0 - scr_frac  // remainder

    SensitivityResult {
        scr_contribution: scr_frac,
        weight_contribution: wt_frac,
        total_cv: trough.uncertainty / trough.value,
    }
}
```

Αυτό πληροφορεί τον κλινικό ερευνητή: *«Το 67% της αβεβαιότητας της δοσολογίας σας προέρχεται από την εξέταση κρεατινίνης. Αν θέλετε ακριβέστερη δόση, χρειάζεστε καλύτερη μέτρηση κρεατινίνης — για παράδειγμα κυστατίνη C — και όχι πιο ακριβή ζυγαριά.»*

## Όλα μαζί

```sio
fn main() -> i32 with IO, Mut, Panic, Div {
    let labs = measure_patient()
    let cl = estimate_clearance(labs)
    let vd = estimate_volume(labs)

    let dose = 1000.0   // 1g vancomycin
    let tau = 12.0       // q12h

    let trough = predict_trough(cl, vd, dose, tau)

    print("Predicted trough: ")
    println(trough.value)
    print(" ± ")
    println(trough.uncertainty)
    print(" mg/L\n")

    let sens = analyze_sensitivity(labs, dose, tau)
    print("SCr contribution: ")
    println(sens.scr_contribution)
    print("Weight contribution: ")
    println(sens.weight_contribution)

    0
}
```

## Βασικά συμπεράσματα

- Η αβεβαιότητα διαδίδεται αυτόματα σε όλες τις αριθμητικές πράξεις
- Η ανάλυση ευαισθησίας αποκαλύπτει ποιες μετρήσεις έχουν τη μεγαλύτερη σημασία
- Η πλήρης διαδρομή (μέτρηση → εκτίμηση → πρόβλεψη → ανάλυση) είναι ασφαλής ως προς τους τύπους
- Οι δηλώσεις εφέ διασφαλίζουν ότι δηλώνεται κάθε πράξη που μπορεί να αποτύχει
- Δεν χρειάζονται χειροκίνητοι τύποι διάδοσης αβεβαιότητας — το Sounio την αναλαμβάνει
