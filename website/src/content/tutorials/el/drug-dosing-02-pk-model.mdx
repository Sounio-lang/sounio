# Κατασκευή μοντέλου PK

Ένα φαρμακοκινητικό μοντέλο (PK) ενός διαμερίσματος περιγράφει πώς κινείται ένα φάρμακο στο σώμα. Έχει τρεις βασικές παραμέτρους:

- **Κάθαρση (CL)**: πόσο γρήγορα απομακρύνει το σώμα το φάρμακο (L/h)
- **Όγκος κατανομής (Vd)**: ο φαινομενικός όγκος στον οποίο κατανέμεται το φάρμακο (L)
- **Χρόνος ημιζωής (t½)**: ο χρόνος που χρειάζεται για να υποδιπλασιαστεί η συγκέντρωση στο πλάσμα (h)

Οι παράμετροι συνδέονται με τη σχέση `t½ = 0.693 × Vd / CL`.

## Ορισμός του μοντέλου

Στο Sounio αναπαριστούμε τις παραμέτρους PK ως struct:

```sio
struct PKParams {
    clearance: f64,    // L/h
    volume: f64,       // L
    dose: f64,         // mg
    tau: f64,          // dosing interval, hours
}
```

Τώρα ας γράψουμε συναρτήσεις που υπολογίζουν τα παράγωγα μεγέθη. Παρατηρήστε τις δηλώσεις εφέ:

```sio
fn half_life(pk: PKParams) -> f64 with Div {
    0.693 * pk.volume / pk.clearance
}

fn elimination_rate(pk: PKParams) -> f64 with Div {
    pk.clearance / pk.volume
}

fn peak_concentration(pk: PKParams) -> f64 with Div {
    // Cmax after first dose (IV bolus, 1-compartment)
    pk.dose / pk.volume
}

fn trough_concentration(pk: PKParams, ke: f64) -> f64 with Div, Mut, Panic {
    // Cmin at steady state
    let cmax = peak_concentration(pk)
    let numerator = cmax * exp_approx(0.0 - ke * pk.tau)
    let denominator = 1.0 - exp_approx(0.0 - ke * pk.tau)
    numerator / denominator
}
```

Κάθε συνάρτηση δηλώνει ακριβώς ποια εφέ χρειάζεται:

- `with Div` — εκτελεί διαίρεση (θα μπορούσε να διαιρέσει με μηδέν αν `CL = 0`)
- `with Mut` — χρησιμοποιεί εσωτερικά μεταβλητή κατάσταση
- `with Panic` — μπορεί να προσπελάσει πεδία struct με έλεγχο ορίων

## Υπολογισμός ενός σεναρίου δοσολογίας

Ας τα συνδυάσουμε με ένα ρεαλιστικό σενάριο βανκομυκίνης:

```sio
fn exp_approx(x: f64) -> f64 with Mut, Panic, Div {
    if x > 10.0 {
        let half = exp_approx(x / 2.0)
        return half * half
    }
    if x < 0.0 - 10.0 { return 1.0 / exp_approx(0.0 - x) }
    var sum = 1.0
    var term = 1.0
    var n = 1
    while n <= 25 {
        term = term * x / (n as f64)
        sum = sum + term
        n = n + 1
    }
    sum
}

fn main() -> i32 with IO, Mut, Panic, Div {
    let pk = PKParams {
        clearance: 4.5,  // L/h (typical for vancomycin)
        volume: 50.0,    // L
        dose: 1000.0,    // mg
        tau: 12.0,       // q12h dosing
    }

    let ke = elimination_rate(pk)
    let t_half = half_life(pk)
    let cmax = peak_concentration(pk)
    let cmin = trough_concentration(pk, ke)

    print("Half-life: ")
    println(t_half)            // ~7.7 hours
    print("Peak (Cmax): ")
    println(cmax)              // 20.0 mg/L
    print("Trough (Cmin): ")
    println(cmin)              // ~6.8 mg/L

    0
}
```

## Το πρόβλημα: κρυφή αβεβαιότητα

Το μοντέλο παράγει αριθμούς που μοιάζουν ακριβείς: `Cmin = 6.8 mg/L`. Πόσο αξιόπιστη είναι όμως αυτή η τιμή; Η κάθαρση των 4.5 L/h προέρχεται από μέσο όρο πληθυσμού. Για τον συγκεκριμένο ασθενή μπορεί να βρίσκεται οπουδήποτε μεταξύ 3.0 και 6.0 L/h, ανάλογα με τη νεφρική του λειτουργία.

Το θεραπευτικό παράθυρο της βανκομυκίνης είναι 15–20 mg/L για τη συγκέντρωση κατωφλίου (δοσολογία με καθοδήγηση από AUC). Είναι το `6.8 mg/L` με ασφάλεια κάτω από το όριο τοξικότητας ή είναι η αβεβαιότητα αρκετά μεγάλη ώστε η πραγματική τιμή να μπορεί να είναι επικίνδυνα υψηλή;

Με ακατέργαστες τιμές `f64` δεν μπορούμε να απαντήσουμε. Στο επόμενο μάθημα θα αντικαταστήσουμε τις παραμέτρους μας με τιμές `Knowledge<T>` που μεταφέρουν αβεβαιότητα.

## Βασικά συμπεράσματα

- Τα structs του Sounio αναπαριστούν φυσικά τις παραμέτρους PK
- Οι δηλώσεις εφέ (`with Div, Mut, Panic`) κάνουν ρητές τις υπολογιστικές απαιτήσεις
- Τα παραδοσιακά μοντέλα `f64` δημιουργούν ψευδή ακρίβεια — κρύβουν την αβεβαιότητα πίσω από ακριβείς αριθμούς
- Το επόμενο βήμα είναι να γίνει η αβεβαιότητα μέρος πρώτης τάξης του μοντέλου
