# Τι είναι η Επιστημονική Ρυθμιστική;

Κάθε μέριμο στην Επιστήμη φέρει δυστυχία. Κότε ο φαρμακευτής μέριμει τον προσωπικό του βαθμό της κρεατινίνης στο 1,2 μγ/ΔΛ, ο αριθμός δεν είναι τονιστός — η διαγνόστικη έχει κουμποστασία δυστυχίας στοργενικής τότε τόσο για 5%. Κότε ο διάδοχος προσορίζει 500 μγ της βανκομυκινής, το προσωπικό πολλοκύτος της δοσίας που είναι βιομεταφόρτωσης αντί της αποδίδει στον πατιέντα ακόμα και η διάρκεια της νεφροποιησης του, και η βάρα του και η δεκάδιο άλλων παραμέτρων που γνωρίζουμε μόνο ακόμα για να είναι τους προσωπικούς.

Μεριμοσυνδρασίες γλώσσες προγραμμιστικών γίνονται προσεκτικά. Ένα `float` είναι ένα `float`, και `1.2` τρατείται ως το αντίστοιχο με αντικατάσταση αντίστοιχη αντίστοιχη προσωπική. Ο Sounio προσφέρει μία διαφορετική δράση.

## Επιστήμη σε Βασικά Δεδομένα

Στο Sounio, ένας αριθμός μπορεί να φέρει **επιστημονική μετάδοση** — πληροφορίες περί της πιστώση μας στον αριθμό αυτό. Η συστήμα τύπου διαδραστεί σε:

- **Δεδομένα**: ένας αριθμός ανάκτησης (`f64`, `i32`)
- **Επιστήμη**: ένας αριθμός πλήσιο του με την δυστυχία του (`Knowledge<f64>`)

Εδώ η διαφορά:

```sio
// Δεδομένα ανάκτησης — δεν υπάρχει πληροφορία δυστυχίας
let creatinine: f64 = 1.2

// Επιστήμη — τιμή + δυστυχία της
let creatinine: Knowledge<f64> = measure(1.2, uncertainty: 0.06)
```

Η συντακτική της συντακτικής `measure` δημιουργεί έναν τύπο `Knowledge<f64>` τιμή: η καλύτερη μέριμο είναι 1.2, και η δυστυχία του είναι 0.06 (5% CV).

## Γιατί Αυτό Ματιά Μας;

Κατά την υπολογιστική με τιμές `Knowledge`, η δυστυχία **διανομάζεται αυτόματα**. Εάν υπολογίζουμε την κατανόηση του φάρμακου από την κρεατινίνη, το αποτέλεσμα φέρει δυστυχία — και ο Sounio τακτικά τον ακολουθεί.

```sio
fn cockcroft_gault(age: f64, weight: Knowledge<f64>, scr: Knowledge<f64>) -> Knowledge<f64> {
    // CrCl = (140 - age) * weight / (72 * SCr)
    let numerator = (140.0 - age) * weight
    let denominator = 72.0 * scr
    numerator / denominator
}
```

Η εξοδοτική `Knowledge<f64>` αυτόματα ανταποδίδει την συνδυασμένη δυστυχία από τους δύο `weight` και `scr`. Δεν χρειάζεται μηχανική διανομή σφάλματος.
