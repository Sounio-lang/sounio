# Επισκόπηση Εισαγωγής

Σε αυτή την επισκόπηση θα μάθεις τα αρχικά και τη βασική κατανόηση του Sounio γράψαντας ένα πρόγραμμα Γειά Σου Κόσμε.

## Προαπαιτήσεις

- Ενεργοποιηθεί το Sounio στο σύστημά σας ([Οδηγία ενεργοποίησης](/learn/getting-started))
- Ένας επεξεργαστής κειμένου αντίθετος σας

## Επόμενος Βήμης: Δημιουργήστε τον Αρχείο

Δημιουργήστε έναν νέο αρχείο με τον όνομο `hello.sio`:

```sio
fn main() with IO {
    print("Γειά Σου Κόσμε!")
}
```

Επισκευάστε το παραπάνω:

- `fn main()` δηλώνει την κεντρική συνάρτηση, την εντροπή κάθε πρόγραμμα του Sounio
- `with IO` δηλώνει ότι η αυτή η συνάρτηση ενεργοποιεί εφαρμογές εισαγωγής (εκτύπωση στον κόσμο)
- `print("...")` εκτυπώνει κειμένο στον κόσμο

## Επόμενος Βήμης: Εκτελέστε το Πρόγραμμά

Άνοιγματε την τερμιναλή σας και εκτελέστε:

```bash
sounio run hello.sio
```

Μελέτε το παρακάτω:

```
Γειά Σου Κόσμε!
```

Συγγνώμη! Λάβετε το αρχικό πρόγραμμά σας του Sounio.

## Επόμενος Βήμης: Προσθέστε Ρουτίνες

Λάθε πιο ενημερωτικό:

```sio
fn main() with IO {
    let name = "Sounio"
    let version = 1.0

    print("Καλώς Ηλλάδες " + name + " v" + version.to_string())
}
```
