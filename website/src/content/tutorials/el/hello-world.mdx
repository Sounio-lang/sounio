# Το πρώτο σας πρόγραμμα Sounio

Πρώτα ακολουθήστε την
[ελληνική εγκατάσταση](/el/learn/getting-started). Η συμβατή πλατφόρμα και
η ταυτότητα του μεταγλωττιστή προηγούνται της εκτέλεσης.

## Διαβάστε ένα πλήρες πραγματικό πρόγραμμα

Το ακόλουθο είναι το υπάρχον `examples/hello.sio`. Δεν αλλάζουμε τον κώδικα
της αναφοράς όταν μεταφράζουμε την εξήγηση.

```sio
// First Sounio program

fn main() -> i32 with IO {
    println("Hello, Sounio")
    return 0
}
```

Η `main` είναι το σημείο εισόδου, το `with IO` δηλώνει την επίδραση
εισόδου/εξόδου και η `println` εκτυπώνει το μήνυμα. Η επιστροφή μηδέν
είναι μέρος του συμβολαίου αυτού του παραδείγματος.

## Ελέγξτε και εκτελέστε

Μετά την ταυτοποίηση του συμβατού προφίλ, από τη ρίζα του αποθετηρίου:

```sh
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
./bin/souc check examples/hello.sio
./bin/souc run examples/hello.sio
```

Το αναμενόμενο μήνυμα είναι `Hello, Sounio`. Καταγράψτε την πραγματική
έξοδο και τον τερματισμό· μην αντιγράφετε το αναμενόμενο ως παρατήρηση.
Ενδέχεται να εμφανίζονται επιπλέον πληροφορίες του μεταγλωττιστή.

## Κάντε μία δική σας αλλαγή

Κρατήστε την αναφορά αμετάβλητη. Σε ένα δικό σας πλήρες αρχείο, αλλάξτε
μόνο το μήνυμα. Ελέγξτε και εκτελέστε το νέο αρχείο, όχι το αρχικό.
Μην προσθέτετε συγχρόνως νέα βιβλιοθήκη, formatting API και διαφορετικό
τύπο επιστροφής.
