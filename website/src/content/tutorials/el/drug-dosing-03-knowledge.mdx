## Αβέβαιες μετρήσεις με Knowledge&lt;T&gt;

Στο προηγούμενο μάθημα δημιουργήσαμε ένα PK μοντέλο με ακριβείς τιμές `f64`. Τώρα θα το αναβαθμίσουμε, ώστε να παρακολουθεί την αβεβαιότητα χρησιμοποιώντας τον τύπο `Knowledge<T>` του Sounio.

## Από το f64 στο Knowledge&lt;f64&gt;

Κάθε κλινική μέτρηση έχει αβεβαιότητα. Μια τιμή κρεατινίνης ορού 1,2 mg/dL σημαίνει στην πράξη «περίπου 1,2, με τυπική απόκλιση γύρω στο 0,06». Στο Sounio:

```sio
// Before: raw number, uncertainty unknown
let scr: f64 = 1.2

// After: value + standard uncertainty
let scr: Knowledge<f64> = measure(1.2, uncertainty: 0.06)
```

Ο constructor `measure()` δημιουργεί μια τιμή `Knowledge<f64>` με:

- **value**: την καλύτερη εκτίμηση (1,2)
- **uncertainty**: την τυπική αβεβαιότητα (0,06, που αντιστοιχεί σε συντελεστή μεταβλητότητας ±5%)

## Κατασκευή επιστημολογικού PK μοντέλου

Ας επαναορίσουμε τις παραμέτρους PK, ώστε να μεταφέρουν αβεβαιότητα:

```sio
struct EpistemicPK {
    clearance: Knowledge<f64>,    // L/h ± uncertainty
    volume: Knowledge<f64>,       // L ± uncertainty
    dose: f64,                    // mg (known exactly — we control the dose)
    tau: f64,                     // hours (known exactly — we set the schedule)
}
```

Παρατηρήστε ότι τα `dose` και `tau` παραμένουν απλά `f64`: είναι **αποφάσεις** που λαμβάνουμε, όχι μετρήσεις. Αβεβαιότητα φέρουν μόνο τα μεγέθη που μετρήθηκαν.

## Δημιουργία παραμέτρων για συγκεκριμένο ασθενή

Ένα ρεαλιστικό κλινικό σενάριο για τη δοσολογία βανκομυκίνης:

```sio
fn create_patient_pk() -> EpistemicPK {
    EpistemicPK {
        // Clearance: estimated from Cockcroft-Gault
        // Population mean 4.5 L/h, but 30% inter-individual variability
        clearance: measure(4.5, uncertainty: 1.35),

        // Volume: estimated from body weight
        // 50 L ± 10% (weight-based estimation error)
        volume: measure(50.0, uncertainty: 5.0),

        dose: 1000.0,   // 1g vancomycin (exact)
        tau: 12.0,       // q12h (exact)
    }
}
```

Η αβεβαιότητα της κάθαρσης, 1,35 L/h (συντελεστής μεταβλητότητας 30%), αποτυπώνει πραγματική κλινική μεταβλητότητα: η κάθαρση της βανκομυκίνης εξαρτάται από τη νεφρική λειτουργία, την ηλικία, το βάρος και τη γενετική — παράγοντες που δεν γνωρίζουμε με ακρίβεια για κάθε ασθενή.

## Αριθμητική με τιμές Knowledge

Όταν εκτελείτε αριθμητικές πράξεις σε τιμές `Knowledge<T>`, το Sounio διαδίδει αυτόματα την αβεβαιότητα με διάδοση σφάλματος πρώτης τάξης (τη μέθοδο delta):

```sio
// Division propagates uncertainty from both operands
fn epistemic_half_life(pk: EpistemicPK) -> Knowledge<f64> {
    0.693 * pk.volume / pk.clearance
}

// The result carries combined uncertainty:
// σ(t½) = t½ × √((σ_V/V)² + (σ_CL/CL)²)
```

Δεν χρειάζεται να γράψετε τον τύπο διάδοσης: τον χειρίζεται ο τύπος `Knowledge<T>`. Ο compiler επαληθεύει ότι όλες οι πράξεις είναι ασφαλείς ως προς την αβεβαιότητα.

## Εξαγωγή πληροφοριών

Μπορείτε να ρωτήσετε μια τιμή `Knowledge<f64>` για τα επιμέρους συστατικά της:

```sio
fn main() with IO {
    let pk = create_patient_pk()
    let t_half = epistemic_half_life(pk)

    // Access the best estimate
    let value = t_half.value        // ~7.7 hours

    // Access the standard uncertainty
    let uncert = t_half.uncertainty // ~2.7 hours

    // Relative uncertainty (coefficient of variation)
    let cv = uncert / value         // ~35%

    print("Half-life: ")
    println(value)
    print(" ± ")
    println(uncert)
    print(" hours (CV: ")
    println(cv)
    print(")\n")
}
```

Συντελεστής μεταβλητότητας 35% στον χρόνο ημιζωής σημαίνει ότι οι προβλέψεις δοσολογίας μας έχουν σημαντική αβεβαιότητα. Πρόκειται για **κρίσιμη** κλινική πληροφορία που η απλή αριθμητική `f64` θα έκρυβε.

## Βασικά συμπεράσματα

- Το `Knowledge<f64>` τυλίγει μια τιμή μαζί με την τυπική αβεβαιότητά της
- Χρησιμοποιήστε `measure(value, uncertainty: sigma)` για να δημιουργήσετε επιστημολογικές τιμές
- Οι αριθμητικές πράξεις διαδίδουν αυτόματα την αβεβαιότητα
- Οι αποφάσεις (δόση, πρόγραμμα) παραμένουν απλά `f64` — αβεβαιότητα έχουν μόνο οι μετρήσεις
- Ο compiler διασφαλίζει ότι δεν θα αναμείξετε κατά λάθος βέβαιες και αβέβαιες τιμές με λανθασμένο τρόπο
