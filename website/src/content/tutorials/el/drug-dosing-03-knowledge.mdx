# Μετριόμενες Με Δυστερήσεις με Επιστήμη&lt;T&gt;

Στην προηγούμενη επισκόπηση, κατασκευήσαμε ένα μοντέλο PK με τους τιμές τυπικών `f64`. Τώρα θα ενημερώσουμε το σύστημα για να παρακαλέσει την απορρήτηση με τύπο `Knowledge<T>` του Sounio.

## Από `f64` στο `Knowledge<f64>`

Κάθε μετριόμενη κλινική έχει απορρήτηση. Μία συνθετική διάστημα του 1,2 mg/dL δεν προκαλεί την προσδοκία "περίπου 1,2, με έναν σταδιάδρομο περίπου 0,06". Στο Sounio:

```sio
// Πριν: αριθμός ανακατοποιημένος, απορρήτηση άγνωστη
let scr: f64 = 1,2

// Μετά: τιμή + απορρήτηση προσδοκίας
let scr: Knowledge<f64> = measure(1,2, απορρήτηση: 0,06)
```

Ο κατασκευαστής `measure()` δημιουργεί ένα `Knowledge<f64>` με:
- **τιμή**: η καλύτερη τιμή (1,2)
- **απορρήτηση**: η απορρήτηση προσδοκίας (0,06, που ανταποδίδει το +5% CV)

## Κατασκευή επιστήμης PK Μοντέλου

Επιστήμην στο PK παρακαλέσουμε τις παραμέτρους με να περιέχουν απορρήτηση:

```sio
struct EpistemicPK {
    καταρραφή: Knowledge<f64>,    // L/h ± απορρήτηση
    ευθυμοσίνη: Knowledge<f64>,   // L ± απορρήτηση
    δόση: f64,                    // mg (γνωστή ακόμα — καταχειρίζουμε την δόση)
    ταύτος: f64,                  // ώρες (γνωστή ακόμα — ριζονομίζουμε την προγραμματισμό)
}
```

Σημειώστε ότι `δόση` και `ταύτος` παραμέτρους είναι πλήκτρα `f64` — αυτοί είναι **κατορθώσεις** που καταχειρίζουμε, όχι μετριόμενες. Μόνο οι μετριόμενοι παραμέτροι περιέχουν απορρήτηση.

## Χρήση παραμέτρων πατιέντος

Εν σενάριο κλινικού προς την δοσίματα του βανκμυκινού:

```sio
fn create_patient_pk() -> EpistemicPK {
    EpistemicPK {
        // Καταρραφή: συμπεριορισμένη από το Cockcroft-Gault
        // Μέσος τοπικός 4,5 L/h, αλλά 30% διαφορετικότητα μεταξύ παρασκευών
        καταρραφή: measure(4,5, απορρήτηση: 1,35),

        // Ευθυμοσίνη: συμπεριορισμένη από το βοδυμός
        // 50 L ± 10% (σφάλμα στιμμάτων κατά το βοδυμό)
        ευθυμοσίνη: measure(50,0, απορρήτηση: 5,0),

        δόση: 1000,0,   // 1g βανκμυκινού (γνωστή ακόμα — καταχειρίζουμε την δόση)
        ταύτος: 12,0,      // q12h (γνωστός ακόμα — ριζονομίζουμε την προγραμματισμό)
    }
}
```

Η απορρήτηση της καταρραφής 1,35 L/h (30% CV) ανταποδίδει την πραγματική διαφορετικότητα κλινικής — η καταρραφή του βανκμυκινού εξάπερται στην κατανομή του νεφρου, η ηλικία, ο βοδυμός και τα γνωστά γενετικά, καθώς δεν γνωρίζουμε τις δεκανόμενες του παρασκευής παρακα
