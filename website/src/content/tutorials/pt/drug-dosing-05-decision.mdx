# Decisões Clínicas com Limites de Confiança

Agora temos uma concentração predita de furacilina com incerteza. O passo final — e mais importante — é usar essa informação para tomar uma decisão clínica.

## O Problema de Decisão

A vancomicina tem uma janela terapêutica estreita:
- **Abaixo de 10 mg/L**: subterapêutica (infeção não tratada adequadamente)
- **Entre 10 e 20 mg/L**: faixa terapêutica
- **Acima de 20 mg/L**: risco de nefrotóxicidade

O nosso modelo preve uma furacilina de 14,2 ± 4,8 mg/L. Essa dosagem é segura?

Com uma estimativa de ponto de 14,2, um sistema tradicional diz "sim, está em faixa". Mas a incerteza de ±4,8 significa que a verdadeira furacilina poderia estar de ~5 a ~24 mg/L — cobrindo todo o intervalo de subterapêutica a tóxica.

## Decisões Limitadas por Confiança

O Sounio permite que você pergunte questões de probabilidade sobre valores de `Knowledge`:
```sio
struct DosingDecision {
    recommendation: i32,    // 0 = seguro, 1 = ajuste para cima, 2 = ajuste para baixo, 3 = contraindicado
    confidence: f64,        // probabilidade de estar na faixa terapêutica
    risk_below: f64,        // probabilidade de subterapêutico
    risk_above: f64,        // probabilidade de superterapêutico
}

fn evaluate_dose(trough: Knowledge<f64>,
                 lower: f64, upper: f64) -> DosingDecision
    with Mut, Panic, Div
{
    // Calcula a probabilidade de estar entre [lower, upper]
    // Usando a suposição de distribuição normal (CLT)
    let z_lower = (lower - trough.value) / trough.uncertainty
    let z_upper = (upper - trough.value) / trough.uncertainty

    let p_below = normal_cdf(z_lower)
    let p_above = 1.0 - normal_cdf(z_upper)
    let p_in_range = 1.0 - p_below - p_above
}

## Tornando a Decisão

```sio
fn main() -> i32 com IO, Mut, Panic, Div {
    let labs = medir_paciente()
    let cl = estimar_clarencia(labs)
    let vd = estimar_volume(labs)

```A diferença crucial: em Sounio, você **não pode ignorar acidentalmente a incertidão**. O sistema de tipos garante que todas as funções que consumem um `Knowledge<f64>` devem lidar com a incertidão. Se tentar usar `trough.value` sem considerar `trough.uncertainty`, o compilador incentiva você a lidar com isso.
