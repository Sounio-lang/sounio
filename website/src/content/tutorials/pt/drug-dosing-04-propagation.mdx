# Propagação de Incertezas através do Modelo

Definimos nossos parâmetros farmacocinéticos com incertezas. Agora, vejamos como essa incertezas passa por um cálculo de doses completo — de medidas de pacientes até concentrações preditas de medicamento.

## O Eixo Completo

Um fluxo de trabalho farmacocinético clínico parece assim:

1. **Medir** laboratórios de pacientes (creatina, peso) → entradas incrédulas
2. **Estimar** parâmetros farmacocinéticos (limiar, volume) → incertezas derivadas
3. **Prever** concentrações de medicamento (Cmax, Cmin) → incertezas compôndidas
4. **Decidir** se a doses é segura → decisão limitada por confiança

Em Sounio, cada etapa preserva e propaga automaticamente a incertezas.

        age: 65.0,
    }
}

## Passo 2: Estimar Parâmetros FarmacocinéticosA equação de Cockcroft-Gault estimada a limpeza de creatinina a partir dos laboratórios do paciente. Como os entradas são `Knowledge&lt;f64&gt;`, a saída leva automaticamente a propagação de incertidão:

```sio
fn estimate_clearance(labs: PatientLabs) -> Knowledge<f64> {
    // CrCl (mL/min) = (140 - idade) × peso / (72 × SCr)
    let numerador = (140.0 - labs.idade) * labs.peso
    let denominador = 72.0 * labs.serum_creatinine
    numerator / denominador
}

fn estimate_volume(labs: PatientLabs) -> Knowledge<f64> {
    // Vd ≈ 0.7 L/kg × peso (com incertidão do modelo)
    0.7 * labs.peso
}
```

A estimativa de limpeza herda incertidão de tanto `peso` quanto `serum_creatinine`. A estimativa de volume herda incertidão de `peso`. Sounio calcula esses automaticamente.

## Step 3: Prever Concentrações
```sio
fn prever_troca(cl: Conhecimento<f64>, vd: Conhecimento<f64>,
                dose: f64, tau: f64) -> Conhecimento<f64> {
    let ke = cl / vd                          // taxa de eliminação
    let cmax = dose / vd                      // concentração máxima
    let decay = exp_k(0.0 - ke * tau)         // exp(-ke × tau)
    let acumulação = 1.0 / (1.0 - decay)   // fator de acumulação estacionária
    cmax * decay * acumulação
}
```

Cada operação compounding a incerteza. Até que chegamos à previsão do furacil, reflete a incerteza combinada de todas as medidas upstream.

# Análise de Sensibilidade

## Introdução

A função `analyze_sensitivity` calcula a contribuição da variação dos medicamentos entre diferentes variáveis dos pacientes. Ela fornece informações sobre como a variação dos medicamentos está distribuída entre as variáveis de claridade (CL) e dos volumes distribuídos (Vd), e como a variação dos medicamentos está relacionada à medida de SCr (Sérume Crênica).

## Parâmetros

- `labs`: Um objeto `PatientLabs` que contém os dados dos pacientes.
- `dose`: A dosagem do medicamento em mg.
- `tau`: O tempo de lag em horas.

## Retorno

- `SensitivityResult`: Um objeto contendo as contribuições da variação dos medicamentos entre a SCr e o peso do paciente, e a variância total.

## Exemplo de Uso

```rust
fn analyze_sensitivity(labs: PatientLabs, dose: f64, tau: f64) -> SensitivityResult
    with Mut, Panic, Div
{
    let cl = estimate_clearance(labs)
    let vd = estimate_volume(labs)
    let trough = predict_trough(cl, vd, dose, tau)

    // Variância decomposição via análise sobol
    let total_var = trough.uncertainty * trough.uncertainty

    // Contribuição da SCr (por meio da claridade)
    let scr_var = cl.uncertainty * cl.uncertainty
    let scr_frac = scr_var / total_var

    // Contribuição do peso (por meio de CL e Vd)
    let wt_frac = 1.0 - scr_frac  // restante

    SensitivityResult {
        scr_contribution: scr_frac,
        weight_contribution: wt_frac,
        total_cv: trough.uncertainty / trough.value,
    }
}
```

Isso diz ao clínico: *"67% da sua incertidão de dosagem provêm da análise de SCr. Se deseja uma dosagem mais precisa, obtenha uma medida melhor de SCr (por exemplo, Cystatin C) em vez de uma escala mais precisa."*
