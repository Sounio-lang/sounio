# Construindo um Modelo PK

Um modelo farmacocinético unicompartmento descreve como um medicamento se move pelo corpo. Ele tem três parâmetros principais:

- **Limiar (CL)**: a taxa com que o corpo elimina o medicamento (L/h)
- **Volume de distribuição (Vd)**: o volume aparente em que o medicamento se distribui (L)
- **Metade de vida (t½)**: tempo para a concentração sanguínea reduzir para metade (h)

Esses são relacionados: `t½ = 0.693 × Vd / CL`.

## Definindo o Modelo

Em Sounio, representamos os parâmetros PK como uma estrutura:

```sio
struct PKParams {
    clearance: f64,    // L/h
    volume: f64,       // L
    dose: f64,         // mg
    tau: f64,          // intervalo de dosagem, horas
}
```

Agora escrevamos funções que calculam quantidades derivadas. Observa as anotações de efeito:

```sio

    0.693 * pk.volume / pk.clearance

## O Problema: Incerteza Escondida

Este modelo fornece números precisos: Cmin = 6,8 mg/L. Mas como confiáveis são esses? O valor de limiar terapêutico de 4,5 L/h foi obtido de um valor médio de população. Para *este* paciente, poderia estar entre 3,0 e 6,0 L/h dependendo de sua função renal.

A janela terapêutica de vancomicina é de 15–20 mg/L para a média de paciente (orientado pelo AUC). É 6,8 mg/L seguramente abaixo do limiar de toxicidade, ou a incerteza é suficientemente grande para que a média verdadeira possa estar altamente perigosa?

Com valores `f64` brutos, não temos maneira de responder a essa questão. Na próxima lição, substituiremos seus parâmetros por valores `Knowledge<T>` que carregam incerteza.
