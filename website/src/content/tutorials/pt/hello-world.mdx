# Tutorial de Introdução ao Mundo

Neste tutorial, você aprenderá os fundamentals de Sounio escrevendo um pequeno programa de "Olá Mundo".

## Pré-requisitos

- Sounio instalado em seu sistema ([Guia de Instalação](/learn/getting-started))
- Um editor de texto de sua escolha

## Passo 1: Crie seu Arquivo

Crie um novo arquivo chamado `hello.sio`:

```sio
fn main() with IO {
    print("Olá, Mundo!")
}
```

Vamos desmontar isso:

- `fn main()` declara a função principal, o ponto de entrada de qualquer programa Sounio
- `with IO` declara que esta função faz efeitos de IO (imprimir no console)
- `print("...")` imprime texto no console

## Passo 2: Execute Seu Programa

Abrir sua terminal e executar:

```bash
sounio run hello.sio
```

Você deve ver:

```
Olá, Mundo!
```

Parabéns! Você escreveu seu primeiro programa Sounio.

## Passo 3: Adicionar Variáveis

Vamos tornar isso mais interessante:

```sio
fn main() with IO {
    let name = "Sounio"
    let version = 1.0

    print("Bem-vindo a " + name + " v" + version.to_string())
}
```
