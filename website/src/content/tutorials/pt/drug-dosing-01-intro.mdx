# O que é Computação Epistêmica?

Todo medida na ciência traz incerteza. Quando um farmacêutico mede o nível de creatinina de um paciente em 1,2 mg/dL, esse número não é exato — a análise tem uma variabilidade de coeficiente de aproximadamente 5%. Quando um médico receita 500 mg de vancomicina, a doses biologicamente disponíveis reais dependem da função renal, peso e dezenas de outros fatores que sabemos apenas de maneira aproximada.

A maioria dos idiomas de programação ignoram isso. Um `float` é um `float`, e `1,2` é tratado como se fosse conhecido com infinita precisão. Sounio adota uma abordagem diferente.

## Conhecimento vs. Dados

Em Sounio, um valor pode conter **meta-informação epistêmica** — informação sobre a nossa confiança em esse valor. O sistema de tipos distingue entre:

- **Dados**: um número bruto (`f64`, `i32`)
- **Conhecimento**: um número mais sua incerteza (`Knowledge<f64>`)

Aqui está a diferença:

```sio
// Dado bruto — nenhuma informação sobre a incerteza
let creatinine: f64 = 1,2

// Conhecimento — valor + incerteza padrão
let creatinine: Knowledge<f64> = measure(1,2, incerteza: 0,06)
```

A função `measure` cria um valor `Knowledge<f64>`: a melhor estimativa é 1,2, e a incerteza padrão é 0,06 (5% CV).

## Por que Isso Importa?

Quando você trabalha com valores `Knowledge`, a incerteza **propaga automaticamente**. Se você calcula a eliminação de medicamento a partir da creatinina, o resultado também consegue a incerteza — e Sounio o rastreia para você.

```sio
fn cockcroft_gault(idade: f64, peso: Knowledge<f64>, scr: Knowledge<f64>) -> Knowledge<f64> {
    // CrCl = (140 - idade) * peso / (72 * SCr)
    let numerador = (140,0 - idade) * peso
    let denominador = 72,0 * scr
    numerator / denominador
}
```

A saída `Knowledge<f64>` automaticamente reflete a incerteza combinada de ambos `peso` e `scr`. Não é necessário propagar erros manualmente.

## Efeitos: Rastreamento de Efeitos Adicionais

Sounio também rastreia **efetos** — o que uma função pode fazer. Se uma função ler de um arquivo, deve declarar `com IO`. Se ele alocar memória, `com Alocação`. Se ele pode dividir por zero, `com Div`.

```sio
fn safe_divide(a: f64, b: f64) -> f64 com Div {
    a / b
}

fn greet(nome: string) com IO {
    print("Olá, ")
    print(nome)
    print("\n")
}
```

Isto não é apenas documentação — o compilador **aplica** isso. Uma função sem `com IO` não pode chamar `print`. Isso significa que você pode olhar em qualquer assinatura de função e saber exatamente o que ela pode fazer.

## Pontos Clave

- O tipo `Knowledge<T>` de Sounio rastra a incerteza como um conceito de primeira classe
- Efeitos (`com IO`, `com Div`, `com Mut`) fazem explicitos os efeitos adicionais
- Juntos, esses recursos impedem a propagação silenciosa de suposições ruins — o mais perigoso bug na computação científica
