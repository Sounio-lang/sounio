# Primeros Pasos

Los programas de Sounio son archivos `.sio` que se verifican, ejecutan o compilan con `souc`. Esta guía es el punto de entrada práctico para el flujo público actual: parte del artefacto de compilador versionado, valida con `souc check`, y trata los gates y fixtures del repositorio como la fuente de verdad de lo que realmente funciona hoy.

## Verificado hoy
- El lanzador canónico verificado en `$(pwd)/bin/souc` es el punto de entrada documentado más seguro.
- En este proyecto aparecen dos números de versión que nombran cosas distintas: **2.1.0** es la release del lenguaje (badge del README, `CITATION.cff`, `CHANGELOG.md`), y **Madaros v0.80.0** es el build del compilador que imprime `bin/souc --version` (motor por defecto Madaros). Las antiguas cadenas de versión beta anteriores a 2.0 están retiradas.
- La cifra e2e de la stdlib se está volviendo a medir. El archivo de resultado versionado (`artifacts/stdlib/stdlib_e2e_result.v1.json`, 2026-05-12) es anterior a la aplicación de la privacidad de módulos, así que aquí no se cita ninguna tasa de aprobación.
- El compilador solo tiene como objetivo Linux x86-64 y emite ELF estático. El Cranelift JIT ya no se distribuye (CHANGELOG 2.1.0). `souc build --backend gpu` emite PTX para un esqueleto de patrones de kernel con nombre, no un backend GPU general, y el backend WASM es un borrador bloqueado ([#2237](https://github.com/Sounio-lang/sounio/issues/2237)). Ver [TOUR.md §6](https://github.com/Sounio-lang/sounio/blob/main/TOUR.md).
- Apunta `SOUNIO_STDLIB_PATH` al árbol versionado `stdlib/`.
- Prefiere `souc check` antes de `run` o `build`.

## Caveats actuales
- El comportamiento depende del binario exacto de `souc`, no solo de los archivos presentes en el repositorio.
- Un build Cargo en la raíz ya no es la mejor historia inicial para la documentación pública.

## Pruébalo en este repositorio

```bash
export SOUC_BIN="$(pwd)/bin/souc"
export SOUNIO_STDLIB_PATH="$(pwd)/stdlib"

"$SOUC_BIN" --version
"$SOUC_BIN" check examples/hello.sio
"$SOUC_BIN" check tests/run-pass/covid_2020_kernel.sio
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
```
