# Primeros Pasos

Los programas de Sounio son archivos `.sio` que se verifican, ejecutan o compilan con `souc`. Esta guía es el punto de entrada práctico para el flujo público actual: parte del artefacto de compilador versionado, valida con `souc check`, y trata los gates y fixtures del repositorio como la fuente de verdad de lo que realmente funciona hoy.

## Verificado hoy
- El lanzador canónico verificado en `$(pwd)/bin/souc` es el punto de entrada documentado más seguro. El flujo público por defecto es **ELF/Mach-O nativo self-hosted** — no un build de Rust/Cargo ni Cranelift JIT como historia de incorporación.
- Los perfiles omega opcionales (Cranelift JIT, GPU) existen aparte del contrato por defecto de `bin/souc`; confirma la capacidad con `souc info` antes de documentarla como disponible.
- Apunta `SOUNIO_STDLIB_PATH` al árbol versionado `stdlib/`.
- Prefiere `souc check` antes de `run` o `build`.

## Caveats actuales
- El comportamiento depende del binario exacto de `souc`, no solo de los archivos presentes en el repositorio.
- Un build Cargo en la raíz ya no es la mejor historia inicial para la documentación pública.

## Pruébalo en este repositorio

```bash
export SOUC_BIN="$(pwd)/bin/souc"
export SOUNIO_STDLIB_PATH="$(pwd)/stdlib"

"$SOUC_BIN" --version
"$SOUC_BIN" check examples/hello.sio
"$SOUC_BIN" check tests/run-pass/covid_2020_kernel.sio
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
```
