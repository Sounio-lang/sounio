# Code Generation

Los docs de generación de código ahora se atan al artefacto que verificamos: Cranelift JIT es real, mientras que otras afirmaciones de backend necesitan confirmación específica por artefacto.

## Verificado hoy
- El artefacto público versionado informa que Cranelift JIT está habilitado.
- Backends como LLVM, GPU y LSP deben confirmarse por artefacto, no inferirse a partir del árbol de fuentes.
- Trata los tests y los artefactos de gate como evidencia más fuerte que la prosa aspiracional o los nombres de directorio.

## Caveats actuales
- El artefacto JIT público incluido informa que GPU está desactivado.
- El comportamiento depende del binario exacto de `souc`, no solo de los archivos presentes en el repositorio.
