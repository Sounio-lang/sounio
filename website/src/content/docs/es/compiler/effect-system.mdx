# Effect System

El sistema de efectos sigue siendo central en el diseño, pero los docs públicos ahora separan el contrato de firma aplicado del modelo más rico de handlers todavía en evolución activa.

## Verificado hoy
- Los efectos explícitos con `with ...` siguen siendo parte real del contrato del lenguaje.
- Usa `with IO` en el borde externo y mantén el resto del pipeline lo más puro posible.
- Los efectos personalizados forman parte del diseño del lenguaje, pero la ergonomía profunda de handlers sigue evolucionando.

## Caveats actuales
- El modelo más rico de handlers existe en el diseño, pero el soporte de ejecución sigue siendo desigual.
- Backends como LLVM, GPU y LSP deben confirmarse por artefacto, no inferirse a partir del árbol de fuentes.
