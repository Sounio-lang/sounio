# Scientific Features

Las features científicas ahora se describen a través de las lanes que realmente pasan y de las superficies de librería que siguen parcialmente deshabilitadas o en soft-fail.

## Verificado hoy
- Los scripts de gate y los artefactos versionados son la evidencia más fuerte para las afirmaciones públicas.
- `tests/run-pass/vancomycin_propagation.sio` y el fixture médico documentan el flujo epistemic actual.
- Los artefactos versionados de la stdlib informan `251 pass / 0 fail / 0 skip / 251 total`, con `604` archivos `.sio` y `111` archivos deshabilitados.

## Caveats actuales
- El runtime científico local todavía rastrea cuatro regression probes en modo soft.
- Los módulos stub y los archivos `*.sio.disabled` son inventario de roadmap, no APIs estables.
