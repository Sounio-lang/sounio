# Vancomycin Uncertainty

El caso de vancomicina sigue siendo la prueba pública más clara de que las restricciones epistémicas pueden producir negativa en tiempo de compilación en Sounio.

## Verificado hoy
- `tests/run-pass/vancomycin_propagation.sio` y el fixture médico documentan el flujo epistemic actual.
- `tests/compile-fail/vancomycin_low_conf.sio` sigue demostrando la negativa en tiempo de compilación.
- Los assets en `/docs/assets/vancomycin-ship/` siguen siendo la evidencia visual pública de este caso de estudio.

## Caveats actuales
- El comportamiento depende del binario exacto de `souc`, no solo de los archivos presentes en el repositorio.
- El modelo completo de incertidumbre y proveniencia es más rico en la spec y en la stdlib que en el artefacto validado de hoy.

## Pruébalo en este repositorio

```bash
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/run-pass/med/vancomycin_full_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
"$SOUC_BIN" check tests/compile-fail/med/vancomycin_low_conf_refusal.sio
```
