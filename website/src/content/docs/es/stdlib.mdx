# Biblioteca Estándar

La stdlib es grande y activa, pero los docs públicos ahora la describen mediante conteos de inventario respaldados por gates y caveats explícitos sobre módulos deshabilitados o stub.

## Verificado hoy
- Los artefactos versionados de la stdlib informan `251 pass / 0 fail / 0 skip / 251 total`, con `604` archivos `.sio` y `111` archivos deshabilitados.
- Los scripts de gate y los artefactos versionados son la evidencia más fuerte para las afirmaciones públicas.
- Trata los tests y los artefactos de gate como evidencia más fuerte que la prosa aspiracional o los nombres de directorio.

## Caveats actuales
- Los módulos stub y los archivos `*.sio.disabled` son inventario de roadmap, no APIs estables.
- El comportamiento depende del binario exacto de `souc`, no solo de los archivos presentes en el repositorio.
