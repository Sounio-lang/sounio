# Feature Status

Esta página es el panel de estado compacto para el contrato público. Los números se regeneran a partir de gate JSONs versionados y el README.md mediante `npm run sync:artifacts` — no son texto de marketing mantenido a mano.

<FeatureStatusPanel />

## Por qué importan estos números

- Provienen de artefactos versionados, no de texto aspiracional de roadmap.
- Definen lo que la documentación puede afirmar sin salvedades.
- Explican por qué partes grandes del repositorio todavía deben describirse como trabajo activo, superficie stub, o inventario deshabilitado, en lugar de APIs estables.

## Cómo usar esta página

- Úsala como el resumen de estado de la puerta de entrada.
- Usa las páginas de documentación más detalladas cuando necesites profundidad de workflow, arquitectura o implementación.
- Usa los artefactos en bruto cuando necesites detalle exacto a nivel de lane o prueba legible por máquina.
