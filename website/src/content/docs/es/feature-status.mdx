# Feature Status

Esta página ahora informa el snapshot realmente entregado: conteos respaldados por artefactos, lanes activas y caveats explícitos sobre superficies deshabilitadas o en soft-fail.

## Verificado hoy
- La instantánea de features de este sitio está basada en artefactos de estado versionados.
- Los artefactos versionados de la stdlib informan `251 pass / 0 fail / 0 skip / 251 total`, con `604` archivos `.sio` y `111` archivos deshabilitados.
- El artefacto JIT versionado informa que perfil JIT opcional (não é o onboarding default).
- El artefacto GPU versionado informa GPU codegen habilitado y emisión PTX vía `build --backend gpu`.
- Self-hosted GPU emission: `kretikos emit-ptx` (PTX), `kretikos emit-metal` (MSL), and `kretikos emit-cubin` (CUBIN) from in-tree emitters
- Los lanes GPU attestados hoy son CUDA `cuda-sm80` y ROCm `rocm-gfx942`.

## Caveats actuales
- El runtime científico local todavía rastrea cuatro regression probes en modo soft.
- Los módulos stub y los archivos `*.sio.disabled` son inventario de roadmap, no APIs estables.
