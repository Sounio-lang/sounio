# Herramientas

La historia de tooling ahora está fundamentada en el artefacto `souc` versionado, en las capacidades que reporta y en los scripts de gate que ejercitan el repositorio.

## Verificado hoy
- El artefacto versionado de `souc` expone la superficie real de la CLI directamente con `--help` e `info`.
- Los scripts de gate y los artefactos versionados son la evidencia más fuerte para las afirmaciones públicas.
- Prefiere `souc check` antes de `run` o `build`.

## Caveats actuales
- El comportamiento depende del binario exacto de `souc`, no solo de los archivos presentes en el repositorio.
- Backends como LLVM, GPU y LSP deben confirmarse por artefacto, no inferirse a partir del árbol de fuentes.

## Pruébalo en este repositorio

```bash
"$SOUC_BIN" --help
"$SOUC_BIN" info
"$SOUC_BIN" fmt --help
"$SOUC_BIN" lint --help

bash scripts/selfhost/selfhost_zero_fallback_gate.sh
```
