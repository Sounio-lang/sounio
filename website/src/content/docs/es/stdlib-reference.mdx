# Referencia de la biblioteca estandar

La stdlib de Sounio se encuentra en `stdlib/` dentro del repositorio. El snapshot actual de confiabilidad es **251 pass / 0 fail / 0 skip / 251 total** a traves de fixtures respaldados por gates.

## Modulos principales

### `stdlib/io`

Operaciones de entrada/salida. Todas las funciones requieren el efecto `IO`.

| Function | Signature | Description |
|----------|-----------|-------------|
| `println` | `fn println(s: str) with IO` | Imprime string con salto de linea a stdout |
| `print` | `fn print(s: str) with IO` | Imprime string sin salto de linea |
| `read_line` | `fn read_line() -> str with IO` | Lee una linea desde stdin |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | Lee un archivo completo como string |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | Escribe un string a un archivo |

### `stdlib/math`

Funciones matematicas y constantes.

| Function | Signature | Description |
|----------|-----------|-------------|
| `sqrt` | `fn sqrt(x: f64) -> f64` | Raiz cuadrada |
| `abs` | `fn abs(x: f64) -> f64` | Valor absoluto |
| `sin` | `fn sin(x: f64) -> f64` | Seno (radianes) |
| `cos` | `fn cos(x: f64) -> f64` | Coseno (radianes) |
| `exp` | `fn exp(x: f64) -> f64` | Exponencial natural |
| `ln` | `fn ln(x: f64) -> f64` | Logaritmo natural |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | Exponenciacion |
| `PI` | `f64` | 3.14159265358979... |
| `E` | `f64` | 2.71828182845904... |

### `stdlib/collections`

Operaciones sobre estructuras de datos.

| Function | Signature | Description |
|----------|-----------|-------------|
| `len` | `fn len<T>(arr: &[T]) -> i64` | Longitud del arreglo |
| `push` | `fn push<T>(arr: &![T], val: T)` | Agregar al final del arreglo |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | Remover el ultimo elemento |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | Transformar elementos |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | Conservar elementos que coincidan |
| `++` | `[T] ++ [T] -> [T]` | Operador de concatenacion de arreglos |

### `stdlib/sync`

Primitivas de concurrencia. Disponibles desde el Sprint 86.

| Type | Description |
|------|-------------|
| `Mutex<T>` | Lock de exclusion mutua (respaldado por pthread) |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` |

## Modulos cientificos

### `stdlib/pharma`

Toolkit de farmacometria para modelado PK/PD.

| Function | Description |
|----------|-------------|
| `pk_one_compartment` | Modelo PK de un compartimento |
| `compute_auc` | Calculo de area bajo la curva |
| `dose_adjust` | Ajuste bayesiano de dosis con confianza |

### `stdlib/fmri`

Procesamiento de senal de fMRI funcional (estado del gate: PASSING).

| Function | Description |
|----------|-------------|
| `bold_signal` | Extraccion de senal BOLD |
| `glm_fit` | Ajuste de modelo lineal general |
| `threshold_clusters` | Umbral a nivel de cluster con proveniencia |

### `stdlib/darwin_pbpk`

Modelado farmacocinético de base fisiológica (estado del gate: PASSING).

| Característica | Descripción |
|----------|-------------|
| **Modelos Principales** | Modelos PBPK de 14 y 28 compartimentos con solvers Tsit5 |
| **Mecanismos** | Partición de péptidos, composición de tejidos y cálculos de Rodgers-Rowland Kp |
| **Aproximación** | Aproximación de cuasi-equilibrio (QE) para compartimentos de equilibrio rápido |
| **Epistémicos** | Seguimiento de incertidumbre nativo vía cumulantes y evaluación Hessiana |

### `stdlib/genomics`

Analisis de secuencias genomicas con propagacion de incertidumbre.

### `stdlib/nn`

Capas y operaciones de redes neuronales.

## Modulos epistemicos

### `stdlib/epistemic`

Operaciones principales sobre tipos epistemicos.

| Type | Description |
|------|-------------|
| `Knowledge<T>` | Valor con intervalo de confianza y proveniencia |
| `Validated<T>` | Valor que paso un gate de validacion |
| `Intervention<T>` | Marcador de intervencion causal |
| `Counterfactual<T>` | Marcador de razonamiento contrafactual |

| Function | Signature | Description |
|----------|-----------|-------------|
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | Crear una medicion |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | Extraer el nivel de confianza |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | Propagar incertidumbre a traves de un computo |
