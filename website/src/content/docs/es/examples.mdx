# Ejemplos

Los ejemplos ahora se enmarcan primero alrededor de fixtures verificados. Trata `tests/` como la evidencia actual más fuerte y `examples/` como material más pequeño de onboarding.

## Verificado hoy
- `examples/hello.sio` sigue siendo el punto de partida verificado más pequeño.
- `tests/run-pass/covid_2020_kernel.sio` es un fixture científico actual y verificado.
- `tests/run-pass/vancomycin_propagation.sio` y el fixture médico documentan el flujo epistemic actual.

## Caveats actuales
- `tests/compile-fail/vancomycin_low_conf.sio` sigue demostrando la negativa en tiempo de compilación.
- Los módulos stub y los archivos `*.sio.disabled` son inventario de roadmap, no APIs estables.

## Pruébalo en este repositorio

```bash
"$SOUC_BIN" check examples/hello.sio
"$SOUC_BIN" check tests/run-pass/covid_2020_kernel.sio
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
```
