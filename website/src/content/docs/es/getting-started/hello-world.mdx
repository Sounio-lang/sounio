# Hola, Mundo

Vamos a escribir tu primer programa en Sounio.

## Crear el Archivo

Crea un archivo nuevo llamado `hello.sio`:

```sio
fn main() with IO {
    println("Hello, Sounio!")
}
```

## Entender el Código

- **`fn main()`** - El punto de entrada de todo programa Sounio
- **`with IO`** - Declara que esta función realiza IO (recomendado; la especificación exige efectos explícitos)
- **`println(...)`** - Imprime un valor en la consola

## Ejecutar el Programa

```bash
souc run hello.sio
```

Salida:
```
Hello, Sounio!
```

## Agregar Variables

```sio
fn main() with IO {
    let name = "Sounio"
    let year = 2026

    print("Welcome to ")
    println(name)

    print("Established in ")
    println(year)
}
```
