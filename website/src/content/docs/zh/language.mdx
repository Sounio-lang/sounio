# 语言指南

本节记录 `souc` 当前实现的 Sounio *表层语言*，并在规范领先于实现时给出提示。

## 与 Rust 风格语法的关键区别

- 可变绑定使用 `var`（不是 `let mut`）
- 可变引用使用 `&!T`（不是 `&mut T`）
- 效果通过函数签名里的 `with IO, Panic, ...` 明确声明
