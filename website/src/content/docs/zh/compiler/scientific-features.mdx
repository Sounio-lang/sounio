# Scientific Features

科学特性页面现在通过真正通过的 lane，以及那些仍然部分禁用或 soft-fail 的库表面来描述。

## 今日已验证
- gate 脚本和提交的构件是公开声明最强的证据。
- `tests/run-pass/vancomycin_propagation.sio` 和 med fixture 共同描述了当前的 epistemic 工作流。
- 提交的 stdlib 构件报告为 `251 pass / 0 fail / 0 skip / 251 total`，其中有 `927` 个 `.sio` 文件和 `0` 个禁用文件。

## 当前限制
- 本地科学运行时仍以 soft 模式跟踪四个回归探针。
- stub 模块和 `*.sio.disabled` 文件属于路线图库存，不应视为稳定 API。
