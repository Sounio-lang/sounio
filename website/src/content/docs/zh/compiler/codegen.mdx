# Code Generation

代码生成文档现在回连到我们验证过的构件：Cranelift JIT 是真实可用的，而其他后端声明需要按构件逐一确认。

## 今日已验证
- 提交的公开构件报告 Cranelift JIT 为启用状态。
- LLVM、GPU 和 LSP 等后端能力必须按构件确认，不能只看源码目录。
- 测试和 gate 构件比愿景式描述或目录名称更值得信任。

## 当前限制
- 仓库中提交的公开 JIT 构件报告 GPU 支持为关闭状态。
- 真实行为取决于具体的 `souc` 二进制，而不只是仓库里有哪些文件。
