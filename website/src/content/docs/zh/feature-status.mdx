# Feature Status

本页是公开契约的紧凑状态面板。数字通过 `npm run sync:artifacts` 从已提交的 gate JSON 和 README.md 重新生成——不是手工维护的营销文案。

<FeatureStatusPanel />

## 为什么这些数字重要

- 它们来自已提交的构件，而不是有抱负的路线图文案。
- 它们定义了文档在不加限定条件的情况下可以声称的内容。
- 它们解释了为什么仓库中的大部分内容仍应被描述为进行中的工作、stub 表面或已禁用库存，而不是稳定的 API。

## 如何使用本页

- 把它当作门户状态摘要来使用。
- 需要工作流、架构或实现深度时，使用更详细的文档页面。
- 需要精确的 lane 级细节或机器可读证明时，使用原始构件。
