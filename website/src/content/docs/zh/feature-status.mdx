# Feature Status

这个页面现在报告真实交付状态：有构件支撑的通过计数、活跃 lane，以及对禁用或 soft-fail 表面的明确说明。

## 今日已验证
- 本站的功能快照以已提交的状态构件为依据。
- 提交的 stdlib 构件报告为 `251 pass / 0 fail / 0 skip / 251 total`，其中有 `927` 个 `.sio` 文件和 `0` 个禁用文件。
- 已提交的 JIT 构件报告 可选 JIT 配置文件（非默认入门路径）状态。
- 已提交的 GPU 构件报告 GPU codegen 已启用，并支持通过 `build --backend gpu` 输出 PTX。
- Self-hosted GPU emission: `kretikos emit-ptx` (PTX), `kretikos emit-metal` (MSL), and `kretikos emit-cubin` (CUBIN) from in-tree emitters
- 当前 attested 的 GPU 计算 lanes 是 CUDA `cuda-sm80` 与 ROCm `rocm-gfx942`。

- 本地科学运行时仍以 soft 模式跟踪四个回归探针。
- stub 模块和 `*.sio.disabled` 文件属于路线图库存，不应视为稳定 API。
