# 标准库参考

Sounio 标准库位于仓库的 `stdlib/` 目录下。当前可靠性快照为：**81 通过 / 0 失败 / 1 跳过 / 共 82 项**（基于门控测试用例）。

## 核心模块

### `stdlib/io`

输入/输出操作。所有函数都需要 `IO` effect。

| 函数 | 签名 | 说明 |
|----------|-----------|-------------|
| `println` | `fn println(s: str) with IO` | 向 stdout 打印字符串并换行 |
| `print` | `fn print(s: str) with IO` | 向 stdout 打印字符串，不换行 |
| `read_line` | `fn read_line() -> str with IO` | 从 stdin 读取一行 |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | 将整个文件读取为字符串 |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | 将字符串写入文件 |

### `stdlib/math`

数学函数与常量。

| 函数 | 签名 | 说明 |
|----------|-----------|-------------|
| `sqrt` | `fn sqrt(x: f64) -> f64` | 平方根 |
| `abs` | `fn abs(x: f64) -> f64` | 绝对值 |
| `sin` | `fn sin(x: f64) -> f64` | 正弦（弧度） |
| `cos` | `fn cos(x: f64) -> f64` | 余弦（弧度） |
| `exp` | `fn exp(x: f64) -> f64` | 自然指数 |
| `ln` | `fn ln(x: f64) -> f64` | 自然对数 |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | 幂运算 |
| `PI` | `f64` | 3.14159265358979... |
| `E` | `f64` | 2.71828182845904... |

### `stdlib/collections`

数据结构操作。

| 函数 | 签名 | 说明 |
|----------|-----------|-------------|
| `len` | `fn len<T>(arr: &[T]) -> i64` | 数组长度 |
| `push` | `fn push<T>(arr: &![T], val: T)` | 追加到数组末尾 |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | 移除最后一个元素 |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | 变换元素 |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | 保留匹配的元素 |
| `++` | `[T] ++ [T] -> [T]` | 数组连接运算符 |

### `stdlib/sync`

并发原语。自 Sprint 86 起可用。

| 类型 | 说明 |
|------|-------------|
| `Mutex<T>` | 互斥锁（基于 pthread） |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` |

## 科学模块

### `stdlib/pharma`

药物动力学/药效学（PK/PD）建模工具包。

| 函数 | 说明 |
|----------|-------------|
| `pk_one_compartment` | 单室 PK 模型 |
| `compute_auc` | 曲线下面积计算 |
| `dose_adjust` | 带置信度的贝叶斯剂量调整 |

### `stdlib/fmri`

功能性 MRI 信号处理（门控状态：通过）。

| 函数 | 说明 |
|----------|-------------|
| `bold_signal` | BOLD 信号提取 |
| `glm_fit` | 一般线性模型拟合 |
| `threshold_clusters` | 带溯源的簇级阈值处理 |

### `stdlib/darwin_pbpk`

基于生理学的药代动力学建模 (gate 状态: PASSING)。

| 功能 | 描述 |
|----------|-------------|
| **核心模型** | 带有 Tsit5 求解器的 14 和 28 房室 PBPK 模型 |
| **机制** | 肽分配、组织组成和 Rodgers-Rowland Kp 计算 |
| **近似** | 用于快速平衡房室的准平衡 (QE) 近似 |
| **认知论** | 通过累积量和海森矩阵评估进行本机不确定性跟踪 |

### `stdlib/genomics`

带不确定性传播的基因组序列分析。

### `stdlib/nn`

神经网络层和操作。

## 认知模块

### `stdlib/epistemic`

核心认知类型操作。

| 类型 | 说明 |
|------|-------------|
| `Knowledge<T>` | 带置信区间和溯源信息的值 |
| `Validated<T>` | 通过验证门控的值 |
| `Intervention<T>` | 因果干预标记 |
| `Counterfactual<T>` | 反事实推理标记 |

| 函数 | 签名 | 说明 |
|----------|-----------|-------------|
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | 创建一个测量值 |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | 提取置信度 |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | 通过计算传播不确定性 |
