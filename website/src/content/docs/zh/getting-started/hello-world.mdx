# Hello World

我们来写你的第一个 Sounio 程序。

## 创建文件

创建一个名为 `hello.sio` 的新文件:

```sio
fn main() with IO {
    println("Hello, Sounio!")
}
```

## 理解代码

- **`fn main()`** - 每个 Sounio 程序的入口点
- **`with IO`** - 声明该函数会执行 IO（推荐；规范要求显式效果）
- **`println(...)`** - 向控制台输出一个值

## 运行程序

```bash
souc run hello.sio
```

输出:
```
Hello, Sounio!
```

## 添加变量

```sio
fn main() with IO {
    let name = "Sounio"
    let year = 2026

    print("Welcome to ")
    println(name)

    print("Established in ")
    println(year)
}
```
