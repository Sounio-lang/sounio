# Language Spec (v1.0.0)

把语言规范当作 Sounio 的更大模型来阅读，然后用当前构件、测试和 gate 支撑的文档去验证每一条具体主张。

## 今日已验证
- 语言规范可能领先于当前公开构件真正执行的能力。
- 测试和 gate 构件比愿景式描述或目录名称更值得信任。
- 显式 `with ...` effect 仍然是语言真实合同的一部分。

## 当前限制
- LLVM、GPU 和 LSP 等后端能力必须按构件确认，不能只看源码目录。
- 单位与 quantity 语法存在，但端到端约束仍然只有部分实现。
