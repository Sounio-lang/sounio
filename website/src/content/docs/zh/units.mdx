# 单位（Units）

单位仍然是语言方向中的重要部分，但当前最稳妥的公开描述仍然是：语法存在，而约束实现仍是部分的。

## 今日已验证
- 单位与 quantity 语法存在，但端到端约束仍然只有部分实现。
- 当涉及单位、effects 或置信度敏感值时，显式注解仍然最稳妥。
- 测试和 gate 构件比愿景式描述或目录名称更值得信任。

## 当前限制
- 语言规范可能领先于当前公开构件真正执行的能力。
- 真实行为取决于具体的 `souc` 二进制，而不只是仓库里有哪些文件。
