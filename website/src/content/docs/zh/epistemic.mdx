# 认识论类型

Sounio 面向科学计算与合规/监管场景。在这些场景中，数值往往不是"纯粹的数字"。测量值与推导量应当携带:

- 不确定性（计量学）
- 置信度/可信度（trust）
- 溯源（来源 + 变换历史）

## 四种认识论类型

Sounio 有四种第一级认识论 wrapper 类型。所有类型共享 `.value: T` 和 `.epsilon: f64`（置信度分数，0–1）字段。

### Knowledge\<T\>

用不确定性与溯源包裹一个测量值。这是基础认识论类型。

```sio
let dose: Knowledge<mg> = Knowledge(500.0, ε=0.97, prov="run_042")

if dose.epsilon > 0.95 {
  approve_for_decision(dose)
} else {
  request_remeasurement(dose)
}
```

提取普通的 `T` 必须通过带理由字符串的显式操作 — 不会意外丢失认识论元数据:

```sio
let raw: mg = dose.unwrap("人工覆盖，已审计")
```

### Validated\<T\>

通过正式阈值检查的值变为 `Validated<T>` — 编译器将其与原始 `Knowledge<T>` 区别对待的独立类型。

```sio
let safe: Validated<mg> = validate(dose, threshold: 0.95)

// Validated<T> 可传递给要求已证明安全的函数
administer(safe)
```

### Intervention\<T\>

表示因果干预 — do-calculus 算子 `do(X=x)`。`.epsilon` 字段携带干预估计的置信度。

```sio
// 因果干预: do(Treatment = active)
let treated: Intervention<bool> = intervene(true)

if treated.epsilon > 0.90 {
  run_rct_arm(treated)
}
```

### Counterfactual\<T\>

表示反事实查询 — 在不同条件下变量 *本来会是* 什么。反事实的置信度反映了可识别性和模型质量。

```sio
// 如果 Alice 接受过教育，收入会是多少?
let cf: Counterfactual<f64> = counterfactual(
  observed: 30000.0,
  under: education_iv
)

if cf.epsilon > 0.90 {
  report_finding(cf)
}
```

## 今天可用的部分（编译器现状）

四种类型均经过解析、类型检查，并通过完整 pipeline（HIR → SIR → HLIR → 原生 ELF）编译:

- 构造: `Knowledge(...)`, `validate(...)`, `intervene(...)`, `counterfactual(...)`
- 字段访问: `.value`, `.epsilon`
- 置信度门控: `if x.epsilon > threshold { ... }`
- 解包: `.unwrap("原因")` 提取普通 `T`

## 规范 vs 实现

完整设计的目标更丰富: 基于原则的不确定性传播、置信度的单调性，以及在纯变换下 append-only 的溯源。

其中一部分已体现在语言规范与 stdlib 设计文档中，但具体强制程度可能随编译器模式与特性开关而变化。
