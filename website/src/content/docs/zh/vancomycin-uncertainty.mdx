# Vancomycin Uncertainty

vancomycin 案例仍然是最清晰的公开证据，说明 epistemic 约束可以在 Sounio 中驱动编译期拒绝。

## 今日已验证
- `tests/run-pass/vancomycin_propagation.sio` 和 med fixture 共同描述了当前的 epistemic 工作流。
- `tests/compile-fail/vancomycin_low_conf.sio` 仍然证明了编译期拒绝。
- `/docs/assets/vancomycin-ship/` 下的资源仍然是这个案例研究的公开可视化证据。

## 当前限制
- 真实行为取决于具体的 `souc` 二进制，而不只是仓库里有哪些文件。
- 完整的不确定性和 provenance 模型在 spec 与 stdlib 文档中比今天验证过的构件更丰富。

## 在这个仓库中验证

```bash
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/run-pass/med/vancomycin_full_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
"$SOUC_BIN" check tests/compile-fail/med/vancomycin_low_conf_refusal.sio
```
