# LSP

Η ενσωμάτωση editor παραμένει πραγματικό code path, αλλά πρέπει να περιγράφεται ως feature-gated και artifact-dependent αντί για καθολικά διαθέσιμη.

## Επαληθευμένο σήμερα
- Η υποστήριξη LSP υπάρχει ως code path και feature-gated binary story, όχι ως default capability του checked-in artifact.
- Για βαθύτερα internals, διαβάστε μαζί τα repo docs και τον πηγαίο κώδικα αντί να εμπιστεύεστε παλιό marketing copy.
- Αντιμετωπίστε τα tests και τα gate artifacts ως ισχυρότερη απόδειξη από aspirational prose ή ονόματα directories.

## Τρέχουσες επιφυλάξεις
- Το checked-in δημόσιο JIT artifact αναφέρει ότι το LSP είναι απενεργοποιημένο.
- Η συμπεριφορά εξαρτάται από το ακριβές binary `souc`, όχι μόνο από τα αρχεία που υπάρχουν στο αποθετήριο.

## Δοκιμάστε το σε αυτό το αποθετήριο

```bash
cargo build -p souc --release --features lsp
./target/release/sounio-lsp --help
./target/release/sounio-lsp --stdio
```
