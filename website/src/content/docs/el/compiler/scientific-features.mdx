# Scientific Features

Τα scientific features περιγράφονται πλέον μέσω των lanes που πράγματι περνούν και των library surfaces που παραμένουν μερικώς disabled ή soft-failing.

## Επαληθευμένο σήμερα
- Τα gate scripts και τα checked artifacts είναι η ισχυρότερη απόδειξη για δημόσιους ισχυρισμούς.
- Το `tests/run-pass/vancomycin_propagation.sio` και το med fixture τεκμηριώνουν το τρέχον epistemic workflow.
- Τα checked-in stdlib artifacts αναφέρουν `251 pass / 0 fail / 0 skip / 251 total`, με `927` αρχεία `.sio` και `0` απενεργοποιημένα αρχεία.

## Τρέχουσες επιφυλάξεις
- Το τοπικό scientific runtime εξακολουθεί να παρακολουθεί τέσσερα regression probes σε soft mode.
- Τα stub modules και τα αρχεία `*.sio.disabled` είναι inventory του roadmap, όχι σταθερά APIs.
