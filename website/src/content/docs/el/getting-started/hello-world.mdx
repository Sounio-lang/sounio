# Hello World

Ας γράψουμε το πρώτο σας πρόγραμμα Sounio.

## Δημιουργία Αρχείου

Δημιουργήστε ένα νέο αρχείο με όνομα `hello.sio`:

```sio
fn main() with IO {
    println("Hello, Sounio!")
}
```

## Κατανόηση Κώδικα

- **`fn main()`** - Το σημείο εισόδου κάθε προγράμματος Sounio
- **`with IO`** - Δηλώνει ότι η συνάρτηση κάνει IO (προτείνεται· η προδιαγραφή απαιτεί ρητά effects)
- **`println(...)`** - Εκτυπώνει μια τιμή στην κονσόλα

## Εκτέλεση Προγράμματος

```bash
souc run hello.sio
```

Έξοδος:
```
Hello, Sounio!
```

## Προσθήκη Μεταβλητών

```sio
fn main() with IO {
    let name = "Sounio"
    let year = 2026

    print("Welcome to ")
    println(name)

    print("Established in ")
    println(year)
}
```
