Πριν εκτελέσετε κώδικα, ολοκληρώστε την
[ελληνική εγκατάσταση](/el/learn/getting-started/). Επιβεβαιώστε συμβατή
πλατφόρμα, πραγματικό εκτελέσιμο και αποτύπωμα· το Linux ELF δεν εκτελείται
εγγενώς σε macOS ARM64.

## Το πλήρες πρόγραμμα

Αυτό είναι ακριβώς το `examples/hello.sio`. Το παρακάτω τμήμα είναι
κώδικας Sounio, όχι εντολές για το τερματικό.

```sio
// First Sounio program

fn main() -> i32 with IO {
    println("Hello, Sounio")
    return 0
}
```

Η `main` είναι το σημείο εισόδου. Το `with IO` δηλώνει την επίδραση
εισόδου/εξόδου· η `println` εκτυπώνει το μήνυμα. Η επιστροφή μηδέν
ανήκει στο συμβόλαιο αυτού του συγκεκριμένου παραδείγματος.

## Έλεγχος και εκτέλεση

Από τη ρίζα του checkout, αφού επιβεβαιώσετε το συμβατό προφίλ:

```sh
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
./bin/souc check examples/hello.sio
./bin/souc run examples/hello.sio
```

Το αναμενόμενο μήνυμα είναι `Hello, Sounio` και ο αναμενόμενος κωδικός
τερματισμού είναι μηδέν. Αποθηκεύστε την πραγματική έξοδο και των δύο
εντολών. Ο έλεγχος δεν είναι εκτέλεση και ένα ιστορικό τεκμήριο δεν
αποτελεί σημερινή παρατήρηση του δικού σας περιβάλλοντος.

Για μια δική σας παραλλαγή, αντιγράψτε ολόκληρο το πρόγραμμα σε νέο αρχείο
και αλλάξτε μόνο το μήνυμα. Μην αλλάζετε την αρχική αναφορά. Στη συνέχεια
ελέγξτε και εκτελέστε το νέο αρχείο.
