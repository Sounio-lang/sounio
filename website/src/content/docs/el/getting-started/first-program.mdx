Μετά το [αρχικό μήνυμα](/el/learn/getting-started/hello-world/), μελετήστε
μία μόνο νέα έννοια: μια δομή με δύο πεδία. Το παράδειγμα είναι το
υπάρχον `examples/native/struct_basic.sio`, χωρίς αλλαγές στον κώδικα.

## Πλήρης πηγή Sounio

```sio
// Struct literal construction and field access in native-v2 driver.
// Expected: prints "7", exits 0.

struct Point { x: i64, y: i64 }

fn main() -> i64 with IO {
    let p = Point { x: 3, y: 4 }
    let s = p.x + p.y
    print_int(s)
    print_char(10)
    0
}
```

Η `struct Point` ορίζει τον τύπο. Η έκφραση `Point { ... }` κατασκευάζει
μια τιμή και οι `p.x`, `p.y` προσπελαύνουν πεδία με το όνομά τους.
Οι συναρτήσεις εκτύπωσης χρησιμοποιούν την επίδραση `IO`. Η τελική
έκφραση `0` είναι η τιμή επιστροφής αυτής της `main`.

## Επαναλάβετε τον έλεγχο στο δικό σας προφίλ

Ολοκληρώστε πρώτα την [εγκατάσταση](/el/learn/getting-started/).
Από τη ρίζα του checkout:

```sh
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
./bin/souc check examples/native/struct_basic.sio
./bin/souc run examples/native/struct_basic.sio
```

Το αρχικό αρχείο δηλώνει αναμενόμενη έξοδο `7` και τερματισμό μηδέν.
Αυτά είναι κριτήρια σύγκρισης, όχι καταγραφή νέας εκτέλεσης εδώ.
Διατηρήστε χωριστά τη δική σας πραγματική έξοδο και την ταυτότητα του
μεταγλωττιστή. Τα ιστορικά αποτελέσματα του συγκεκριμένου αρχείου
βρίσκονται στο [μητρώο παραδειγμάτων](https://github.com/Sounio-lang/sounio/blob/main/docs/llm-guide/example-manifest.json).

## Επόμενο βήμα χωρίς σημασιολογικές παρακάμψεις

Σε νέο αρχείο, κρατήστε τη δομή και προσαρμόστε ένα πεδίο τη φορά.
Μια συνηθισμένη δομή με πεδία `value`, `uncertainty`, `confidence` δεν
είναι αυτομάτως `Knowledge<T>` και δεν αποδεικνύει διάδοση αβεβαιότητας,
μονάδων ή προέλευσης δεδομένων. Μη χρησιμοποιείτε ένα τέτοιο υποκατάστατο
για να παρουσιάσετε επιστημική ή κλινική ασφάλεια.

Για πραγματικές επιστημονικές διεπαφές, ακολουθήστε τον
[ελληνικό οδηγό ανάπτυξης](https://github.com/Sounio-lang/sounio/blob/main/docs/el/developing.md),
τον [οδηγό LLM](https://github.com/Sounio-lang/sounio/blob/main/docs/guide/LLM_PROGRAMMING_GUIDE_EL.md)
και τους περιορισμούς του συγκεκριμένου API και προφίλ.
