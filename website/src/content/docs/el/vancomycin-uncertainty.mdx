# Vancomycin Uncertainty

Η μελέτη περίπτωσης vancomycin παραμένει η πιο καθαρή δημόσια απόδειξη ότι epistemic περιορισμοί μπορούν να οδηγήσουν σε compile-time άρνηση στο Sounio.

## Επαληθευμένο σήμερα
- Το `tests/run-pass/vancomycin_propagation.sio` και το med fixture τεκμηριώνουν το τρέχον epistemic workflow.
- Το `tests/compile-fail/vancomycin_low_conf.sio` εξακολουθεί να αποδεικνύει compile-time άρνηση.
- Τα docs assets στο `/docs/assets/vancomycin-ship/` παραμένουν η δημόσια οπτική απόδειξη για αυτό το case study.

## Τρέχουσες επιφυλάξεις
- Η συμπεριφορά εξαρτάται από το ακριβές binary `souc`, όχι μόνο από τα αρχεία που υπάρχουν στο αποθετήριο.
- Το πλήρες μοντέλο αβεβαιότητας και provenance είναι πλουσιότερο στη spec και στη stdlib από ό,τι στο σημερινό checked artifact.

## Δοκιμάστε το σε αυτό το αποθετήριο

```bash
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/run-pass/med/vancomycin_full_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
"$SOUC_BIN" check tests/compile-fail/med/vancomycin_low_conf_refusal.sio
```
