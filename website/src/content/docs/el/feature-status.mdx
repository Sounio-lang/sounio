Η Sounio αναπτύσσεται ενεργά. Αξιολογούμε κάθε δυνατότητα με την ακριβή
πηγή, το πραγματικό εκτελέσιμο, τον στόχο και τις παρατηρήσεις της.
Δεν παρουσιάζουμε έναν αποθηκευμένο πίνακα ως νέα μέτρηση.

## Πρακτικός χάρτης

| Περιοχή | Τι χρειάζεται να γνωρίζετε |
|---|---|
| Linux x86-64 | Υπάρχει αποθηκευμένο προμεταγλωττισμένο Madaros· ταυτοποιήστε τα bytes του. |
| macOS ARM64 | Υπάρχει ξεχωριστή εγγενής διαδικασία με δικά της τεκμήρια. Το Linux ELF δεν είναι συμβατό εκτελέσιμο. |
| GPU | Απαιτείται ειδική κάλυψη λειτουργίας και πραγματική συσκευή· ένα όνομα στόχου δεν επαρκεί. |
| Μονάδες και επιστημικά κανάλια | Η επιβολή και η διάδοση χρειάζονται διακριτικούς ελέγχους της επιλεγμένης διαδρομής. |
| Επιστημονικές βιβλιοθήκες | Υπαρκτός πηγαίος κώδικας δεν σημαίνει καθολική επιστημονική επικύρωση. |
| Παραδείγματα LLM | Οι αποτυχίες διατηρούνται και αποκλείονται από τις προτεινόμενες συνταγές. |

## Πού βρίσκονται τα τεκμήρια;

Διαβάστε τις [τρέχουσες εκτελέσεις CI](https://github.com/Sounio-lang/sounio/actions),
την [αναφορά Madaros](https://github.com/Sounio-lang/sounio/blob/main/docs/MADAROS_STATUS.md)
και το τεκμήριο που ονομάζει το συγκεκριμένο παράδειγμα. Μην γενικεύετε
μια επιτυχία σε όλο το αποθετήριο ή σε άλλο target.

Ο [ελληνικός οδηγός αναφοράς](https://github.com/Sounio-lang/sounio/blob/main/docs/el/language-reference.md)
εξηγεί τις σημασιολογικές διακρίσεις και το πεδίο της μετάφρασης.
Οι [ανάγκες του έργου](https://github.com/Sounio-lang/sounio/blob/main/docs/el/contributing.md)
δείχνουν πού μπορεί να βοηθήσει ένας νέος συνεργάτης.
