# Feature Status

Αυτή η σελίδα αναφέρει πλέον το πραγματικό shipped snapshot: artifact-backed pass counts, active lanes και ρητά caveats για disabled ή soft-failing surfaces.

## Επαληθευμένο σήμερα
- Το snapshot χαρακτηριστικών σε αυτόν τον ιστότοπο βασίζεται σε committed status artifacts.
- Τα checked-in stdlib artifacts αναφέρουν `251 pass / 0 fail / 0 skip / 251 total`, με `927` αρχεία `.sio` και `0` απενεργοποιημένα αρχεία.
- Το checked-in JIT artifact αναφέρει ότι το προαιρετικό JIT profile (όχι default onboarding).
- Το checked-in GPU artifact αναφέρει ενεργό GPU codegen και PTX emission μέσω `build --backend gpu`.
- Self-hosted GPU emission: `kretikos emit-ptx` (PTX), `kretikos emit-metal` (MSL), and `kretikos emit-cubin` (CUBIN) from in-tree emitters
- Οι attested GPU compute lanes σήμερα είναι CUDA `cuda-sm80` και ROCm `rocm-gfx942`.

## Τρέχουσες επιφυλάξεις
- Το τοπικό scientific runtime εξακολουθεί να παρακολουθεί τέσσερα regression probes σε soft mode.
- Τα stub modules και τα αρχεία `*.sio.disabled` είναι inventory του roadmap, όχι σταθερά APIs.
