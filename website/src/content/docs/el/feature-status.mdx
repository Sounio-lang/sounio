# Feature Status

Αυτή η σελίδα είναι ο συνοπτικός πίνακας κατάστασης για το δημόσιο contract. Οι αριθμοί παράγονται από committed gate JSONs και το README.md μέσω `npm run sync:artifacts` — δεν είναι χειροκίνητα συντηρημένο marketing κείμενο.

<FeatureStatusPanel />

## Γιατί αυτοί οι αριθμοί έχουν σημασία

- Προέρχονται από committed artifacts, όχι από φιλόδοξο roadmap κείμενο.
- Ορίζουν τι μπορούν να ισχυριστούν τα docs χωρίς επιφυλάξεις.
- Εξηγούν γιατί μεγάλα τμήματα του repo πρέπει ακόμη να περιγράφονται ως ενεργή εργασία, stub surface, ή απενεργοποιημένο inventory αντί για σταθερά APIs.

## Πώς να χρησιμοποιήσετε αυτή τη σελίδα

- Χρησιμοποιήστε τη ως τη σύνοψη κατάστασης στην είσοδο.
- Χρησιμοποιήστε τις πιο λεπτομερείς σελίδες όταν χρειάζεστε βάθος σε workflow, αρχιτεκτονική, ή υλοποίηση.
- Χρησιμοποιήστε τα raw artifacts όταν χρειάζεστε ακριβή λεπτομέρεια σε επίπεδο lane ή machine-readable απόδειξη.
