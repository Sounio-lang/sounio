# Έλεγχος Ροής

Τα conditionals, loops και το `match` παραμένουν μέρος της σταθερής διδακτικής επιφάνειας, αλλά τα ασφαλέστερα παραδείγματα είναι όσα περνούν από τα τρέχοντα fixtures.

## Επαληθευμένο σήμερα
- Βασικά bindings, functions και control flow παραμένουν μέρος της υποστηριζόμενης επιφάνειας της γλώσσας.
- Αντιμετωπίστε τα tests και τα gate artifacts ως ισχυρότερη απόδειξη από aspirational prose ή ονόματα directories.
- Προτιμήστε `souc check` πριν από `run` ή `build`.

## Τρέχουσες επιφυλάξεις
- Η γλωσσική προδιαγραφή μπορεί να προηγείται από αυτά που εφαρμόζει το τρέχον δημόσιο artifact.
- Η συμπεριφορά εξαρτάται από το ακριβές binary `souc`, όχι μόνο από τα αρχεία που υπάρχουν στο αποθετήριο.

## Δοκιμάστε το σε αυτό το αποθετήριο

```bash
let max = if a > b { a } else { b }

match state {
    0 => println("cold")
    _ => println("hot")
}
```
