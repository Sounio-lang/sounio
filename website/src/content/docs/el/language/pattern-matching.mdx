# Pattern Matching

Η έκφραση `match` παρέχει εξαντλητικό pattern matching πάνω σε τιμές. Ο compiler ελέγχει ότι καλύπτονται όλες οι περιπτώσεις και προειδοποιεί για μη προσβάσιμα arms.

## Βασικό matching

```sio
fn describe(x: i32) -> str {
    match x {
        0 => "zero",
        1 => "one",
        _ => "other",
    }
}
```

Το wildcard `_` ταιριάζει με οποιαδήποτε τιμή και χρησιμοποιείται ως catch-all.

## Matching σε enums

```sio
enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
    Triangle(f64, f64, f64),
}

fn area(s: Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rectangle(w, h) => w * h,
        Shape::Triangle(a, b, c) => {
            let s = (a + b + c) / 2.0
            sqrt(s * (s - a) * (s - b) * (s - c))
        },
    }
}
```

Αν παραλείψετε ένα variant, ο compiler αναφέρει σφάλμα για μη εξαντλητικό matching.

## Guards

Τα arms ενός pattern μπορούν να περιλαμβάνουν `if` guards για επιπλέον συνθήκες:

```sio
fn classify_temp(celsius: f64) -> str {
    match celsius {
        t if t < 0.0 => "freezing",
        t if t < 20.0 => "cold",
        t if t < 35.0 => "comfortable",
        _ => "hot",
    }
}
```

## Matching σε structs

```sio
struct Point { x: f64, y: f64 }

fn quadrant(p: Point) -> str {
    match p {
        Point { x, y } if x > 0.0 && y > 0.0 => "I",
        Point { x, y } if x < 0.0 && y > 0.0 => "II",
        Point { x, y } if x < 0.0 && y < 0.0 => "III",
        Point { x, y } if x > 0.0 && y < 0.0 => "IV",
        _ => "on axis",
    }
}
```

## Τρέχοντες περιορισμοί

- Η αποδόμηση tuples σε `let` bindings (`let (a, b) = pair`) δεν υποστηρίζεται ακόμα. Χρησιμοποιήστε `match` αντ' αυτού.
- Το εμφωλευμένο pattern matching σε βαθιά εμφωλευμένα structs λειτουργεί, αλλά ο εξαντλητικός έλεγχος δεν καλύπτει ακόμα όλες τις περιπτώσεις.
- Τα or-patterns (`A | B => ...`) αναγνωρίζονται από τον parser, αλλά ο έλεγχος κάλυψης γι' αυτά βρίσκεται ακόμα σε ωρίμανση.
