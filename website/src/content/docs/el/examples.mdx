# Examples

Αυτό το repo περιέχει δύο καλές πηγές “known-good” Sounio code:

- `tests/run-pass/`: μικρά, στοχευμένα προγράμματα που χρησιμοποιεί το CI (καλύτερο για να μάθετε σύνταξη)
- `examples/`: μεγαλύτερα demos και domain code (μερικά μπορεί να είναι aspirational ή να απαιτούν feature flags)

## Run a Test Fixture

```bash
souc run tests/run-pass/hello.sio
souc run tests/run-pass/for_in_loops.sio
souc check tests/run-pass/async_basic.sio
```

## A Few Canonical Snippets

Hello world:

```sio
fn main() with IO {
    println("Hello, Sounio!")
}
```

Match:

```sio
let y = match x {
    0 => 10
    1 => 20
    _ => 30
}
```

Explicit `Knowledge<T>` unwrap:

```sio
let k = Knowledge { value: 42.0 }
let x: f64 = k.unwrap("accepted for demo")
```
