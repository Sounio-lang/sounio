# Examples

Τα παραδείγματα πλαισιώνονται πλέον πρώτα γύρω από επαληθευμένα fixtures. Αντιμετωπίστε τα `tests/` ως την ισχυρότερη τρέχουσα απόδειξη και τα `examples/` ως μικρότερο onboarding υλικό.

## Επαληθευμένο σήμερα
- Το `examples/hello.sio` παραμένει το μικρότερο επαληθευμένο σημείο εκκίνησης.
- Το `tests/run-pass/covid_2020_kernel.sio` είναι ένα τρέχον, επαληθευμένο scientific fixture.
- Το `tests/run-pass/vancomycin_propagation.sio` και το med fixture τεκμηριώνουν το τρέχον epistemic workflow.

## Τρέχουσες επιφυλάξεις
- Το `tests/compile-fail/vancomycin_low_conf.sio` εξακολουθεί να αποδεικνύει compile-time άρνηση.
- Τα stub modules και τα αρχεία `*.sio.disabled` είναι inventory του roadmap, όχι σταθερά APIs.

## Δοκιμάστε το σε αυτό το αποθετήριο

```bash
"$SOUC_BIN" check examples/hello.sio
"$SOUC_BIN" check tests/run-pass/covid_2020_kernel.sio
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
```
