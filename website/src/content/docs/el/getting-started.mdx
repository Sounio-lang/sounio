# Ξεκινώντας

Τα προγράμματα Sounio είναι αρχεία `.sio` που ελέγχονται, εκτελούνται ή γίνονται build με το `souc`. Η τρέχουσα δημόσια διαδρομή ξεκινά από το checked-in self-hosted native artifact (`bin/souc`) και ένα check-first workflow.

## Επαληθευμένο σήμερα
- Το ασφαλέστερο τεκμηριωμένο σημείο εκκίνησης είναι ο canonical launcher στο `$(pwd)/bin/souc`.
- Σε αυτό το έργο εμφανίζονται δύο αριθμοί έκδοσης που ονομάζουν διαφορετικά πράγματα: το **2.1.0** είναι η έκδοση της γλώσσας (badge του README, `CITATION.cff`, `CHANGELOG.md`) και το **Madaros v0.80.0** είναι το build του compiler που τυπώνει το `bin/souc --version` (προεπιλεγμένη μηχανή Madaros). Οι παλαιότερες beta εκδόσεις πριν από το 2.0 έχουν αποσυρθεί.
- Ο αριθμός e2e της stdlib επαναμετριέται. Το δεσμευμένο αρχείο αποτελέσματος (`artifacts/stdlib/stdlib_e2e_result.v1.json`, 2026-05-12) προηγείται της επιβολής ιδιωτικότητας modules, οπότε δεν αναφέρεται ποσοστό επιτυχίας εδώ.
- Ο compiler στοχεύει μόνο Linux x86-64 και παράγει στατικό ELF. Το Cranelift JIT δεν διατίθεται πλέον (CHANGELOG 2.1.0). Το `souc build --backend gpu` παράγει PTX για έναν σκελετό ονομασμένων μοτίβων kernel, όχι γενικό GPU backend, και το WASM backend είναι μπλοκαρισμένο προσχέδιο ([#2237](https://github.com/Sounio-lang/sounio/issues/2237)). Δείτε [TOUR.md §6](https://github.com/Sounio-lang/sounio/blob/main/TOUR.md).
- Ορίστε το `SOUNIO_STDLIB_PATH` προς το versioned δέντρο `stdlib/`.
- Προτιμήστε `souc check` πριν από `run` ή `build`.

## Τρέχουσες επιφυλάξεις
- Η συμπεριφορά εξαρτάται από το ακριβές binary `souc`, όχι μόνο από τα αρχεία που υπάρχουν στο αποθετήριο.
- Ένα top-level Cargo build δεν είναι πια η καλύτερη πρώτη εμπειρία για τα δημόσια docs.

## Δοκιμάστε το σε αυτό το αποθετήριο

```bash
export SOUC_BIN="$(pwd)/bin/souc"
export SOUNIO_STDLIB_PATH="$(pwd)/stdlib"

"$SOUC_BIN" --version
"$SOUC_BIN" check examples/hello.sio
"$SOUC_BIN" check tests/run-pass/covid_2020_kernel.sio
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
```
