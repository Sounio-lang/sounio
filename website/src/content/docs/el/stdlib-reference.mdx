# Αναφορά Βασικής Βιβλιοθήκης

Η stdlib της Sounio βρίσκεται στο `stdlib/` του αποθετηρίου. Το τρέχον στιγμιότυπο αξιοπιστίας είναι **251 pass / 0 fail / 0 skip / 251 total** σε gate-backed fixtures.

## Βασικά modules

### `stdlib/io`

Λειτουργίες εισόδου/εξόδου. Όλες οι συναρτήσεις απαιτούν το effect `IO`.

| Συνάρτηση | Υπογραφή | Περιγραφή |
|-----------|----------|-----------|
| `println` | `fn println(s: str) with IO` | Εκτύπωση string με αλλαγή γραμμής στο stdout |
| `print` | `fn print(s: str) with IO` | Εκτύπωση string χωρίς αλλαγή γραμμής |
| `read_line` | `fn read_line() -> str with IO` | Ανάγνωση γραμμής από το stdin |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | Ανάγνωση ολόκληρου αρχείου ως string |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | Εγγραφή string σε αρχείο |

### `stdlib/math`

Μαθηματικές συναρτήσεις και σταθερές.

| Συνάρτηση | Υπογραφή | Περιγραφή |
|-----------|----------|-----------|
| `sqrt` | `fn sqrt(x: f64) -> f64` | Τετραγωνική ρίζα |
| `abs` | `fn abs(x: f64) -> f64` | Απόλυτη τιμή |
| `sin` | `fn sin(x: f64) -> f64` | Ημίτονο (ακτίνια) |
| `cos` | `fn cos(x: f64) -> f64` | Συνημίτονο (ακτίνια) |
| `exp` | `fn exp(x: f64) -> f64` | Φυσικό εκθετικό |
| `ln` | `fn ln(x: f64) -> f64` | Φυσικός λογάριθμος |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | Ύψωση σε δύναμη |
| `PI` | `f64` | 3.14159265358979... |
| `E` | `f64` | 2.71828182845904... |

### `stdlib/collections`

Λειτουργίες δομών δεδομένων.

| Συνάρτηση | Υπογραφή | Περιγραφή |
|-----------|----------|-----------|
| `len` | `fn len<T>(arr: &[T]) -> i64` | Μήκος πίνακα |
| `push` | `fn push<T>(arr: &![T], val: T)` | Προσθήκη στο τέλος πίνακα |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | Αφαίρεση τελευταίου στοιχείου |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | Μετασχηματισμός στοιχείων |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | Διατήρηση στοιχείων που ταιριάζουν |
| `++` | `[T] ++ [T] -> [T]` | Τελεστής συνένωσης πινάκων |

### `stdlib/sync`

Primitives ταυτοχρονισμού. Διαθέσιμα από το Sprint 86.

| Τύπος | Περιγραφή |
|-------|-----------|
| `Mutex<T>` | Κλείδωμα αμοιβαίου αποκλεισμού (βασισμένο σε pthread) |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` |

## Επιστημονικά modules

### `stdlib/pharma`

Εργαλειοθήκη φαρμακομετρίας για μοντελοποίηση PK/PD.

| Συνάρτηση | Περιγραφή |
|-----------|-----------|
| `pk_one_compartment` | Μονοδιαμερισματικό μοντέλο PK |
| `compute_auc` | Υπολογισμός εμβαδού κάτω από την καμπύλη |
| `dose_adjust` | Bayesian προσαρμογή δόσης με εμπιστοσύνη |

### `stdlib/fmri`

Επεξεργασία σήματος λειτουργικής MRI (κατάσταση gate: PASSING).

| Συνάρτηση | Περιγραφή |
|-----------|-----------|
| `bold_signal` | Εξαγωγή σήματος BOLD |
| `glm_fit` | Προσαρμογή γενικού γραμμικού μοντέλου |
| `threshold_clusters` | Κατωφλίωση σε επίπεδο cluster με provenance |

### `stdlib/darwin_pbpk`

Φυσιολογικά βασισμένη φαρμακοκινητική μοντελοποίηση (κατάσταση gate: PASSING).

| Χαρακτηριστικό | Περιγραφή |
|----------|-------------|
| **Κύρια Μοντέλα** | Μοντέλα PBPK 14 και 28 διαμερισμάτων με επιλυτές Tsit5 |
| **Μηχανισμοί** | Κατανομή πεπτιδίων, σύνθεση ιστών και υπολογισμοί Rodgers-Rowland Kp |
| **Προσέγγιση** | Προσέγγιση οιονεί-ισορροπίας (QE) για διαμερίσματα ταχείας ισορροπίας |
| **Επιστημικά** | Εγγενής παρακολούθηση αβεβαιότητας μέσω cumulantes και αξιολόγησης Hessian |

### `stdlib/genomics`

Ανάλυση γονιδιωματικών αλληλουχιών με διάδοση αβεβαιότητας.

### `stdlib/nn`

Στρώματα και λειτουργίες νευρωνικών δικτύων.

## Επιστημικά modules

### `stdlib/epistemic`

Βασικές λειτουργίες επιστημικών τύπων.

| Τύπος | Περιγραφή |
|-------|-----------|
| `Knowledge<T>` | Τιμή με διάστημα εμπιστοσύνης και provenance |
| `Validated<T>` | Τιμή που έχει περάσει πύλη επικύρωσης |
| `Intervention<T>` | Δείκτης αιτιακής παρέμβασης |
| `Counterfactual<T>` | Δείκτης αντιπραγματικού συλλογισμού |

| Συνάρτηση | Υπογραφή | Περιγραφή |
|-----------|----------|-----------|
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | Δημιουργία μέτρησης |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | Εξαγωγή επιπέδου εμπιστοσύνης |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | Διάδοση αβεβαιότητας μέσα από υπολογισμό |

## Κατάσταση modules

Για τη μηχαναγνώσιμη κατάσταση gate κάθε module, δείτε:
- `artifacts/stdlib/stdlib_reliability_status.v1.json`
- Τη σελίδα [κατάστασης δυνατοτήτων](/docs/feature-status)

Τα modules που δεν αναφέρονται εδώ μπορεί να είναι stubs, απενεργοποιημένα ή πειραματικά. Ελέγξτε `souc info` για τα διαθέσιμα modules του τρέχοντος artifact.
