# Standard Library Reference

The Sounio stdlib ships at `stdlib/` in the repository. The current reliability snapshot is **251 pass / 0 fail / 0 skip / 251 total** across gate-backed fixtures.

## Core modules

### `stdlib/io`

Input/output operations. All functions require the `IO` effect.

| Function | Signature | Description |
|----------|-----------|-------------|
| `println` | `fn println(s: str) with IO` | Print string with newline to stdout |
| `print` | `fn print(s: str) with IO` | Print string without newline |
| `read_line` | `fn read_line() -> str with IO` | Read a line from stdin |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | Read entire file as string |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | Write string to file |

### `stdlib/math`

Mathematical functions and constants.

| Function | Signature | Description |
|----------|-----------|-------------|
| `sqrt` | `fn sqrt(x: f64) -> f64` | Square root |
| `abs` | `fn abs(x: f64) -> f64` | Absolute value |
| `sin` | `fn sin(x: f64) -> f64` | Sine (radians) |
| `cos` | `fn cos(x: f64) -> f64` | Cosine (radians) |
| `exp` | `fn exp(x: f64) -> f64` | Natural exponential |
| `ln` | `fn ln(x: f64) -> f64` | Natural logarithm |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | Exponentiation |
| `PI` | `f64` | 3.14159265358979... |
| `E` | `f64` | 2.71828182845904... |

### `stdlib/collections`

Data structure operations.

| Function | Signature | Description |
|----------|-----------|-------------|
| `len` | `fn len<T>(arr: &[T]) -> i64` | Array length |
| `push` | `fn push<T>(arr: &![T], val: T)` | Append to array |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | Remove last element |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | Transform elements |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | Keep matching elements |
| `++` | `[T] ++ [T] -> [T]` | Array concatenation operator |

### `stdlib/sync`

Concurrency primitives. Available since Sprint 86.

| Type | Description |
|------|-------------|
| `Mutex<T>` | Mutual exclusion lock (pthread-backed) |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` |

## Science modules

### `stdlib/pharma`

Pharmacometrics toolkit for PK/PD modeling.

| Function | Description |
|----------|-------------|
| `pk_one_compartment` | Single-compartment PK model |
| `compute_auc` | Area under the curve calculation |
| `dose_adjust` | Bayesian dose adjustment with confidence |

### `stdlib/fmri`

Functional MRI signal processing (gate status: PASSING).

| Function | Description |
|----------|-------------|
| `bold_signal` | BOLD signal extraction |
| `glm_fit` | General linear model fitting |
| `threshold_clusters` | Cluster-level thresholding with provenance |

### `stdlib/darwin_pbpk`

Physiologically-based pharmacokinetic modeling (gate status: PASSING).

| Feature | Description |
|----------|-------------|
| **Core Models** | 14- and 28-compartment PBPK models with Tsit5 solvers |
| **Mechanisms** | Peptide partitioning, tissue composition, and Rodgers-Rowland Kp calculations |
| **Approximation** | Quasi-equilibrium (QE) approximation for rapid equilibrium compartments |
| **Epistemics** | Native uncertainty tracking via Cumulants and Hessian evaluation |

### `stdlib/genomics`

Genomic sequence analysis with uncertainty propagation.

### `stdlib/nn`

Neural network layers and operations.

## Epistemic modules

### `stdlib/epistemic`

Core epistemic type operations.

| Type | Description |
|------|-------------|
| `Knowledge<T>` | Value with confidence interval and provenance |
| `Validated<T>` | Value that has passed a validation gate |
| `Intervention<T>` | Causal intervention marker |
| `Counterfactual<T>` | Counterfactual reasoning marker |

| Function | Signature | Description |
|----------|-----------|-------------|
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | Create a measurement |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | Extract confidence level |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | Propagate uncertainty through a computation |
