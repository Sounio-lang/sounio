# Getting Started

Status: Sounio 3.0 (pre-release).

The shortest path is the [demo Codespace](https://codespaces.new/Sounio-lang/sounio?devcontainer_path=.devcontainer%2Fdemo%2Fdevcontainer.json). It uses `.devcontainer/demo` (Ubuntu 24.04, 4 CPUs, 16 GB), runs `scripts/demo_env_setup.sh`, and opens `TOUR.md`. This page did not create a Codespace, so it does not report a creation time. The setup script says `bash scripts/tour.sh` is about 35 seconds after setup.

From the repository root:

```sh
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
./bin/souc check examples/hello.sio
./bin/souc run examples/hello.sio
```

The program prints `Hello, Sounio`. The compiler prints a log before that line. Exit status 0. Measured on Linux x86-64 on 20 November 2026 with the committed prebuilt.

On Linux without Codespaces, run those three commands after `git clone --depth 1 https://github.com/Sounio-lang/sounio.git`. Checksums, the macOS ARM64 source build, and the absence of a Windows path are on [Install](/install/).
