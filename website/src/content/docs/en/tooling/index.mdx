# IDE & Tooling

Sounio provides first-class editor support through the Language Server Protocol and dedicated extensions.

## Editor Support

### VS Code

The official [VS Code extension](https://marketplace.visualstudio.com/items?itemName=sounio.sounio-vscode) provides:

- Syntax highlighting for `.sio` files
- Real-time diagnostics and error reporting
- Epistemic type visualization (confidence badges)
- Effect annotations and quick fixes
- Unit of measure hints
- Tensor shape inference
- Interactive REPL integration

**Install:**
```bash
code --install-extension sounio.sounio-vscode
```

### Other Editors

Any editor with LSP support can use the Sounio language server:

| Editor | Setup |
|--------|-------|
| **Neovim** | Use `nvim-lspconfig` with `souc lsp` |
| **Emacs** | Use `lsp-mode` or `eglot` |
| **Helix** | Add to `languages.toml` |
| **Sublime Text** | Use LSP package |
| **Zed** | Native LSP support |

## Language Server Features

The Sounio LSP is designed to surface the language's advanced type system features in your editor.

### Unique Capabilities

Unlike traditional language servers, Sounio's LSP understands:

- **Epistemic Types** - Confidence levels, provenance chains, evidence tracking
- **Algebraic Effects** - Effect inference, handler suggestions, purity analysis
- **Units of Measure** - Dimensional analysis, physics-aware suggestions
- **Refinement Types** - SMT-backed verification, counterexample display
- **Tensor Shapes** - Shape inference for scientific computing

### Quick Reference

| Feature | Shortcut (VS Code) |
|---------|-------------------|
| Toggle epistemic mode | `Ctrl+Shift+E` |
| Show confidence analysis | `Ctrl+Shift+C` |
| Show provenance chain | `Ctrl+Shift+P` |
| Run file | `F5` |
| Type check | `Ctrl+Shift+B` |
| Show AST | Command Palette |

## Command Line Tools

### Compiler

```bash
# Type check a file
souc check file.sio

# Run with JIT
souc run file.sio

# Show intermediate representations
souc check file.sio --show-ast --show-hir

# Compile to native binary
souc build file.sio -o output
```

### REPL

```bash
# Start interactive REPL
souc repl

# REPL with epistemic mode
souc repl --epistemic
```

### Formatter

```bash
# Format a file
souc fmt file.sio

# Check formatting without modifying
souc fmt --check file.sio
```

### Linter

```bash
# Lint a file
souc lint file.sio

# Lint with specific rules
souc lint --rules scientific file.sio
```
