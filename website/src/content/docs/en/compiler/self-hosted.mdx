# Self-Hosted Compiler

The Sounio compiler is written in Sounio (.sio). It parses, type-checks, lowers to IR, runs the 12 named passes of the -O cleanup listed on this page, and emits a Linux x86-64 ELF that is static unless the program has external relocations, with no LLVM and no Cranelift on that path. Linux x86-64 is the default shipped target.

## Pipeline

```
Source (.sio) → Lexer → Parser → AST
    → ir/lower.sio → IrModule (custom IR)
    → Optimization passes
    → native/codegen.sio → x86-64 machine code
    → native/elf.sio → ELF binary
```

This pipeline is the **default public compiler path** via `bin/souc`. It writes a Linux x86-64 ELF directly. That file is static unless the program has external relocations. Linux x86-64 is the default shipped target. This path does not call LLVM or Cranelift.

## Optimization passes

When `-O` is set, cleanup runs these 12 named passes from `opt_cleanup_function_mfi` in `self-hosted/ir/opt_cleanup.sio`. Dead-code elimination is one pass, scheduled again after SCCP-lite, so the dispatcher takes 13 steps.

1. **Immediate dedup** (`ocp_mfi_dedup_imm`). An `IrLoadImm` becomes an `IrCopy` when an earlier register already holds that immediate.
2. **Constant folding** (`ocp_mfi_const_fold`). Fold integer arithmetic, bitwise, and compare operations when both operands are known constants, plus partial-constant identity and annihilation.
3. **Copy propagation** (`ocp_mfi_copy_prop`). Rewrite sources through `IrCopy` chains.
4. **Dead-store elimination** (`ocp_mfi_dse`). Drop an earlier write that is never read before the next write.
5. **Redundant jump elimination** (`ocp_mfi_redundant_jump`). A jump or branch whose next instruction is its target label becomes a nop.
6. **Jump-to-return** (`ocp_mfi_jump_to_return`). An `IrJump` into a block whose first real instruction is `IrReturn` folds to `IrReturn`.
7. **Unreachable code after a jump** (`ocp_mfi_dead_after_jump`). Code after an unconditional jump, until the next label, becomes a nop.
8. **Dead label elimination** (`ocp_mfi_dead_label`). A label that no jump or branch targets becomes a nop.
9. **Common subexpression elimination** (`ocp_mfi_cse`). A repeated mapped binary operation becomes an `IrCopy`.
10. **Dead-code elimination** (`ocp_mfi_dce_once`). A pure definition whose destination is never read becomes a nop. The cleanup runs this sweep up to eight times here, then once more after SCCP-lite.
11. **SCCP-lite** (`ocp_mfi_sccp`). Fold a branch whose condition is a known constant, and fold binary operations again after copy chains.
12. **NOP compaction** (`ocp_mfi_compact_nops`). Pack out `IrNop` holes. Label identifiers stay symbolic.

An integral-center rewrite in the same function runs only when `OCP_RESEARCH_EXACT_INTEGRAL_CENTER` is 1. It is not one of the 12. A compile with no imports also runs inlining, a loop pass, and tail-call optimization when `-O` is set (`self-hosted/compiler/main.sio`). Imported Linux x86-64 programs take this cleanup and return. E-graph rewriting, non-power-of-two strength reduction, LICM, global value numbering, and load sinking stay on the by-value self-test spine in the same file, so they are not steps of this `-O` cleanup. The full e-graph call returns without rewriting a non-empty function.

## Register allocation

The native backend uses a 4-register linear-scan allocator targeting `r12`, `r13`, `r14`, `r15` (callee-saved). Stack spills use adaptive `disp8`/`disp32` encoding to minimize code size.

## Profile-guided optimization

The self-hosted compiler implements a complete PGO pipeline:

1. **Instrumentation**: `IrProfCounter` opcodes inject `INC [RIP+disp32]` at function entries.
2. **Profile dump**: `__prof_dump` writes `.sprof` files at exit with per-function execution counts.
3. **Strategy promotion**: Hot functions (count > 1000) promote to `AGGRESSIVE`, warm functions (> 100) to `PRECISION`.
4. **Profile-guided inlining**: Inline scoring incorporates strategy bonuses.
5. **Profile-guided layout**: Hot functions sorted to the front of the binary for cache locality.

## Running the self-hosted compiler

```bash
SOUC=./bin/souc

# Self-test (runs all internal test cases)
$SOUC run self-hosted/compiler/main.sio -- --self-test

# Check only (no codegen)
$SOUC run self-hosted/compiler/main.sio -- --check

# IR dump for specific function
$SOUC run self-hosted/compiler/main.sio -- --ir-dump --fn=main
```

## Verification

The self-hosted compiler validates itself through 347+ self-tests covering every optimization pass. Gate scripts (e.g., `scripts/sprint52_regalloc_gate.sh`) run the full test matrix and report PASS/FAIL/NOT_RUN counts.
