The [effect system overview](/learn/effects/) is the user-facing contract: a named function declares `with`, and a caller that omits a callee's effect is rejected. This page is the contributor map of the checker that enforces that contract, and of what handlers do today.

## What the checker runs

`self-hosted/check/effects.sio` is the set. It names 30 built-in effects, ids 0 through 29 (`effect_named_id_max` returns 29), and `effects_subset` is the call check: every required id must appear in the declared array. `self-hosted/check/check.sio` calls that check. The same file keeps `current_effects` as eight slots. A ninth distinct effect is E246 (`checker_emit_e246`), not a silent drop. An unknown name that is not held is E246 as well. Held names are listed in `effect_name_is_held` and are still dropped.

Named functions are not inferred by default. A missing `with` is E035. Closure bodies are inferred onto the closure signature in `checker_check_closure_expr_inplace`, and the enclosing function's effect set is restored afterwards. Cross-function inference for named functions is `SOUNIO_EFFECT_INFER=1`, off by default (`checker_effect_inference_enabled`).

lean_single is the other engine. It stores a bitmask in `FN_EFFECTS` (`self-hosted/compiler/lean_single.sio`) and checks calls with `bitset_is_subset`. The eight-slot ceiling is Madaros. lean_single accepts nine. Both engines emit E035 when the callee's effect is not in the caller.

## What is parsed and not implemented

`effect` items are parsed in `self-hosted/parser/items.sio`. A semicolon after an operation is optional: the item parser skips a semicolon or a newline before the next operation. The collector Madaros runs, `checker_collect_item_inplace`, has no arm for an effect item, so the declaration is not registered. See EFF-021 in `docs/spec/2026-10/03-evidence.tsv`.

`handle` is parsed in `self-hosted/parser/exprs.sio` (`parse_handle_expr`). `self-hosted/ir/lower.sio` treats `ExprHandle` as unsupported control flow. Madaros fails the check with "expression kind was not checked in place". lean_single reports E200. There is no handler backend.

`TyEffectVar` and `TyEffectRow` exist in `self-hosted/check/types.sio`. Nothing calls `ty_effect_var` or `ty_effect_row`. `self-hosted/check/effects_row.sio` is not imported by the checker that runs. `self-hosted/effects/` has no `use effects::` importer under `self-hosted/`.
