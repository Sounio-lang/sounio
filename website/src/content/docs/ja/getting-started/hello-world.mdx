# Hello World

最初の Sounio プログラムを書いてみましょう。

## ファイルを作成する

`hello.sio` という新しいファイルを作成します:

```sio
fn main() with IO {
    println("Hello, Sounio!")
}
```

## コードを読む

- **`fn main()`** - すべての Sounio プログラムのエントリポイント
- **`with IO`** - この関数が IO を行うことを宣言します（推奨。仕様は効果の明示を要求します）
- **`println(...)`** - 値をコンソールへ出力します

## 実行する

```bash
souc run hello.sio
```

出力:
```
Hello, Sounio!
```

## 変数を追加する

```sio
fn main() with IO {
    let name = "Sounio"
    let year = 2026

    print("Welcome to ")
    println(name)

    print("Established in ")
    println(year)
}
```
