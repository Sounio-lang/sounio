# 言語ガイド

このセクションは `souc` が受け付ける Sounio の *表層言語* を、仕様が実装より先行している場合は注記付きでまとめます。

## Rust 風構文との主な違い

- 可変バインディングは `var`（`let mut` ではない）
- 可変参照は `&!T`（`&mut T` ではない）
- エフェクトは関数シグネチャに `with IO, Panic, ...` として宣言する
