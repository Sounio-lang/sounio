# 標準ライブラリリファレンス

Sounioの標準ライブラリはリポジトリ内の `stdlib/` に同梱されています。現在の信頼性スナップショットは、ゲート対応フィクスチャ全体で **251 pass / 0 fail / 0 skip / 251 total** です。

## コアモジュール

### `stdlib/io`

入出力操作です。すべての関数は `IO` エフェクトを必要とします。

| Function | Signature | Description |
|----------|-----------|-------------|
| `println` | `fn println(s: str) with IO` | 改行付きでstdoutに文字列を出力 |
| `print` | `fn print(s: str) with IO` | 改行なしで文字列を出力 |
| `read_line` | `fn read_line() -> str with IO` | stdinから1行読み取り |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | ファイル全体を文字列として読み取り |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | 文字列をファイルに書き込み |

### `stdlib/math`

数学関数と定数です。

| Function | Signature | Description |
|----------|-----------|-------------|
| `sqrt` | `fn sqrt(x: f64) -> f64` | 平方根 |
| `abs` | `fn abs(x: f64) -> f64` | 絶対値 |
| `sin` | `fn sin(x: f64) -> f64` | 正弦（ラジアン） |
| `cos` | `fn cos(x: f64) -> f64` | 余弦（ラジアン） |
| `exp` | `fn exp(x: f64) -> f64` | 自然指数関数 |
| `ln` | `fn ln(x: f64) -> f64` | 自然対数 |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | 累乗 |
| `PI` | `f64` | 3.14159265358979... |
| `E` | `f64` | 2.71828182845904... |

### `stdlib/collections`

データ構造操作です。

| Function | Signature | Description |
|----------|-----------|-------------|
| `len` | `fn len<T>(arr: &[T]) -> i64` | 配列の長さ |
| `push` | `fn push<T>(arr: &![T], val: T)` | 配列に要素を追加 |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | 最後の要素を削除 |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | 要素を変換 |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | 条件に合う要素を保持 |
| `++` | `[T] ++ [T] -> [T]` | 配列結合演算子 |

### `stdlib/sync`

並行処理プリミティブです。スプリント86以降で利用可能です。

| Type | Description |
|------|-------------|
| `Mutex<T>` | 相互排他ロック（pthreadベース） |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` |

## 科学モジュール

### `stdlib/pharma`

PK/PDモデリングのための薬物動態ツールキットです。

| Function | Description |
|----------|-------------|
| `pk_one_compartment` | 単一コンパートメントPKモデル |
| `compute_auc` | 曲線下面積（AUC）計算 |
| `dose_adjust` | 信頼度付きベイズ用量調整 |

### `stdlib/fmri`

機能的MRI信号処理です（ゲートステータス: PASSING）。

| Function | Description |
|----------|-------------|
| `bold_signal` | BOLD信号抽出 |
| `glm_fit` | 一般線形モデルフィッティング |
| `threshold_clusters` | 来歴付きクラスターレベル閾値処理 |

### `stdlib/darwin_pbpk`

生理学的薬物動態モデリング (gate ステータス: PASSING)。

| 機能 | 説明 |
|----------|-------------|
| **コアモデル** | Tsit5ソルバーを備えた14および28コンパートメントPBPKモデル |
| **メカニズム** | ペプチド分配、組織組成、およびRodgers-Rowland Kp計算 |
| **近似** | 迅速な平衡コンパートメントのための準平衡 (QE) 近似 |
| **認識論** | キュムラントとヘッセ行列評価を介したネイティブな不確実性追跡 |

### `stdlib/genomics`

不確かさ伝播を伴うゲノム配列解析です。

### `stdlib/nn`

ニューラルネットワークのレイヤーと演算です。

## 認識論的モジュール

### `stdlib/epistemic`

コア認識論的型操作です。

| Type | Description |
|------|-------------|
| `Knowledge<T>` | 信頼区間と来歴を持つ値 |
| `Validated<T>` | バリデーションゲートを通過した値 |
| `Intervention<T>` | 因果介入マーカー |
| `Counterfactual<T>` | 反事実推論マーカー |

| Function | Signature | Description |
|----------|-----------|-------------|
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | 測定値を作成 |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | 信頼度を抽出 |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | 計算を通じて不確かさを伝播 |
