# 例

examples は現在、まず検証済み fixture を中心に説明されます。`tests/` を最も強い現在の証拠とみなし、`examples/` は小さな導入教材として使ってください。

## 本日時点で確認済み
- `examples/hello.sio` は今でも最小の検証済みスタート地点です。
- `tests/run-pass/covid_2020_kernel.sio` は現在も検証済みの科学 fixture です。
- `tests/run-pass/vancomycin_propagation.sio` と med fixture が、現在の epistemic workflow を示しています。

## 現在の注意点
- `tests/compile-fail/vancomycin_low_conf.sio` は今でもコンパイル時拒否を証明します。
- stub module と `*.sio.disabled` は roadmap 在庫であり、安定 API ではありません。

## このリポジトリで確認する

```bash
"$SOUC_BIN" check examples/hello.sio
"$SOUC_BIN" check tests/run-pass/covid_2020_kernel.sio
"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
```
