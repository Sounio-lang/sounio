# エピステミック型

Sounio は科学計算や規制下の計算を想定しており、値は「ただの数」ではないことが多いです。測定値や導出量は次を伴うべきです:

- 不確かさ（メトロロジー）
- 信頼度/信用度（trust）
- 来歴（出所 + 変換履歴）

## 4つのエピステミック型

Sounio には第一級のエピステミック wrapper 型が4つあります。すべてが `.value: T` と `.epsilon: f64`（信頼スコア、0–1）フィールドを共有します。

### Knowledge\<T\>

不確かさと来歴を持つ測定値をラップします。これが基本となるエピステミック型です。

```sio
let dose: Knowledge<mg> = Knowledge(500.0, ε=0.97, prov="run_042")

if dose.epsilon > 0.95 {
  approve_for_decision(dose)
} else {
  request_remeasurement(dose)
}
```

純粋な `T` を取り出すには、理由文字列つきの明示的な操作が必要です — エピステミックメタデータをうっかり捨てることはできません:

```sio
let raw: mg = dose.unwrap("手動オーバーライド、監査済み")
```

### Validated\<T\>

閾値チェックを正式に通過した値は `Validated<T>` になります — コンパイラが生の `Knowledge<T>` とは区別して扱う独立した型です。

```sio
let safe: Validated<mg> = validate(dose, threshold: 0.95)

// Validated<T> は安全性が証明された関数に渡せます
administer(safe)
```

### Intervention\<T\>

因果介入を表します — do-calculus の演算子 `do(X=x)` です。`.epsilon` フィールドは介入推定の信頼度を持ちます。

```sio
// 因果介入: do(Treatment = active)
let treated: Intervention<bool> = intervene(true)

if treated.epsilon > 0.90 {
  run_rct_arm(treated)
}
```

### Counterfactual\<T\>

反事実クエリを表します — 異なる条件下で変数が *どうなっていたか* です。反事実の信頼度は識別可能性とモデル品質を反映します。

```sio
// Alice が教育を受けていた場合の収入は?
let cf: Counterfactual<f64> = counterfactual(
  observed: 30000.0,
  under: education_iv
)

if cf.epsilon > 0.90 {
  report_finding(cf)
}
```

## いま動くこと（コンパイラの現状）

4つすべての型が、パース・型チェック・完全パイプライン（HIR → SIR → HLIR → ネイティブ ELF）を通じてコンパイルされます:

- 構築: `Knowledge(...)`, `validate(...)`, `intervene(...)`, `counterfactual(...)`
- フィールドアクセス: `.value`, `.epsilon`
- 信頼度ゲート: `if x.epsilon > threshold { ... }`
- アンラップ: `.unwrap("理由")` で純粋な `T` を取り出す

## 仕様 vs 実装

完全な設計では、より豊かな振る舞いを目指します: 原理に基づく不確かさ伝播、信頼度の単調性、純粋変換での append-only な来歴などです。

これらは仕様や stdlib 設計ドキュメントに現れますが、実際の強制はコンパイラのモードや feature flags によって変わることがあります。
