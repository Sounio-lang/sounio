# Feature Status

このページは現在、artifact に裏付けられた pass 数、アクティブな lane、そして無効化・soft-fail 面に関する明示的な注意を含む、実際の shipped snapshot を示します。

## 本日時点で確認済み
- このサイトの機能スナップショットは、コミット済みの status artifact に基づいています。
- チェックイン済み stdlib artifact は `251 pass / 0 fail / 0 skip / 251 total`、`.sio` ファイル `927` 件、無効ファイル `0` 件を報告しています。
- チェックイン済み JIT artifact では オプションの JIT プロファイル（デフォルトのオンボーディングではない）と報告されます。
- チェックイン済み GPU artifact では GPU codegen 有効と `build --backend gpu` による PTX 出力が報告されます。
- Self-hosted GPU emission: `kretikos emit-ptx` (PTX), `kretikos emit-metal` (MSL), and `kretikos emit-cubin` (CUBIN) from in-tree emitters
- 現在 attested されている GPU compute lane は CUDA `cuda-sm80` と ROCm `rocm-gfx942` です。

## 現在の注意点
- ローカルの science runtime では、4 つの regression probe が soft mode で追跡されています。
- stub module と `*.sio.disabled` は roadmap 在庫であり、安定 API ではありません。
