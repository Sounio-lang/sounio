# Feature Status

このページは公開契約のコンパクトな状態ボードです。数値は `npm run sync:artifacts` によって、コミット済みの gate JSON と README.md から再生成されます——手作業で維持されるマーケティング文言ではありません。

<FeatureStatusPanel />

## この数値が重要な理由

- コミット済みのartifactから取得されており、願望的なroadmap文言ではありません。
- ドキュメントが留保なしに主張できる内容を定義します。
- リポジトリの大部分が、なぜ安定したAPIではなく、進行中の作業、stub surface、または無効化された在庫として説明されるべきかを説明します。

## このページの使い方

- フロントドアのステータス要約として使ってください。
- ワークフロー、アーキテクチャ、実装の詳細が必要な場合は、より詳細なドキュメントページを使ってください。
- レーン単位の正確な詳細や機械可読な証拠が必要な場合は、生のartifactを使ってください。
