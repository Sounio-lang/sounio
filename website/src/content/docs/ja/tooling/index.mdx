# ツール

tooling の説明は現在、チェックイン済み `souc` artifact、その報告する能力、そしてリポジトリを実行する gate script に基づいています。

## 本日時点で確認済み
- チェックイン済みの `souc` artifact は `--help` と `info` を通じて現在の CLI 表面を直接示します。
- gate script とチェックイン済み artifact が、公開上の主張に対する最も強い証拠です。
- `run` や `build` の前に、まず `souc check` を使ってください。

## 現在の注意点
- 実際の挙動は、リポジトリ上のファイルだけではなく、使用している `souc` バイナリそのものに依存します。
- LLVM、GPU、LSP などの backend は、ソース配置ではなく artifact ごとに確認する必要があります。

## このリポジトリで確認する

```bash
"$SOUC_BIN" --help
"$SOUC_BIN" info
"$SOUC_BIN" fmt --help
"$SOUC_BIN" lint --help

bash scripts/selfhost/selfhost_zero_fallback_gate.sh
```
