# 标准库参考

Sounio标准库在仓库中位于`stdlib/`。当前可靠性快照为**251 pass / 0 fail / 0 skip / 251 total**，跨过网关后效。

## 核心模块

### `stdlib/io`

输入/输出操作。所有函数都需要`IO`效果。

| 函数 | 签名 | 描述 |
|------|------|------|
| `println` | `fn println(s: str) with IO` | 带换行符打印字符串到标准输出 |
| `print` | `fn print(s: str) with IO` | 不带换行符打印字符串 |
| `read_line` | `fn read_line() -> str with IO` | 从标准输入读取一行 |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | 将整个文件作为字符串读取 |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | 将字符串写入文件 |

### `stdlib/math`

数学函数和常数。

| 函数 | 签名 | 描述 |
|------|------|------|
| `sqrt` | `fn sqrt(x: f64) -> f64` | 平方根 |
| `abs` | `fn abs(x: f64) -> f64` | 绝对值 |
| `sin` | `fn sin(x: f64) -> f64` | 正弦（弧度） |
| `cos` | `fn cos(x: f64) -> f64` | 余弦（弧度） |
| `exp` | `fn exp(x: f64) -> f64` | 自然指数 |
| `ln` | `fn ln(x: f64) -> f64` | 自然对数 |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | 指数运算 |
| `PI` | `f64` | 3.14159265358979... |
| `E` | `f64` | 2.71828182845904... |

### `stdlib/collections`

数据结构操作。

| 函数 | 签名 | 描述 |
|------|------|------|
| `len` | `fn len<T>(arr: &[T]) -> i64` | 数组长度 |
| `push` | `fn push<T>(arr: &![T], val: T)` | 追加到数组中 |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | 移除最后一个元素 |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | 转换元素 |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | 保留匹配元素 |
| `++` | `[T] ++ [T] -> [T]` | 数组连接运算符 |

### `stdlib/sync`

并发原语。自Sprint 86可用。

| 类型 | 描述 |
|------|------|
| `Mutex<T>` | 互斥锁（基于pthread） |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` |

## 科学模块

### `stdlib/pharma`

PK/PD建模的药理学工具箱。

| 函数 | 描述 |
|------|------|
| `pk_one_compartment` | 单室PK模型 |
| `compute_auc` | 曲线下面积计算 |
| `dose_adjust` | 贝叶斯剂量调整，置信度 |

### `stdlib/fmri`

功能磁共振成像信号处理（网关状态：通过）。

| 函数 | 描述 |
|------|------|
| `bold_signal` | BOLD信号提取 |
| `glm_fit` | 一般线性模型拟合 |
| `threshold_clusters` | 簇级阈值化，带有溯源 |

### `stdlib/darwin_pbpk`

生理性基于药代动力学建模（网关状态：通过）。

| 特性 | 描述 |
|------|------|
| **核心模型** | 14和28室生理性基于药代动力学模型，使用Tsit5求解器 |
| **机制** | 肽分配，组织组成，和Rodgers-Rowland Kp计算 |
| **近似** | 快速平衡室的准平衡近似 |
| **表征** | 通过Cumulants和Hessian评估的原生不确定性跟踪 |

### `stdlib/genomics`

带有不确定性传播的基因组序列分析。

### `stdlib/nn`

神经网络层和操作。

## 表征模块

### `stdlib/epistemic`

核心表征类型操作。

| 类型 | 描述 |
|------|------|
| `Knowledge<T>` | 带有置信区间和溯源的值 |
| `Validated<T>` | 已通过验证网关的值 |
| `Intervention<T>` | 因果干预标记 |
| `Counterfactual<T>` | 反事实推理标记 |

| 函数 | 签名 | 描述 |
|------|------|------|
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | 创建测量 |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | 提取置信度 |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | 在计算中传播不确定性 |
