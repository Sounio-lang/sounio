# 模式匹配

`match` 表达式提供详尽模式匹配，编译器会检查所有情况是否被覆盖，并警告未被覆盖的分支。

## 基本匹配

```sio
fn describe(x: i32) -> str {
    match x {
        0 => "零",
        1 => "一",
        _ => "其他",
    }
}
```

通配符 `_` 匹配任何值，用作捕获所有。

## 枚举匹配

```sio
enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
    Triangle(f64, f64, f64),
}

fn area(s: Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rectangle(w, h) => w * h,
        Shape::Triangle(a, b, c) => {
            let s = (a + b + c) / 2.0
            sqrt(s * (s - a) * (s - b) * (s - c))
        },
    }
}
```

如果你省略了一个变体，编译器会报告非详尽匹配错误。

## 守卫

模式臂可以包含 `if` 守卫以进行额外条件判断：

```sio
fn classify_temp(celsius: f64) -> str {
    match celsius {
        t if t < 0.0 => "冰冻",
        t if t < 20.0 => "寒冷",
        t if t < 35.0 => "舒适",
        _ => "热",
    }
}
```

## 结构体匹配

```sio
struct Point { x: f64, y: f64 }

fn quadrant(p: Point) -> str {
    match p {
        Point { x, y } if x > 0.0 && y > 0.0 => "一",
        Point { x, y } if x < 0.0 && y > 0.0 => "二",
        Point { x, y } if x < 0.0 && y < 0.0 => "三",
        Point { x, y } if x > 0.0 && y < 0.0 => "四",
        _ => "在轴上",
    }
}
```

## 当前限制

- `let` 绑定中的元组解构 (`let (a, b) = pair`) 尚未支持。请使用 `match` 代替。
- 嵌套模式匹配在深度嵌套的结构体上工作，但并非所有情况下都被详尽检查。
- 或模式 (`A | B => ...`) 被解析，但对它们的覆盖检查仍在发展中。
