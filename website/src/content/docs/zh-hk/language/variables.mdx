# 變數 & 類型

變數和本地類型推理是當前語言表面的最穩定部分。此頁面聚焦於您今天可以安全展示在範例中的形式，以及它們如何與當前檢查器堆疊互動。

## 當前契約

- `let` 是默認不可變綁定形式。
- `var` 可用於可變本地和循環式狀態。
- 直觀的本地推斷效果良好，但明確註解仍然是文檔值互動與單元、效果或認識邊界時最安全的表達方式。
- 元組、數組和標量式本地綁定仍然是良好的教學材料，因為它們在範例和測試中一致出現。

## 常見模式

```sio
let x = 42
let ratio: f64 = 0.5
let pair = (x, ratio)
var total = x

total = total + 1
```

## 檢查器檢查位置

- `self-hosted/check/types.sio` 和 `self-hosted/check/infer.sio` 是本地類型和推斷工作最相關的模塊。
- `self-hosted/check/env.sio` 追蹤綁定的演進環境模型。
- `self-hosted/check/units.sio` 和 `self-hosted/check/epistemic.sio` 是普通本地開始與領域特定的類型規則互動的地方。

## 實碼指導

- 使用推斷的本地變數來處理小、明顯的值，並在您希望文檔或診斷保持無歧義的地方使用明確註解。
- 對看起來太 Rust 式、Julia 式或 Python 式的舊範例保持懷疑；Sounio 有其自己的語法和語義。
- 當有疑問時，使用 `souc check` 驗證確切的範例，而不是依賴記憶。
