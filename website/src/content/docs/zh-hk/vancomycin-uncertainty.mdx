# 万古霉素不确定性

这是文档站点上最强的公开案例研究，因为它展示了Sounio存在的原因：信心、证据和可追溯性不是程序的注释；它们是程序是否继续执行的一部分。当前仓库仍然证明了这一点，具有真实的固定装置和截图。

## 核心证明点

- `tests/run-pass/vancomycin_propagation.sio` 展示了当前较轻的传播路径。
- `tests/run-pass/med/vancomycin_full_propagation.sio` 是med车道上更全面的临床内核式示例。
- `tests/compile-fail/vancomycin_low_conf.sio` 和 `tests/compile-fail/med/vancomycin_low_conf_refusal.sio` 证明了低置信状态可以在运行时之前被拒绝。
- `tests/compile-fail/med/vancomycin_weak_evidence_refusal.sio` 展示了证据层约束也很重要。

## 验证命令

```bash
export SOUC_BIN="$(pwd)/bin/souc"
export SOUNIO_STDLIB_PATH="$(pwd)/stdlib"

"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/run-pass/med/vancomycin_full_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
"$SOUC_BIN" check tests/compile-fail/med/vancomycin_low_conf_refusal.sio
"$SOUC_BIN" check tests/compile-fail/med/vancomycin_weak_evidence_refusal.sio
```

## 本页演示

- 信心阈值可以成为编译时契约。
- 拒绝路径是验证的公共故事的一部分，而不仅仅是研究愿望。
- med固定装置家族将更广泛的认识模型与万古霉素给药领域联系起来，其中错误的信心处理不是表面上的bug。

## 如何负责任地讨论

- 描述通过`check`验证的编译时拒绝路径。
- 当更大的运行时或自托管执行路径仍有限制时，要明确指出。
- 使用案例研究来解释为什么Sounio将类型、可追溯性和信心耦合在一起，而不是将它们作为独立的子系统处理。
