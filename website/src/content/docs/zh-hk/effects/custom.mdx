# 自定義效果

自定義效果是語言故事的一部分，但它們更接近於目前可展示行為和仍在積極設計和實現中的更豐富處理者模型之間的分界。本頁直接記錄了這個分界。

## 安全的主張

- 已檢查的是封閉的內建 effect 名單，寫在簽名的 `with` 裡。
- 使用者宣告的 `effect` 與 handler 只被解析，尚未實作。
- 具名函式不會自動得到 effect。缺了 `with` 就是編譯錯誤。

## 模型級別的自定義效果草圖

`effect` 宣告可以被解析，但尚未實作。這一頁沒有可用的自訂 effect。已檢查的合同在 [effect system](/learn/effects/)。

## 實現表面

- 呼叫檢查在 `self-hosted/check/effects.sio` 的 `effects_subset`。
- `self-hosted/effects/` 底下沒有被 `self-hosted/` 引用的 handler 後端。

## 文檔立場

- 不要把自訂 effect 寫成已經能用。
- handler 是解析了、沒有後端。
- 英文說明在 [effect system](/learn/effects/)。
