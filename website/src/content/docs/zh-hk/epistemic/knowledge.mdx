# `知識<T>`

`知識<T>`仍然是Sounio知識模型中最具體且公開的入口。即使完整設計包括更豐富的元數據和傳播規則，已檢查的公開契約已經確立了一個重要不變性：知識上下文不應靜默消失。

## 當前契約

- 只要可能，保持值以`知識`形式封裝。
- 從知識數據轉換為純數據應該在明確的邊界發生，例如`unwrap(reason)`。
- 原因字串不是裝飾細節；它是目前公開表面上明確強制的來源邊界。

## 代表使用

```sio
let k = 知識 { value: 42.0 }
let accepted: f64 = k.unwrap("為演示而接受")
```

## 倉庫映射

- `docs/reference/KNOWLEDGE_REFERENCE.md`解釋了更大的值模型和預期的算術行為。
- `self-hosted/check/epistemic.sio`是檢查行為的第一個實現文件。
- `tests/run-pass/vancomycin_propagation.sio`是在實際工作流程中展示這個概念的最佳小範例。

## 重要注意事項

- 不要假設研究導向的文檔中描述的每個字段都以相同的方式暴露在已檢查的 artefact 中。
- 不要將`知識`描述為僅僅是標記封裝；在本倉庫中，它意味著承擔審計和決策意義。
- 如果您想聲稱自動傳播語義，請指向當前的範例或明確標記聲稱為更大模型的一部分。
