# 不确定性

不确定性是 Sounio 故事的核心，但好的文档需要将数学模型与当前 artifact 强制执行的表面分开。本页既记录了模型试图表达的内容，也记录了您可以使用当前 fixtue 证明的内容。

## 现在验证的内容

- 信心敏感的拒绝不是假设性的；它是由当前的 compile-fail fixtue 执行的。
- 已检查的合约已经证明了弱证据和低信心状态可以在运行前阻止程序。
- 更丰富的传播模型在研究文档和参考文档中仍然可见，即使特定的 artifact 只暴露了一部分。

## 值得了解的模式级传播规则

- 对于独立加法和减法，标准不确定性通常通过二次方组合。
- 对于乘法和除法，相对不确定性传播是更有用的心理模型。
- 信心和来源是决策边界的组成部分，而不仅仅是数值负载。

## 在此仓库中验证行为的地方

- `tests/run-pass/vancomycin_propagation.sio` 是使用 `souc check` 验证当前传播的最简单示例。
- `tests/compile-fail/vancomycin_low_conf.sio` 证明了拒绝路径仍然存活。
- `docs/research/vancomycin-uncertainty.md` 解释了这些 fixtue 背后的临床案例研究。

## 验证命令

```bash
export SOUC_BIN="$(pwd)/bin/souc"
export SOUNIO_STDLIB_PATH="$(pwd)/stdlib"

"$SOUC_BIN" check tests/run-pass/vancomycin_propagation.sio
"$SOUC_BIN" check tests/compile-fail/vancomycin_low_conf.sio
```
