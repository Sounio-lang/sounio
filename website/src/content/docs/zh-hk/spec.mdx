# 规格说明

规格说明仍然很重要，但在当前仓库中，应将其视为一种真理层，而不是全部真理。全面的文档需要解释如何将规格说明与制品、测试和源代码布局一起使用，而不是将其视为当前行为描述的完整描述。

## 如何正确使用规格说明

- 使用规格说明了解预期的语言模型和术语。
- 使用`souc check`、固定件和状态制品了解当前推荐的制品实际上强制执行的内容。
- 使用源目录，如`self-hosted/check/`、`self-hosted/parser/`和`self-hosted/native/`了解今日实施工作如何组织。

## 规格说明特别擅长

- 跨切概念，如效果、认识类型、单位和精炼。
- 跨越多个后端或子系统的长远设计意图。
- 帮助理解更注重实施的仓库文档的词汇和正式框架。

## 规格说明并未取代

- 当前`souc info`中的制品状态。
- `tests/run-pass/`、`tests/compile-fail/`和`tests/stdlib/`中的固定件支持证明。
- 机器可读状态制品，位于`artifacts/stdlib/`下。
