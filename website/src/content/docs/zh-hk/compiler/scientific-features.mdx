# 科学特性

Sounio 的科学计算不是单一模块或噱头。它是知识型、标准库领域车道、超复数数学、GPU 工作以及领域特定测试的结合。因此，一个全面的页面必须审视整个系统，而不仅仅是语法。

## 目前最强项

- 受门控的标准库科学车道 `fmri` 和 `darwin_pbpk` 都通过了。
- 目前七个超执行车道在所需门控中通过。
- 仓库包含 `hypercomplex`、`gpu`、`tensor` 和 `distributed` 工作的自托管目录，以及领域特定的示例和基准测试。

## 源图

- `tests/stdlib/fmri/` 和 `tests/stdlib/darwin_pbpk/` 是当前最强的公共科学证明点。
- `tests/stdlib/nn/`、`onn/`、`qnn/`、`snn/`、`spnn/`、`quantnn/` 和 `math/` 映射了当前通过的超车道。
- `self-hosted/hypercomplex/`、`self-hosted/gpu/` 和 `self-hosted/tensor/` 是科学运行时工作最明显的自托管实现表面。
- `benchmarks/` 和 `docs/research/` 提供了更广泛的背景，但这些工件和测试仍然是当前支持声明的最强来源。

## 重现受门控科学图片

```bash
bash scripts/stdlib/stdlib_hyper_execution_gate.sh
STDLIB_RUNTIME_REGRESSION_STRICT=1 bash scripts/stdlib_science_pipeline_gate.sh
```

## 文档指导

- 以通过的车道和验证的固定件开始。
- 将禁用的或占位符的科学模块视为路线图库存。
- 在讨论高级领域，如 GPU 原生科学内核或深度超复数后端时，明确您是在谈论源树实现工作还是经过验证的公共工件行为。
