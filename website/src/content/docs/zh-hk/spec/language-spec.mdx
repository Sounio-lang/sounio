# 語言規範 (v1.0.0)

語言規範是Sounio的廣泛模型，不是保證每個功能都同樣在已驗證的公開藝術品中暴露。本頁解釋了如何有效地閱讀它，而不會混淆設計廣度與即時支持廣度。

## 有效的閱讀順序

- 從`spec/LANGUAGE_SPECIFICATION.md`中的高層語言模型和術語開始。
- 然後檢查您關心的部分對應的相關文檔頁面、當前測試和`souc info`輸出。
- 對於實現細節，請遵循相應的自托管的子系統，而不是僅僅依賴規範。

## 規範有助於上下文化的主題

- 類型結構和進階打型概念。
- 效果和處理程序設計。
- 單位、精細化和知識值作為語言層面的概念。
- 超越當前預設藝術品的更廣泛的後端和執行模型概念。

## 交叉檢查聲明的地點

- `tests/run-pass/`和`tests/compile-fail/`以檢查語言行為。
- `artifacts/stdlib/*.json`以檢查庫和科學層面的支持。
- `self-hosted/`子系統目錄以檢查當前的實現結構。
