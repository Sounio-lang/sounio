# Referencia da Biblioteca Padrao

A stdlib de Sounio esta em `stdlib/` no repositorio. O snapshot atual de confiabilidade e **81 pass / 0 fail / 1 skip / 82 total** em fixtures com suporte de gate.

## Modulos principais

### `stdlib/io`

Operacoes de entrada/saida. Todas as funcoes requerem o efeito `IO`.

| Funcao | Assinatura | Descricao |
|--------|------------|-----------|
| `println` | `fn println(s: str) with IO` | Imprime string com nova linha em stdout |
| `print` | `fn print(s: str) with IO` | Imprime string sem nova linha |
| `read_line` | `fn read_line() -> str with IO` | Le uma linha de stdin |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | Le arquivo inteiro como string |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | Escreve string em arquivo |

### `stdlib/math`

Funcoes matematicas e constantes.

| Funcao | Assinatura | Descricao |
|--------|------------|-----------|
| `sqrt` | `fn sqrt(x: f64) -> f64` | Raiz quadrada |
| `abs` | `fn abs(x: f64) -> f64` | Valor absoluto |
| `sin` | `fn sin(x: f64) -> f64` | Seno (radianos) |
| `cos` | `fn cos(x: f64) -> f64` | Cosseno (radianos) |
| `exp` | `fn exp(x: f64) -> f64` | Exponencial natural |
| `ln` | `fn ln(x: f64) -> f64` | Logaritmo natural |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | Exponenciacao |
| `PI` | `f64` | 3.14159265358979... |
| `E` | `f64` | 2.71828182845904... |

### `stdlib/collections`

Operacoes com estruturas de dados.

| Funcao | Assinatura | Descricao |
|--------|------------|-----------|
| `len` | `fn len<T>(arr: &[T]) -> i64` | Tamanho do array |
| `push` | `fn push<T>(arr: &![T], val: T)` | Adiciona ao final do array |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | Remove ultimo elemento |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | Transforma elementos |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | Mantem elementos que correspondem |
| `++` | `[T] ++ [T] -> [T]` | Operador de concatenacao de arrays |

### `stdlib/sync`

Primitivas de concorrencia. Disponivel desde o Sprint 86.

| Tipo | Descricao |
|------|-----------|
| `Mutex<T>` | Lock de exclusao mutua (baseado em pthread) |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` |

## Modulos epistemicos

### `stdlib/epistemic`

Operacoes centrais de tipos epistemicos.

| Tipo | Descricao |
|------|-----------|
| `Knowledge<T>` | Valor com intervalo de confianca e proveniencia |
| `Validated<T>` | Valor que passou por um gate de validacao |
| `Intervention<T>` | Marcador de intervencao causal |
| `Counterfactual<T>` | Marcador de raciocinio contrafactual |

| Funcao | Assinatura | Descricao |
|--------|------------|-----------|
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | Cria uma medicao |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | Extrai o nivel de confianca |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | Propaga incerteza atraves de uma computacao |
