# Referência da Biblioteca Padrão

A biblioteca padrão do Sounio reside no diretório `stdlib/` da raiz do repositório. O estado de fiabilidade verificado e validado por portões (*gates*) automatizados é de **251 passadas / 0 falhas / 0 ignoradas / 251 total**.

## Módulos Principais

### `stdlib/io`

Operações de entrada e saída. Toda a interação com streams de E/S requer a declaração explícita do efeito `IO`.

| Função | Assinatura | Descrição |
| :--- | :--- | :--- |
| `println` | `fn println(s: str) with IO` | Escreve uma cadeia de caracteres seguida de uma nova linha na saída padrão (`stdout`) |
| `print` | `fn print(s: str) with IO` | Escreve uma cadeia de caracteres na saída padrão sem introduzir uma nova linha |
| `read_line` | `fn read_line() -> str with IO` | Lê uma linha de texto a partir do fluxo de entrada padrão (`stdin`) |
| `read_file` | `fn read_file(path: str) -> str with IO, Panic` | Lê a totalidade de um ficheiro de texto, podendo falhar caso o caminho seja inválido |
| `write_file` | `fn write_file(path: str, data: str) with IO, Panic` | Grava o conteúdo de texto fornecido no caminho especificado |

### `stdlib/math`

Constantes matemáticas elementares e funções transcendentes e algébricas fundamentais.

| Função | Assinatura | Descrição |
| :--- | :--- | :--- |
| `sqrt` | `fn sqrt(x: f64) -> f64` | Raiz quadrada |
| `abs` | `fn abs(x: f64) -> f64` | Valor absoluto (módulo) |
| `sin` | `fn sin(x: f64) -> f64` | Seno (ângulo em radianos) |
| `cos` | `fn cos(x: f64) -> f64` | Cosseno (ângulo em radianos) |
| `exp` | `fn exp(x: f64) -> f64` | Exponencial de base natural $e^x$ |
| `ln` | `fn ln(x: f64) -> f64` | Logaritmo natural (base $e$) |
| `pow` | `fn pow(base: f64, exp: f64) -> f64` | Exponenciação $x^y$ |
| `PI` | `f64` | Constante pi ($\pi \approx 3.14159265358979$) |
| `E` | `f64` | Constante de Euler ($e \approx 2.71828182845904$) |

### `stdlib/collections`

Operações estruturais em agregados de dados (*arrays*).

| Função / Operador | Assinatura | Descrição |
| :--- | :--- | :--- |
| `len` | `fn len<T>(arr: &[T]) -> i64` | Devolve o tamanho absoluto de um *array* |
| `push` | `fn push<T>(arr: &![T], val: T)` | Adiciona um elemento ao final de um *array* dinâmico |
| `pop` | `fn pop<T>(arr: &![T]) -> T with Panic` | Remove e devolve o último elemento, podendo falhar se o *array* estiver vazio |
| `map` | `fn map<T, U>(arr: &[T], f: fn(T) -> U) -> [U]` | Aplica uma função de projeção a todos os elementos do *array* |
| `filter` | `fn filter<T>(arr: &[T], f: fn(&T) -> bool) -> [T]` | Filtra e retém os elementos que satisfazem o predicado |
| `++` | `[T] ++ [T] -> [T]` | Operador nativo de concatenação e fusão de *arrays* |

### `stdlib/sync`

Mapeamento de primitivas de concorrência e sincronização de fios de execução (disponíveis desde o Sprint 86).

| Tipo / Função | Assinatura | Descrição |
| :--- | :--- | :--- |
| `Mutex<T>` | — | Trinco de exclusão mútua assente no padrão POSIX Thread (`pthread`) |
| `lock` | `fn lock(m: &!Mutex<T>) with IO` | Bloqueia a execução até adquirir o trinco exclusivo |
| `unlock` | `fn unlock(m: &!Mutex<T>) with IO` | Liberta o trinco exclusivo para outros fios de execução |

## Módulos Científicos

### `stdlib/pharma`

Biblioteca analítica para modelagem farmacocinética e farmacodinâmica (PK/PD).

| Função | Descrição |
| :--- | :--- |
| `pk_one_compartment` | Simulação analítica do modelo de dosagem em compartimento único |
| `compute_auc` | Integração numérica para cálculo da Área Sob a Curva (AUC) |
| `dose_adjust` | Ajuste bayesiano de regimes posológicos assegurando limiares de confiança epistémica |

### `stdlib/fmri`

Módulo dedicado ao processamento de sinal de Ressonância Magnética Funcional (estado verificado: PASS).

| Função | Descrição |
| :--- | :--- |
| `bold_signal` | Extração e modelagem do sinal BOLD (*Blood-Oxygen-Level-Dependent*) |
| `glm_fit` | Ajuste estatístico via Modelo Linear Geral (GLM) sobre matrizes cerebrais |
| `threshold_clusters` | Limiarização estocástica e clusterização com rastreio de proveniência de dados |

### `stdlib/darwin_pbpk`

Modelagem farmacocinética com base fisiológica (status do gate: PASSING).

| Funcionalidade | Descrição |
|----------|-------------|
| **Modelos Principais** | Modelos PBPK de 14 e 28 compartimentos com solucionadores Tsit5 |
| **Mecanismos** | Particionamento de peptídeos, composição de tecidos e cálculos Rodgers-Rowland Kp |
| **Aproximação** | Aproximação de quase-equilíbrio (QE) para compartimentos de rápido equilíbrio |
| **Epistêmicos** | Rastreamento nativo de incerteza via cumulantes e avaliação Hessiana |

### `stdlib/genomics`

Comparação e alinhamento de sequências genómicas com incorporação e propagação de margens de erro de sequenciação.

### `stdlib/nn`

Operações tensoriais, propagação para a frente (*forward*) e treino de camadas de redes neurais profundas.

## Módulos Epistémicos

### `stdlib/epistemic`

Núcleo do sistema epistémico de propagação de incertezas do Sounio.

| Tipo | Descrição |
| :--- | :--- |
| `Knowledge<T>` | Tipo opaco que encapsula um valor nominal, o seu intervalo de incerteza (GUM) e a árvore de proveniência |
| `Validated<T>` | Estrutura de prova que certifica que um valor superou com êxito um portão regulatório ou analítico |
| `Intervention<T>` | Marcador matemático que sinaliza uma intervenção causal no âmbito de modelos estruturais |
| `Counterfactual<T>` | Estrutura lógica concebida para a avaliação de hipóteses e raciocínio contrafactual |

| Função | Assinatura | Descrição |
| :--- | :--- | :--- |
| `measure` | `fn measure<T>(val: T, uncertainty: f64) -> Knowledge<T>` | Inicializa uma medição empírica associando o respetivo desvio-padrão de incerteza |
| `confidence` | `fn confidence<T>(k: &Knowledge<T>) -> f64` | Extrai e calcula a margem ou nível de confiança do envelope epistémico |
| `propagate` | `fn propagate<T>(k: Knowledge<T>, f: fn(T) -> T) -> Knowledge<T>` | Propaga o desvio de incerteza de forma rigorosa através de uma função matemática |

## Estado e Fiabilidade dos Módulos

Para consultar o inventário detalhado de cobertura por portão de integração contínua:
- Analise os relatórios detalhados em `artifacts/stdlib/stdlib_reliability_status.v1.json`.
- Aceda à secção de [Estado das Funcionalidades](/docs/feature-status).

Os módulos que não constem deste sumário representam projetos experimentais, esboços (*stubs*) ou áreas temporariamente desativadas. Utilize a diretiva `souc info` para listar os módulos nativos ativos no seu binário de execução.
