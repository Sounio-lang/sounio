# Pattern Matching

A expressao `match` fornece pattern matching (correspondencia de padroes) exaustivo sobre valores. O compilador verifica que todos os casos estao cobertos e avisa sobre arms inalcancaveis.

## Matching basico

```sio
fn describe(x: i32) -> str {
    match x {
        0 => "zero",
        1 => "one",
        _ => "other",
    }
}
```

O wildcard `_` corresponde a qualquer valor e e usado como catch-all.

## Matching em enums

```sio
enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
    Triangle(f64, f64, f64),
}

fn area(s: Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rectangle(w, h) => w * h,
        Shape::Triangle(a, b, c) => {
            let s = (a + b + c) / 2.0
            sqrt(s * (s - a) * (s - b) * (s - c))
        },
    }
}
```

Se voce omitir uma variante, o compilador reporta um erro de matching nao exaustivo.

## Guards

Arms de pattern podem incluir guards com `if` para condicoes adicionais:

```sio
fn classify_temp(celsius: f64) -> str {
    match celsius {
        t if t < 0.0 => "freezing",
        t if t < 20.0 => "cold",
        t if t < 35.0 => "comfortable",
        _ => "hot",
    }
}
```

## Matching em structs

```sio
struct Point { x: f64, y: f64 }

fn quadrant(p: Point) -> str {
    match p {
        Point { x, y } if x > 0.0 && y > 0.0 => "I",
        Point { x, y } if x < 0.0 && y > 0.0 => "II",
        Point { x, y } if x < 0.0 && y < 0.0 => "III",
        Point { x, y } if x > 0.0 && y < 0.0 => "IV",
        _ => "on axis",
    }
}
```

## Limitacoes atuais

- Desestruturacao de tuplas em bindings `let` (`let (a, b) = pair`) ainda nao e suportada. Use `match` como alternativa.
- Pattern matching aninhado em structs profundamente aninhadas funciona, mas a verificacao de exaustividade ainda nao cobre todos os casos.
- Or-patterns (`A | B => ...`) sao parseados, mas a verificacao de cobertura para eles ainda esta amadurecendo.
