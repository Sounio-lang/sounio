# Correspondência de Padrões (*Pattern Matching*)

A expressão `match` oferece correspondência de padrões exaustiva sobre valores. O compilador verifica que todos os casos são cobertos e avisa sobre braços inalcançáveis.

## Correspondência básica

```sio
fn describe(x: i32) -> str {
    match x {
        0 => "zero",
        1 => "one",
        _ => "other",
    }
}
```

O coringa `_` corresponde a qualquer valor e é usado como cláusula catch-all.

## Correspondência em enums

```sio
enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
    Triangle(f64, f64, f64),
}

fn area(s: Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rectangle(w, h) => w * h,
        Shape::Triangle(a, b, c) => {
            let s = (a + b + c) / 2.0
            sqrt(s * (s - a) * (s - b) * (s - c))
        },
    }
}
```

Se você omitir uma variante, o compilador reporta um erro sobre correspondência não exaustiva.

## Guards

Braços de padrão podem incluir guards `if` para condições adicionais:

```sio
fn classify_temp(celsius: f64) -> str {
    match celsius {
        t if t < 0.0 => "freezing",
        t if t < 20.0 => "cold",
        t if t < 35.0 => "comfortable",
        _ => "hot",
    }
}
```

## Correspondência em structs

```sio
struct Point { x: f64, y: f64 }

fn quadrant(p: Point) -> str {
    match p {
        Point { x, y } if x > 0.0 && y > 0.0 => "I",
        Point { x, y } if x < 0.0 && y > 0.0 => "II",
        Point { x, y } if x < 0.0 && y < 0.0 => "III",
        Point { x, y } if x > 0.0 && y < 0.0 => "IV",
        _ => "on axis",
    }
}
```

## Limitações atuais

- Desestruturação de tuplas em bindings `let` (`let (a, b) = pair`) ainda não é suportada. Use `match` em vez disso.
- Correspondência de padrões aninhados em structs profundamente aninhadas funciona, mas ainda não é verificada exaustivamente em todos os casos.
- Padrões de disjunção (`A | B => ...`) são parseados, mas a verificação de cobertura para eles ainda está amadurecendo.
