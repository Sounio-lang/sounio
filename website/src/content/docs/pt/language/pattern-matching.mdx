# Correspondência de Padrões (*Pattern Matching*)

A expressão estruturada `match` oferece um mecanismo avançado e exaustivo de correspondência de padrões (*pattern matching*) sobre valores lógicos e tipos de dados. O compilador valida estaticamente a exaustividade de todos os braços (*arms*) da expressão, emitindo avisos imediatos caso detete cenários inalcançáveis ou ramos não tratados.

## Utilização Básica

```sio
fn describe(x: i32) -> str {
    match x {
        0 => "zero",
        1 => "um",
        _ => "outro",
    }
}
```

O caractere universal de substituição `_` (comodinho ou *wildcard*) corresponde a qualquer valor e atua como uma cláusula de salvaguarda para capturar todas as opções restantes (*catch-all*).

## Correspondência em Enumerações (Enums)

```sio
enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
    Triangle(f64, f64, f64),
}

fn area(s: Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rectangle(w, h) => w * h,
        Shape::Triangle(a, b, c) => {
            let s = (a + b + c) / 2.0
            sqrt(s * (s - a) * (s - b) * (s - c))
        },
    }
}
```

Se omitir deliberadamente qualquer variante da enumeração, o compilador interromperá o processo de compilação acusando uma falha de correspondência não exaustiva (*non-exhaustive pattern matching*).

## Guardas de Controlo (*Guards*)

Os braços de correspondência podem ser refinados através de guardas de controlo utilizando a diretiva `if` para avaliar expressões booleanas complementares:

```sio
fn classify_temp(celsius: f64) -> str {
    match celsius {
        t if t < 0.0 => "gelado",
        t if t < 20.0 => "frio",
        t if t < 35.0 => "ameno",
        _ => "quente",
    }
}
```

## Correspondência em Estruturas (Structs)

O `match` também permite desestruturar e interrogar os campos internos de uma estrutura (*struct*) de forma direta:

```sio
struct Point { x: f64, y: f64 }

fn quadrant(p: Point) -> str {
    match p {
        Point { x, y } if x > 0.0 && y > 0.0 => "I",
        Point { x, y } if x < 0.0 && y > 0.0 => "II",
        Point { x, y } if x < 0.0 && y < 0.0 => "III",
        Point { x, y } if x > 0.0 && y < 0.0 => "IV",
        _ => "sobre o eixo",
    }
}
```

## Limitações Atuais

- **Desestruturação Local:** A desestruturação direta de tuplos através de atribuições `let` (por exemplo, `let (a, b) = par`) ainda não é suportada. Recomenda-se o recurso ao bloco `match` como alternativa.
- **Aninhamento Complexo:** A correspondência em estruturas ou variantes profundamente aninhadas funciona estavelmente, mas a validação rigorosa de exaustividade por parte do compilador para estes cenários ainda se encontra em fase de aperfeiçoamento.
- **Padrões de Disjunção:** A utilização de operadores de união num único braço (`A | B => ...`) é suportada pelo analisador sintático, contudo o motor de prova de cobertura está a ser ativamente otimizado para cobrir todos os casos extremos.
