# Primeiros Passos

Programas Sounio são arquivos `.sio` compilados e executados com o compilador `souc`.

## 1) Instalar o `souc`

### Compilar a partir do código-fonte (recomendado)

```bash
git clone https://github.com/sounio-lang/sounio.git
cd sounio

# Build the compiler
cargo build -p souc --release

# Run it from the repo
./target/release/souc --version
```

### Opcional: colocar `souc` no seu PATH

```bash
sudo cp ./target/release/souc /usr/local/bin/souc
```

## 2) Olá, Mundo

Crie `hello.sio`:

```sio
fn main() with IO {
    println("Hello, Sounio!")
}
```

Verifique tipos e execute:

```bash
souc check hello.sio
souc run hello.sio
```
