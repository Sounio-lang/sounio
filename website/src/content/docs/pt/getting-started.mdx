Comece com um compilador compatível, verifique um programa pequeno e depois execute-o. Este guia usa o inicializador canônico do repositório, `./bin/souc`, cujo compilador padrão é o Madaros.

## Obtenha o repositório

Você precisa de Git, Bash e ferramentas Unix usuais. No terminal:

```sh
git clone https://github.com/Sounio-lang/sounio.git
cd sounio
git rev-parse HEAD
uname -sm
```

Guarde a revisão do código e escolha a preparação adequada ao seu sistema:

| Sistema | Preparação |
| --- | --- |
| Linux x86_64 | Use o Madaros pré-compilado para Linux x86-64, versionado no repositório, por meio de `./bin/souc`. Siga o [guia de instalação](https://github.com/Sounio-lang/sounio/blob/main/INSTALL.md) (em inglês). |
| macOS ARM64 (Apple Silicon) | Primeiro compile e instale o artefato nativo, seguindo o [guia de macOS ARM64](https://github.com/Sounio-lang/sounio/blob/main/docs/compiler/MADAROS_MACOS_ARM64.md) (em inglês). O ELF de Linux não roda nativamente no macOS. |
| Outros sistemas | Estas instruções não fornecem um pré-compilado compatível. Consulte o guia de instalação antes de continuar. |

A compilação nativa para macOS exige um executável de bootstrap gerado do código-fonte atual, assinado e com permissão de execução, ferramentas de linha de comando da Apple com `clang++` compatível com C++23 e `codesign`, o comando `timeout` e os cabeçalhos Boost. A validação completa da instalação também exige um dispositivo Metal real. O [guia nativo](https://github.com/Sounio-lang/sounio/blob/main/docs/compiler/MADAROS_MACOS_ARM64.md) detalha esses pré-requisitos e instala `artifacts/self-hosted/madaros-arm64-macos`, preferido pelo inicializador no Apple Silicon após as substituições explícitas de binário. Apenas clonar o repositório não basta nessa plataforma.

Nenhum desses caminhos começa com `cargo build` na raiz do repositório.

## Identifique o compilador

Após concluir a preparação da sua plataforma, execute na raiz do repositório:

```sh
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
./bin/souc info
./bin/souc --version
```

`bin/souc` é um inicializador. Inspecione o caminho `raw_elf` informado por `info`: substituições explícitas e artefatos locais podem selecionar um compilador diferente do pré-compilado versionado. Guarde essa identidade junto dos resultados. Para o pré-compilado Linux, o checksum registrado está em `bin/madaros-linux-x86_64.sha256`; o artefato macOS tem identidade própria. Não troque de compilador para contornar uma falha de plataforma ou de preparação.

## Verifique e execute o primeiro exemplo

Quando o compilador selecionado for compatível com a sua plataforma:

```sh
./bin/souc check examples/hello.sio
./bin/souc run examples/hello.sio
```

Execute o segundo comando somente se a verificação passar. A mensagem esperada é `Hello, Sounio`, com código de saída zero. Guarde a saída real e o código de saída: passar na verificação não comprova o comportamento em execução, e estas instruções não são um relato de nova execução.
