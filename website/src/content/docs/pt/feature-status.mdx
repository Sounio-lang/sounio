# Estado das Funcionalidades

Esta página é o painel de estado compacto do contrato público. Os números são gerados a partir de artefatos de gate já commitados e do README.md via `npm run sync:artifacts` — não são texto de marketing mantido manualmente.

<FeatureStatusPanel />

## Por que esses números importam

- Vêm de artefatos commitados, não de texto aspiracional de roadmap.
- Definem o que a documentação pode afirmar sem ressalvas.
- Explicam por que partes grandes do repositório ainda devem ser descritas como trabalho ativo, superfície stub ou inventário desativado, e não como APIs estáveis.

## Como usar esta página

- Use-a como o resumo de estado da porta de entrada.
- Use as páginas de documentação mais detalhadas quando precisar de profundidade de workflow, arquitetura ou implementação.
- Use os artefatos brutos quando precisar de detalhe exato por lane ou prova legível por máquina.
