# Feature Status

Esta página agora relata o snapshot realmente entregue: contagens sustentadas por artefatos, lanes ativas e caveats explícitos sobre superfícies desativadas ou em soft-fail.

## Verificado hoje
- O retrato de features neste site é fundamentado em artefatos de status versionados.
- Os artefatos versionados da stdlib informam `81 pass / 0 fail / 1 skip / 82 total`, com `604` arquivos `.sio` e `111` arquivos desativados.
- O artefato JIT versionado informa Cranelift JIT habilitado.
- O artefato GPU versionado informa GPU codegen habilitado e emissão PTX via `build --backend gpu`.
- As lanes GPU atestadas hoje são CUDA `cuda-sm80` e ROCm `rocm-gfx942`.
