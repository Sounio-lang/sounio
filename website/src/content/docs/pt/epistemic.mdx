# Tipos Epistêmicos

A computação epistêmica ainda é a parte do Sounio que mais claramente o diferencia. O contrato público é mais restrito do que a visão de pesquisa completa, mas é real: o artefato verificado, os fixtures atuais e os testes de recusa oferecem uma base concreta.

## O que está atualmente demonstrado

- A linguagem ainda modela valores no estilo `Knowledge` como uma ideia de primeira classe.
- O caminho verificado atual comprova limites explícitos de unwrap e comportamento de recusa baseado em confiança.
- Os fixtures de vancomicina e de COVID continuam sendo as melhores demonstrações compactas de por que a tipagem epistêmica importa neste repositório.

## Onde ler e onde verificar

- `docs/reference/KNOWLEDGE_REFERENCE.md` descreve o modelo mais amplo da API epistêmica.
- `docs/research/vancomycin-uncertainty.md` explica em detalhe o estudo de caso público mais forte.
- `self-hosted/check/epistemic.sio` é o diretório voltado à implementação a inspecionar para o trabalho atual do checker.
- `tests/run-pass/vancomycin_propagation.sio`, `tests/run-pass/covid_2020_kernel.sio` e os fixtures relacionados de compile-fail são os pontos de prova atuais.

## Padrão epistêmico mínimo

```sio
let dose = Knowledge { value: 42.0 }
let accepted: f64 = dose.unwrap("demo boundary")
```

## Como documentar esta área de forma responsável

- Separar o contrato verificado do modelo de pesquisa mais amplo.
- Usar fixtures e testes de recusa para afirmações sobre comportamento em tempo de compilação.
- Tratar proveniência, confiança e incerteza como parte da narrativa da linguagem, mesmo quando um artefato específico expõe apenas parte do modelo completo.
