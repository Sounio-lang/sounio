# Biblioteca Padrão

A stdlib é grande e ativa, mas os docs públicos agora a descrevem por contagens de inventário sustentadas por gates e caveats explícitos sobre módulos desativados ou stub.

## Verificado hoje
- Os artefatos versionados da stdlib informam `251 pass / 0 fail / 0 skip / 251 total`, com `927` arquivos `.sio` e `0` arquivos desativados.
- Scripts de gate e artefatos versionados são a evidência mais forte para declarações públicas.
- Trate testes e artefatos de gate como evidência mais forte do que texto aspiracional ou nomes de diretório.

## Ressalvas atuais
- Módulos stub e arquivos `*.sio.disabled` são inventário de roadmap, não APIs estáveis.
- O comportamento depende do binário `souc` exato, não apenas dos arquivos presentes no repositório.
