# `Knowledge<T>`

`Knowledge<T>` continua sendo a superfície epistêmica aplicada com mais clareza: carregue o valor encapsulado o máximo possível e faça unwrap apenas com uma razão registrada.

## Verificado hoje
- `Knowledge<T>` ainda exige fronteiras de unwrap explícitas em vez de extração silenciosa.
- `unwrap(reason)` é a fronteira de proveniência mais claramente aplicada hoje.
- Trate testes e artefatos de gate como evidência mais forte do que texto aspiracional ou nomes de diretório.

## Ressalvas atuais
- O modelo completo de incerteza e proveniência é mais rico na spec e na stdlib do que no artefato validado de hoje.
- O comportamento depende do binário `souc` exato, não apenas dos arquivos presentes no repositório.

## Teste neste repositório

```bash
let k = Knowledge { value: 42.0 }
let accepted: f64 = k.unwrap("accepted for demo")
```
