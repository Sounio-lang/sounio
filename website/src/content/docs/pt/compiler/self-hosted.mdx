# Compilador Self-Hosted

O Sounio inclui um compilador *self-hosted* escrito inteiramente em arquivos `.sio`. Este compilador é capaz de realizar a análise sintática (*parsing*), a verificação de tipos (*type-checking*), a conversão para representação intermediária (redução para IR), a otimização e a emissão direta de binários nativos ELF x86-64 — sem depender do LLVM, do Cranelift ou de qualquer gerador de código externo.

## Pipeline de Compilação

```
Origem (.sio) → Lexer → Parser → AST
    → ir/lower.sio → IrModule (IR própria)
    → Passagens de Otimização
    → native/codegen.sio → Código de Máquina x86-64
    → native/elf.sio → Binário ELF
```

Este pipeline é o **caminho padrão do compilador público** via `bin/souc`. Ele emite binários ELF/Mach-O nativos diretamente, sem arquivos de objeto intermediários. Perfis opcionais de LLVM e de Cranelift JIT existem em artefatos omega separados — eles não são a história principal de onboarding.

## Módulos Principais

| Módulo | Arquivo | Propósito |
| :--- | :--- | :--- |
| **Lexer** | `self-hosted/lexer/` | Tokenização do código-fonte |
| **Parser** | `self-hosted/parser/` | Construção da AST |
| **Redução para IR** | `self-hosted/ir/lower.sio` | Conversão da AST para IR, cálculo de estratégias |
| **Tipos de IR** | `self-hosted/ir/ir.sio` | Definições de `IrFunction`, `IrModule` e `IrInstr` |
| **Otimizador** | `self-hosted/ir/opt_cleanup.sio` | Constant folding, DCE, redução de força |
| **Perfil** | `self-hosted/ir/profile.sio` | Dados de profiling `.sprof`, promoção de estratégia |
| **Inliner** | `self-hosted/ir/inline.sio` | Inlining de funções guiado por perfil |
| **Layout** | `self-hosted/ir/layout.sio` | Ordenação de funções guiada por perfil |
| **E-graph** | `self-hosted/ir/egraph.sio` | Saturação de igualdade para regras algébricas |
| **Codegen** | `self-hosted/native/codegen.sio` | Emissão de instruções x86-64 |
| **Frame** | `self-hosted/native/frame.sio` | Layout do stack frame, alocação de registradores |
| **ELF** | `self-hosted/native/elf.sio` | Emissão do formato binário ELF |
| **Relocações** | `self-hosted/native/reloc.sio` | Relocações de símbolos e seções |
| **Entrada** | `self-hosted/compiler/main.sio` | Driver de CLI e orquestração da compilação |

## Passagens de Otimização

O otimizador *self-hosted* inclui mais de 20 passagens, construídas de forma incremental ao longo dos sprints 51-110:

- **Constant folding**: avalia em tempo de compilação aritmética de valores já conhecidos como constantes.
- **Dead code elimination**: mark-sweep para remover instruções não utilizadas.
- **Strength reduction**: substitui `x * 2^n` por `x << n`, `x / 2^n` por `x >> n`, `x % 2^n` por `x & (2^n - 1)`.
- **Copy propagation**: rastreia cadeias de `IrCopy` para habilitar mais folding.
- **Peephole**: `IrCopy(r,r)` vira `IrNop`, elimina `IrLoadImm` duplicados.
- **Normalização algébrica**: `x - x` vira 0, `x ^ x` vira 0, folding de cadeias de constantes como `(x + 3) + 5` vira `x + 8`.
- **Saturação de E-graph**: canonicalização comutativa, identidades bit a bit, anulação por multiplicação.
- **CSE**: tabela hash de 128 entradas com ordenação canônica de operandos.
- **LICM**: içar `IrLoadImm` invariantes de laço para fora das back edges.
- **GVN**: numeração global de valores com tabela de 128 entradas.
- **Simplificação booleana**: `(x == 0) == 0` vira `IrCopy(x)`, `bool != 0` vira `IrCopy(bool)`.
- **Folding de branch condicional**: `BranchTrue(constante_conhecida)` vira `IrJump` ou `IrNop`.
- **Jump-to-return**: `IrJump(L)` onde `L+1 = IrReturn` vira `IrReturn`.

## Alocação de Registradores

O backend nativo usa um alocador linear-scan de 4 registradores, direcionado a `r12`, `r13`, `r14`, `r15` (callee-saved). Spills para a pilha usam codificação adaptativa `disp8`/`disp32` para minimizar o tamanho do código.

## Otimização Guiada por Perfil (PGO)

O compilador self-hosted implementa um pipeline completo de PGO:

1. **Instrumentação**: opcodes `IrProfCounter` injetam `INC [RIP+disp32]` nos pontos de entrada das funções.
2. **Dump de perfil**: `__prof_dump` grava arquivos `.sprof` na saída, com contagens de execução por função.
3. **Promoção de estratégia**: funções quentes (contagem > 1000) são promovidas a `AGGRESSIVE`, funções mornas (> 100) a `PRECISION`.
4. **Inlining guiado por perfil**: o score de inlining incorpora bônus de estratégia.
5. **Layout guiado por perfil**: funções quentes são ordenadas no início do binário para localidade de cache.

## Como Executar o Compilador Self-Hosted

```bash
SOUC=./bin/souc

# Self-test (roda todos os casos de teste internos)
$SOUC run self-hosted/compiler/main.sio -- --self-test

# Apenas verificação (sem geração de código)
$SOUC run self-hosted/compiler/main.sio -- --check

# Dump de IR para uma função específica
$SOUC run self-hosted/compiler/main.sio -- --ir-dump --fn=main
```

## Verificação

O compilador self-hosted se valida através de mais de 347 self-tests cobrindo cada passagem de otimização. Scripts de gate (ex.: `scripts/sprint52_regalloc_gate.sh`) rodam a matriz completa de testes e reportam contagens de PASS/FAIL/NOT_RUN.
