# Scientific Features

Recursos científicos agora são descritos pelas lanes que realmente passam e pelas superfícies de biblioteca ainda parcialmente desativadas ou em soft-fail.

## Verificado hoje
- Scripts de gate e artefatos versionados são a evidência mais forte para declarações públicas.
- `tests/run-pass/vancomycin_propagation.sio` e o fixture médico documentam o fluxo epistemic atual.
- Os artefatos versionados da stdlib informam `251 pass / 0 fail / 0 skip / 251 total`, com `927` arquivos `.sio` e `0` arquivos desativados.

## Ressalvas atuais
- O runtime científico local ainda acompanha quatro regressões em modo soft.
- Módulos stub e arquivos `*.sio.disabled` são inventário de roadmap, não APIs estáveis.
