# Code Generation

Os docs de geração de código agora são amarrados ao artefato que verificamos: Cranelift JIT é real, enquanto outras afirmações de backend precisam de confirmação específica por artefato.

## Verificado hoje
- O artefato público versionado informa Cranelift JIT habilitado.
- Backends como LLVM, GPU e LSP precisam ser confirmados por artefato, e não inferidos pela árvore de fontes.
- Trate testes e artefatos de gate como evidência mais forte do que texto aspiracional ou nomes de diretório.

## Ressalvas atuais
- O artefato JIT público versionado informa suporte a GPU desativado.
- O comportamento depende do binário `souc` exato, não apenas dos arquivos presentes no repositório.
