Conclua primeiro a [preparação da plataforma](/pt/learn/getting-started/). Linux x86-64 usa o pré-compilado versionado; macOS ARM64 precisa do compilador nativo construído separadamente. Confirme a identidade do compilador selecionado antes de executar os comandos.

## O programa completo

Este é o código completo de [`examples/hello.sio`](https://github.com/Sounio-lang/sounio/blob/main/examples/hello.sio), sem alterações. O bloco abaixo contém código Sounio; os comandos de terminal aparecem separadamente.

```sio
// First Sounio program

fn main() -> i32 with IO {
    println("Hello, Sounio")
    return 0
}
```

`main` é o ponto de entrada. `with IO` declara o efeito de entrada e saída usado por `println`. O `return 0` explícito define o código de saída de sucesso deste programa.

## Verifique e execute

Na raiz do repositório, após concluir a preparação:

```sh
export SOUNIO_STDLIB_PATH="$PWD/stdlib"
./bin/souc check examples/hello.sio
./bin/souc run examples/hello.sio
```

Prossiga para `run` somente após `check` passar. A mensagem esperada é `Hello, Sounio`, com código de saída zero. Registre a saída real e o código de saída de cada comando. Passar na verificação não comprova execução bem-sucedida; o resultado esperado aqui não é uma nova medição do seu ambiente.

Para experimentar uma variação, copie o programa completo para outro arquivo `.sio` e altere a mensagem. Verifique e execute esse arquivo, mantendo o exemplo do repositório intacto.
