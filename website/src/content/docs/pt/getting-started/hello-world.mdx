# Olá, Mundo

Vamos escrever seu primeiro programa em Sounio.

## Criando o Arquivo

Crie um novo arquivo chamado `hello.sio`:

```sio
fn main() with IO {
    println("Hello, Sounio!")
}
```

## Entendendo o Código

- **`fn main()`** - O ponto de entrada de todo programa Sounio
- **`with IO`** - Declara que a função faz IO (recomendado; a especificação exige efeitos explícitos)
- **`println(...)`** - Imprime um valor no console

## Executando o Programa

```bash
souc run hello.sio
```

Saída:
```
Hello, Sounio!
```

## Adicionando Variáveis

```sio
fn main() with IO {
    let name = "Sounio"
    let year = 2026

    print("Welcome to ")
    println(name)

    print("Established in ")
    println(year)
}
```
