# Olá, Mundo

O menor caminho atual de hello world continua sendo um `main` simples com `with IO`, validado com `check` antes de tentar `run`.

## Verificado hoje
- `examples/hello.sio` continua sendo o ponto de partida verificado mais simples.
- Efeitos explícitos com `with ...` continuam fazendo parte do contrato real da linguagem.
- Prefira `souc check` antes de `run` ou `build`.

## Ressalvas atuais
- `run` depende do artefato e do caminho de runtime escolhidos.
- O comportamento depende do binário `souc` exato, não apenas dos arquivos presentes no repositório.

## Teste neste repositório

```bash
fn main() with IO {
    println("Hello, Sounio!")
}

# then
"$SOUC_BIN" check hello.sio
"$SOUC_BIN" run hello.sio
```
