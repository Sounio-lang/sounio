# 介绍 Sounio

我们很高兴宣布推出 **Sounio**，一种从根本上为知识计算设计的编程语言——知道它们不知道什么的程序。

## 为什么选择 Sounio？

现代科学计算面临一个基本问题：我们的工具将所有的值都视为精确的，而实际上，测量不确定性无处不在。一个传感器读到的 `23.5°C` 的温度值并不是精确的——它可能是 `23.5 ± 0.2°C` 的 95% 置信度。

Sounio 将不确定性作为一等概念：

```sio
let temp: Knowledge<°C> = measure(
    value: 23.5,
    uncertainty: 0.2,
    source: "sensor_001"
)

// 不确定性会自动在计算中传播
let temp_f = temp * 1.8 + 32.0  // 仍然跟踪不确定性！
```

## 关键特性

### 知识类型

`Knowledge<T>` 类型将任何值与其不确定性、血统和置信度级别包装在一起。当你将知识值相加时，不确定性将根据 GUM（测量不确定度表达指南）标准传播。

### 代数效应

副作用在类型系统中被跟踪。每个函数声明它需要什么效果：

```sio
fn read_config() -> Config with IO, Fail {
    let content = perform IO::read("config.toml")?;
    parse_toml(content)?;
}
```

### 度量单位

类型安全的维度分析在编译时防止单位错误：

```sio
let distance: km = 42.195;
let time: h = 2.5;
let speed: km/h = distance / time  // 类型检查！
```
