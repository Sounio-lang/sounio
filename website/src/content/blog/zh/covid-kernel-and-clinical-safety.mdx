# 发布类型拒绝示例

今天，我们发布了两个示例，展示了为什么Sounio在实际决策系统中很重要：

- 一个**2020年3月COVID内核**，具有明确的时间有效性和认识论类型
- 一个**万古霉素临床安全性门**，在编译时拒绝低置信度处方

这些示例现在出现在网站的“学习”和“科学”部分。

## 1) 2020年COVID内核

该内核使用明确的时间窗口和置信度感知的类型建模政策相关输入：

```bash
souc check tests/run-pass/covid_2020_kernel.sio
```

这使得假设可审计，并防止过时或弱依据的值静默地流过政策逻辑。

## 2) 万古霉素安全性传播 + 拒绝

传播示例展示了给药步骤中的置信度演变：

```bash
souc check tests/run-pass/vancomycin_propagation.sio
```

拒绝示例强制执行最小置信度阈值：

```bash
souc check tests/compile-fail/vancomycin_low_conf.sio
```

这是一个严格的编译时安全性边界，而不仅仅是运行时警告。
