# タイプ付き拒否例の配布

今日は、実際の決定システムで Sounio の重要さを示す 2つの例を公開します:

- 明示的に時間的に有効で、知識的に分かりやすい型を持つ **2020年3月の COVID カーネル**
- コンパイル時に低確信度の予剤薬の予定を拒否する **ビンコミシンの臨床安全ゲート**

これらの例は、今後も学習とサイエンスセクションで表示されます。

## 1) COVID 2020 カーネル

カーネルは、時間的な有効期限と確信度によって型付きの入力をモデル化します:

```bash
souc check tests/run-pass/covid_2020_kernel.sio
```

これにより、仮定の審計可能に保つことと、廃れたやはりやかりやすい値が政策ロジックに静かに流れることを防ぐことができます。

## 2) ビンコミシンの安全伝播と拒否

伝播フィックスチャーは、予定ステップごとに確信度の変化を示します:

```bash
souc check tests/run-pass/vancomycin_propagation.sio
```

拒否フィックスチャーは、最低確信度の閾値を強制します:

```bash
souc check tests/compile-fail/vancomycin_low_conf.sio
```

これは、コンパイル時の安全な境界であり、実行時に最善を尽くした警告ではなくなります。
