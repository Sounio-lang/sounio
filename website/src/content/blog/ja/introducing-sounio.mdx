# Sounioの紹介

Sounioを発表することにより、知識を持つプログラムを作成するために設計された新しいプログラミング言語をお知らせします。

## Sounioの理由

現代的な科学計算には基本的的な問題があります。すなわち、すべての値を正確として扱うことですが、実際には測定の不确定性が普遍的です。センサーからの`23.5°C`の温度測定値は正確ではないです。それは`23.5 ± 0.2°C`で95％の確信度です。

Sounioは不确定性を最初のクラスの概念として扱います：

```sio
let temp: Knowledge<°C> = measure(
    value: 23.5,
    uncertainty: 0.2,
    source: "sensor_001"
)

// 不确定性は自動的に計算に沿って伝播します
let temp_f = temp * 1.8 + 32.0  // まだ不确定性を追跡しています！
```

## キー特徴

### 知識タイプ

`Knowledge<T>`型は、その不确定性、証拠、信頼度を持つ任意の値をラップします。知識値を組み合わせると、不确定性は測定のガイドライン（Guide to the Expression of Uncertainty in Measurement）標準に従って伝播します。

### 代数効果

タイプシステムで副作用が追跡されます。すべての関数は必要な効果を宣言します：

```sio
fn read_config() -> Config with IO, Fail {
    let content = perform IO::read("config.toml")?;
    parse_toml(content)?;
}
```

### 測定単位

コンパイル時に単位エラーを防ぐための型安全な次元分析を行います：

```sio
let distance: km = 42.195;
let time: h = 2.5;
let speed: km/h = distance / time;  // 型チェックされます！
```
