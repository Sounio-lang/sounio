# Παραδείγματα τυπικά ελεγχόμενης απόρριψης

Σήμερα παρουσιάζουμε δύο παραδείγματα που δείχνουν γιατί το Sounio έχει σημασία σε πραγματικά συστήματα λήψης αποφάσεων:

- έναν **πυρήνα COVID του Μαρτίου 2020** με ρητή χρονική ισχύ και επιστημολογικούς τύπους·
- μια **κλινική πύλη ασφάλειας για τη βανκομυκίνη** που απορρίπτει συνταγογραφήσεις με χαμηλή εμπιστοσύνη κατά τη μεταγλώττιση.

Τα παραδείγματα αυτά εμφανίζονται πλέον στις ενότητες Learn και Science του ιστοτόπου.

## 1) Πυρήνας COVID του 2020

Ο πυρήνας μοντελοποιεί εισόδους σχετικές με την πολιτική, με ρητά χρονικά όρια ισχύος και τύπους που λαμβάνουν υπόψη την εμπιστοσύνη:

```bash
souc check tests/run-pass/covid_2020_kernel.sio
```

Έτσι οι παραδοχές παραμένουν ελέγξιμες και αποτρέπεται η αθόρυβη ροή παρωχημένων ή ανεπαρκώς τεκμηριωμένων τιμών μέσα στη λογική πολιτικής.

## 2) Διάδοση ασφάλειας για τη βανκομυκίνη και απόρριψη

Το παράδειγμα διάδοσης παρουσιάζει την εξέλιξη της εμπιστοσύνης στα διαδοχικά βήματα δοσολογίας:

```bash
souc check tests/run-pass/vancomycin_propagation.sio
```

Το παράδειγμα απόρριψης επιβάλλει ένα ελάχιστο όριο εμπιστοσύνης:

```bash
souc check tests/compile-fail/vancomycin_low_conf.sio
```

Πρόκειται για αυστηρό όριο ασφάλειας κατά τη μεταγλώττιση, όχι για προειδοποίηση χρόνου εκτέλεσης που λειτουργεί μόνο κατά το δυνατόν.
