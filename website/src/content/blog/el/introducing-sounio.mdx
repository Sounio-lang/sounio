# Γνωρίστε το Sounio

Με χαρά παρουσιάζουμε το **Sounio**, μια νέα γλώσσα προγραμματισμού σχεδιασμένη εξαρχής για επιστημολογική υπολογιστική — προγράμματα που γνωρίζουν τι δεν γνωρίζουν.

## Γιατί το Sounio;

Η σύγχρονη επιστημονική υπολογιστική αντιμετωπίζει ένα θεμελιώδες πρόβλημα: τα εργαλεία μας συχνά χειρίζονται όλες τις τιμές σαν να ήταν ακριβείς, ενώ στην πραγματικότητα η αβεβαιότητα των μετρήσεων είναι παντού παρούσα. Μια ένδειξη θερμοκρασίας `23.5°C` από έναν αισθητήρα δεν είναι ακριβής· μπορεί να είναι `23.5 ± 0.2°C` με επίπεδο εμπιστοσύνης 95%.

Το Sounio κάνει την αβεβαιότητα έννοια πρώτης τάξης:

```sio
let temp: Knowledge<°C> = measure(
    value: 23.5,
    uncertainty: 0.2,
    source: "sensor_001"
)

// Uncertainty propagates automatically through calculations
let temp_f = temp * 1.8 + 32.0  // Still tracks uncertainty!
```

## Κύρια χαρακτηριστικά

### Επιστημολογικοί τύποι

Ο τύπος `Knowledge<T>` τυλίγει κάθε τιμή μαζί με την αβεβαιότητα, την προέλευσή της και το επίπεδο εμπιστοσύνης της. Όταν συνδυάζετε τιμές γνώσης, η αβεβαιότητα διαδίδεται σύμφωνα με τα πρότυπα GUM (Guide to the Expression of Uncertainty in Measurement).

### Αλγεβρικά εφέ

Οι παρενέργειες παρακολουθούνται στο σύστημα τύπων. Κάθε συνάρτηση δηλώνει τα εφέ που χρειάζεται:

```sio
fn read_config() -> Config with IO, Fail {
    let content = perform IO::read("config.toml")?
    parse_toml(content)?
}
```

### Μονάδες μέτρησης

Η ανάλυση διαστάσεων με ασφάλεια τύπων αποτρέπει τα σφάλματα μονάδων κατά τη μεταγλώττιση:

```sio
let distance: km = 42.195
let time: h = 2.5
let speed: km/h = distance / time  // Type-checked!
```
