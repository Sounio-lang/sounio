# Εισήδηση στον Σουνιώ

Είμαστε υπερυπολογισμένοι να δημιουργήσουμε **τον Σουνιώ**, νέον γλώσσα γραμματισμού προγραμματισμού, προγραμματισμός προσαρμόζεται στην Επιστημονική Ροπολογία—προγραμματισμοί που γνώριζουν το αδιόσκοπο τους.

## Γιατί τον Σουνιώ;

Η Μοντέρνη Επιστημονική Ροπολογία αντιμετωπίζει έναν βασικό πρόβλημα: οι εργαλεία μας διατηρούν όλα τις τιμές ως τελικές, όταν οι γνώμες συγκεκριμένων προσαρμόζονται σε περιεχόμενο. Έναν τερμινομέτρο διαγραφής της 23,5°C από ενεργεία δεν είναι τελική—μπορεί να είναι 23,5 ± 0,2°C με 95% τιμή πιστότητας.

Ο Σουνιώ κατασκευάζει την αδιόσκοπο ως προαγωρισμένον:

κατάδοση της temp: Επιστήμη<°C> = μέριμος(
    τιμή: 23,5,
    αδιόσκοπος: 0,2,
    ειδοποιητής: "sensor_001"
)

// Η αδιόσκοπος αντιμετωπίζεται αυτόματα σε καλυπτομένους προσαρμοστές
