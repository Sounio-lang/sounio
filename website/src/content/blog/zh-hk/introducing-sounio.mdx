# 认识 Sounio

我们很高兴宣布 **Sounio**，一种专为认识计算而设计的编程语言。

## 为什么选择 Sounio？

现代科学计算面临一个根本问题：我们的工具将所有值视为精确的，而实际上，测量不确定性是普遍存在的。一个传感器读出的温度值 `23.5°C` 并不是精确的——它可能是 `23.5 ± 0.2°C` 的 95% 置信度。

Sounio 将不确定性视为第一级概念：

```sio
let temp: Knowledge<°C> = measure(
    value: 23.5,
    uncertainty: 0.2,
    source: "sensor_001"
)

// 不确定性在计算中自动传播
let temp_f = temp * 1.8 + 32.0  // 仍然追踪不确定性！
```

## 关键特性

### 认识类型

`Knowledge<T>` 类型将任何值与其不确定性、证明和置信度级别一起包装。当你结合知识值时，不确定性将根据 GUM（测量不确定度指南）标准进行传播。

### 代数效果

副作用在类型系统中被跟踪。每个函数声明它所需的效果：

```sio
fn read_config() -> Config with IO, Fail {
    let content = perform IO::read("config.toml")? 
    parse_toml(content)? 
}
```

### 单位测量

类型安全的维度分析在编译时防止单位错误：

```sio
let distance: km = 42.195
let time: h = 2.5
let speed: km/h = distance / time  // 类型检查！
```
