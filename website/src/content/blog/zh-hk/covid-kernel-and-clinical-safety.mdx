# 发布带类型拒绝的例子

今日我们发表两个例子，证明Sounio在实际决策系统中为何重要：

- 一个**2020年3月COVID内核**，具有明确的有效时间窗口和认知类型
- 一个**万古霉素临床安全网关**，在编译时拒绝低信心的处方

这些例子现在出现在网站的“学习”和“科学”部分。

## 1) COVID 2020内核

内核用明确的有效时间窗口和信心意识类型来建模政策相关的输入：

```bash
souc check tests/run-pass/covid_2020_kernel.sio
```

这使假设可审计，并防止过时或弱基的数值在政策逻辑中静默流过。

## 2) 万古霉素安全传播 + 拒绝

传播固定件展示了剂量步骤中的信心演变：

```bash
souc check tests/run-pass/vancomycin_propagation.sio
```

拒绝固定件强制执行最低信心阈值：

```bash
souc check tests/compile-fail/vancomycin_low_conf.sio
```

这是一个硬性的编译时安全界限，不是最佳努力的运行时警告。
