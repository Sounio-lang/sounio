# Introduciendo Sounio

¡Nos encanta anunciar **Sounio**, un nuevo lenguaje de programación diseñado desde cero para la computación epistémica, que son programas que saben qué no saben.

## ¿Por qué Sounio?

La computación científica moderna enfrenta un problema fundamental: nuestras herramientas tratan todos los valores como exactos, cuando en realidad, la incertidumbre de la medición es omnipresente. Una lectura de temperatura de `23.5°C` de un sensor no es exacta, podría ser `23.5 ± 0.2°C` con una confianza del 95%.

Sounio hace de la incertidumbre un concepto de primera clase:

```sio
let temp: Conocimiento<°C> = medir(
    valor: 23.5,
    incertidumbre: 0.2,
    fuente: "sensor_001"
)

// La incertidumbre se propaga automáticamente a través de las calculaciones
let temp_f = temp * 1.8 + 32.0  // Aún rastrea la incertidumbre!
```

## Características clave

### Tipos Epistémicos

El tipo `Knowledge<T>` rodea cualquier valor con su incertidumbre, provenancia y nivel de confianza. Cuando combinas valores de conocimiento, la incertidumbre se propaga de acuerdo con los estándares GUM (Guía para la Expresión de la Incertidumbre en la Medición).

### Efectos Algebraicos

Los efectos secundarios se rastran en el sistema de tipos. Cada función declara los efectos que necesita:

```sio
fn leer_config() -> Config con IO, Fallar {
    let contenido = realizar IO::leer("config.toml")?;
    parsear_toml(contenido)?;
}
```

### Unidades de Medida

La análisis dimensional asegura que los errores de unidades sean detectados en el tiempo de compilación:

```sio
let distancia: km = 42.195
let tiempo: h = 2.5
let velocidad: km/h = distancia / tiempo  // Verificado por tipo!
```
