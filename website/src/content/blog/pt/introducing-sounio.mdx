# Introduzindo Sounio

Nós estamos entusiasmados para anunciar **Sounio**, uma nova linguagem de programação desenhada do zero para computação epistêmica—programas que sabem o que não sabem.

## Por que Sounio?

A computação científica moderna enfrenta um problema fundamental: nossas ferramentas tratarem todos os valores como precisos, ao invés de reconhecer que a incerteza nas medidas é prevalente. Uma leitura de temperatura de `23.5°C` de um sensor não é exata—pode ser `23.5 ± 0.2°C` com 95% de confiança.

Sounio faz da incerteza um conceito de primeira classe:

```sio
let temp: Conhecimento<°C> = medir(
    valor: 23.5,
    incerteza: 0.2,
    fonte: "sensor_001"
)

// A incerteza se propaga automaticamente em cálculos
let temp_f = temp * 1.8 + 32.0  // Ainda rastreia a incerteza!
```

## Recursos Principais

### Tipos Epistêmicos

O tipo `Conhecimento<T>` envolve qualquer valor com sua incerteza, provência e nível de confiança. Quando você combinar valores de conhecimento, a incerteza se propaga de acordo com os padrões do GUM (Orientação para a Expressão de Incerteza em Medidas).

### Efeitos Algebraicos

Os efeitos secundários são rastreados no sistema de tipos. Cada função declara quais efeitos precisa:

```sio
fn ler_config() -> Config com IO, Fail {
    let conteúdo = perform IO::ler("config.toml")?
    parse_toml(conteúdo)?
}
```

### Unidades de Medida

A análise dimensional tipada impede erros de unidade no tempo de compilação:

```sio
let distância: km = 42.195
let tempo: h = 2.5
let velocidade: km/h = distância / tempo  // Verificado pelo tipo!
```
