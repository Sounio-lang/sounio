# i18n Coverage Audit — 2026-04-20

## Summary

Five non-English locales are configured: pt (Português), el (Ελληνικά), zh (中文), ja (日本語), es (Español).
Only `en` is in `fullyLocalizedLocales`, so the translation banner is shown on every non-English page.

**Banner behaviour after this audit pass:**
- All non-English pages now show: "This page has not yet been translated for this release. The English version is authoritative." with a link to the English URL.
- The banner is served in the target language where a translation exists in the locale JSON (pt, zh, ja, es). For el, the banner is in English deliberately — see Greek note below.
- The previous `isDocsPath` suppression that hid the banner on `/learn/*` has been removed. All pages including `/learn/getting-started` now show the banner.

## Status Key

| Symbol | Meaning |
|--------|---------|
| `translated-stale` | Locale-specific content file exists but is older/shorter than the current English version |
| `falls-back` | No locale-specific content; page delegates to the English Astro component |
| `ui-translated` | UI strings translated in locale JSON; page body falls back to English |
| `banner-shown` | Banner is rendered at runtime for this locale |

All non-English routes have `banner-shown = yes` after this pass.

## Greek (el) — Special Note

`el.json` is 13 KB vs 7.8–9.4 KB for other locales. The extra size reflects longer translated strings and a more thorough initial translation pass — someone invested care here.

The Sounio name comes from Cape Sounion (Σούνιο), making the Greek locale symbolically significant. For this reason:

- The locale banner for el is intentionally left in English rather than adding a quick Greek phrase. Any Greek text on this site should be reviewed by a native speaker before shipping.
- The `el.json` strings that already exist have not been touched.
- No additional machine translation has been added for el.
- Action required: recruit a native Greek reviewer before marking el as `fullyLocalized`.

## What was NOT changed

- `fullyLocalizedLocales` in `src/lib/i18n.ts` still contains only `en`. No locale has been promoted to "fully localized" — that requires a human review pass.
- The locale-specific `.mdx` files in `content/docs/[locale]/` have not been updated. They are stale but intact; updating them is a separate translation task.
- No machine translation was added anywhere.

---

## How to promote a locale to fully localized

1. Verify all `content/docs/[locale]/` files match the current English versions.
2. Verify the main Astro pages (index, language, proof, manifesto, etc.) have locale-specific variants or that the fallback is intentional.
3. Add the locale to `fullyLocalizedLocales` in `src/lib/i18n.ts`:
   ```ts
   export const fullyLocalizedLocales = new Set<Locale>(['en', 'pt']);
   ```
4. The banner will stop appearing for that locale automatically.
