Stdlib Reference

API reference for the Sounio standard library modules.

標準ライブラリリファレンス

Sounioの標準ライブラリはリポジトリ内の stdlib/ に同梱されています。現在の信頼性スナップショットは、ゲート対応フィクスチャ全体で 81 pass / 0 fail / 1 skip / 82 total です。

コアモジュール

stdlib/io

入出力操作です。すべての関数は IO エフェクトを必要とします。

FunctionSignatureDescription
printlnfn println(s: str) with IO改行付きでstdoutに文字列を出力
printfn print(s: str) with IO改行なしで文字列を出力
read_linefn read_line() -> str with IOstdinから1行読み取り
read_filefn read_file(path: str) -> str with IO, Panicファイル全体を文字列として読み取り
write_filefn write_file(path: str, data: str) with IO, Panic文字列をファイルに書き込み

科学モジュール

stdlib/pharma

PK/PDモデリングのための薬物動態ツールキットです。

FunctionDescription
pk_one_compartment単一コンパートメントPKモデル
compute_auc曲線下面積（AUC）計算
dose_adjust信頼度付きベイズ用量調整

stdlib/fmri

機能的MRI信号処理です（ゲートステータス: PASSING）。

FunctionDescription

生理学的薬物動態（PBPK）モデリングです（ゲートステータス: PASSING）。

stdlib/genomics

不確かさ伝播を伴うゲノム配列解析です。

stdlib/nn

ニューラルネットワークのレイヤーと演算です。

stdlib/epistemic

モジュールステータス

各モジュールの機械可読なゲートステータスについては、以下を参照してください:

  • artifacts/stdlib/stdlib_reliability_status.v1.json
  • フィーチャーステータスページ

ここに記載されていないモジュールは、スタブ、無効化、または実験的な可能性があります。現在のアーティファクトで利用可能なモジュールについては souc info で確認してください。
