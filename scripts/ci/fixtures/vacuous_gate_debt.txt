# Gates that run in CI, exit 0, and verify NOTHING — inventoried, shrink-only.
#
# A gate may legitimately skip because the ENVIRONMENT cannot host it: no GPU,
# no ptxas, not Linux, not x86-64. Ninety-eight such skips exist across
# scripts/ci and they are correct — you cannot run a GPU test without a GPU.
#
# This file is for the other kind. Here the environment is fine and the SUBJECT
# is missing: the gate cannot build or find the thing it exists to test. That is
# not an environment limitation, it is a hole in the compiler being reported as
# a green check. #2160 established the rule for the sibling case — death has
# kinds, and unjudgeable is debt that must shrink. Same rule here.
#
# Format: <gate script>\t<the symbol or capability that is absent>
#
# A gate whose subject is missing and which is NOT listed here must exit
# non-zero. Adding a line is a deliberate act that shows up in a diff; the count
# may only fall. When the subject appears, delete the line — the gate will then
# run for real, and if it was wrong all along you will find out then.
scripts/ci/ontology_cli_smoke_gate.sh	ontology_run_cli
# ── The `bootstrap` / `opt` gates: NOT dead, pointed at the wrong binary ─────
#
# Seven gates invoke `souc bootstrap …` or `souc opt policy …`. None of them is
# vacuous in the sense above -- every one has `set -e` and dies, so they report
# red rather than green. They are described here because the first reading of
# them was wrong in a way worth recording.
#
# The reading was: the Rust `souc` crate went in 79acc192e1, so the verbs went
# with it, so these gates are dead code. Measured, that is false. The checked
# artifact artifacts/omega/souc-bin/souc-linux-x86_64-gpu still has both verb
# families and answers for them:
#
#   $ artifacts/omega/souc-bin/souc-linux-x86_64-gpu bootstrap verify --bundle bootstrap
#   bootstrap verify ok: manifest=bootstrap/artifacts/manifest.v2.json artifacts=1 ...   rc=0
#
# The default bin/souc is Madaros, the self-hosted compiler, which never had
# them. So the gates are runnable; they simply name a binary that cannot serve
# them, and said so through a diagnostic that names a missing FILE:
#
#   error: at bootstrap:0:0 - could not read input file
#
# Each now refuses up front via scripts/lib/souc_verb_guard.sh, which probes
# differentially (ask what the binary does with a verb that cannot exist, ask
# what it does with this one, compare) so it works against both engines, and
# points at a binary that has the verb -- but only after verifying that one does.
#
#   scripts/selfhost/selfhost_independence_gate.sh    souc bootstrap verify/init/cycle
#   scripts/selfhost/selfhost_cycle_gate.sh           souc bootstrap verify/init/cycle
#   scripts/omega/omega_strict_closure_gate.sh        souc bootstrap verify/init/cycle
#   scripts/omega/omega_prepare_policy_smoke.sh       souc opt policy train
#   scripts/omega/omega_policy_status.sh              souc opt policy status
#   scripts/bootstrap/omega_canonical_policy_sign.sh  souc opt policy sign
#   scripts/bootstrap/bootstrap_verify_artifacts.sh   souc bootstrap verify
#
# Two of them additionally had a ROOT_DIR that climbed one directory too few and
# landed in scripts/ instead of the repo root -- the same restructure that left
# 31 scripts naming their own pre-move path. With both repaired,
# bootstrap_verify_artifacts.sh runs green against the checked artifact for the
# first time since February.
#
