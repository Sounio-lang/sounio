# Gates that run in CI, exit 0, and verify NOTHING — inventoried, shrink-only.
#
# A gate may legitimately skip because the ENVIRONMENT cannot host it: no GPU,
# no ptxas, not Linux, not x86-64. Ninety-eight such skips exist across
# scripts/ci and they are correct — you cannot run a GPU test without a GPU.
#
# This file is for the other kind. Here the environment is fine and the SUBJECT
# is missing: the gate cannot build or find the thing it exists to test. That is
# not an environment limitation, it is a hole in the compiler being reported as
# a green check. #2160 established the rule for the sibling case — death has
# kinds, and unjudgeable is debt that must shrink. Same rule here.
#
# Format: <gate script>\t<the symbol or capability that is absent>
#
# A gate whose subject is missing and which is NOT listed here must exit
# non-zero. Adding a line is a deliberate act that shows up in a diff; the count
# may only fall. When the subject appears, delete the line — the gate will then
# run for real, and if it was wrong all along you will find out then.
