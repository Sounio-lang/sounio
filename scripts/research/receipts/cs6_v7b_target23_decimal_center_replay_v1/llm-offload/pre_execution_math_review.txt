**CAPD containment comparison details:**

The CAPD intervals come from `binary64_decimal(x)` for x = hex float string. So the Decimal value is exactly the float64 value.

- CAPD interval = rigorous enclosure of true determinant over the rectangle
- Point determinant = approximation at the center

The point value can be inside the CAPD interval even if the rigorous enclosure is "wrong" (too wide). Conversely, the point value can be outside the CAPD interval if the CAPD interval is too tight (or wrong).

So containment is evidence of consistency, but not proof of correctness.

**Comparison threshold:**

1E-16 is the threshold for delta between coarse and fine determinants. This is an absolute threshold, not relative. As mentioned, if the determinant magnitudes are very small (e.g., 1E-20), 1E-16 agreement is impossible (the values would essentially be zero relative to each other).

If determinants are O(1E-3) (rough estimate from q0_area ≈ -1E-3 and exp factors), then 1E-16 agreement requires ~13 digits of agreement. RK4 with step 2^-9 vs 2^-10 (factor 2 finer) gives global error reduction by ~16 (RK4 is 4th order). So if coarse error is ε, fine error is ε/16, and delta ≈ 15ε/16.

For delta ≤ 1E-16, need ε ≤ 1E-16 × 16/15 ≈ 1E-16. So coarse RK4 error ≤ 1E-16 in determinant.
