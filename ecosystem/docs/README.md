## Building the Documentation

### Prerequisites

Install mkdocs and the material theme:

```bash
pip install mkdocs mkdocs-material
```

### Build Static Site

```bash
cd triple-sounio-ecosystem/docs
mkdocs build
```

Output: `site/` directory with static HTML.

### Serve Locally

```bash
mkdocs serve
```

Visit http://localhost:8000 in your browser. Auto-reloads on file changes.

### Deploy to GitHub Pages

```bash
mkdocs gh-deploy
```

Deploys to `gh-pages` branch (requires git remote named `origin`).

## Customization

### Change Site Name/Colors

Edit `mkdocs.yml`:

```yaml
site_name: Your New Name
theme:
  palette:
    primary: blue      # Change color
    accent: cyan
```

### Add New Pages

1. Create `.md` file in `docs/docs/`
2. Add entry to `nav:` in `mkdocs.yml`
3. Run `mkdocs serve` to preview

### Modify Navigation

Edit `mkdocs.yml` → `nav:` section:

```yaml
nav:
  - Home: index.md
  - About: about.md
  - sounio-py:
    - Overview: sounio-py/overview.md
    # Add more here
```

## Troubleshooting

### "mkdocs command not found"

```bash
pip install mkdocs mkdocs-material
```

### "theme 'material' not found"

```bash
pip install mkdocs-material
```

### Changes not showing

Restart `mkdocs serve`:

```bash
# Ctrl+C to stop
mkdocs serve
```

### Wrong paths in links

Ensure links use **relative paths**:

- ✅ `[Link](quickstart.md)` (same directory)
- ✅ `[Link](../sounio-py/overview.md)` (different section)
- ❌ `[Link](/sounio-py/overview.md)` (absolute; breaks on gh-pages)
