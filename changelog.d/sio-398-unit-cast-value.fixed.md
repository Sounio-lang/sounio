An accepted unit cast no longer turns the number into 0.0. `lower_cast_type_is_f64` only recognized the spellings `f64` and `f32`, so `7.25 as kg` and `raw as molal` fell through to `float_to_int`; the integer bits, read back as f64, printed `0.000000`. A known unit is the same f64 word as `as f64` (identity for a float source, `int_to_float` for an integer source). This is branding, not a scale conversion: `500.0 as mg` stays 500. `tests/run-pass/unit_cast_preserves_value.sio` pins the `molal` call, `as kg`, `as mg`, and `7 as kg`.
