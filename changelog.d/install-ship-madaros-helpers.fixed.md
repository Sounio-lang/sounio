The release tarball (`scripts/release.sh`, i.e. `scripts/install.sh --prefix`) now runs. `bin/souc` and `bin/madaros` source `scripts/lib/resolve_madaros.sh`, which the installer did not ship, so an extracted release died at its first command; `souc --version` also had no `CHANGELOG.md`/`CITATION.cff` to name its version from. The installer now ships both helpers and both files, the install gate checks that the installed `souc --version` names the tree's version, and the Release Gate runs it.
