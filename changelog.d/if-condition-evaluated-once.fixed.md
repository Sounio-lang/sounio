Madaros: the condition of an `if` used as a value (`let p = if f() == 0 { a } else { b }`, an `if` passed as an argument or assigned) is evaluated once. The variance walk that follows the taken arm lowered the condition a second time, so every call in it ran twice and the value came from the second call — in every program, with or without uncertainty. A random-number draw inside such a condition skipped every other number (`tests/run-pass/if_expr_condition_evaluated_once.sio`).
