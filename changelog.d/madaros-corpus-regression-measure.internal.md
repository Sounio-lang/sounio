Pull request CI now also runs every `tests/run-pass` program under the Madaros compiler built from the pull request's own source and compares the failures with `tests/madaros_corpus_baseline.txt` (job `madaros-corpus-regression`). Until now the full suite ran only on the lean_single stage2 binary, and the Madaros lanes ran only tests that a pull request itself changed. The new job is a measurement: it is non-blocking and outside the CI Decision list, and it will become required once the baseline is reconciled with what it reports.
