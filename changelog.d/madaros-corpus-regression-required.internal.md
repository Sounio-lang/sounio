The Madaros corpus regression job (`madaros-corpus-regression`) is now required by CI Decision. It runs every `tests/run-pass` program under the Madaros built from the pull request's own source, and a program that passes on main but fails under the pull request now turns the pull request red. Failures already listed in `tests/madaros_corpus_baseline.txt` (123 after #3681) stay allowed.
