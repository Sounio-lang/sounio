Bootstrap root A, first stage: `bootstrap/roots/a/seed-a`, a 271-byte Linux x86-64 loader written by hand byte by byte, with its annotated listing `seed-a.hex`. It decodes format A (lowercase hexadecimal pairs, `#` comments) and refuses anything else. The new CI gate `scripts/ci/root_a_seed_gate.sh` checks that the binary reproduces itself from its listing, runs fixed and all-256-byte vectors, and fuzzes it against a C++23 reference model.
