A loop no longer lets a Knowledge value reassigned in its body be read as its pre-loop value. Before the body of `while`, `loop` or `for` is checked, every Knowledge binding the body reassigns is widened to Unknown. Before this, `cur - acc`, with `acc = cur` at the end of the body, was accepted as an exact operation on the same source and printed variance 2.0 where the true value is 0. A struct field read through a shadowing binding now uses that binding's own source set, not the set of an outer binding with the same name.
