In the no-Madaros fallback, `bin/souc` exec'd the legacy lean_single ELF with the verb arguments untranslated: `souc run file.sio` compiled a source literally named `run` and wrote the output ELF over `file.sio` when a file named `run` existed in the working directory (exit 0, the user's source replaced by a binary), and `souc check` / `souc compile` misrouted the same way. The fallback now goes through the same verb translation as the forced `SOUNIO_SOUC_ENGINE=lean_single` branch; behavior on the default Madaros path and the forced-legacy branch is unchanged.
