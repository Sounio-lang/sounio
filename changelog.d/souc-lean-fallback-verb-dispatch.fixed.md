In the no-Madaros fallback, `bin/souc` exec'd the legacy lean_single ELF with the verb arguments untranslated: `souc run file.sio` compiled a source literally named `run` and wrote the output ELF over `file.sio` when a file named `run` existed in the working directory (exit 0, the user's source replaced by a binary), and `souc check` / `souc compile` / `souc build` misrouted the same way. The fallback and the forced `SOUNIO_SOUC_ENGINE=lean_single` branch now share one verb translation, including the `build` alias of `compile`; behavior on the default Madaros path is unchanged.
