Bootstrap root B, first stage: `bootstrap/roots/b/seed-b`, a 283-byte Linux x86-64 loader written by hand byte by byte, separately from root A's `seed-a`, with its annotated listing `seed-b.oct`. It decodes format B (three-digit octal groups, separators only between groups, `;` comments) and refuses anything else. The new CI gate `scripts/ci/root_b_seed_gate.sh` checks its self-reproduction, the cross-check between the roots (`seed-a` assembles `seed-b.hex` into `seed-b`, `seed-b` assembles `seed-a.oct` into `seed-a`), fixed and all-256-byte vectors, and a differential fuzz against a C++23 reference model.
