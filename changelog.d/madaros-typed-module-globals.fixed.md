Madaros checks module-level globals against their declared type inside functions: a typed global in a binding, argument or assignment of the wrong type is now E001/E009, and writing a module `let` with a unique name is E003. A struct or enum whose name is also a unit symbol (`K`) now resolves to the user type, and `souc check` keeps one global table for the whole module closure, so a `var` beside an imported `let` of the same name is no longer refused with a false E003.
