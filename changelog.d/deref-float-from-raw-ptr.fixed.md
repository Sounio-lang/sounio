Direct dereference of a raw `*mut f64` (via cast, via `*mut f64` param, or via a declared struct field such as `b[0].ptr` through `&!` array params) now resolves float-ness in `deref_operand_pointee_kind_ref`, so the value lowers through float registers and `as i64` casts instead of reading float bits as an integer; non-float raw derefs keep today's behavior, and the SIO-557 byte-width path is untouched. Adds run-pass coverage for all four shapes.
