Madaros: `Knowledge<f64>` (+ - * /) an exact constant now compiles with first-order GUM (the constant has variance 0 and confidence 1). Before, every mixed form was refused with E004, while lean_single accepted it. Only a float literal, its negation, or a module-level `let`/`const` counts as exact. Any other `f64` is refused with the new E313, because its type says nothing about its uncertainty. `x * SCALE` with a module-level constant used to pass the checker, since such a constant is typed unknown inside a function, and then crash at run time. It is now lowered correctly when the constant is a float and refused otherwise.
