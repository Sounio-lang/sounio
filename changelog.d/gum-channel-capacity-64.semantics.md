Madaros's first-order GUM lowering now tracks up to 64 uncertainty channels per function, up from 32, so programs that hold many `Knowledge<f64>` values (for example a record of 18 measured parameters) and also inline a numeric kernel compile instead of being refused. The E303 refusal still fires, fail-closed, when a compilation that uses uncertainty needs more than 64 channels; the correlation limit (E304, channels 0 through 7) and the checker's separate 256-source limit (E178) are unchanged. Programs that already compiled generate byte-identical code. Follows #3565 and #3545.
