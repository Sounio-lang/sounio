Madaros: a bare call is resolved through the calling module's own `use` items. A pub fn of a module the caller never imported — reachable before only because some other module had loaded it — is refused with `error[E-NOT-IMPORTED]`, naming the module that defines it. Named imports, globs and `pub use` re-exports (followed up to four levels) are honoured, and a local binder of the same spelling is a local. Measured before: `use math::pure::{exp}` then `log_sum_exp(0.0, 0.0)` compiled and ran. The tree's own violations (`llm::serve`, `gpu::opt::fusion`, `gpu::opt::autotune`, `gpu::metal` and four tests) now import what they call (`scripts/ci/madaros_import_hygiene_gate.sh`).
A whole-module import (`use m`, no braces) brings in the module's pub fns, as a glob does: 88 files in the tree are written that way.
