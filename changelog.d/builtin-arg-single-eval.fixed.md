Fixes the SIO-146 double evaluation of compound math-builtin arguments: `log(0.5 + unif(st))` consumed the RNG twice because the FO transfer re-lowered the argument value for the derivative with full emission (the second value feeds only the derivative and is discarded, but its side effects execute). The value-relowering sites for transfer kinds 2, 4, 6, 7, 8 and 9 now bail (variance unknown) unless the arguments are relower-safe, mirroring the closure-inline guard; pure arguments take the identical code as before.
