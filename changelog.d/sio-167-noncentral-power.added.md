The standard library now provides checked genuine noncentral-t CDF/SF/log-tails and quantiles, directional one-sided/two-sided t-test power and an evaluated minimum-integer sample-size search. A mode-centered bidirectional Poisson/Beta mixture handles the positive orientation; opposite-direction tails use an independently qualified positive conditional integral with explicit work, quadrature and truncation estimates. A shared checked Gamma log-prefix supports accurate mode weights.
