Programs that return or carry aggregates (tuples, structs, fixed arrays) inside a long loop no longer exhaust the handle table (exit 182) or the arena (exit 181). Loops now run in a region that is reset at the end of every iteration, and carried values are copied out. Region exits also stopped scanning integer words for encoded references: a counter whose value fell in the handle-id range used to keep its region alive forever. A 6 M-iteration `Epistemic` accumulation that died at 4.19 M now completes. A struct of `{f64, i64, f64}` carried for 4 M iterations peaks at 68 kB of resident memory instead of 402 MB.
