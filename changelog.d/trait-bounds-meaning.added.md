A trait bound on a type parameter, `fn f<T: Lj>(x: T)`, now has meaning. A method call on a value of type `T` resolves through the traits `T` is bounded by (with `Self` replaced by `T`), so a generic body that calls `x.lj()` type-checks whether or not anything instantiates it; it used to fail E011. A method that none of the bounds declares is refused with the new E316. A call that instantiates a bounded parameter with a type that has no impl of the bound (`f::<SrNa>` without `impl Lj for SrNa`) is refused with the new E315, which names the type, the trait and the parameter, instead of surfacing as E011 inside the instantiated body.
