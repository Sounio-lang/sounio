The stdlib E2E runner now builds `libstdlib_platform.so` from `runtime/stdlib_platform.cpp` before running, so the platform-backed sync, massive, profile and time tests measure the stdlib instead of failing on `dlopen` (platform status 2). `fmri::nifti` reads file bytes through a `string` parameter rather than declaring it `[i8; 0]`, which the type checker now rejects. The three heavy `darwin_pbpk::bbb` UQ tests (HDMR 7D, PCE Sobol, VOI) declare a 120 s timeout; they run 26–36 s, too close to the 30 s default.
