On arm64, `lean_single` keeps a tuple-typed variable's value when it is reassigned from a call: it used to store a pointer to its single aggregate-return buffer, so the next tuple returned by any call overwrote the variable. The macOS Madaros is compiled by `lean_single`, and this let `var G = 9223372036854775807 + 1` through without E300 there. A new macOS CI step compiles and runs `tests/run-pass/tuple_var_reassign_keeps_values.sio` with the arm64 `lean_single`.
