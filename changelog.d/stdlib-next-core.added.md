The standard library gains budgeted dynamic heaps and sets, owned nested JSON with exact numeric tokens and checked integer conversion, multi-record IUPAC FASTA and dynamic GFF3 annotation readers, checked native file I/O and an owned adapter for the existing CSV reader. Native concurrency now includes bounded MPMC channels, explicit close/drain/token invalidation, effectful workers, a cooperative polling executor, monotonic wake deadlines and nonblocking socket readiness/connect completion. The scientific workflow example composes the existing QR, SVD, quantile and rendering APIs into independently verified JSON, SVG and PNG artifacts.
