`print`/`println` of an integer or bool element of a destructured tuple now compiles on Madaros. `let (status, v, u) = f(..)` left `status` with no scalar kind, so `print(status)` was refused ("cannot safely lower print/println argument with unresolved scalar kind"); this blocked `chemistry/test_pbpk_clearance_ode`. Integer and bool tuple slots are now tracked per local (`tuple_int_mask`, from an annotation, a call's or method's declared tuple return type, an alias, or a tuple literal), alongside the existing f64 and f64-array slot masks.
