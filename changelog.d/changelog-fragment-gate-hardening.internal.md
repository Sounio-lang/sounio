The changelog fragment gate (ADR-018 §4) now enforces rules it previously only documented: a compiler/runtime/stdlib pull request that edits `CHANGELOG.md` is refused (the release manager assembles it from fragments), a fragment added by rename or copy counts toward the census, a fragment that is empty or whitespace-only at the head commit fails, and a malformed `PR_CREATED_AT` no longer earns the pre-cutoff exemption by accident of string comparison. The gate's selftest grows from 11 to 22 cases, including a synthetic git history for the non-emptiness arm.
