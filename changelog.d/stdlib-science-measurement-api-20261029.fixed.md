`science::lib` exported nothing: `Measurement`, its fields, and the GUM API (`measurement_new`, `measurement_add`/`sub`/`mul`/`div`, `measurement_relative_error`, `propagate_sum`, `propagate_product`, `significant_figures`, `round_to_uncertainty`, `weighted_mean`) were all private, so every importer was refused with E175/E259. They are now `pub`; the `sci_*` numeric helpers stay private.
