Stdlib modules that Madaros refused at `souc check` now type-check: `epistemic::stats` print helpers declare `IO`; `epistemic::knowledge` exports `epistemic_new` (the long name of `ep_new`) that the DP tests import; `fmri::nifti` and `fmri::pipeline_real` declare `Mut` and use `str_len` instead of string methods; `mem::arena` aligns with integer arithmetic and uses `0 as *mut u8` instead of the undefined `null_mut()`; `particle_physics::bsm_physics` and `event_pipeline` drop imports of names `cross_section` never defined; `collections::heap_vec` declares `Mut` on its free-function push/free and the generic `HeapVec<T>` bodies are well typed. `os::env` no longer calls `getenv(3)`, which the native backend cannot link (E250): it reads `/proc/self/environ` through `syscall6`, and `env_get` now copies the value into `out`.
