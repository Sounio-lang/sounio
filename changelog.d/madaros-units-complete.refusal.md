Madaros now refuses a unit mismatch in a return value (explicit `return` and the implicit tail of a body) with `error[E041]: unit mismatch in return value`, including a bare number returned from a unit-typed function. A unit-typed value returned as plain `f64` is still accepted. `f64<UnitExpr>` annotations and numeric literal suffixes that name an unregistered unit are refused with the new `E302`. The literal suffix `10.0<m>` now parses and brands the literal with its unit (float literals only). The energy units `J`, `eV`, `keV`, `MeV` and `GeV` resolve on first use, so `J + eV` is refused as a unit mismatch and `joules as eV` compiles. E041 on arithmetic now says whether the dimensions differ or only the scale.
