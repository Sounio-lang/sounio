`llm_serve` completions and SSE token frames embedded raw control bytes in the JSON `"text"` when the completion contained a newline or tab: the escape helper appended a Sounio `"\n"` / `"\t"` literal, which the lexer decodes to the raw control byte (LEX-012), so strict JSON parsers rejected the response (`Invalid control character`). The helper now emits the two-byte JSON escapes for newline and tab byte-wise, as it already did for carriage return; quote, backslash and `\u00XX` handling are unchanged, and the SSE frame-terminating newlines are untouched. Fixes #3484.
