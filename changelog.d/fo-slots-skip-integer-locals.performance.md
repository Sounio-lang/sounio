Madaros no longer gives integer and bool `var` locals first-order uncertainty slots. One uncertainty channel anywhere in a function (an `if` that assigns an integer counter is enough) made every integer `var` carry sensitivity slots and, since #2827, a residual slot rewritten at every loop head and assignment. `obo_elplus_driver.sio`, which has no `f64` at all, compiled to 385 KB instead of 156 KB and ran in 623 s instead of 166 s; the 168 `tests/run-pass` programs that use `measure` or `Knowledge` print the same output as before.
