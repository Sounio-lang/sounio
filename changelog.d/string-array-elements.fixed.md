Elements of a `[string; N]` local work on Madaros: `names[1] = "zeta"` stores the string, and `println(names[i])` prints it. The array local was classified as a string itself, so an element store took the raw-byte path and wrote one byte into the GC handle word (SIGSEGV), and a read was printed as the pointer value. A wrapper struct (`FrameStr` in `stdlib/data/frame.sio`) is no longer needed for this.
