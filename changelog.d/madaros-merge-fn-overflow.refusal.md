A program whose separately lowered modules need more than `IR_MAX_FUNCS` function-table slots when merged is now refused with `ir_merge_fn_overflow` and the slot count. The merge used to stop at the limit and drop the remaining functions silently. This happens in the `SOUNIO_MADAROS_DEP_MERGE=place` lane and the `--probe-machine-ir` route. In the same lanes, region reclamation is vetoed for the whole program when a merged module may hold casts lowered without the region hook. The place lane also fills preseeded stubs in place instead of spending a second slot on every imported function, so it now holds as many functions as the default lane.
