A training step can take each numeric batch from native Arrow IPC. `arrow::feed` packs every record batch into one contiguous little-endian float32 matrix, with an optional int64 `label` column in the same slab, so the device copy is a single transfer of `nbytes` bytes. The native codec still limits that transfer to 16 rows and 8 float32 columns (512 feature bytes). Nulls, float64 features, and nested values are refused.
