Torch steps can take numeric batches from an Arrow IPC file. `tools/arrow_feed` memory-maps a float32 feature matrix and slices each step as one contiguous `[batch, features]` tensor. With CUDA, the DataLoader pins that view and a side stream copies the next batch to the device while the current batch is in use. The native Sounio IPC codec is not this path: a batch past 16 rows or a 4096-byte body is refused there, which is too small to fill a GPU transfer.
