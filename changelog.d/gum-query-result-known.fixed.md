Madaros: a number read from the uncertainty budget (`variance_of`, `covariance_of`, `uncertainty_of`, `sensitivity_of`, `hessian_of`, `second_order_mean`, and the new `en_of`, `birge_of`, `neff_of`) is a known number, with no uncertainty of its own, as in GUM. A weight built from them, such as the inverse-variance weight `variance_of(b) / (variance_of(a) + variance_of(b))`, used to make every later query of a value that used it refuse to compile (KL-11, "depends on the call to `variance_of`"); it now gives the exact result (`tests/run-pass/gum_query_result_is_known.sio`).
