The type arguments written on a generic struct literal, `Pair::<Na, Cl> { d: 3.0 }`, are no longer thrown away by the parser. They give the type of every parameter that no field determines (a phantom or marker parameter). Before, such a literal was named after a placeholder, `Pair__T__T`, and a correct program was rejected with E001 or E008 against `Pair<Na, Cl>`; and a turbofish that contradicted the fields, `Box2::<i64> { v: 2.5 }`, compiled with the written type silently ignored.
