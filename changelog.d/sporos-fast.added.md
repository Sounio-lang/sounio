`bootstrap/model/sporos_fast.cpp` is a C++23 Sporos interpreter: the same bytecode, checker, semantics, exit statuses and error names as the Lean reference `sporos`, roughly 30 000 times faster. `upper` on 10 MB of input takes 2.0 s. Under `noPhys` a program can observe a provenance only through its length, so a value is kept as its word plus the length of its provenance modulo 2^64. `bootstrap/model/sporos_diff.sh N` checks the interpreter against the reference. It runs the example programs on random inputs, and N random checker-valid programs from `sporos_gen.cpp`, then compares exit status, output and error byte for byte. On 2026-11-16: 5016 runs, 0 disagreements.
