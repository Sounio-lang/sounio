Σπόρος (Sporos), the language of stage 1 of bootstrap root A, has a reference semantics in Lean (`formal/Sporos/`). It is a stack machine over wrapping 64-bit words: words with declared stack effects and locals, free jumps inside a word with a declared height at every jump target, with 70 operations (57 primitives on the data stack plus 13 instructions for literals, the auxiliary stack, locals, jumps and calls). Every value carries its provenance, the set of (input byte, instruction, core) origins that determined it; branch conditions join a context label that is never removed. The clock, the current core, the sensors and the confidence of a provenance are parameters of the semantics. `run_safe` proves that a program accepted by the stack-effect checker, on any input and at any step, never underflows a stack, reads a bad local, jumps outside its word or calls a missing word. `echo` is checked, and its run on "hi" is evaluated in Lean.
