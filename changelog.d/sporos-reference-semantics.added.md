Σπόρος (Sporos), the language of stage 1 of bootstrap root A, has a reference semantics in Lean (`formal/Sporos/`). It is a stack machine over wrapping 64-bit words: words with declared stack effects and locals, free jumps inside a word with a declared height at every jump target, with 70 operations (57 primitives on the data stack plus 13 instructions for literals, the auxiliary stack, locals, jumps and calls). Every value carries its provenance, the set of (input byte, instruction, core) origins that determined it; branch conditions join a context label that is never removed. The clock, the current core, the sensors and the confidence of a provenance are parameters of the semantics. `run_safe` proves that a program accepted by the stack-effect checker, on any input and at any step, never underflows a stack, reads a bad local, jumps outside its word or calls a missing word. `echo` is checked, and its run on "hi" is evaluated in Lean. `streq` and `strhash` carry the provenance of the bytes they read, and `copy` reads every byte from the memory before the copy (memmove on overlap); `Sporos/Witness.lean` checks both on concrete states. The provenance is also computed as a union DAG in an append-only arena (`Sporos/Dag*.lean`), the representation the interpreters will use; `drun_init` proves that the DAG machine and the list machine give the same result from the initial state, for every program, input and number of steps.
