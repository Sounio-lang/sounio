Madaros now registers declared effects (`effect X { .. }`). The checker's *mut collect spine had no `ItemEffect` arm, so every user effect was inert: each `with X` was refused with E246 ("not a declared user effect") and `use m::{X}` with E-USE-ITEM, while lean_single accepted the same source. `stdlib/coordination/loom_continuity.sio` (`pub effect LoomHostTrust {}`) could not be checked by Madaros. A declared user effect is now enforced like a builtin one: calling a `with X` function from one that does not declare `X` is E035.
