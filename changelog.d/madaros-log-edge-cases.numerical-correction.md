`log` (builtin id 17, also `ln`) on x86-64 returned silent wrong values outside normal positive finite inputs: `log(0)` gave -709.09 instead of -inf, `log(-1)` gave 0 instead of NaN, `log(+inf)` and subnormal arguments were wrong (a subnormal's error reached 3e14 ulp). It now returns -inf for +-0, NaN for negative and NaN inputs, +inf for +inf, and pre-scales subnormals by 2^54. Oracle: libquadmath `logq`, `scripts/dev/gen_math_trans_tests.cpp`, `tests/run-pass/math_trans_values.sio`. Results for normal inputs are bit-identical to before.
