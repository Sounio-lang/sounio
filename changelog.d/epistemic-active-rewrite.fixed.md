`epistemic::active` compiles again on both engines. It had been written against types that no longer exist (Rust lifetimes, `BetaConfidence`, a `provenance` field, `.is_empty()` on slices), so every program importing it failed to parse. It now reads the flat `Epistemic` (val, variance, confidence 0..1000). `update_belief` keeps the old Beta rule on that integer: the prior Beta has mean c/1000 and concentration 2 (the Beta(1, 1) every measured value used to start from), successes = trunc(10 · obs_precision / prior_precision) and failures = 1 are added as counts, and the new confidence is round(1000 · α/(α+β)); `update_belief_with_prior_strength` takes the concentration explicitly. Logarithms and square roots now use the full-range `math::pure::ln` and `ep_sqrt` instead of local series that lost accuracy away from 1. Action and observation lists are two parallel `&[f64]` slices instead of a slice of tuples, `most_uncertain` returns an index, and `update_sequential` panics on slices of different lengths. `propagate::monte_carlo` accepts a callback with `Mut, Div, Panic`, as its own body runs with them; pure callbacks still fit. Values agree with the C++23 oracle `tests/oracles/active_belief_update.cpp`.
