A bare `pow(x, y)` call no longer compiles into a binary that dies with SIGILL (SIO-205). Native-v2 had no builtin for the plain `pow` name, so the call reached the empty-stub `ud2` while the compiler still reported success; plain `pow` now resolves to the existing `ffi_pow` kernel (builtin 49, the same implementation the first-order variance path already used). `tests/run-pass/pow_float_result.sio` pins `pow(3, 2) = 9`, `pow(2, 10) = 1024` and `pow(9, 0.5) = 3`.
