Madaros now compiles a single function of up to 65536 IR instructions and 65536 virtual registers. The old limit was 16384 for both. `tests/stdlib/data/test_bigframe_ops_stdlib.sio` has one `main` that needs 37526 instructions, so it was refused at that limit. The native per-function tables sized from those limits were raised with them: labels and patches, return jumps, float typing, raw-tag and register-class tables, and the high-vreg float bitset. The bitset had held only 16384 bits, so above that point float marks would have been dropped without any error. A function past the new limit is still refused with the same `needs N IR instructions but IR_MAX_INSTRS is 65536` error, and no binary is written.
