`as` between compatible units now multiplies by the registered scale, so `1 m + (1 cm as m)` is 1.01 instead of 2, and `1 m as cm` is 100 instead of 1. An accepted unit cast had been branding only, leaving the magnitude unchanged; the conversion now uses the checker's unit table (`cm` is 0.01 `m`, `mm` is 0.001 `m`, `km` is 1000 `m`, `mg` is 0.000001 `kg`).
