Knightian and aleatory source identity now crosses function calls and struct fields. A call returns its summary's sources: the argument sources it forwards, the named sources it declares, and the fresh residues it creates, kept apart per call site. A struct field carries its own set into projection. Recursion is summarised as `Unknown`, which a precise requirement refuses. `id(k) - id(k)` now cancels to `[0, 0]`, and two calls that create fresh residues no longer cancel. Before, identity was dropped at the call boundary, so a value carrying a Knightian source could be accepted at a precise requirement.
