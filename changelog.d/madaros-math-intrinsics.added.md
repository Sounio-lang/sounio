Madaros (x86-64) now compiles `tan`, `atan`, `tanh`, `asin` and `acos` instead of refusing them with E221, and binds `atan2` and `ln` (an alias of `log`). The kernels are in `native::math_trans`, with constants generated by `scripts/dev/gen_math_trans_consts.sh`. Measured against a `__float128` reference over 40000-point grids: atan 0.83 ulp, atan2 1.15, asin 2.02, acos 1.63, tan 2.38, tanh 2.16, ln 2.75; special values (signed zeros, infinities, NaN, domain errors) are exact. `tan` returns NaN for `|x| >= 2^50` (KL-22). First-order variance and Hessian propagate through all seven, including the new binary `atan2` rule (transfer kind 13), so a `Knowledge` argument keeps its uncertainty. The compile-fail test `native_math_without_backend_builtin.sio`, which asserted the old E221, is replaced by `run-pass/native_math_atan_family_emitted.sio`.
