Native-v2: dereferencing a `*mut i8`/`*mut u8` now performs a byte load with the pointee's signedness (movsx/movzx) instead of the default 8-byte word load, which returned whole words (e.g. 26470 for a byte holding 102). Storing through a byte pointer is a single-byte store for the same reason (a word store zeroed the seven neighbour bytes). The width travels on the instruction from the lowerer — through casts, recorded pointees, declared struct fields (including `let` aliases of field pointers), and the MIR pipeline — while borrows still move whole pointers; other pointees are unchanged.
