`fractal::mandelbrot::compute_orbit` no longer exhausts the Madaros runtime arena when the Hessian is enabled. The curvature source was accumulated with a by-value `tensor16_get`/`tensor16_set` pair per element, copying the 32 KiB `Tensor16` about 2e5 times per orbit (~7 GiB) into an arena that is never reclaimed, so `neuro/test_neuro` died with `arena full (allocation of 32800 bytes)` in `connectome_to_features`. The source term is now filled in a local `[f64; 4096]` buffer and added once per step (`tensor16_from_data` + `tensor16_add`); each element receives exactly one term, so the result is bit-identical.
