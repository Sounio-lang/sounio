Madaros now refuses implicit IO builtins called without `with IO`, with E035 (SIO-27, #2760). `println`, `print`, `print_f64`, `read_file`, `write_file`, `write_bytes`, `append_file` and `file_size` were bound import-unknown with no attributed effects, so a function could perform IO while declaring none; they now carry the IO effect whenever the name does not resolve to a user-declared function (the same rule lean_single applies), in both checker spines. (`read_i64`/`write_f64` and friends are raw pointer accessors, not file IO, and stay effect-free, as in lean_single.) The Mut half needed no change: mutation through `&!T` already drew E035, and mutating a function-local `var` is the spec §7.2.1 escape rule. New compile-fail fixtures pin all three shapes; the w17 witness (IO leak through an unannotated HOF) is promoted to closed.
