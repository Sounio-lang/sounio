A pull request whose earlier head already passed CI Decision no longer reruns the heavy jobs after merging main when the merge brought in only website, docs or new changelog fragments. `scripts/ci/ci_reuse_green_ancestor.sh` looks for that earlier head, and the impact classifier then classifies by the delta from it. Any change to a workflow, a script, stdlib, tests or the compiler in that delta, or a deleted fragment, disqualifies it. If the GitHub API cannot answer, the full classification runs. The `impact_ci_selftest.sh` script has seven new controls.
