An imported `i64` global whose value equals the BSS string-init sentinel (`-800001`) is an integer again under `Madaros`. Since `#3603`, `bss_global_scalar_kind` treated the sentinel alone as a string marker, so a comparison against such a global lowered to `str_eq` on two integers and the program faulted; the compiler's own `BSS_INIT_STRING_MAGIC` is such a global, so the self-built `gen2` crashed compiling `self-hosted/compiler/main.sio` and the fixed-point rung stopped at `run`. A slot now counts as a string literal only when it also carries a non-empty literal payload, as the x86 codegen already required (`imported_string_magic_i64_const.sio`).
