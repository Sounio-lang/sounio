`darwin_pbpk::core::pbpk28_params::pbpk28_params_rapamycin_fullvd` and `darwin_pbpk::epistemic_pbpk28::ep28_rapamycin_fullvd_priors`: a PBPK28 rapamycin set with the clinical distribution volume. The existing set is capped (V_ss 48.67 L, IV half-life 2.9 h; row 12 of `docs/audit/PBPK28_LIBRARY_AUDIT_2026-11-08.md`). The new set multiplies every tissue Kp except the brain's by one factor (20.815064) so that V_ss is 840 L (12 L/kg, Zimmerman & Kahan 1997); the measured terminal half-life of a 5 mg IV bolus is 51.0 h, inside the clinical 62 ± 16 h. The capped set is unchanged and stays the parity reference. Test: `tests/run-pass/pbpk28_rapamycin_fullvd.sio` (Madaros and `lean_single`).
