Madaros emits `GUM_UNTRACKED_CONTAINER` at unsupported measured-container operations instead of silently dropping uncertainty (issue #3546). This includes dynamic indexing of measured arrays, conditional or loop stores, measured array initializers and copies, array escapes, and measured struct-field stores. Use measured scalars or straight-line local `f64` arrays with literal indices; these refusals also apply before an eventual `variance_of` or `uncertainty_of` query.
