Sporos: a proved collector for the provenance arena (`formal/Sporos/DagGC.lean`). `gc` keeps node 0 and every node reachable from what the state names, in order, renumbered. `gc_spec` proves that from a valid state the compacted state is valid and stands for the same list state; `MemZero` (memory beyond its size carries no provenance) is the invariant this needs, and every step keeps it. `drunC_init` proves that a run collecting at any points, with any allocator, computes exactly what the list machine computes; `gc_drops_dead` checks a dead union and its leaf are dropped.
