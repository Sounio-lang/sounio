When `scripts/ci/ci_reuse_green_ancestor.sh` turns down an earlier head of the pull request, it now says why on stderr, one `ci-reuse: skip <sha>: <reason>` line per candidate, and the Impact log keeps that text. The reasons it can give are: a raw delta that is not reusable, no successful `pull_request` run listing this PR, a failed API call (with the error text), a run that itself reused a verdict, missing impact rows or checkout line, lanes not covered, or a tested tree that differs from the tree tested now. The first live miss was #3750 at `3aefd8f93a`: its only change since a green head was in `docs/`, yet it got `reused_from=` empty, and nothing in the log said which condition failed. `impact_ci_selftest.sh` control 13 checks that a refused candidate prints its reason.
