Implicit-borrow call behaviour is now pinned by regression tests (SIO-352). Passing an identifier where a `&Point` parameter is expected borrows it and prints 7, as ADR-020 (D-26) rules; passing a temporary or a field access in the same position is refused with E009 instead of compiling. The segfault this card reported was already fixed in the source (and the shipped prebuilt has since been refreshed), but no test covered any of the three shapes, so the fix could regress silently.
