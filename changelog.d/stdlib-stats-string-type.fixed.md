Five stdlib statistics modules now type-check: `stats/causal/propensity.sio`, `stats/clinical/meta_analysis.sio`, `stats/clinical/power_analysis.sio`, `stats/multivariate/cluster.sio` and `stats/timeseries/kalman.sio` declared fields as `String`, which is not a type in Sounio — the builtin is `string`. Every one of them failed to compile with "field initializer has wrong type: expected String, found string". No numerical or behavioural change is possible: these modules had no importer, so no program could have depended on the broken declarations.
