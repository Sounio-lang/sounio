The `Stdlib Reliability` workflow measures the full stdlib E2E on every run, even when an earlier sub-gate fails, and uploads it as `stdlib_e2e_measured.v1.json`. Before this, a red hyper lane stopped the gate and the uploaded E2E file was the stale committed one. Each run also uploads `stdlib_e2e_receipt.v1.json` with the runner exit code, the SHA and `measurement: valid` or `unavailable`; totals count as measured only when a fresh file with the expected schema exists.
