The fixed-array Wilcoxon entry points and run_tests now declare Alloc because they own bounded dynamic scratch. Existing sample arguments and original result fields remain, but default p-values change to conditional exact inference and the result layout expands with method, log-probability and availability fields. Callers must declare Alloc and rebuild; both repository example callers are updated. Allocation-free checked callers supply their own buffers. The former Gaussian method is available only through explicitly named normal_approx entry points.
