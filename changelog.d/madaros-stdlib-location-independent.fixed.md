A Madaros binary no longer depends on where the stdlib is installed. The overflow trap wrote the absolute path of a stdlib file into the ELF, so the same program compiled against the same stdlib in two directories gave two different binaries. A stdlib file is now embedded as `stdlib/<rest>`; diagnostics still print the full path. New gate `scripts/ci/madaros_stdlib_location_independent_gate.sh`, wired into core-c.
