Madaros no longer segfaults programs in which a speculative helper inline is discarded. Since e47278b51 a failed FO-inline handed its virtual registers back, but the float marks it had recorded for them stayed, so the next integer value given the same register number was treated as a float (`demos/hydrogen/valley_chain_epistemic.sio` crashed with SIGSEGV; `obo_elplus_driver.sio` lost its `ALL PASS`). The discarded instructions are still dropped; the registers are not reused.
