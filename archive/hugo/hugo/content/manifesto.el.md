Για δεκαετίες, οι γλώσσες προγραμματισμού αντιμετώπιζαν τους αριθμούς ως τέλειους: το `3.14159` είναι ακριβώς αυτό, ούτε περισσότερο ούτε λιγότερο. Αλλά η επιστήμη δεν λειτουργεί έτσι. Κάθε μέτρηση έχει σφάλμα. Κάθε μοντέλο έχει αβεβαιότητα. Κάθε πρόβλεψη έχει όρια εμπιστοσύνης.

Το **Σούνιο** βασίζεται σε μια ριζικά καινοτόμα προϋπόθεση: **η αβεβαιότητα δεν είναι σφάλμα—είναι χαρακτηριστικό**.

## Οι Πέντε Αρχές της Epistemic Computing

### 1. Όλη η Γνώση είναι Αβέβαιη

Στον φυσικό κόσμο, δεν υπάρχει τέτοιο πράγμα όπως μια τέλεια μέτρηση. Η αρχή της αβεβαιότητας του Heisenberg δεν είναι περιορισμός των οργάνων μας—είναι θεμελιώδης ιδιότητα της πραγματικότητας. Ακόμη και οι μακροσκοπικές μετρήσεις φέρουν θόρυβο, σφάλμα βαθμονόμησης και πεπερασμένη ακρίβεια.

```sio
// Λάθος: προσποιούμενοι ότι γνωρίζουμε ακριβώς
let concentration = 5.23  // mg/L... αλλά πραγματικά;

// Σωστό: αναγνωρίζοντας την αβεβαιότητα
let concentration = Knowledge::new(5.23 mg/L, uncertainty: 0.15 mg/L)
```

Το Σούνιο το καθιστά ρητό. Όταν δηλώνετε μια τιμή, πρέπει να σκεφτείτε: *πόσο καλά γνωρίζω πραγματικά αυτήν;*

### 2. Η Provenance είναι Αδιαπραγμάτευτη

Δεδομένα χωρίς προέλευση είναι δεδομένα χωρίς εμπιστοσύνη. Όταν μια ρυθμιστική αρχή ρωτά «από πού προέρχεται αυτός ο αριθμός;», θα πρέπει να έχετε μια απάντηση που ιχνηλατεί πίσω στις πρωτογενείς πηγές.

```sio
let clearance = Knowledge::new(
    value: 10.5 L/h,
    uncertainty: 1.2 L/h,
    source: Source {
        origin: "Phase III Trial NCT04123456",
        timestamp: 2025-03-15,
        method: "Population PK analysis",
        confidence: 0.95
    }
)
```

Κάθε `Knowledge<T>` φέρει την provenance του. Η καταγωγή των δεδομένων σας είναι εξίσου σημαντική με τα ίδια τα δεδομένα.

### 3. Η Αβεβαιότητα Διαδίδεται Αυτόματα

Η χειροκίνητη διάδοση αβεβαιότητας είναι κουραστική και επιρρεπής σε σφάλματα. Το GUM (Guide to the Expression of Uncertainty in Measurement) ορίζει πώς συνδυάζονται οι αβεβαιότητες μέσω μαθηματικών πράξεων. Το Σούνιο το υλοποιεί αυτόματα.

```sio
let mass = Knowledge::new(100.0 g, uncertainty: 0.5 g)
let volume = Knowledge::new(50.0 mL, uncertainty: 0.2 mL)

// Υπολογισμός πυκνότητας με αυτόματη διάδοση
let density = mass / volume
// density.uncertainty υπολογίζεται μέσω GUM:
// δρ/ρ = sqrt((δm/m)² + (δV/V)²)
```

Εσείς γράφετε τη φυσική. Ο μεταγλωττιστής χειρίζεται τη στατιστική.

### 4. Οι Πύλες Εμπιστοσύνης Ελέγχουν την Εκτέλεση

Όχι όλες οι πράξεις υπολογισμού πρέπει να προχωρούν τυφλά. Όταν η εμπιστοσύνη πέσει κάτω από ένα όριο, η εκτέλεση πρέπει να παγώσει, να προειδοποιήσει ή να πάρει εναλλακτικές διαδρομές.

```sio
fn critical_decision(data: Knowledge<f64>) -> Action {
    if data.confidence < 0.90 {
        return Action::RequestMoreData
    }

    if data.confidence < 0.95 {
        return Action::ProceedWithCaution(data)
    }

    Action::Proceed(data)
}
```

Αυτό δεν είναι αμυντικός προγραμματισμός—είναι *epistemic programming*. Το σύστημα γνωρίζει τι δεν γνωρίζει.

### 5. Συμμόρφωση με Πρότυπα κατά Σχεδιασμό

Η επιστήμη έχει πρότυπα για έναν λόγο. Το Σούνιο είναι φτιαγμένο για να συμμορφώνεται με:

- **GUM** — ISO Guide to the Expression of Uncertainty in Measurement
- **ISO 17025** — Competence of testing and calibration laboratories
- **21 CFR Part 11** — Electronic records and signatures (FDA)
- **FAIR Principles** — Findable, Accessible, Interoperable, Reusable data

Αυτά δεν είναι μεταγενέστερες σκέψεις—είναι αρχιτεκτονικές βάσεις.

## Το Πρόβλημα που Λύνουμε

### Η Κρίση της Αναπαραγωγικότητας

Μεταξύ 2011 και 2021, εκτιμάται ότι σπαταλήθηκαν 28 δισεκατομμύρια δολάρια σε μη αναπαραγωγική προκλινική έρευνα μόνο στις Ηνωμένες Πολιτείες. Οι αιτίες είναι πολλές, αλλά μία ξεχωρίζει: **η απώλεια πληροφοριών αβεβαιότητας**.

Όταν μια μέτρηση `5.23 mg/L` μεταβιβάζεται μεταξύ συστημάτων, αποθηκεύεται σε βάσεις δεδομένων και χρησιμοποιείται σε υπολογισμούς—το `±0.15` συχνά εξαφανίζεται. Οι μεταγενέστερες αναλύσεις το αντιμετωπίζουν ως ακριβές. Συμπεράσματα εξάγονται που η αρχική αβεβαιότητα θα είχε αποκλείσει.

### Η Λύση

Το Σούνιο καθιστά την αβεβαιότητα *μολυσματική*. Δεν μπορείτε να την αποβάλετε κατά λάθος. Το σύστημα τύπων δεν σας επιτρέπει να μετατρέψετε `Knowledge<T>` σε απλό `T` χωρίς ρητή αναγνώριση.

```sio
let safe_value = measurement.value  // Σφάλμα μεταγλωττιστή!

let safe_value = measurement.unwrap_certain()  // Απαιτεί confidence > 0.99

let safe_value = measurement.acknowledge_uncertainty()  // Ρητή εξαίρεση, καταγραφή
```

## Ο Δρόμος Μπροστά

Το Σούνιο δεν είναι ολοκληρωμένο. Ίσως ποτέ να μην είναι. Αλλά οι αρχές είναι καθορισμένες:

1. **Η αβεβαιότητα είναι πρώτης τάξης** — Όχι βιβλιοθήκη, όχι σχόλιο, αλλά θεμελιώδης τύπος.

2. **Η διάδοση είναι σωστή** — Συμμορφωμένη με GUM, δοκιμασμένη, επαληθευμένη.

3. **Η provenance διατηρείται** — Από την πηγή στο αποτέλεσμα, η αλυσίδα είναι άθικτη.

4. **Η εμπιστοσύνη είναι δράσιμη** — Το σύστημα ανταποκρίνεται σε ό,τι γνωρίζει και δεν γνωρίζει.

5. **Τα πρότυπα είναι ενσωματωμένα** — Η συμμόρφωση δεν είναι προαιρετική.

Αν πιστεύετε ότι η επιστήμη αξίζει καλύτερα εργαλεία—ότι η αβεβαιότητα πρέπει να υπολογίζεται, όχι να αγνοείται—ότι η αναπαραγωγικότητα είναι χαρακτηριστικό, όχι ατύχημα—τότε το Σούνιο είναι για εσάς.
