# UX Improvement Plan - Q1 Quality

## Current State Assessment

The architecture pages exist but lack basic UX navigation elements:

- No sidebar navigation between architecture pages
- No table of contents for long content
- No next/prev navigation
- No breadcrumb navigation
- No call-to-action links
- Poor visual hierarchy
- No section navigation within pages

## Critical Issues

### 1. Single Content Pages (single.html)

**Problem**: Template is too basic - just title + content + lastmod
**Missing**:

- Table of contents for navigation
- Section navigation links
- Next/Prev buttons
- Related pages
- Quick links back to homepage

### 2. Architecture Pages  

**Problem**: Users land on detailed pages with no way to navigate back to overview

### 3. No Cross-Linking

**Problem**: Pages don't link to each other
**Missing**: Related architecture pages, related content

## Solution: Enhanced Template

### Phase 1: Better Single Page Template

Create sidebar with:

- Table of contents (auto-generated from headings)
- Next/Prev navigation buttons
- Breadcrumb navigation
- Related pages section

### Phase 2: Enhanced Architecture Pages  

Add internal navigation:

- Quick jump links to other architecture pages
- Section overview cards
- "Back to Architecture Overview" link
- "Next: [Type System]" button

### Phase 3: CSS Styling

Add professional styling:

- Sidebar with active state
- Table of contents styling
- Next/Prev buttons
- Breadcrumb styling
