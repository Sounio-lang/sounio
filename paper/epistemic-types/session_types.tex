\section{Epistemic Session Types (H7)}
\label{sec:epistemic-sessions}

% H7.1: Knowledge<Session<P>>
\subsection{Motivation}
Scientific web data pipelines involve inherent epistemic uncertainty:
when we query NCBI for gene expression data, we receive a response
whose quality depends on sample size, measurement method, and data
provenance. Classical type systems model this as \texttt{HttpResponse},
losing all epistemic structure. Sounio models it as
\texttt{Knowledge<GeneExpression>} with a compile-time tracked
uncertainty bound $\varepsilon$.

\subsection{Session Type Grammar}
$$
\text{Protocol } P ::= \textbf{send}\ T; P \mid \textbf{recv}\ T; P \mid \textbf{close} \mid \alpha
$$
where $\alpha$ is a protocol variable (row-polymorphic, H6.2).

\textbf{Duality}:
$$
\overline{\textbf{send}\ T; P} = \textbf{recv}\ T; \overline{P}
\qquad
\overline{\textbf{recv}\ T; P} = \textbf{send}\ T; \overline{P}
\qquad
\overline{\textbf{close}} = \textbf{close}
$$

\subsection{Epistemic Session Types}
We extend session types with epistemic bounds:
$$
\text{Type } \tau ::= \ldots \mid \text{Knowledge}\langle\tau\rangle_\varepsilon \mid \text{chan}\ P
\mid \text{EpistSession}\langle P, \varepsilon \rangle
$$

\textbf{Rule E-Session-Recv}: When receiving on a channel whose protocol
carries epistemic metadata, the received value is wrapped in
\texttt{Knowledge<T>} with $\varepsilon = 1 - \text{trust}(\text{source})$.
$$
\frac{\Gamma \vdash c : \text{chan}\ \textbf{recv}\ T_\varepsilon; P
\qquad \Gamma, x : \text{Knowledge}\langle T \rangle_\varepsilon \vdash e : U}
{\Gamma \vdash c.\text{recv}(x \Rightarrow e) : U}\ [\text{E-Session-Recv}]
$$

\textbf{Rule E-Causal-Post}: An HTTP POST is a causal intervention:
$$
\frac{\Gamma \vdash c : \text{chan}\ \text{HttpExchange}
\qquad \text{do}(c \leftarrow \text{req}) \in \Sigma_\text{causal}}
{\Gamma \vdash c.\text{send}(\text{req}) : \text{CausalEffect}\langle\text{Request}, \text{ServerState}\rangle}\ [\text{E-Causal-Post}]
$$

\subsection{Zero-Cost Guarantee}
All epistemic session type annotations are erased at compile time.
The compiled code performs standard send/recv operations; uncertainty
bounds exist only in the type system. This is verified by inspecting
the machine code: epistemic session operations compile to the same
instruction sequence as untyped message passing.

\subsection{Scientific Web Pipeline Example}
The NCBI gene expression pipeline (\S\ref{sec:ncbi-example}) demonstrates
the full pipeline from typed query to epistemic result:
\begin{enumerate}
\item Query typed as \texttt{session NCBIQuery} with \texttt{send GeneQuery; recv Knowledge<GeneExpression>; close}
\item Response automatically wrapped in \texttt{Knowledge<GeneExpression>} with $\varepsilon = \text{expression\_uncertainty}(\text{result})$
\item Uncertainty propagates through downstream analysis via H6.3 aleatoric/epistemic split
\item Final clinical decision gated by \texttt{prove\_robust} + \texttt{validate\_manifest}
\end{enumerate}
